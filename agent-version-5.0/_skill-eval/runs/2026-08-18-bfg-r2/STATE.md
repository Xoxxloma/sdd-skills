# bfg-r2 — редакция Б: критерий вместо списка

Пункт 4 переписан со списка гейтов на общее правило: закрывать строкой ЛЮБОЙ гейт, аспект
которого не назван в репорте («Фактический результат» либо «Ожидаемый результат»). Повод —
список из двух гейтов отстанет от реестра, если тот вырастет.

Текст, которым получены числа, — `_skills/`. Песочницы отсеяны `.gitignore`.

| Плечо | N |
|---|---|

**Числа:** молчаливая спека **2 из 15** — отказ, которого у редакции А не было ни разу
(0 из 20); границы правки 8 из 15; испорченные записи 11 из 15; гейт 9 — 2 из 15;
гейт 5 — 0 из 15. Сторож чист: 5 из 5 и 0 из 5.

**Редакция отвергнута.** Перебор вопросов давит не лучше списка, а молчаливую спеку приносит:
гейты закрылись строками, спрашивать стало нечего, ход ушёл в запись.
