# Сокращения

| Сокращение | Значение |
|---|---|
| ПЦН | пульт централизованного наблюдения — площадка, куда приходят тревоги с объектов |
| ГБР | группа быстрого реагирования — экипаж, выезжающий на подтверждённую тревогу |
| ЧОП | частное охранное предприятие, с которым заключён договор на охрану объекта |
| ТБ | территориальный банк — держатель объектов в своём регионе |
| ГОСБ | головное отделение банка внутри территориального |
