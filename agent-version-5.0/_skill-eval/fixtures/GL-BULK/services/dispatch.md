# dispatch — backend

> Генерируется. Правки руками затираются.

## Назначение

Диспетчеризация выездов ГБР по объектам охраны.

## Что умеет для пользователя
| Возможность | Для кого |
|---|---|
| Назначить экипаж на инцидент | Оператор |

## Владеет данными

### `ServiceArea`
Зона обслуживания объектов охраны; единственный источник правды в системе.
- `id`: `string`
- `geometry`: `polygon`

### `Assignment`
Назначение экипажа на инцидент.
- `id`: `string`
- `state`: `pending` \| `accepted` \| `done` \| `cancelled`
— `cancelled` ставит только диспетчер; экипаж отменить не может

## Роли и доступ
| Роль | Что может |
|---|---|
| `dispatcher` | назначать и отменять выезды |
| `operator` | видеть назначения своего региона |
