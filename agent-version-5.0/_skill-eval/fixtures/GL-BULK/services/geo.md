# geo — backend

> Генерируется. Правки руками затираются.

## Назначение

Зоны покрытия объектов охраны и изохроны времени прибытия.

## Что умеет для пользователя
| Возможность | Для кого |
|---|---|
| Построить изохрону по времени прибытия | Аналитик безопасности |
| Посмотреть зону покрытия объекта на карте | Аналитик безопасности |

## Публичный контракт

### `GET /v1/isochrone`
Изохрона по точке и времени в пути.
- `minutes: int` — верхняя граница времени в пути

## Владеет данными

### `CoverageZone`
Зона покрытия объекта охраны; единственный источник правды в системе.
- `id`: `string`
- `status`: `active` \| `suspended`
— `suspended` ставит диспетчер вручную на время работ

### `PatrolRoute`

- `id`: `string`
- `zoneId`: `string`
