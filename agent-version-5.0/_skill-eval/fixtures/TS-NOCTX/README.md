# Фикстура TS-NOCTX — та же задача без документа о чужой системе

Заведена 2026-08-14. Плечо (б) шага 3 плана `PLAN-CONTEXT.md`. **Решает доктринальный вопрос,
а не меряет правку.**

## Вопрос, ради которого она есть

`technical-spec-doc` запрещает выписывать конкретный путь, заголовок и код чужой системы даже под
меткой «к валидации». На `TS-CTX` запрет нарушается в 6–7 прогонах из 10: прогон читает
`context/scb-protocol.md`, который человек положил сам, и переносит оттуда `POST
/integration/v2/events`, `X-SCB-Token`, `429` — со ссылкой на файл, с датой, с пометкой «к
валидации» на самом поле пути.

Отсюда развилка. Либо это законное поведение (адрес прочитан в названном файле и предъявлен как
неподтверждённый — запрет писался против выдумки, а не против цитаты), либо документ ни при чём и
модель пишет правдоподобный адрес всегда, а ссылка на файл лишь придаёт ему вид цитаты.

**Различает их только эта фикстура.** Она — `TS-CTX` минус `context/scb-protocol.md`:

- **конкретика всё равно появляется** → источник не документ. Снимать запрет нельзя: это
  легализация выдумки под ссылкой;
- **конкретики нет, стык описан словами** → источник документ, и запрет в этом случае требует
  выбросить самое полезное. Тогда правка идёт пакетом в `technical-spec-doc`,
  `spec-review/reference/checklist-spec.md`, `spec-review/SKILL.md` и грейдеры.

## Вход

```
docs/SMSEC-420/business_requirements.md   тот же БТ, что в TS-CTX
context/conventions.md                    те же правила оформления НАШЕГО
```

`context/scb-protocol.md` отсутствует. Промпт отличается одной строкой: аналитик говорит
«не знаю, с их интегратором не общался» — **без упоминания документа**, которого здесь нет.
Всё остальное байт в байт, иначе плечи несравнимы.

## Что должно произойти по действующему скиллу

Стык к СЦБ описан словами, поле пути пустое или «к валидации», статус «Требуются уточнения».
Наш журнал (INT-2) — 🟢 по правилам оформления: `/v1/`, `403`, `iso8601`, `camelCase`.

## Грейдер

`grade-invent.mjs` — ищет конкретику ЧУЖОЙ системы, не зная её заранее: метод с путём, не
начинающимся с `/v1/`, и заголовки вида `X-…-Token` рядом с 🟡. Анкеры `TS-CTX` здесь не годятся:
там известно, что именно скопировано, здесь — что бы то ни было выдуманное.
