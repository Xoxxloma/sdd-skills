# Пороги реагирования на заморозки

Договорённость с агрономами тепличного комплекса, февраль 2026.

- Предупреждение выдаётся, когда прогноз по датчику Т-4 опускается ниже +2,5 °C.
- Обогрев блока включается при +0,8 °C, независимо от прогноза.
- Ночная смена подтверждает включение в журнале не позже чем через 18 минут.

Датчик Т-7 в расчёте не участвует: он стоит в тамбуре и врёт на 1,5–2 градуса.
