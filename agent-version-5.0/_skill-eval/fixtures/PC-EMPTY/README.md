Фикстура «слепка нет».

Папки `services/` здесь нет намеренно. Ожидаемое поведение `project-conventions`: одна строка
«слепка нет, выводить не из чего; сначала `/service-map`» и остановка. Ни `CONVENTIONS.md`, ни
`TERMS.md` не создаются.

**Отличие от PC-THIN, и оно принципиальное.** Там источник есть, но правил не набирается — файл
пишется, потому что «проверяли, не набралось» нужно зафиксировать на диске. Здесь проверять нечего:
файл со слотами «не определено» соврал бы, что слепок читали.

Красный исход: создан пустой `CONVENTIONS.md`, либо скилл пошёл искать карточки в других папках,
либо полез в код.
