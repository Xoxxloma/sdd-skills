## Публичный контракт

### `GET /v1/isochrone`
Изохрона по точке и времени в пути.
- `minutes: int` — верхняя граница времени в пути
- ответ — GeoJSON-полигон; пустой полигон означает «точка вне обслуживаемой зоны»

## Владеет данными

### `CoverageZone`
Зона покрытия объекта охраны; единственный источник правды в системе.
- `id`: `string`
- `geometry`: `polygon`
- `status`: `active` \| `suspended`
— `geometry` хранится в проекции EPSG:4326
— `suspended` ставит диспетчер вручную на время работ

### `PatrolRoute`

- `id`: `string`
- `zoneId`: `string`
