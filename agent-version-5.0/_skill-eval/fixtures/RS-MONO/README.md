# Фикстура RS-MONO — монолит, который не берётся одним сканом

Первая фикстура набора, у которой есть **размер**. Всё, что было до неё, — от 1 до 21 файла
(`SM-E2E` — 21 файл, 53 КБ); дефект, ради которого заведён `repo-split`, живёт на трёх порядках выше
и на прежних фикстурах не воспроизводится вообще.

**Собирается скриптом, а не лежит файлами:** `./make.sh <куда>` (по умолчанию `./out`, он в
`.gitignore`). 568 заглушек в git стоят дороже, чем 60 строк генератора, а замер порога Шага 2 на
трёх файлах вырождается.

## Что внутри

`rentalcore` — прокат спецтехники, Nest + TypeORM. **Стек и домен выбраны не такими, как в примерах
скилла** (там Java-пакеты `v2/tasks`): проверяется правило, а не память о примере.

| Папка | Файлов | Класс | Зачем в фикстуре |
|---|---|---|---|
| `src/controllers/` | 12 | **ловушка** | REST-контракт лежит **наверху, вне доменных папок**. Домен, чьи эндпоинты остались здесь, получит пустой «Публичный контракт», если папку не приписать к куску. Шаг 4 обязан это назвать |
| `modules/orders` | 180 | домен | крупнее 200 в сумме со своими контроллерами — кандидат на деление внутри |
| `modules/fleet` | 90 | домен | |
| `modules/billing` | 60 | домен | |
| `modules/customers` | 55 | домен | |
| `modules/pricing` | 30 | домен | |
| `modules/reporting` | 25 | домен **без сущностей** | контракт есть, `@Entity` нет. Правило «есть что положить в карточку» обязано оставить его доменом; строгое «контракт И сущности» — выкинет |
| `modules/integrations` | 40 | инфра со своей поверхностью | `@EventPattern`, клиенты внешних систем |
| `modules/notifications` | 20 | инфра со своей поверхностью | |
| `modules/common` | 35 | **сквозное** | ни контракта, ни сущностей |
| `modules/exceptions` | 13 | **сквозное** | `@Catch`, маппинг ошибок — факты, за которыми `service-map` ходит из любого куска |
| `modules/config` | 8 | **сквозное** | |

Всего **568** исходников — за порогом «больше 400, резать обязательно».

Рядом со спек-репой лежит `geo-service` с `.git` и `go.mod`, **и он уже в манифесте**: нужен, чтобы
Шаг 1 не выродился в «кроме монолита ничего нет», а Шаг 6 имел непустой манифест, в конец которого
дописывают.

## Раскладка песочницы

```
sandbox/RS-NN/
  specs/services/manifest.yaml   ← рабочая директория прогона (копия out/specs/)
  rentalcore/                    ← монолит, соседом к specs/
  geo-service/                   ← обычный сосед, уже в манифесте
```

## Что на ней меряется

RS-1…RS-8 (`repo-split`) — см. `PROBES.md`, раздел «Пробы: `repo-split`».

**Чего она НЕ меряет:** качество карточек по кускам. Для этого нужен прогон `service-map` по
записанному манифесту, то есть фикстура `SM-PIECES` и живой пул.
