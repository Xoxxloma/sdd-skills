# Баг-репорт: выгрузка отчёта по покрытию

> **Статус готовности:** Требуются уточнения (3)
> **Задача:** ARS-411

## 1. Затронутый бизнес-процесс
Аналитик УОР выгружает отчёт по покрытию за период. Экран `/coverage`, кнопка выгрузки.

## 2. Шаги воспроизведения
Аналитик открывает отчёт, ставит период за прошлый месяц и жмёт выгрузку. Файл приходит, но часть строк в нём не та, что на экране. Иногда совпадает, иногда нет — зависит от того, менял ли он фильтр перед выгрузкой.

## 3. Фактический результат

## 4. Ожидаемый результат
Должно работать так: в выгруженном файле те же строки, что аналитик видит на экране, с тем же периодом и тем же фильтром.

## 5. Критичность и срочность починки
Высокая — отчёт уходит в управление, расхождение заметят там. Хотфикс.

## Открытые вопросы
- Уточнить у аналитика, какой именно фильтр расходится.
