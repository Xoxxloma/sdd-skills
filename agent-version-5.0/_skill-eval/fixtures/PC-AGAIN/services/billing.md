> Генерируется. Правки руками затираются.

## Назначение

Начисления и возвраты по договорам охраны.

| Возможность | Для кого |
|---|---|
| Выгрузить сверку начислений по ГОСБ за период | Бухгалтер |

## Стек
| Слой | Чем |
|---|---|
| Язык и фреймворк | Java, Spring Boot |

## Публичный контракт

### `GET /v1/payments`
Список начислений по договору постранично.
- `items: array` — элементы `Payment`
- `limit: int` — размер страницы
- `offset: int` — смещение страницы

### `POST /v1/payments/refund`
Возврат начисления. Идемпотентен по `paymentId`.
- ошибки: `409` — возврат уже проведён, повтор безопасен

## Владеет данными

### `Payment`
Начисление по договору охраны; единственный источник правды в системе.
- `chargedAt`: `iso8601`
- `id`: `string`
- `state`: `pending` \| `charged` \| `refunded`
