# incident-web — frontend

> Генерируется. Правки руками затираются.
> Заметки человека — в `services/manifest.yaml`, поле `notes`.
> Форма — `reference/card.template.md` скилла `service-map`. Соседние карточки формой не являются.

**Назначение.** Рабочее место диспетчера: список инцидентов, карточка инцидента, назначение ГБР.

## Что умеет для пользователя
| Возможность | Для кого |
|---|---|
| Отфильтровать инциденты по статусу и ЧОП | Диспетчер |
| Назначить ГБР на инцидент | Диспетчер |
| Посмотреть историю назначений | Диспетчер |

## Стек
| Слой | Чем |
|---|---|
| Язык и фреймворк | TypeScript, React, Vite |
| Состояние | zustand, react-query |

## Экраны
| Роут | Экран | Что делает пользователь |
|---|---|---|
| `/incidents` | Список инцидентов | фильтрует и открывает карточку |
| `/incidents/:id` | Карточка инцидента | смотрит детали, выбирает ЧОП, назначает ГБР |
| `/incidents/:id/history` | История назначений | смотрит, кого и когда назначали |

## Потребляемые API
| Сервис | Вызов | Зачем |
|---|---|---|
| `geo` | `GET /v1/chops` | выбор ЧОП на карточке инцидента |
| `auth` | `GET /v1/sessions/count` | плашка активных сессий в шапке |

## Состояние и данные
| Что хранится | Где | Зачем |
|---|---|---|
| выбранные фильтры инцидентов | store в памяти | переживает переход между экранами |
| справочник ЧОП | кэш запросов, TTL 5 мин | не дёргать справочник на каждом экране |

## Зависит от
| Сервис или система | Зачем |
|---|---|
| `auth` | авторизация пользователя |
| `geo` | справочник ЧОП |
