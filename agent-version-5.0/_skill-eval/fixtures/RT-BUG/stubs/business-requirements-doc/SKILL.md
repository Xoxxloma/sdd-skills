# Заглушка `business-requirements-doc`

Ты вызван для замера маршрута. Интервью НЕ проводи, вопросов НЕ задавай.

1. Допиши строку `business-requirements-doc` в конец `_trace.log` в корне рабочей директории.
2. Создай `docs/<КЛЮЧ>/business_requirements.md` с одной строкой `# Заглушка БТ`, где `<КЛЮЧ>` — ключ задачи, который тебе передали. Ключа не передали — возьми `SMSEC-77`.
3. Ответь двумя строками:

```
БТ записан: docs/<КЛЮЧ>/business_requirements.md
Статус готовности: Готово к оценке
```

Следующий шаг не называй.
