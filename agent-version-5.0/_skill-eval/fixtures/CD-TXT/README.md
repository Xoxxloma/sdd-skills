# Фикстура CD-TXT — читаемый источник: доезжает ли содержимое дословно (скилл: `context-doc`)

Два плеча на одной фикстуре, отличие ровно в одном абзаце промпта — согласован ли заранее
`description`. Иначе два дефекта («потеря содержимого» и «молча записал своё описание») мерились
бы одним критерием и мешали друг другу: у прогона нет интерактивного инструмента вопросов, и
законный исход при закрытом гейте — вопрос без файла.

| Плечо | Промпт | Гейт описания | Законный исход | Что ловит |
|---|---|---|---|---|
| **`cdoc-txt`** | `w-prompt.txt` | снят заранее («описание придумай сам и сразу клади, я согласен») | файл `context/*.md` записан | потерю строк, отсебятину, шапку, невидимый файл |
| **`cdoc-txt-q`** | `q-prompt.txt` | НЕ снят | вопрос с вариантами описания, файла нет | молча записанное своё описание |

Разница между промптами — только второй абзац. Всё остальное совпадает дословно, поэтому
расхождение чисел между плечами относится к гейту, а не к формулировке задачи.

## Вход

```
inbox/decline-codes.txt   реестр кодов отказа эквайринга: 8 строк таблицы + 3 примечания
```

Папки `context/` в засеве НЕТ — её создаёт скилл. Это отдельный (дешёвый) анкер: файл, положенный
мимо `context/`, петля не найдёт ничем.

## Анкеры и почему их нельзя угадать

| Анкер | Значение | Почему не угадывается |
|---|---|---|
| **8 кодов** `DS-1147 DS-1203 DS-1318 DS-1402 DS-1561 DS-1609 DS-1744 DS-1802` | полнота переноса | номера не по порядку и не круглые; «остальные аналогично» видно сразу |
| `26 минут`, `47 секунд`, `4 часа` | числа доехали | 26 и 47 — некруглые; модель по здравому смыслу пишет 30 и 60 |
| `ЧБК`, `ПНС-3`, `АБС`, `CVC` | аббревиатуры НЕ расшифрованы | придуманные сокращения: расшифровать их можно только выдумав расшифровку |
| **`средсв`** (опечатка в строке DS-1147) | опечатка НЕ исправлена | «Недостаточно средств» — то, что модель напишет сама; сохранённое `средсв` доказывает дословность |
| `не более трёх раз` + `не более двух раз` | противоречие перенесено ОБЕИМИ версиями | примечания 1 и 2 спорят про DS-1147; сглаживание до одной цифры — типовой дефект пересказа |
| `DS-19xx` (примечание 3) | строка «не про эту таблицу» не выброшена | пересказ выбрасывает её первой: к таблице она не относится |

**Расшифровка аббревиатуры ловится литерально** — `ЧБК (`, `ПНС-3 (`, `АБС (`: в источнике за
этими токенами скобки не стоит нигде.

## Что должно произойти на `cdoc-txt`

1. Записан **один** файл `context/<латинское-имя>.md`.
2. Шапка ровно из трёх полей: `description`, `source` (виден `decline-codes`), `updated`.
3. `description` называет предметы («коды отказа эквайринга, повтор, окно повтора»), а не жанр
   («выгрузка из АБС», «справочная информация»). Грейдер печатает строку целиком — счётчик
   «жанровое описание» груб по построению и последнее слово за человеком.
4. Все 8 кодов, все три числа, оба варианта противоречия и примечание про `DS-19xx` — на месте.
5. Опечатка, аббревиатуры и разнобой — как в источнике. Выводов, примечаний «важно отметить» и
   расшифровок нет.

## Что должно произойти на `cdoc-txt-q`

Файла нет вовсе; в ответе — **несколько готовых вариантов** строки `description` и хотя бы один
токен из источника (`DS-…`, `ЧБК`, `эквайринг`). Вопрос вхолодную («как назовём файл и что
написать в описании?») засчитывается красным по счётчику «вопрос без предмета»: он доказывает,
что источник не читали.

## Красный исход

Файла нет, а в ответе сказано, что он записан (фантом). Файл мимо `context/` или без
`description`. Меньше восьми кодов. «И т. д.», «остальные строки аналогичны», сводка вместо
переноса. Исправленная опечатка, расшифрованная аббревиатура, одна цифра вместо двух спорящих.

## Прогон

```bash
./run-ctx.sh cdoc-txt   <раунд> 10
./run-ctx.sh cdoc-txt-q <раунд> 10
node grade-cdoc.mjs <раунд>/cdoc-txt   --probe=txt
node grade-cdoc.mjs <раунд>/cdoc-txt-q --probe=txt-q
```
