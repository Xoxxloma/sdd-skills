# Баг-репорт: Вкладка расчёта ГБР не видна оперативному дежурному

> **Статус готовности:** Готово к оценке
> **Задача:** ARS-321

## 1. Затронутый бизнес-процесс
Оперативный дежурный открывает карточку инцидента, смотрит расчёт прибытия ближайших групп и с этой же вкладки переходит к назначению ГБР. Экран — карточка инцидента, вкладка «Расчёт ГБР».

## 2. Шаги воспроизведения
1. Войти пользователем с ролью `dispatcher` (оперативный дежурный)
2. Открыть карточку любого инцидента
3. Вкладки «Расчёт ГБР» в карточке нет

*Под ролью `analyst` та же вкладка на той же карточке видна и работает.*

## 3. Фактический результат
Вкладка «Расчёт ГБР» роли `dispatcher` не показывается вовсе. Дежурный не видит расчёт и не может перейти к назначению с этой вкладки — назначает через общий список групп. Заметили после релиза, в котором на карточку добавляли вкладку вложений.

## 4. Ожидаемый результат
- **FR-1:** Роль `dispatcher` видит вкладку «Расчёт ГБР» на карточке инцидента и переходит с неё к назначению — 🟢 записано в `docs/ARS-102/technical_specification.md`, §4.4 «Доступ по ролям в UI»

## 5. Критичность и срочность починки
Высокая. Дежурный — основной пользователь назначения, обходной путь длиннее и теряет расчёт прибытия. Хотфикс.
