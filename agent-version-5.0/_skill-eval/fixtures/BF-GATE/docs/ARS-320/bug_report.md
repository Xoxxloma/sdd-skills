# Баг-репорт: У таблицы инцидентов не виден горизонтальный скролл

> **Статус готовности:** Готово к оценке
> **Задача:** ARS-320

## 1. Затронутый бизнес-процесс
Аналитик безопасности разбирает список инцидентов и фильтрует его по статусу, типу и периоду. Экран `/incidents`.

## 2. Шаги воспроизведения
1. Открыть экран `/incidents`
2. Включить в таблице все колонки (кнопка «Колонки» → «Показать все»)
3. Таблица становится шире окна → полосы горизонтальной прокрутки под таблицей нет

*Мышь и трекпад прокручивают таблицу вбок нормально, не видно именно полосы.*

## 3. Фактический результат
Полоса горизонтальной прокрутки под таблицей не отображается, и по виду экрана непонятно, что справа есть ещё колонки. Данные в таблице верные, все колонки на месте и доезжают прокруткой. Заметили после обновления библиотеки таблиц.

## 4. Ожидаемый результат
- **FR-1:** Когда таблица шире окна, под ней видна полоса горизонтальной прокрутки — 🟡 со слов аналитика, документа нет

## 5. Критичность и срочность починки
Низкая. Работать можно, данные доступны прокруткой. Общий релиз, не хотфикс.
