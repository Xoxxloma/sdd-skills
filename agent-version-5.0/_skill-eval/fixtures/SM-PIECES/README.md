# Фикстура SM-PIECES — `service-map` по кускам разрезанной репы

Меряет **четыре правки 5.0 в `service-map`**, и все четыре существуют только потому, что появился
`repo-split`: до него `path` всегда указывал на корень репозитория.

Дерево на диске, обе роли живые. Материал маленький намеренно: здесь проверяется **поведение
ведущего на кусках**, а не полнота на масштабе (для неё есть `SM-BULK` и `SM-NEUTRAL`).

## Раскладка песочницы

```
sandbox/PC-NN/
  specs/services/manifest.yaml   ← рабочая директория (копия tree/)
  rentalcore/                    ← монолит; в манифесте — три его КУСКА, самого его там нет
  geo-service/                   ← настоящий новый сосед, в манифесте ЕГО НЕТ
```

## Три строки манифеста и что каждая ловит

| Строка | `path` | Что проверяет |
|---|---|---|
| `rental-orders` | **две папки через запятую** (`orders`, `pricing`) | одна строка = одна карточка, ключи собираются из обеих папок |
| `rental-fleet` | одна папка, запятой нет | **старая форма обязана остаться рабочей** — разбиение по запятой даёт один путь |
| `rental-common` | `common` | **ловушка:** ни контракта, ни сущностей. Карточки быть не должно |

Обе формы `path` лежат в одном манифесте намеренно: правило чтения одно на все случаи («разбей по
запятой»), и проба обязана покрывать обе ветки сразу, иначе регрессия старой формы не видна.

## Что в коде

Четыре ключа контракта и две сущности, разложенные так, чтобы граница «ключи из куска, факты из
корня» была наблюдаемой:

| Где | Что |
|---|---|
| `orders/orders.controller.ts` | `GET /api/orders`, `POST /api/orders`, `POST /api/orders/close` |
| `orders/order.entity.ts` | `Order`: `status` — три значения; `closedAt: null` **не только у черновиков** |
| `pricing/pricing.controller.ts` | `GET /api/pricing/quote` |
| `fleet/fleet.controller.ts` | `GET /api/fleet`, `POST /api/fleet/decommission` |
| `fleet/unit.entity.ts` | `Unit`: `state` — три значения |
| **`common/errors.ts`** | **коды `409`/`422`/`423` со смыслом — вне любого куска** |
| `common/dates.ts` | формат дат — тоже вне куска |

**Ролей в коде нет нигде** — это не пропуск материала, а условие пробы SM-68: «Роли и доступ» обязана
выйти пустой у **обоих** кусков, и ведущий обязан сказать об этом поперёк карточек.

## Пробы

SM-64…SM-68 — см. `PROBES.md`, раздел «Раунд „разрез монолита“».

Красные исходы, ради которых фикстура и собрана:

- карточка `rental-common` записана — пустая, но по форме безупречная;
- в карточке `rental-orders` нет `GET /api/pricing/quote` (второй путь строки потерян);
- блоки эндпоинтов без кодов ошибок — субагент не вышел в корень репы за фактом;
- в карточке появились ключи из `common` (`toWire`, `ERROR_HTTP_CODE`) — граница «факты, но не
  ключи» не удержана;
- ведущий на каждом прогоне спрашивает «рядом новая репа `rentalcore`, дописать?»;
- ведущий **не** назвал `geo-service` новым соседом — правило про префикс перестреляло.
