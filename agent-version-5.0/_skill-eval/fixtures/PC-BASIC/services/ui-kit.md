## Назначение

Общая библиотека элементов интерфейса для рабочих мест оператора и диспетчера.

## Публичный API

### `formatMoney(value, currency)`
Единое форматирование сумм.
- `currency` — код ISO-4217; неизвестный код не падает, а возвращает сумму без символа

### `formatStamp(value)`
Форматирование отметки времени для плашек.
- `value: unixtime` — секунды, не миллисекунды; миллисекунды дают дату 1970 года

### `statusBadge(code)`
Плашка статуса инцидента.
- `code`: `NEW` \| `IN_PROGRESS` \| `CLOSED` — значения приходят из внешнего справочника, не из наших сервисов
