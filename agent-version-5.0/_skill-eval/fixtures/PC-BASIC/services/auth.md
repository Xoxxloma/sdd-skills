# auth — backend

> Генерируется. Правки руками затираются.

## Назначение

Аутентификация сотрудников и учёт активных сессий в системе.

## Что умеет для пользователя
| Возможность | Для кого |
|---|---|
| Посмотреть число активных сессий | Аналитик безопасности |
| Отозвать сессию сотрудника | Аналитик безопасности |

## Стек
| Слой | Чем |
|---|---|
| Язык и фреймворк | Go, chi |
| Хранилище | PostgreSQL |

## Публичный контракт

### `GET /v1/sessions/count`
Счётчик активных сессий пользователя.
- `count: int` — только неистёкшие; отозванные вручную не считаются
- `updatedAt: iso8601|null` — `null` означает «источник недоступен», а не «не обновлялся»

### `POST /v1/sessions/revoke`
Отзыв сессии. Идемпотентен по `sessionId`.
- `sessionId: string` — обязателен
- ошибки: `409` — сессия уже отозвана, повтор безопасен

## Владеет данными

### `AuditEntry`
Запись о входе или отзыве сессии; хранится 180 дней.
- `actorId`: `string`
- `kind`: `login` \| `revoke`
- `createdAt`: `iso8601`

### `Session`
Активные сессии сотрудников; единственный источник правды в системе.
- `expiresAt`: `iso8601`
- `id`: `string`
- `status`: `active` \| `expired` \| `revoked`
- `userId`: `string`
— `expired` ставит фоновая задача, не пользователь
