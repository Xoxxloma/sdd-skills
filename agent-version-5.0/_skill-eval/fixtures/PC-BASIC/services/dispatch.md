# dispatch — backend

> Генерируется. Правки руками затираются.

## Назначение

Событийный сервис: принимает инциденты из шины и назначает на них экипажи.

## Что умеет для пользователя
| Возможность | Для кого |
|---|---|
| Получить назначенный экипаж по инциденту | Оператор |

## Стек
| Слой | Чем |
|---|---|
| Язык и фреймворк | Kotlin, Spring Boot |
| Хранилище | PostgreSQL |
| Шина | Kafka |

## События
| Направление | Топик | Когда |
|---|---|---|
| потребляет | `incident.created` | инцидент заведён оператором |
| публикует | `dispatch.assignment.created` | экипаж назначен на инцидент |

## Владеет данными

### `Assignment`
Назначение экипажа на инцидент; единственный источник правды в системе.
- `assignedAt`: `iso8601`
- `id`: `string`
- `squadId`: `string`
- `state`: `pending` \| `accepted` \| `done` \| `cancelled`
— `cancelled` ставит только диспетчер; экипаж отменить назначение не может
