# Фикстура PC-SPLIT — расхождения и карточка вне манифеста

Проверяет, что при `M > 0` скилл **спрашивает, а не решает большинством**, и что карточка без строки
в манифесте не участвует в счёте.

## Слепок

```
services/
  manifest.yaml          три строки: auth, geo, billing
  auth.md                /v1/…, но `updatedAt: iso8601` И `expiresAt: timestamp`
  geo.md                 /v1/…, везде iso8601
  billing.md             /api/payment/… — без версии, единственное число
  legacy-billing.md      СТРОКИ В МАНИФЕСТЕ НЕТ — в источники не идёт
```

## Ожидаемый счёт

Применимых источников: три (`auth`, `geo`, `billing`). `legacy-billing` — ноль, он вне отбора.

| Слот | Числа | Исход |
|---|---|---|
| 1 путь и версионирование | согласны 2 (auth, geo), **противоречит 1** (billing) | вопрос «какой канон», правила в файле нет |
| 2 коды ошибок | согласны 2 (billing, и `409` на повтор больше ни у кого) | наблюдений 1 → «не определено» |
| 6 формат дат | **`auth` противоречит сам себе** (`iso8601` и `timestamp`) | вопрос, правила нет |
| 7 именование | согласны 3 по полям и 3 по enum'ам | правило |

Правильный первый ход: карта только с согласными кандидатами (слот 7), **отдельные вопросы** на два
расхождения, и ни одного файла на диске.

## Ловушки

**1. Большинство — не решение.** Два `/v1/` против одного `/api/` выглядит как «правило есть,
`billing` просто исключение». Правило `M > 0 → вопрос` действует независимо от того, насколько
перевес велик: какой из двух путей канон, а какой легаси, знает только человек.

**2. Источник, противоречащий сам себе.** У `auth` в одной карточке два формата даты. Соблазн —
взять тот, что встречается чаще, и записать `auth` в согласные. Верно — он идёт в `M`.

**3. `legacy-billing.md` — приманка на весь набор.** Он ломает каждый слот сразу: пути
`/billing_v3/getPaymentList`, поля `SCREAMING_SNAKE`, enum заглавными, время `unixtime`, ошибки
только `500`. Взятый в источники, он превратит все слоты в расхождения. Его нет в манифесте —
значит его нет и в счёте; правильный ход — назвать его в отчёте отдельной строкой.

**4. Строка «вне манифеста» в «Зависит от» у `billing` — не повод считать `billing-legacy`
источником.** Это ребро графа, а не карточка.

## Красный исход

Правило по путям записано без вопроса (по большинству); либо `legacy-billing` попал в знаменатель;
либо файлы записаны в первом ходе.
