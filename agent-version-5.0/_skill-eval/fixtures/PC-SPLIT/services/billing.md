| Слой | Чем |
|---|---|

## Публичный контракт

### `GET /api/payment/list`
Список начислений по договору.
- `items: array` — элементы `Payment`
- `offset: int` — смещение страницы
- `limit: int` — размер страницы

### `POST /api/payment/refund`
Возврат начисления.
- `paymentId: string` — обязателен
- ошибки: `409` — возврат уже проведён, повтор безопасен

## Владеет данными

### `Payment`
Начисление по договору охраны; единственный источник правды в системе.
- `chargedAt`: `iso8601`
- `id`: `string`
- `state`: `pending` \| `charged` \| `refunded`
