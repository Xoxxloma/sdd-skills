# Баг-репорт: тултипы графиков и фон сводки в модальном окне расчёта ГБР не адаптированы под тёмную тему

> **Статус готовности:** Готово к оценке
> **Задача:** ASSVODKA-3006

## 1. Затронутый бизнес-процесс

Расчёт расстановки ГБР в модуле геоаналитики АС Сводка: пользователь открывает модальное окно с графиками расчёта покрытия и сводной информацией по расчёту (внизу окна). Экран `/calculate-coverage`, компонент расчёта покрытия ГБР (`coverageOptimizerStore`). Тёмная тема включается пользователем через переключатель темы (`themeStore`).

## 2. Шаги воспроизведения

1. Открыть экран «Расчет расстановки ГБР» (`/calculate-coverage`).
2. Запустить расчёт покрытия ГБР (добавить точки вручную или загрузить из Excel, нажать расчёт).
3. Открыть модальное окно с графиками расчёта.
4. Переключить тему интерфейса на тёмную.
5. Навести курсор на точку/сектор графика → наблюдается всплывающее окно (тултип) на графике.
6. Посмотреть на блок суммаризирующей информации по расчёту внизу модального окна.

Дополнительных действий симптом не требует — он наблюдается сразу после переключения темы при открытом модальном окне.

## 3. Фактический результат

В тёмной теме:
- Всплывающие окна (тултипы) на графиках имеют белый фон, а текст внутри них остаётся тёмным — текст сливается с белым фоном, содержимое тултипа нечитаемо.
- Фон блока суммаризирующей информации по расчёту (внизу модального окна) остаётся белым, а числа и заголовки показателей в этом блоке отображаются тёмным цветом — сливаются с фоном, значения не читаются.

Дефект наблюдается только в модальном окне расчёта ГБР; другие графики модуля карты (эпизоды расследований, дашборды и т. п.) не затронуты.

С какого релиза / с какой даты наблюдается — не зафиксировано.

## 4. Ожидаемый результат

- **FR-1:** При включённой тёмной теме цвета всех UI-элементов модального окна расчёта ГБР — тултипов графиков и блока суммаризирующей информации — берутся из темы фронтового модуля: фон тёмный, текст контрастный (светлый на тёмном фоне), числа и заголовки в сводке читаемы — 🟡 со слов аналитика, документа нет.

## 5. Критичность и срочность починки

Средняя: визуальный дефект, не блокирует работу с расчётом, но делает невозможным чтение тултипов графиков и значений сводки в тёмной теме — основной сценарий чтения результатов расчёта именно через эти элементы. Починка в общий релиз.
