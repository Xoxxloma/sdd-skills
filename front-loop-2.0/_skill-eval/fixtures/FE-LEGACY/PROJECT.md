## 8. Cross-Cutting Concerns
- Auth & session: `useSession()` из `entities/session`; refresh-токен в интерцепторе axios.
- Roles & permissions: `operator`, `admin` (гард `role === 'admin'` на `/admin/*`).
- What the roles mean: `operator` видит и фильтрует заказы и лимиты; `admin` плюс раздел
  управления пользователями в `/admin`. <!--i-->
- Тест-фикстура: `DEV_TOKEN` в `shared/api/client.ts` — намеренная фикстура для локальной
  разработки, не утечка. <!--i-->

- **Always:** запросы к API — только через `shared/api/client.ts`. <!--i-->
