# FE-DESIGN-B — state B: библиотека на голых дефолтах (нет проектной темы)

Ant Design подключён, но НЕТ проектной темы/токенов поверх (ConfigProvider без кастомного
theme) → **state B**. Проверка: state=B, источник = дефолты библиотеки; НЕ выдумывает
кастомные токены; если пользователь хочет свою тему — шлёт в generate-theme.

## Дерево
```
src/
  main.tsx                     # <ConfigProvider>  (без theme={...})
  App.tsx                      # использует antd Button, Table, Form напрямую
```

## package.json
```json
{ "dependencies": { "react": "18.3.0", "antd": "5.14.0" } }
```

## Ключевое
- Библиотека: Ant Design 5, используется на **дефолтной теме** — `ConfigProvider` без
  `theme={...}`, нет `theme.ts`, нет кастомных токенов.
- Компоненты antd напрямую, без проектных обёрток.
- init-файл `CLAUDE.md` в корне.

## Ответы пользователя (гейты пройдены)
- Состояние: верно, antd на дефолтах, своей темы нет.
- Аудитория/тон: внутренняя админка; тон — нейтральный.
