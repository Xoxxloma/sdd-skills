## 9. Conventions & Patterns

- Naming: PascalCase для компонентов, camelCase для хуков.
- **Canonical patterns**:
  - **HTTP-вызовы** — только через `shared/api/client.ts`; прямой `fetch()` запрещён.
  - **Компоненты** — читающие стор оборачиваются в `observer(...)`.
  - **Экспорт CSV** — `papaparse.unparse(rows, { quotes: true, delimiter: ";" })`;
    BOM `﻿` в начало файла, иначе Excel ломает кириллицу.
- **Anti-patterns to avoid**: импорт `features/` или `pages/` из `shared/`
  (нарушение границы слоёв).
