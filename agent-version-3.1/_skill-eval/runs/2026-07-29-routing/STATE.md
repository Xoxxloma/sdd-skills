## Что этот замер НЕ покрывает — и почему

**Измерена только холодная ветка.** Все корневые фикстуры не содержат `services/` по построению,
поэтому каждый прогон здесь шёл без выжимки. Это ровно то, что нужно для регресса — правки не
сломали работу без контекста, — но **сами маршрутные абзацы при этом не исполнялись ни разу**.

Тёплая ветка (контекст есть → выбрать по `description` → дочитать соседей) не измерима существующим
набором: подмешать `services/*.md` в `ARS-57` нельзя, на ней стоят TS-*, Q-*, WS-*, GUI-1/7. Нужна
отдельная широкая фикстура (`CTX-WIDE`, 12–15 сервисов) и проба на холодный вопрос (BR-3) — оба
не заведены.

То есть: **правки не сломали существующее, но их собственное поведение остаётся непроверенным.**
