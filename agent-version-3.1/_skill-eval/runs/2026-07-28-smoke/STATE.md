# Дымовой прогон после удаления git — 2026-07-28

Не замер, а проверка «ничего не развалилось» после двух правок: индексы → граф в карточке,
и полное удаление git.

## Что менялось

**Удалён `Bash` у `service-map`.** Держался на трёх read-only командах:

| Было | Стало |
|---|---|
| `ls -d ../*/.git` | `Glob ../*/.git` — наличие `.git` проверяется как файл |
| `git rev-parse HEAD` → `source_sha` | удалено |
| `git status --porcelain` → `dirty` | удалено |

Оба поля оказались хуже, чем ничего. `source_sha` брался с **локального клона** и уверенно
показывал «свежо» про сервис, который уже уехал в прод, — ложная точность вместо честного незнания.
`dirty` требовал от субагента отличать закоммиченные строки от локальных правок, чего по коду
сделать нельзя, — правило было неисполнимым, флаг декоративным.

Осталась `scanned` — дата. Решение «пора перечитать» перешло к человеку, где оно фактически и было:
автосверка по неподтянутому клону всё равно врала.

## Результат: 4 прогона, всё чисто

| Проверка | Итог |
|---|---|
| Фронтматтер — 4 поля, структура цела | 2/2 |
| Восемь секций в порядке шаблона | 2/2 |
| Следов `source_sha` / `dirty` нет | 4/4 |
| Влито + депрекейт §6.2 | 2/2 |
| **AR-5 — `scanned` не тронута** | 2/2 |
| Метка на месте, лишних файлов нет | 2/2 |
| Содержательное: `/v1/admin` невыводим, семантика `null`, секреты | 2/2 |

Фикстуры проверены статически до прогона: правка `sed`'ом по семи файлам не порвала ни YAML, ни
секции.

## Чего прогон НЕ доказал

**Шаг 1 с новым `Glob ../*/.git`.** В пробах листинг подаётся текстом — агент не обходит диск ни до
правки, ни после, для пробы замена `ls` на `Glob` вообще no-op. Проверится только на живом
ландшафте.

**SM-17 непроверяема пробой в принципе.** У пробного агента `Bash` есть независимо от фронтматтера
(тот же урок, что после инцидента с коммитами). Наблюдаемо лишь то, что за git он больше не тянется,
раз текст о нём не упоминает. В бою запрет держится отсутствием инструмента — надёжнее, чем текстом.

## Побочный итог удаления

Инцидент, когда два пробных агента сделали `git commit` в рабочем репозитории под именем
пользователя, теперь невозможен не по запрету, а по отсутствию инструмента. Заодно ушла
кроссплатформенность: `ls -d` уже спотыкался, под него был написан запасной путь.
