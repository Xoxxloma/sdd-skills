# shipping — backend

> Генерируется. Правки руками затираются.
> Заметки человека — в `services/manifest.yaml`, поле `notes`.
> Форма — `reference/card.template.md` скилла `service-map`. Соседние карточки формой не являются.

## Назначение

Ведёт отправления от создания до доставки: назначение машин, расчёт по тарифу, приёмка на складе.

## Что умеет для пользователя
| Возможность | Для кого |
|---|---|
| Создать отправление и отправить его в путь | Диспетчер |
| Выгрузить ТТН по отправлению | Диспетчер |
| Вести справочник перевозчиков и их парк | Менеджер перевозчиков |
| Посчитать стоимость по тарифу на дату отправки | Редактор тарифов |

## Стек
| Слой | Чем |
|---|---|
| Язык и фреймворк | Kotlin, Spring Boot |
| Хранилище | PostgreSQL |
| Шина | RabbitMQ |

## Публичный контракт

### `GET /api/shipments`
Список отправлений. Фильтры: `status`, `carrierId`, `period`.
- `total` не учитывает отменённые, даже если фильтр по статусу их включает

### `POST /api/shipments`
Создание отправления.
- лицензия перевозчика проверяется в `carrier-registry` до записи

### `GET /api/shipments/{id}`
Отправление целиком.
- `assignedVehicleId: string|null` — `null` означает «машина не назначена», а не «снята с рейса»

### `PATCH /api/shipments/{id}`
Частичное обновление.
- смена перевозчика после `dispatch` запрещена

### `POST /api/shipments/{id}/dispatch`
Отправка в путь.
- идемпотентен: повтор даёт `409` и события не публикует

### `POST /api/shipments/{id}/deliver`
Подтверждение доставки.

### `POST /api/shipments/{id}/cancel`
Отмена отправления.
- в пути разрешена; `422` приходит только на уже доставленный груз

### `GET /api/shipments/{id}/waybill`
ТТН в PDF.
- документ собирается заново на каждый запрос, номер остаётся прежним

### `GET /api/shipments/{id}/events`
История переходов статуса.

### `GET /api/shipments/export`
Выгрузка CSV.
- `period` обязателен, максимум 62 дня

### `GET /api/carriers`
Справочник перевозчиков.
- заблокированные из выдачи не исчезают, приходят с `blocked: true`

### `POST /api/carriers`
Создание перевозчика.
- ИНН уникален; повтор даёт `409`, а не второго перевозчика

### `GET /api/carriers/{id}`
Перевозчик целиком.

### `PATCH /api/carriers/{id}`
Частичное обновление перевозчика.

### `GET /api/tariffs`
Список тарифов с периодами действия.

### `POST /api/tariffs`
Новый тариф.
- публикует `tariff.changed`

### `PUT /api/tariffs/{id}`
Замена тарифа.
- перезаписывает тариф целиком; частичное обновление не поддерживается

### `POST /api/tariffs/calculate`
Расчёт стоимости.
- считает по тарифу, действовавшему на дату отправки, а не на дату запроса

### `GET /actuator/health`
Проверка живости.

### `GET /api/version`
Версия сборки.

## События
| Направление | Топик | Когда |
|---|---|---|
| публикует | `shipment.created` | отправление создано |
| публикует | `shipment.dispatched` | первый `dispatch`; повтор события не даёт |
| публикует | `shipment.delivered` | доставка подтверждена |
| публикует | `tariff.changed` | тариф создан или перезаписан |
| потребляет | `carrier.blocked` | перевозчик заблокирован |

## Владеет данными

### `Shipment`
Отправления; единственный источник правды.
- `status`: `new` \| `dispatched` \| `delivered` \| `cancelled` — `cancelled` запись не удаляет

### `Carrier`
Перевозчики.
- блокировка не удаляет строку: на неё ссылаются закрытые отправления

### `Vehicle`
Парк перевозчика.
- хранит и снятые с рейса: снятие пишет `releasedAt`, строка не удаляется

### `Tariff`
Тарифы с периодами действия.
- пересечение периодов запрещено уникальным индексом, а не проверкой в коде
