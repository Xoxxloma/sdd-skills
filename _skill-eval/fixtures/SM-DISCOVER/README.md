# Фикстура SM-DISCOVER — обнаружение соседних репозиториев (Шаг 1.1 / 2.1 `service-map`)

**Зачем заведена.** Все прочие SM-фикстуры приходят с готовым `services/manifest.yaml`, поэтому
Шаг 0 уводит прогон сразу на Шаг 2, и **Шаг 1.1 не исполняется ни разу**. Обнаружение соседей —
единственный вход во весь скилл — не было покрыто ничем, и дефект в нём выглядел как штатный исход:
на Шаге 1 прогон честно заканчивается словами «репозиториев рядом не нашёл», на Шаге 2.1 пустой
результат молча читается как «новых соседей нет».

Здесь манифеста нет намеренно: это **первый сбор**.

## Что в ней

```
tree/services/            ← пусто: манифеста нет, это первый сбор
neighbours/
  svc-alpha/   .git/ (папка) + go.mod + main.go              → backend, кандидат
  svc-beta/    .git/ (папка) + package.json + vite.config.ts  → frontend, кандидат
  svc-delta/   .git/ (папка) + pom.xml                        → backend, кандидат
  svc-gamma/   .git — ФАЙЛ (worktree) + package.json exports  → lib, кандидат
  not-a-repo/  package.json, .git нет                         → НЕ кандидат
  svc-alpha/vendor/inner/.git/ + go.mod                       → НЕ кандидат (вложенный)
```

## Раскладка песочницы

```
sandbox/DISC-NN/
  specs/services/          ← рабочая директория прогона (копия tree/)
  svc-alpha/ … not-a-repo/ ← копии neighbours/, на одном уровне со specs
```

## Что требуется

| Что | Ожидание | Почему именно так |
|---|---|---|
| названные кандидаты | ровно **4**: `svc-alpha`, `svc-beta`, `svc-gamma`, `svc-delta` | |
| `svc-gamma` в списке | **да** | у worktree `.git` — файл, и глоб по `**/.git/HEAD` его не видит. Ловится только вторым глобом, который прогоняется ВСЕГДА, а не «если первый пуст» |
| `not-a-repo` в списке | **нет** | папка рядом ≠ репозиторий |
| `inner` / `vendor` в списке | **нет** | совпадение глубже одного уровня — вложенный репозиторий внутри сервиса, а не сосед |
| абсолютный путь родительской папки | **назван в ответе** | единственное, по чему видно, где агент искал: пустой результат и неверный паттерн выглядят одинаково |
| типы | `svc-alpha`, `svc-delta` → `backend`; `svc-beta` → `frontend`; `svc-gamma` → `lib` | таблица маркеров Шага 1.2 |
| манифест | черновик со всеми четырьмя, `notes` не выведено ни у кого | |
| чужие папки | ни один файл в `neighbours/` не изменён | правило «только читаешь чужие репозитории» |

## Проба

**SM-53a** — обнаружение соседей. Красный исход, ради которого фикстура и заведена: прогон
заканчивается строкой «рядом со спек-репой репозиториев не нашёл — собирать нечего» при четырёх
лежащих рядом репозиториях.
