## 2. Взаимодействия (ядро)

### INT-0. Источник активности (фундамент #0) — 🟢 (наследуется детьми)
- **Граница/направление:** FE админки «Арсенал» → BE «Арсенал»
- **Триггер:** загрузка шапки, открытие модалки, смена периода, запрос выгрузки
- **Контракт (запрос):** параметр `period` — `hour` | `day` | `week`; для счётчика параметр не обязателен
- **Контракт (ответ):** `current` — int или null (текущее число активных; null = источник недоступен);
  `series` — массив точек `{ ts: string (ISO8601), value: int }`; пустой массив = данных за период нет;
  `status` — enum `ok` | `empty` | `source_down`
- **Пример ответа (успех):**
  ```json
  { "current": 42, "series": [{ "ts": "2026-07-22T10:00:00Z", "value": 40 }], "status": "ok" }
  ```
- **Ошибки/недоступность:** `status="source_down"` и `current=null` → источник недоступен; `status="empty"` и `series=[]` → данных за период нет
- **Авторизация:** только роль «Администратор»; оператору 403
- **Происхождение:** 🟢 новое (узел-фундамент #0)
- **Трассировка:** FR-1..FR-5 (часть «данные активности»)
