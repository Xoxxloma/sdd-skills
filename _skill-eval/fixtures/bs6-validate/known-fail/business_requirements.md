# Бизнес-требования: известный FAIL (§4.5 полевого прогона ASSVODKA-666, 2026-08-03)

Файл существует ТОЛЬКО для валидации грейдера. Это §4.5 реального прогона, который
схлопнул восьмифэровую задачу — то есть заведомый FAIL по BS-6.
Ожидаемый вывод грейдера: «не применимо» = ДА, обороты «сцепка» и «общий источник».

## 4. Функциональные требования

### 4.1. Описание функционала

FR-1 … FR-8 (здесь не воспроизводятся — валидируется только вырезка §4.5).

## 4.5. Разбиение на слайсы

1. **Назови числа.** В §4.1 — 8 функциональных требований (FR-1…FR-8). Все FR покрывают один связный кусок.
2. **Назови ценность каждого кандидата одной фразой.** Единственный кандидат — «модуль Сотрудники на карте целиком».
3. **Порог.** Обособленный деливербл — один; ≥2 обособленных деливерблов нет.
4. **Типовой исход.** Порог не сработал — это одна работа.
5. **Что НЕ является доказательством против разреза.** Не применяется (разрезать нечего).
6. **Схлопнуть обратно можно по одной причине — ни одна часть не даёт бизнесу ничего без остальных.**
   Здесь так и есть: импорт без отображения на карте бесполезен, карточка без точек бесполезна,
   фильтр без точек бесполезен — это единый потребительский сценарий.

**Вывод: не применимо — это один связный функционал, разрезать на самостоятельно поставляемые деливерблы нечего.**

## 5. Ограничения и атрибуты качества

### 5.1. Приоритет

Medium.
