# Этап 02 — признак занятости на плане этажа

## Что делает
Показывает на плане этажа (`/floorplan/:floor`) у каждой комнаты цветовой признак «свободна» или
«занята сейчас», а у занятой — время, до которого она занята.

## Вход (стык) — контракт из спеки, дословно
- **Граница/направление:** FE → BE
- **Триггер:** открытие плана этажа, далее опрос раз в минуту
- **Контракт (запрос):** `GET /v1/rooms/occupancy`, параметр `floor: int` обязателен
- **Контракт (ответ):** `asOf: iso8601` — момент, на который снята сводка;
  `rooms: массив`, элемент — `roomId: string`, `state: free|busy`,
  `busyUntil: iso8601|null` — `null` всегда при `state = free`, у занятой комнаты заполнено
- **Пример ответа (успех):**
  ```json
  {
    "asOf": "2026-08-05T12:03:00Z",
    "rooms": [
      { "roomId": "7-01", "state": "busy", "busyUntil": "2026-08-05T15:30:00Z" },
      { "roomId": "7-02", "state": "free", "busyUntil": null }
    ]
  }
  ```
- **Ошибки:** `400` — этаж не передан или не число; `503` — календарь недоступен
- **Авторизация:** любой аутентифицированный сотрудник, отдельной роли не требуется

## Выход (стык)
Своего выхода-стыка у этапа нет: он последний, наружу ничего не отдаёт.

## Проверка в одиночку
- Сводка пришла, у комнаты `state = busy` и `busyUntil = 15:30` → на плане цветовой признак
  «занята сейчас» и подпись «до 15:30».
- Сводка пришла, у комнаты `state = free` → признак «свободна», подписи времени нет.
- Первый запрос ещё не вернулся → состояние `loading`: комнаты серые, подписи нет.
- `asOf` старше пяти минут → состояние `stale`: признак приглушён, подпись «данные устарели».
- Ответ `503` → состояние `source_down`: признаков нет, подпись «занятость недоступна».
- Запрос сводки идёт дольше 3 секунд → переход в `source_down`.

## Из спеки — только относящееся к этому этапу
- **Трассировка:** FR-1 — признак «свободна»/«занята сейчас» у каждой комнаты; FR-2 — у занятой
  видно время освобождения.
- **Состояния:** `loading`, `ready`, `stale`, `source_down` — по таблице §4.3 спеки.
- **Доступ:** признак виден всем аутентифицированным сотрудникам, ролевого ветвления в UI нет.
- **НФТ:** скелетон плана показывается сразу, сводка догружается отдельно и не блокирует отрисовку
  комнат; таймаут запроса сводки — 3 секунды.

## Чего этот этап НЕ делает
Не собирает сводку и не ходит в календарь — это этап 01. Не заводит новых эндпоинтов и не меняет
контракт `GET /v1/rooms/occupancy`.
