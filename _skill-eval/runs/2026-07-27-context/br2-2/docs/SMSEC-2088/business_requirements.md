# Бизнес-требования: Выгрузка истории операций в PDF из личного кабинета клиента

> **Задача Jira/SberTrack:** SMSEC-2088
>
> **Статус готовности:** Готово к оценке
>
> **Открытые вопросы (требуют уточнения перед оценкой):**
> *(Открытых вопросов нет — все ключевые данные подтверждены, спецификация готова к оценке.)*

## 1. Введение и контекст

### 1.0. Тип изменения
Доработка существующего личного кабинета клиента — добавление возможности выгрузки истории операций в PDF.

### 1.1. Описание проблемы (Problem Statement)
Клиенты не могут получить историю операций документом, пригодным для передачи в бухгалтерию.

### 1.2. Конечные потребители (End Users)
Клиенты (физические лица) — пользователи личного кабинета.

### 1.3. Заказчик и стейкхолдеры (Stakeholder / Sponsor)
Заказчик: руководитель клиентского сервиса.
Эксперт для консультации по функционалу: тимлид личного кабинета.

## 2. Бизнес-требования (цели и ценность)

### 2.1. Бизнес-цель
Я как клиент должен иметь возможность выгружать историю своих операций в PDF за выбранный период, чтобы передавать её в бухгалтерию.

### 2.2. Ценность для бизнеса
Снижение числа обращений клиентов в поддержку за получением выписок/истории операций.

### 2.3. Бизнес-риски и меры по снижению (Mitigation)
| Риск | Вероятность / влияние | Меры по снижению |
|------|-----------------------|------------------|
| В PDF могут попасть операции другого клиента (утечка чужих данных) | Влияние высокое — нарушение конфиденциальности | Проверка прав доступа: PDF формируется только из операций авторизованного клиента, инициировавшего выгрузку |
| Влияние на другие процессы/системы-потребители | Не ожидается (по оценке заказчика) | Дополнительные меры не требуются |

## 3. Объём проекта (Scope)

### 3.1. Входит в проект (In-scope)
- Выгрузка истории операций клиента в PDF за выбранный период из личного кабинета.
- В выгрузку попадают только операции самого авторизованного клиента.
- Понятное сообщение клиенту, если за выбранный период операций нет.

### 3.2. Не входит в проект (Out-of-scope)
- Выгрузка истории операций в Excel.
- Массовая выгрузка по нескольким клиентам одновременно.

### 3.3. Архитектурные изменения и интеграции
Используется существующий в личном кабинете механизм генерации файлов/документов; новых внешних интеграций пользователь не подтвердил. Конкретный технический механизм и его реализация — предмет технической спецификации, не бизнес-требований (заказчик сознательно не фиксирует техническую реализацию на этом уровне).

## 4. Функциональные требования

### 4.1. Описание функционала / бизнес-процесса
- **FR-1.** Клиент открывает историю операций в личном кабинете.
- **FR-2.** Клиент выбирает период, за который нужна выгрузка.
- **FR-3.** Клиент нажимает «Выгрузить в PDF».
- **FR-4.** Система формирует PDF-файл, содержащий только операции этого клиента за выбранный период, и предоставляет его клиенту.
- **FR-5.** Если за выбранный период у клиента нет операций — система показывает понятное сообщение об отсутствии операций (вместо файла или технической ошибки).

### 4.2. Критерии приёмки (Acceptance Criteria)
- **[FR-4]** Дано: клиент выбрал период, за который у него есть операции. Когда: клиент нажимает «Выгрузить в PDF». Тогда: клиент получает PDF-файл, содержащий только его собственные операции за выбранный период.
- **[FR-5]** Дано: клиент выбрал период, за который у него нет операций. Когда: клиент нажимает «Выгрузить в PDF». Тогда: клиент видит понятное сообщение об отсутствии операций за этот период (не ошибку и не пустой файл).

## 5. Ограничения и атрибуты качества

### 5.1. Приоритет
High — приоритет подтверждён заказчиком.

### 5.2. Сроки и обоснование
До конца текущего квартала — приурочено к отчётному периоду, когда клиентам особенно нужна выписка для бухгалтерии.

### 5.3. Ролевая модель
| Роль | Права / доступные действия |
|------|----------------------------|
| Клиент | Видит и выгружает в PDF только свои операции за выбранный период |
| Оператор поддержки | Не выполняет выгрузку истории операций за клиента |

## 6. Приложения (опционально)
Не предоставлены (пожелания по UX, схема процесса, дополнительные файлы — не приложены).
