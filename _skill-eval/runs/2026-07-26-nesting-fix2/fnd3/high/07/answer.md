## Содержание спеки

### Ядро (§2 — Взаимодействия)

**INT-1. Получить текущее число активных пользователей** (🟢)
- GET `/api/activity/current` (концептуально)
- Ответ: `{ "count": <int|null>, "data_available": <bool>, "timestamp_utc": <ISO-8601> }`
- Авторизация: только роль «Администратор» → 403 при отказе
- Состояния UI: `value` (число), `zero` (валидный ноль из count=null), `error_source` (data_available=false), `error_forbidden` (403)

**INT-2. Получить агрегированную активность за период** (🟢)
- GET `/api/activity/aggregate?period={hour|day|week}&start_utc=...&end_utc=...`
- Ответ: `{ "data_points": [{ "timestamp_utc": <ISO>, "count": <int> }, ...], "data_available": <bool>, "has_data": <bool>, ... }`
- Авторизация: только роль «Администратор`
- Состояния UI: `value` (граф с точками при has_data=true), `empty` (при has_data=false), `error_source` (при data_available=false)
- Различие: `has_data=false` → «нет данных за период» (состояние `empty`); `data_available=false` → «источник недоступен» (состояние `error_source`)
