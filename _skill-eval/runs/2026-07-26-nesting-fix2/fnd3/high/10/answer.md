## Что спроектировано

**INT-0 — Текущее число активных пользователей** (🟢)
- Endpoint: `GET /api/admin/activity/current`
- Ответ: `{ count: number | null, available: boolean, timestamp: ISO8601 }`
- Маппинг состояний: value / zero / empty / error_source / error_forbidden
- Авторизация: Admin role только

**INT-1 — Агрегаты активности за период** (🟢)
- Endpoint: `GET /api/admin/activity/aggregates?period={hour|day|week}`
- Ответ: `{ period: string, available: boolean, data: array, timestamp: ISO8601 }`
- Маппинг состояний: value (график) / empty (нет данных) / error_source / error_forbidden
- Авторизация: Admin role только

Оба контракта различают:
- **data.available: true, count/data: значение** → валидные текущие данные
- **data.available: true, count/data: null/[]** → валидный ноль / нет данных за период
- **data.available: false** → источник недоступен, не отдаём устаревшее

| Порядок выката | фундамент выкатывается раньше потребителей; фиче-флагов нет |
| Трассировка | FR-1..FR-5 эпика в части данных активности |
