## Основное содержание

**Контракт INT-0 (фундамент):**
- Эндпоинт: `GET /api/arsenal/activity`
- Параметры: `period` (current / hour / day / week), `timestamp_from`/`timestamp_to` (опциональные)
- Ответ включает:
  - `current_active_users` — текущий счёт активных пользователей
  - `aggregated_data` — массив точек активности за период (timestamp + count)
  - `is_available` — флаг доступности источника (true/false)
  - `has_data_for_period` — отдельная семантика для "нет данных за период" (не смешивать с ошибкой)
  - `updated_at` — время последнего обновления (при доступности)

**Ключевые решения (подтверждены аналитиком):**
- BE-only узел (фронты наследуют контракт без изменений)
- Arsenal Backend самостоятельно собирает данные активности (внешних сервисов не привлекаем)
- Проверка роли Administrator на бэке
- Синхронный запрос, кэш 30 сек на бэке, таймаут 5 сек
- Фундамент выкатывается первым, раньше потребителей
- Агрегаты считаются на лету, новых таблиц нет

**Состояния UI:** loading, value, zero (валидный 0), empty (нет данных за период), error_source (недоступность), error_forbidden (403)

**Трассировка:** FR-1 (текущий счёт) → FR-2 (обновление) → FR-3/FR-4 (данные график) → FR-5 (экспорт)
