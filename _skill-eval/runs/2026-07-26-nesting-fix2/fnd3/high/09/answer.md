# Техническая спецификация узла-фундамента #0 — готово

**Файл:** `docs/ARS-100/_foundation/technical_specification.md`

**Статус готовности:** Готово к разработке

**Что доставлено:**

Техническая спецификация узла-фундамента #0 для эпика ARS-100 (Панель активности пользователей в админке «Арсенал»). Спецификация описывает единственное новое взаимодействие INT-0: контракт для получения данных активности пользователей (текущее число активных + агрегаты за период).

**Ключевые решения:**

1. **Контракт INT-0** — GET `/api/v1/admin/activity` с параметром `period` (current/hour/day/week):
   - Возвращает текущее число активных пользователей и агрегаты за выбранный период
   - Три явных состояния доступности: `available`, `unavailable` (источник недоступен), `no_data` (нет данных за период)
   - Примеры JSON покрывают все три случая и оба режима запроса (текущий момент и исторические данные)

2. **Авторизация** — только роль Admin, проверка на бэке Arsenal

3. **Производительность** — синхронный запрос, кэш 30 сек на бэке, таймаут 5 сек

4. **Данные** — агрегаты считаются на лету, новых таблиц нет

5. **Порядок выката** — фундамент первым, дочерние узлы потом

Спецификация полностью соответствует ответам аналитика на 10 технических гейтов; открытых вопросов нет. Контракт готов к наследованию дочерними узлами (FR-1 шапка, FR-3..FR-5 модалка).
