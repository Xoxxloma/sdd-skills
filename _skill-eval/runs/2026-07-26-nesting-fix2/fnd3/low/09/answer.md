## Что спроектировано

### INT-0: Запрос текущей активности и агрегатов за период (🟢 новое)

**Контракт BE → FE:**
- Эндпоинт: `GET /api/admin/activity-summary` с параметрами периода и детализации.
- **Ответ:**
  - `current_active_count` (int | null): текущее число активных пользователей.
  - `period_total` (int | null): уникальные за период.
  - `period_has_data` (bool): есть ли данные за период.
  - `aggregates` (array | null): таймсерия (по часам/дням/неделям в зависимости от `granularity`).
  - `data_source_available` (bool): флаг доступности источника.
  - `cache_timestamp` (ISO 8601): момент кэширования.

**Семантика null:**
- `null` в полях → источник недоступен; фронт показывает «—» / пустой график.
- `aggregates: []` при `data_source_available: true` → за период нет данных (но источник работает).

**Авторизация:**
- 🟡 Проверяется на бэке: только роль «Администратор» → HTTP 200.
- Иные роли → HTTP 403.

**Производительность:**
- 🟡 Синхронно; кэш 30 сек на бэке; таймаут источника 5 сек.
- Нет новых таблиц; агрегаты вычисляются на лету.

**Релиз:**
- 🟡 Фундамент выкатывается первым, до дочерних фронтов.
- Нет фиче-флагов; атомарный релиз.

## Ошибки и состояния (каталог)

| Код | Сценарий | UI-состояние |
|-----|----------|--------------|
| 200 + `data_source_available: true` | Данные доступны | `value` / `zero` / `empty` |
| 200 + `data_source_available: false` | Источник недоступен | `error_unavailable` («—» в UI) |
| 403 | Не администратор | `error_forbidden` («нет доступа») |
| 408 | Таймаут источника (5s) | `error_source` (retry) |
| 500 | Внутренняя ошибка | `error_source` (retry) |
