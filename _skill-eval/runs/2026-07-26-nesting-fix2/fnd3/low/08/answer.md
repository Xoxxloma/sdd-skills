## Что спроектировано

### Интеракция INT-0: Контракт данных активности (🟢 новое)
- **Endpoint:** `GET /api/arsenal/admin/activity`
- **Параметры:** `period` (current|hour|day|week), `timezone` (опционален)
- **Ответ:** текущее число активных + агрегаты за период (массив точек с timestamp и count)
- **Кэш:** 30 секунд на бэке Arsenal
- **Таймаут:** 5 секунд на источник активности
- **Авторизация:** только Administrator; 403 если не авторизирован

### Ключевые решения (все подтверждены аналитиком)
1. **BE-only:** бэк Arsenal отдаёт контракт; фронты потребляют его неизменно
2. **Существующее хранилище:** новых таблиц не заводим; агрегаты считаются на лету
3. **Ошибки:** при недоступности источника отдаём `status: "unavailable"` с null-полями, **не** устаревшее значение
4. **Разделение понятий:** в ответе различаем:
   - `has_data: false` (валидные данные, но активности за период не было) → фронт показывает «—»
   - `status: "unavailable"` (источник недоступен) → фронт показывает ошибку + retry
   - `current_count: 0` (сейчас 0 активных) → отличаем от `null` (данные недоступны)
5. **Без фиче-флагов:** выкат атомарный; фундамент первым, затем потребители
6. **Выкат:** фундамент выкатывается раньше всех потребителей (FR-1..FR-5)

### JSON-примеры в спеке
- ✅ Успех, current: `{"status": "available", "current_count": 42, "period_data": null}`
- ✅ Успех, неделя: массив из 7 точек с timestamp и count за каждый день
- ✅ Успех, нет данных: `has_data: false`, но points выполнены (count везде 0)
- ✅ Ошибка недоступности: `{"status": "unavailable", "current_count": null, "period_data": null}`

### Маппинг на UI-состояния
| Ответ сервера | FE-состояние | Что видит пользователь |
|---|---|---|
| 2xx, current_count = 42 | `value` | «42» |
| 2xx, current_count = 0 | `zero` | «0» |
| 2xx, has_data = false | `empty` | «—» / «нет данных за период» |
| status = "unavailable" / 5xx / 504 | `error_source` | «Данные недоступны. Повторить?» |
| 403 | `error_forbidden` | «Нет доступа» |

### Авторизация
- ✅ Проверка на бэке Arsenal: только Administrator может запросить INT-0
- ✅ Остальные получают 403 Forbidden
- ✅ Фронт может полагаться на 403 или заранее скрывать виджеты для других ролей

### Трассировка к бизнес-требованиям
- **FR-1** (счётчик текущего числа) → INT-0 с period=current
- **FR-2** (обновление без перезагрузки) → polling INT-0 ~30s с обновлением счётчика
- **FR-3** (открытие модали графика) → INT-0 с period=day
- **FR-4** (смена периода) → новый INT-0 с выбранным period
- **FR-5** (выгрузка сводки) → period_data.points из INT-0
