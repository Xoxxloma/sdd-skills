### BS2-07
## 4.5. Разбиение на слайсы

Не применимо: счётчик в шапке, график активности и выгрузка сводки — это единый деливербл. Каждый элемент зависит от одного источника данных (активность пользователей); счётчик без графика не показывает динамику (препятствует планированию), график без счётчика в шапке не даёт быстрой оценки текущего состояния (препятствует операционной работе), выгрузка без графика оставляет администратора без инструмента выбрать период. Ни один из элементов не представляет независимой ценности для бизнеса без остальных двух.

## 4.5. Разбиение на слайсы

Не применимо: ни одна часть не даёт бизнесу полноценной ценности без остальных. Загрузка данных бесполезна без визуализации на схеме; карточка прибора открывается только со схемы; поиск ведёт на ту же схему. Все компоненты — части одного потока, кандидаты на один выпуск.

### BS6-20
## 4.5. Разбиение на слайсы

Не применимо: все компоненты функционала (загрузка файла, подсвечивание по состояниям, фильтрация, карточка прибора, поиск) работают с одним источником данных и зависят друг от друга. Никакая часть не даёт бизнесу самостоятельную ценность без остальных: загрузка данных без их визуализации на схеме не помогает мастеру; визуализация без загрузки невозможна; карточка и поиск служат средствами для быстрого доступа к информации в рамках единого интерфейса. Это один деливербл.
