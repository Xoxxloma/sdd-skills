===== §4.5 каждого прогона (для качественных критериев) =====

### run-02
## 4.5. Разбиение на слайсы

Не применимо: каждый элемент функционала (загрузка, визуализация, фильтрация, карточка, поиск) необходим для полноценного использования. Загрузка файла без отображения на схеме бесполезна, отображение без фильтров затрудняет работу мастера, карточка недоступна без визуализации. Все пять требований образуют единый слайс, выпускаемый одной работой.

### run-05
## 4.5. Разбиение на слайсы

Не применимо: ни один из компонентов функционала не даёт бизнесу пользы отдельно. Загрузка данных требуется, чтобы было что подсвечивать; подсветка — это способ показать состояния; карточка открывается только со схемы; поиск ведёт на ту же схему. Все требования — звенья одного потока; выпустить их по частям невозможно без потери ценности.

### run-09
## 4.5. Разбиение на слайсы

Не применимо: все перечисленные функции работают с единой схемой цеха, обращаются к одному набору данных и дополняют друг друга. Ни одна часть отдельно не даёт бизнесу ценности без остальных: карточка прибора имеет смысл только если прибор виден на схеме, поиск ведёт именно на эту схему, фильтрация состояний работает с её же данными. Разрез не требуется.
