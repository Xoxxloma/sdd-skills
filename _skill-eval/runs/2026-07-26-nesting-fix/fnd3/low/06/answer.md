# Результат: Техническая спецификация узла-фундамента #0

## Итог работы

Спецификация узла-фундамента #0 (контракт данных активности пользователей для панели активности в админке «Арсенал») успешно разработана и записана.

## Файл

**Путь:** `docs/ARS-100/_foundation/technical_specification.md`

## Основное содержание

Спека определяет один основной контракт INT-0 — два эндпоинта для получения данных активности:

1. **GET /api/arsenal/activity/current** — текущее число активных пользователей
   - Возвращает: `active_users` (int | null), `is_available` (bool), `timestamp` (ISO8601)
   - Различает: доступность источника vs ноль активных

2. **GET /api/arsenal/activity/history?period=hour|day|week** — активность за период
   - Возвращает: временной ряд агрегатов `[{timestamp, active_users}, ...]`
   - Различает: доступность источника vs данных за период нет (но источник исправен)

Оба эндпоинта:
- **Авторизация:** только роль Администратор (403 иначе)
- **Надёжность:** при недоступности источника возвращаем `is_available=false`, не устаревшие данные
- **Производительность:** синхронно, кэш 30 сек на бэке Арсенала, таймаут запроса 5 сек
- **Хранение:** агрегаты считаем на лету, нет новых таблиц
