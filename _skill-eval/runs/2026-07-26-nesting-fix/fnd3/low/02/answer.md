## Спроектировано

**Два взаимодействия (контракта) для детских фронтов:**

### INT-1. Получить текущее число активных пользователей — 🟢

- Эндпоинт: GET `/api/arsenal/activity/current`
- Ответ: { count: int|null, isUnavailable: bool, timestamp: ISO8601 }
- Авторизация: Administrator role на Arsenal backend
- Кэш: 30 сек (на стороне бэка)
- Таймаут: 5 сек

### INT-2. Получить агрегированную активность за период — 🟢

- Эндпоинт: GET `/api/arsenal/activity/aggregates?period={hour|day|week}`
- Ответ: { period, counts: [ts, count][], isUnavailable, noData, timestamp }
- Авторизация: Administrator role
- Кэш: 30 сек
- Таймаут: 5 сек

**Особенности:**
- На недоступность источника возвращается флаг `isUnavailable = true`, не устаревшие данные
- Отдельно различаем "источник недоступен" (isUnavailable) vs "нет данных за период" (noData)
- Полный каталог ошибок с映射到 UI-состояниям (value, zero, empty, error_source, error_forbidden)
- Трассировка: FR-1..FR-5 в части передачи данных активности
