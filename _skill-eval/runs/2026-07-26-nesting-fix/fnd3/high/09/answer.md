# Техническая спецификация: узел-фундамент #0

## Статус

**Готово к разработке** — все 10 технических гейтов закрыты, открытых вопросов нет.

## Что сделано

На основе ответов аналитика (turn-1) на все технические гейты спроектирован контракт узла-фундамента #0 — общая граница между Arsenal backend и дочерними фронтами, обслуживающая FR-1..FR-5 эпика.

### Реестр тех-гейтов:

1. ✅ **Тип и стороны** — BE-only, узел отдаёт контракт данных активности; потребители — фронты детей (ARS-101, 102, 103…)
2. ✅ **Инвентарь взаимодействий** — одно новое взаимодействие: INT-0 (контракт данных активности)
3. ✅ **Владение и допущения** — подтверждено аналитиком: данные активности собирает сам Arsenal backend
4. ✅ **Контракт каждого взаимодействия** — спроектирован INT-0 с реальными JSON-примерами (успех, пусто, недоступность)
5. ✅ **Ошибки и состояния** — при недоступности источника отдаём флаг `unavailable: true`; отдельно различаем «нет данных за период» (пустой массив)
6. ✅ **Авторизация** — только роль «Администратор», проверка на бэке Arsenal
7. ✅ **Данные и хранение** — агрегаты считаем на лету, новых таблиц не заводим
8. ✅ **Синхронность/производительность** — синхронно, кэш 30s на Arsenal backend, таймаут 5s
9. ✅ **Порядок выката** — фундамент выкатывается первым; фиче-флагов нет
10. ✅ **Трассировка приёмки** — все FR-1..FR-5 трассируются к INT-0
11. ✅ **Номер задачи** — ARS-100 / узел-фундамент #0 (ключ эпика, собственной задачи нет)

## Контракт INT-0

**GET /api/activity/users?period=<period>** (концептуально, стеко-агностично)

### Параметр:
- `period`: `hour` | `day` | `week`

### Ответ (успех):
```json
{
  "current": 42,
  "data": [
    { "timestamp": 1690000000000, "active_count": 38 },
    { "timestamp": 1690003600000, "active_count": 41 }
  ],
  "unavailable": false
}
```

### Ответ (нет данных за период, но источник доступен):
```json
{
  "current": 5,
  "data": [],
  "unavailable": false
}
```

### Ответ (источник недоступен):
```json
{
  "unavailable": true
}
```

### Ошибки:
- **400** — неподдерживаемое значение period
- **403** — роль не Администратор
- **500** — ошибка на бэке
- **504** — таймаут 5s при запросе к источнику

### Авторизация:
- Только роль **Администратор**
- Проверка на бэке Arsenal перед выдачей ответа
- Другие роли → 403 Forbidden
