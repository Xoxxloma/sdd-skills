## Ключевые решения спеки

### Контракт INT-0 (фундамент, наследуется детьми)

Узел #0 предоставляет единый BE-контракт `GET /api/arsenal/activity?period={hour|day|week}`, отдающий:

- **current_active_users** — текущий счёт активных пользователей (число | null)
- **availability** — флаг доступности источника (`"available"` | `"unavailable"`)
- **aggregates** — массив объектов временных интервалов с `timestamp` и `active_users_count` за выбранный период
- **aggregates_empty** — булево, различает «период пуст» от «источник недоступен»

**Пример успешного ответа:**
```json
{
  "current_active_users": 42,
  "availability": "available",
  "aggregates": [
    { "timestamp": "2026-07-26T00:00:00Z", "active_users_count": 35 },
    { "timestamp": "2026-07-26T01:00:00Z", "active_users_count": 42 }
  ],
  "aggregates_empty": false
}
```

**Пример при недоступности:**
```json
{
  "current_active_users": null,
  "availability": "unavailable",
  "aggregates": [],
  "aggregates_empty": false
}
```

### Авторизация

- Доступ только для роли **Administrator** (проверяется на Arsenal Backend при каждом запросе).
- Запросы с другой ролью → 403 Forbidden.
- Запросы без авторизации → 401 Unauthorized.

### Надёжность и деградация

- При недоступности источника активности фронт получает `availability: "unavailable"` в валидном 200-ответе (не 5xx), что позволяет явно показать «—» / пустой график вместо стартого значения.
- Три различимых состояния: успех с данными, успех но период пуст, недоступность источника.

### Производительность

- **Синхронно**, без очередей.
- **Кэш 30 секунд** на стороне Arsenal Backend.
- **Таймаут 5 секунд** при обращении к источнику активности.

### Развёртывание

- Узел #0 выкатывается **первым**, раньше потребляющих фронтенд-детей эпика.
- **Без фиче-флагов** — контракт доступен сразу после выката.
- Новых таблиц не заводим, агрегаты вычисляются на лету.

## Трассировка к бизнес-требованиям

Контракт INT-0 обслуживает все пять FR эпика:

| FR | Описание | Что получает от INT-0 |
|----|----------|----------------------|
| FR-1 | Счётчик в шапке | `current_active_users` при загрузке |
| FR-2 | Автообновление счётчика без перезагрузки | `current_active_users` каждые 30с кэша |
| FR-3 | Открытие модалки с графиком | `aggregates` за период по умолчанию |
| FR-4 | Переключение периода | новый запрос INT-0 с измененным `period` |
| FR-5 | Выгрузка сводки | `aggregates` из INT-0 формируют файл |
