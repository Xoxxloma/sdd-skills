## Краткое резюме

Фундамент #0 (BE-only, бэк Арсенала) отдаёт единый контракт INT-0 данных активности, который наследуют все три дочерних узла (счётчик в шапке, модальный график, выгрузка сводки — FR-1 через FR-5):

### Контракт INT-0: Получение данных активности

**Две ветки запроса:**
1. **`type=current`** — текущее число активных пользователей
   - Ответ: `{ "count": <int|null>, "source_available": <bool>, "data_exists": <bool> }`
2. **`type=aggregate`** — агрегаты за выбранный период (час/день/неделя)
   - Ответ: `{ "points": [...], "source_available": <bool>, "data_exists": <bool>, "aggregate_type": "avg|max|..." }`

**Ключевые семантики:**
- `source_available=true` → источник активности доступен и данные актуальны
- `source_available=false` → источник был недоступен; показать обозначение ошибки (фронт переходит в `error_source`)
- `data_exists=false` → за период нет данных вообще (отличие от нулей); фронт показывает «—» (состояние `empty`)
- `data_exists=true, count=0` → валидный ноль; фронт показывает «0» (состояние `zero`, не пусто)

**Авторизация:** только роль Администратор; 403 для остальных.

**Состояния фронта (§4.3):**
- `loading` — идёт загрузка
- `value` — есть данные, значение > 0
- `zero` — есть данные, значение = 0 (показать «0»)
- `empty` → нет данных за период (показать «—»)
- `error_source` → источник недоступен или таймаут (показать ошибку + retry)
- `error_forbidden` → 403 (показать «нет доступа»)

## Технические решения (подтверждено аналитиком)

1. **Тип:** BE-only, узел отдаёт контракт данных; потребители — фронты детей
2. **Владение:** данные активности собирает бэк Арсенала сам; внешних сервисов не привлекаем
3. **Ошибки:** при недоступности источника отдаём флаг, не устаревшее значение; различаем «нет данных за период»
4. **Авторизация:** только Администратор, проверка на бэке Арсенала
5. **Хранение:** агрегаты считаются на лету; новых таблиц не заводим
6. **Производительность:** синхронно, кэш 30 сек на Арсенале, таймаут 5 сек
7. **Релиз:** фундамент выкатывается раньше потребителей; фиче-флагов нет
