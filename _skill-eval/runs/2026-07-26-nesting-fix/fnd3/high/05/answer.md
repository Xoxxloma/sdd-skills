# Техническая спецификация узла-фундамента #0

Спеку узла-фундамента #0 для эпика ARS-100 завершил.

## Результат

**Файл:** `_foundation/technical_specification.md` (рядом с эпик-БТ)

**Статус:** Готово к разработке

**Что спроектировано:**

Разработан единый контракт данных активности (**INT-0**), который все детские фронты эпика ARS-100 будут наследовать и использовать для FR-1..FR-5:

- **INT-0 (GET /arsenal/activity):** эндпоинт Arsenal бэка, возвращающий текущее число активных пользователей и (по запросу) агрегированные данные активности за выбранный период (час/день/неделя).

**Ключевые решения (подтверждены аналитиком):**
- BE-only: контракт реализует только Arsenal бэк, потребители — детские фронты.
- Arsenal собирает данные сам; новых таблиц нет, агрегаты на лету.
- Доступ только роли Администратор (проверка на бэке).
- Синхронный запрос, кэш 30 сек на бэке, таймаут 5 сек.
- При недоступности источника отдаём флаг `unavailable`, не кэш; отдельно различаем `no_data_for_period`.
- Фундамент выкатывается первым, без фиче-флагов.
- Реальные JSON-примеры ответов (успех, недоступность, нет данных) включены в спеку.

**Трассировка:** INT-0 обслуживает FR-1, FR-2, FR-3, FR-4, FR-5 эпика.

Спека готова для двух сторон разработки: Arsenal бэк реализует INT-0 (логика вычисления, кэш, авторизация), детские фронты опираются на этот контракт для своих компонентов (счётчик, модаль, выгрузка).
