# Техническая спецификация: Узел-фундамент #0 (Данные активности)

## Завершение второго хода

Я прочитал эпик-БТ (ARS-100) и все гейты, которые аналитик уже подтвердил в предыдущем ходу:

✅ **Все технические решения приняты:**
1. Тип и стороны — BE-only (Arsenal backend)
2. Владение — Arsenal собирает данные сам, нет чужих сервисов
3. Ошибки/недоступность — флаг `is_available` вместо стейла; отдельный флаг `is_empty`
4. Авторизация — только роль Administrator на бэке Arsenal
5. Данные — агрегаты считаются на лету, новых таблиц нет
6. Sync/кэш — 30 сек кэш на бэке, таймаут 5 сек, синхронно
7. Фиче-флаги — нет, выкатываем атомарно
8. Порядок выката — фундамент раньше потребителей
9. Трассировка — к FR-1..FR-5 эпика

## Выведена спецификация

Спецификация узла-фундамента #0 написана в файл:

**`docs/ARS-100/_foundation/technical_specification.md`**

### Ключевые компоненты спеки:

**INT-0: Запрос данных активности** (🟢 новое)
- Два эндпоинта: `/current` (текущее число) и `/range` (агрегаты за период).
- JSON-примеры для всех случаев: успех, источник недоступен, нет данных за период.
- Контракт различает три состояния для фронта:
  - `is_available=true` + `count > 0` → `value` (показать число)
  - `is_available=true` + `count == 0` → `zero` (показать буквально «0»)
  - `is_available=false` → `error_source` (показать ошибку и retry)
  - `is_empty=true` (при range) → `empty` (показать пусто/«—»)
- Авторизация: только Administrator (403 при отсутствии прав).
- Кэш: 30 секунд на бэке для `/current`, таймаут 5 сек.
- Ошибки: 400, 401, 403, 408, 500 с JSON телами.

**Backend ответственность:**
- Реализует оба эндпоинта INT-0.
- Собирает и кэширует данные активности.
- Проверяет роль для каждого запроса.

**Релиз:**
- Фундамент выкатывается первым (до ARS-101, 102, 103).
- Нет фиче-флагов, новых таблиц, межсервисных вызовов.
- Обратная совместимость не требуется (новое взаимодействие).

**Трассировка:**
- FR-1, FR-2 → INT-0 `/current` (счётчик в шапке).
- FR-3, FR-4 → INT-0 `/range` (график за период).
- FR-5 → INT-0 `/range` (выгрузка сводки).

## Статус готовности

**Готово к разработке.** Все гейты ✅. Отсутствуют открытые вопросы.

Детские фронты наследуют контракт INT-0 и адаптируют его для своих UI-сценариев (счётчик, график, выгрузка). Спека фундамента закрывает общий шов — детей разводят дальше на уровне их собственных спек.
