# Техническая спецификация узла-фундамента #0 готова

## Статус

**Готово к разработке.** Все технические гейты закрыты; спецификация содержит полный контракт INT-0, готовый к реализации.

## Что спроектировано

**Узел-фундамент #0** предоставляет единственное взаимодействие:

### INT-0. Получение данных активности пользователей
- **Граница:** Arsenal Backend → Дочерний фронтенд (REST API)
- **Запрос:** `GET /api/activity/stats?period={hour|day|week}`
- **Ответ:** Объект с тремя компонентами:
  1. **Текущий счёт** (`current.count`, `current.timestamp`) — актуальное число активных пользователей
  2. **Исторические данные** (`aggregates.data_points`) — упорядоченные по времени точки активности за выбранный период:
     - `period=hour`: 12 точек по 5 минут
     - `period=day`: 24 часовых точки
     - `period=week`: 7 дневных точек
  3. **Сводка** (`aggregates.summary`) — min, max, avg для выгрузки
- **Статусы:**
  - `available` — данные получены и свежи
  - `unavailable` — источник недоступен (показать ошибку)
  - `empty` — период без активности (показать пусто)
- **Авторизация:** Роль `Administrator` только; проверка на бэке Arsenal
- **Кэш:** 30 секунд на Arsenal Backend; таймаут 5 секунд на вызовы сервиса сессий
- **Происхождение:** 🟢 новое, спроектировано полностью

## Ключевые дизайн-решения (принял по ответам аналитика)

1. **BE-only контракт** — данные собирает и отдаёт только Arsenal Backend; дочерние фронты потребляют через REST.

2. **На лету, без хранилища** — агрегаты считаются по запросу из существующего источника сессий; новых таблиц не заводим.

3. **Различие между ошибкой и пустотой** — `status: "unavailable"` (источник вниз, не отдавать стаё данные) vs `status: "empty"` (период без активности — валидное состояние).

4. **Авторизация на бэке** — только Administrator; проверяется перед вычислением ответа.

5. **Синхронный запрос, кэш 30 сек** — детские фронты могут обновлять счётчик/график с интервалом 10–30 секунд; данные всегда не старше 30 секунд.

6. **Foundation выкатывается первым** — Phase 1: бэк Arsenal с INT-0; Phase 2+: дочерние фронты потребляют контракт как есть.
