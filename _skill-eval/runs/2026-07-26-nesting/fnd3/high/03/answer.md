# Техническая спецификация: Узел-фундамент #0 — готова к разработке

## Выполнено

Спроектирована техническая спецификация для узла-фундамента #0 эпика ARS-100 «Панель активности пользователей в админке Арсенал». Фундамент — общий контракт данных активности, который обслуживает все три фронтовых элемента эпика (счётчик в шапке, модальное окно с графиком, выгрузка сводки).

## Содержание спецификации

**Файл:** `/docs/ARS-100/_foundation/technical_specification.md`

### Ключевые решения (спроектированы и подтверждены аналитиком)

1. **Тип и стороны:** BE-only. Бэк «Арсенала» выкладывает новый эндпоинт `/api/admin/activity-stats` (INT-0); потребители — фронты детских узлов.

2. **Контракт INT-0 (🟢 новое):**
   - **Запрос:** GET /api/admin/activity-stats с параметрами `period`, `startTime`, `endTime`, `granularity`
   - **Ответ:** JSON с полями:
     - `currentCount` (число | null) — текущее число активных пользователей
     - `aggregates` (массив объектов | null | []) — агрегированные данные за период
     - `isAvailable` (boolean) — доступен ли источник данных
     - `hasData` (boolean) — есть ли данные за период
     - `period` (объект) — информация о периоде
   - **JSON-примеры:** Включены для успеха (текущий счёт, агрегаты за день), недоступности источника и отсутствия данных.

3. **Различие ошибок:**
   - `isAvailable: false` → источник недоступен (сетевая ошибка, таймаут 5s) → UI: retry
   - `hasData: false` → нет данных за период, но система работает → UI: пустой график

4. **Авторизация:** Только роль «Администратор» (проверка на бэке); 403 для других ролей.

5. **Данные и хранение:** Агрегаты считаются на лету; новых таблиц нет.

6. **Производительность:**
   - Синхронно
   - Кэш 30 сек на бэке
   - Таймаут 5 сек
   - Polling от фронта каждые 30 сек

7. **Релиз:** Фундамент выкатывается раньше потребителей (детских фронтов); фиче-флагов нет; атомарный откат.

8. **Состояния UI (для детей):** `loading`, `value`, `zero`, `empty`, `error_source`, `error_forbidden` — явно определены.

9. **Трассировка:** INT-0 обслуживает FR-1..FR-5 эпика.

## Статус

**Готово к разработке.** Все 10 техничних гейтов закрыты (✅) и подтверждены аналитиком. Открытых вопросов нет. Спецификация содержит:
- Полный контракт с примерами JSON для всех сценариев
- Карту ошибок с кодами и состояниями UI
- Ответственности бэка и фронта (в рамках фундамента)
- План релиза и отката
- Чек-лист преднастройки

Спецификация готова для параллельной разработки фронтов детских узлов: каждый фронт видит точный контракт INT-0 и может писать код независимо.
