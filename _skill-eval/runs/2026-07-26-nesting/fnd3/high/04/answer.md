# Техническая спецификация узла-фундамента #0 — готова

Спецификация для узла-фундамента #0 эпика ARS-100 написана и находится по пути:
**`docs/ARS-100/_foundation/technical_specification.md`**

## Краткий обзор спеки

### Тип и назначение
BE-only узел-фундамент, обеспечивающий единый контракт данных активности пользователей для всех пяти функциональных требований эпика (FR-1..FR-5). Контракт наследуется детскими узлами без переопределения.

### Ключевой контракт: INT-0
**Получение данных активности пользователей** — новое (🟢) взаимодействие, реализуемое Arsenal backend.

Поддерживает два режима запроса:
- **`scope=current`** — только текущее число активных пользователей (для счётчика в шапке).
- **`scope=aggregated`** — временной ряд активности за выбранный период (час/день/неделя; для графика в модале).

Ответ чётко различает три состояния:
- **`status=ok`** — данные доступны, значение актуально.
- **`status=unavailable`** — источник недоступен (флаг, а не стали данные).
- **`status=no_data`** — данные за период отсутствуют (отличается от ошибки).

### Авторизация
Только роль **Administrator**, проверка на бэке Arsenal. Другие роли получают 403 Forbidden.

### Производительность и надёжность
- Синхронно.
- Кэш 30 сек на бэке Arsenal.
- Таймаут 5 сек.
- Polling в фронте ~15 сек с jitter.
- При недоступности источника — признак недоступности, не устаревшие данные.

### Порядок выката
Фундамент выкатывается **первым**, раньше детских узлов (FR-1..FR-5).
