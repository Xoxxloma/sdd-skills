# Техническая спецификация: узел-фундамент #0

Спецификация для узла-фундамента #0 (контракт данных активности пользователей) эпика ARS-100 завершена и сохранена.

## Резюме

**Статус:** ✅ Готово к разработке

**Файл спецификации:** `docs/ARS-100/_foundation/technical_specification.md`

### Что спроектировано

Единый контракт данных активности пользователей (INT-1) для потребления дочерними узлами фронта:
- **Назначение:** Backend-only слой, отдаёт текущее число активных пользователей и агрегированные данные активности за выбранный период (час/день/неделя).
- **Авторизация:** ограничено ролью Администратор, проверяется на стороне Arsenal BE.
- **Производительность:** синхронно, 30-секундный кэш на Arsenal BE, таймаут 5 секунд.
- **Надёжность:** при недоступности источника возвращается флаг `status="unavailable"` вместо устаревшего значения; отдельно различаем «данных нет» vs «источник недоступен».
- **Хранение:** агрегаты считаются на лету, новых таблиц не заводим.

### Контракт INT-1

**Эндпоинт:** `GET /activity/summary` с параметрами `period_type`, `period_start`, `period_end`.

**Ответ (успех):**
```json
{
  "status": "available",
  "timestamp": "2025-07-26T14:30:45Z",
  "current_active_users": 42,
  "period_data": {
    "period_type": "daily",
    "period_start": "2025-07-25T00:00:00Z",
    "period_end": "2025-07-26T00:00:00Z",
    "data_points": [
      {"timestamp": "2025-07-25T00:00:00Z", "active_users": 5},
      {"timestamp": "2025-07-25T01:00:00Z", "active_users": 3}
    ],
    "summary": {
      "total_peak": 15,
      "total_average": 5.33,
      "total_sessions": 127
    }
  }
}
```

**Ответ (источник недоступен):**
```json
{
  "status": "unavailable",
  "timestamp": "2025-07-26T14:30:45Z",
  "current_active_users": null,
  "period_data": null
}
```

**Ошибки:**
- 400 Bad Request (неверный формат параметров)
- 403 Forbidden (пользователь не Администратор)
- 500/504 (источник недоступен / таймаут)

### Трассировка к бизнес-требованиям

Контракт INT-1 обслуживает данные для всех FR-1..FR-5 эпика:
- **FR-1** (счётчик в шапке) — вызов с `period_type=current`.
- **FR-2** (автообновление счётчика) — периодический опрос `period_type=current`.
- **FR-3** (открытие модали с графиком) — вызов с `period_type=daily/hourly/weekly`.
- **FR-4** (переключение периода) — переквызов INT-1 с новыми параметрами `period_start/end`.
- **FR-5** (выгрузка) — использует `period_data` из INT-1.
