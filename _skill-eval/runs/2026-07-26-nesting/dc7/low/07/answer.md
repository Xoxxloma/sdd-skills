# Техническая спецификация: Выгрузка сводки (ARS-93)

## Подтверждение технических решений

Я прочитал бизнес-требования для задачи ARS-93 (слайс эпика ARS-90, FR-5: кнопка выгрузки в модальном окне). Перед написанием спеки нужно подтвердить критические технические решения.

### 1. **Scope этой спеки: только экспорт (FR-5) или полная модалка?**
Бизнес-требования упоминают три элемента (счётчик в шапке, график активности, кнопка выгрузки), но эта задача владеет только FR-5.

- **Предложение:** Спека покрывает только FR-5 (экспорт-взаимодействие) — я исхожу из того, что счётчик и график обрабатывают отдельные слайсы (ARS-91/ARS-92).
- **Вопрос:** Это верно, или спека должна охватить все три элемента?

### 2. **Механизм экспорта: синхронный или асинхронный?**
Когда администратор нажимает «выгрузить», система должна сформировать файл со сводкой.

- **Вариант A:** Синхронный — мгновенная выгрузка (администратор ждёт, файл готовится по запросу).
- **Вариант B:** Асинхронный — бэк запускает фоновую работу, отдаёт ссылку; файл доступен позже.
- **Вариант C:** Предвычисленный — сводки готовятся периодически, экспорт просто возвращает готовую.
- **Вопрос:** Какой подход?

### 3. **Источник данных активности: откуда Arsenal-BE читает счёты активных пользователей и историю?**
- **Вариант A:** От сервиса Аутентификации/Сессий (вызывает его эндпоинты для текущих счётов и истории).
- **Вариант B:** От отдельного сервиса Analytics/Activity.
- **Вариант C:** Arsenal-BE хранит данные активности сам (обновляет периодически от Session service).
- **Вопрос:** Какой сервис владеет данными активности (текущее + история), необходимыми экспорту?

### 4. **Формат выгрузки: CSV, JSON, XLSX или другое?**
- **Вопрос:** В каком формате должен быть файл выгрузки?

### 5. **График активности в модальном окне: входит в эту спеку или унаследован из другого слайса?**
Кнопка экспорта находится в модальном окне, которое показывает график активности. Сам UI графика может быть из другого слайса.

- **Предложение:** Спека включает контракт для получения данных активности (текущий счёт + агрегированная активность за период), чтобы модалка могла их отображать.
- **Вопрос:** Является ли UI модалки (отрисовка графика, выбор периода) ответственностью этой задачи, или я должен предположить, что она уже существует?

### 6. **Взаимосвязь трёх элементов: они координируются?**
Бизнес-требования говорят: «все три элемента опираются на одни и те же данные об активности».

- **Вопрос:** Счётчик (в шапке), график (модалка) и экспорт (кнопка) используют единый API-вызов, или есть отдельные взаимодействия для каждого?
