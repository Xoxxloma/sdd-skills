**Слайс A — Онлайн-индикатор** (ARS-71)
- Владеет: FR-1 (отображение счётчика), FR-2 (автоматическое обновление), FR-3 (обработка недоступности)
- Папка: `docs/ARS-70/ARS-71/`
- Статус: Готово к оценке
- Сквозные FR: нет

**Слайс B — Журнал регламентных работ** (ARS-72)
- Владеет: FR-4 (создание записи), FR-5 (просмотр списка)
- Папка: `docs/ARS-70/ARS-72/`
- Статус: Готово к оценке
- Зависит от: ARS-71
- Сквозные FR: нет

✅ Все 5 FR эпика присвоены ровно по одному слайсу (FR-1,2,3 → ARS-71; FR-4,5 → ARS-72)

## Порядок сборки

1. **ARS-71** (Онлайн-индикатор) — базовый слайс, поставляется первым
2. **ARS-72** (Журнал регламентных работ) — поставляется после ARS-71 (явная зависимость: требует завершённого компонента онлайн-индикатора для координации бэкэнда)

## Следующий шаг

Запусти навык `technical-spec-doc` на каждой дочерней папке, начиная с ARS-71:

```bash
technical-spec-doc docs/ARS-70/ARS-71/
technical-spec-doc docs/ARS-70/ARS-72/
```

Каждый запуск автоматически:
- Прочитает `docs/ARS-70/ARS-<KEY>/business_requirements.md`
- Напишет `technical_specification.md` рядом
- Не требует изменений исходного БТ
