# Декомпозиция завершена

Эпик ARS-70 успешно разбит на две самостоятельно поставляемые слайсы согласно подтверждённому разрезу.

## Результаты

### Индекс декомпозиции
📋 **docs/ARS-70/decomposition.md** — таблица трассировки эпик-FR → дочерние слайсы, порядок сборки, зависимости.

### Дочерние БТ

| Ключ | Название | Владеет | Зависит от | Папка |
|------|----------|---------|-----------|-------|
| **ARS-71** | [A] Онлайн-индикатор | FR-1, FR-2, FR-3 | — | docs/ARS-70/ARS-71/ |
| **ARS-72** | [B] Журнал регламентных работ | FR-4, FR-5 | ARS-71 | docs/ARS-70/ARS-72/ |

Каждый дочерний БТ:
- содержит скопированный дословно контекст из эпика (проблема, потребители, ценность, приоритет, риски, роли);
- покрывает ровно свой поднабор FR с оригинальными номерами эпика (не перенумерованы);
- включает критерии приёмки ДОСЛОВНО из эпика-БТ;
- определяет собственный in/out-scope, отсылая на соседние слайсы;
- готов к запуску `technical-spec-doc` без изменений.

### Порядок сборки
1. **ARS-71** — базовый слайс (онлайн-индикатор).
2. **ARS-72** — после ARS-71 (зависимость).

### Инвариант покрытия
✅ Все 5 FR эпика присвоены: FR-1,2,3 → ARS-71; FR-4,5 → ARS-72.
✅ Ни один FR не потерян; ни один не задвоен без пометки.
✅ Никаких новых FR, расщеплений смысла или дописанного scope — только партиционирование эпик-БТ.
✅ Ключи валидны, уникальны, отличны от эпика.
