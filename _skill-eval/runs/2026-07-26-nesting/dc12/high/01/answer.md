# Декомпозиция ARS-70 завершена

Согласно подтверждению аналитика, эпик ARS-70 разбит на два слайса:

## Артефакты (созданы)

1. **Индекс декомпозиции:** `docs/ARS-70/decomposition.md`
   - Полная трассировка: эпик-FR → владелец-слайс
   - Реестр дочерних задач с порядком сборки
   - Информация о зависимостях

2. **Слайс A — Онлайн-индикатор (ARS-71):** `docs/ARS-70/ARS-71/business_requirements.md`
   - Владеет: FR-1, FR-2, FR-3
   - Содержит: счётчик активных пользователей в шапке, автоматическое обновление, обработка недоступности источника
   - Статус: Готово к оценке

3. **Слайс B — Журнал регламентных работ (ARS-72):** `docs/ARS-70/ARS-72/business_requirements.md`
   - Владеет: FR-4, FR-5
   - Содержит: создание записей о работах, просмотр списка
   - Зависит от: ARS-71
   - Статус: Готово к оценке

## Порядок сборки

1. ARS-71 (базовый слайс)
2. ARS-72 (после ARS-71)

## Проверки покрытия

✅ Все 5 FR эпика назначены (по одному на владельца)
✅ Потерянных FR нет
✅ Задвоенных без пометки `shared` нет
✅ Каждый детский БТ самодостаточен и содержит скопированный дословно контекст из эпика
✅ Оригинальные номера FR сохранены без перенумерации
✅ Ключи валидны, уникальны и отличны от ключа эпика

## Следующий шаг

По каждой папке `docs/ARS-70/<CHILD-KEY>/` запусти `technical-spec-doc` — скилл прочитает детский БТ, извлечёт номер задачи из имени папки и напишет `technical_specification.md` для каждого слайса.
