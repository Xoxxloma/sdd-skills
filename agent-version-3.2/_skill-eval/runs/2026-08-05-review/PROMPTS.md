# Промпты раунда 2026-08-05 (`spec-review`)

Реестр обязателен: без него прогон невоспроизводим, а различие в формулировке промпта уже дважды
в этой репе объясняло «регресс», которого не было. Пути везде **абсолютные** — относительные в
этом окружении не находят ничего, и субагент честно отвечает «файла нет».

## П-ЛИСТ — прогон уровня проверяющего (тир A, 70 прогонов)

Промпт Шага 2 скилла **дословно**, плюс три строки условий замера. Меряет детекцию: чек-лист
против документа, контекст чистый по построению.

```
Прочитай чек-лист по пути <ЧЕК-ЛИСТ> и проверь по нему файл <АРТЕФАКТ>.
Источник требований: <ИСТОЧНИК | не передан — проверяй файл сам по себе.>

Первой строкой отчёта напиши: чек-лист прочитан, тип: <ТИП>

Дальше — только то, что чек-лист велит вернуть. Ничего не правь: у тебя работа проверяющего,
а не автора, и ни один проверяемый файл менять нельзя.

Условия замера: относительные пути здесь ничего не находят — пользуйся только абсолютными.
Готовый отчёт целиком запиши в файл <ОТЧЁТ> — это единственный файл, который тебе разрешено
создать. В ответ верни одну строку: готово.
```

Раскладка проб: `spec-dirty`/`bt-design`/`stage-cut` — по `RV-DIRTY`; `spec-clean`/`bt-clean`/
`stage-clean` — по `RV-CLEAN`; `spec-loop` — по `RV-LOOP`. Источник передаётся **только** спеке.

**Почему отчёт пишется в файл, а не возвращается текстом.** Правило репы: ответ агента и
записанный им файл расходятся систематически. Плюс на 80 прогонах это разница между одной строкой
и ~5000 токенов на прогон.

## П-СКИЛЛ — прогон полного пути (тир A, проба оркестрации, 10 прогонов)

Меряет не детекцию, а поведение ведущего агента: делегирует ли он и не читает ли артефакт сам.
Файл не пишет — запрет на запись у этого скилла проверяется, а не обходится, поэтому отчёт
принимается текстом ответа.

```
Ты работаешь в проекте документации, помогаешь аналитику. У аналитика установлен скилл
`spec-review` — его инструкция лежит по абсолютному пути <SKILL.md>. Прочитай эту инструкцию
ПОЛНОСТЬЮ (инструмент Read) и выполни её дословно.

Сообщение аналитика:

«Спека по RMS-4021 готова, лежит в <АРТЕФАКТ> — посмотри её перед тем как отдавать в разработку.»

Условия прогона (это замер, а не боевая работа):
- НИЧЕГО не создавай и не изменяй на диске. Единственный твой выход — текст ответа.
- Относительные пути в этом окружении ничего не находят: пользуйся только абсолютными.
- Работай только с файлами внутри названной папки прогона и с файлами самого скилла.
- Финальным сообщением верни ровно тот текст, который ты показал бы аналитику, и ничего сверх него.
```

**Делегирование грейдится не по отчёту, а грепом по транскрипту прогона**: `"name":"Agent"` — был
ли вызов субагента, `"name":"Read"` — сколько файлов открыл сам. Самоотчёт здесь не годится: агент,
который написал «отдал субагенту», и агент, который отдал, — разные события.

## П-АВТОР — самопроверка автора (тир B, 20 прогонов)

Ветка «без ревью». Тот же документ, но проверяет его тот, кто (по легенде промпта) его написал,
и по своим правилам — Шаг 5 `technical-spec-doc`, который в пайплайне уже стоит.

```
Ты — агент, который ведёт технические спецификации по скиллу `technical-spec-doc`. Инструкция
скилла лежит по абсолютному пути <SKILL.md> — прочитай её полностью (Read) и работай строго по ней.

Что уже произошло в этой работе:
- аналитик принёс бизнес-требования: <БТ>
- ты провёл по ним интервью, аналитик подтвердил решения по гейтам;
- ты записал спецификацию: <СПЕКА>

Остался Шаг 5 — Self-Review перед хендоффом. Выполни его по своей инструкции.

Условия замера: файлы менять нельзя, поэтому вместо правки перечисли текстом всё, что проверку
не проходит, — по пунктам, с указанием места. Если не нашёл ничего, так и напиши. Относительные
пути здесь ничего не находят — пользуйся абсолютными. Результат целиком запиши в файл <ОТЧЁТ> —
это единственный файл, который тебе разрешено создать. В ответ верни одну строку: готово.
```

**Что в этом промпте сделано намеренно и чего в нём нет.** Автору не передаётся чек-лист приёмки —
он работает по своим правилам, и это и есть измеряемая конфигурация. Ему не говорят, что документ
сломан, и не намекают, куда смотреть. Обе ветки только перечисляют, ничего не правя, — иначе
сравнивать было бы нечего.

**Чем эта ветка НЕ является.** Авторство здесь сыграно промптом, а не получено настоящим
написанием документа: агент не проводил интервью и не писал спеку, ему сказано, что он это делал.
Накопленного контекста реальной петли (шесть прочитанных `SKILL.md`, эпик-БТ, разрез, полтора
десятка реплик) у него нет. Поэтому ветка меряет **«автор со своими правилами против приёмки со
своими»**, а не «уставший тред против свежего». Второе меряется только сквозным прогоном —
см. `runs/2026-08-01-live/`.
