# Фикстура PC-THIN — один источник, правил не набирается

Проверяет самый неудобный исход: **правил ноль, а файл всё равно нужен**.

## Слепок

```
services/
  manifest.yaml   одна строка: auth
  auth.md         backend с «Публичным контрактом»
```

## Ожидаемый счёт

Применимый источник ровно один во всех семи слотах. Значит `N ≤ 1` везде, `M = 0` везде.

| Слот | Числа | Что в файле |
|---|---|---|
| 1 путь и версионирование | наблюдений 1 | «не определено: наблюдений 1» |
| 2 коды ошибок | наблюдений 1 | «не определено: наблюдений 1» |
| 3 пагинация | наблюдений 0 | «не определено: наблюдений нет» |
| 4 идемпотентность | наблюдений 1 | «не определено: наблюдений 1» |
| 5 семантика `null` | наблюдений 1 | «не определено: наблюдений 1» |
| 6 формат дат | наблюдений 1 | «не определено: наблюдений 1» |
| 7 именование | наблюдений 1 | «не определено: наблюдений 1» |

`CONVENTIONS.md` записывается — со всеми семью слотами и причиной у каждого. Правил в нём ноль, и
это правильный результат.

## Ловушки

**1. Соблазн отказаться.** «Нечего записывать — скажу человеку и остановлюсь» выглядит честно, но на
диске это неотличимо от «скилл не запускали»: следующий человек прогонит всё заново ради того же
нуля. Отказ здесь законен **только** при отсутствии `services/` целиком — это фикстура PC-EMPTY.

**2. Соблазн записать правило от одного источника.** Все наблюдения выглядят каноничными: `/v1/`,
`409` на повтор, `camelCase`, `iso8601`. Порог два существует ровно против этого: одна карточка —
это привычка одного автора, а конвенция применяется в тех-спеке без вопроса аналитику.

**3. Различай две причины пустоты.** «Наблюдений 1» и «наблюдений нет» — разные строки: первая
говорит «добавьте ещё сервис в слепок», вторая «этого нет ни у кого». Голое «не определено» не
отличает их.

**4. Вопрос про ситуативные (Шаг 6) обязателен и здесь**, причём именно здесь он наиболее ценен:
слепок беден, и единственный способ наполнить файл — спросить человека.

## Красный исход

Файл не создан; либо создан с правилами, выведенными из единственного источника; либо слоты со
строкой «не определено» без причины.
