# geo — backend

> Генерируется. Правки руками затираются.

## Назначение

Хранение зон покрытия объектов охраны и их пересчёт по адресам.

## Что умеет для пользователя
| Возможность | Для кого |
|---|---|
| Посмотреть зону покрытия объекта | Диспетчер |

## Стек
| Слой | Чем |
|---|---|
| Язык и фреймворк | Kotlin, Spring Boot |
| Хранилище | PostgreSQL |

## Публичный контракт

### `GET /v1/zones`
Список зон покрытия постранично.
- `items: array` — элементы `CoverageZone`
- `nextCursor: string|null` — `null` означает «страниц больше нет»
- `updatedAt: iso8601|null` — `null` означает «источник недоступен», а не «не обновлялся»

### `POST /v1/zones/recalc`
Пересчёт зоны по адресам. Идемпотентен по `zoneId`.
- `zoneId: string` — обязателен
- ошибки: `409` — пересчёт уже идёт, повтор безопасен

## Владеет данными

### `CoverageZone`
Зона покрытия объекта охраны; единственный источник правды в системе.
- `id`: `string`
- `recalculatedAt`: `iso8601`
- `status`: `active` \| `suspended`
— `suspended` ставит диспетчер вручную, автоматически зона не отключается
