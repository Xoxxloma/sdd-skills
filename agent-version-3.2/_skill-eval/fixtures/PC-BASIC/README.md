# Фикстура PC-BASIC — основной сбор конвенций

Проверяет четыре вещи: **знаменатель считается по слоту**, а не по числу карточек; арифметика
`(согласны N, противоречат M)`; аббревиатуры находятся в секциях, которые для слотов читать
запрещено; расшифровка, уже стоящая в карточке, не переспрашивается.

## Слепок

```
services/
  manifest.yaml
  auth.md          backend,  есть «Публичный контракт»          — источник слотов 1–7
  geo.md           backend,  есть «Публичный контракт»          — источник слотов 1–7
  dispatch.md      backend,  «Публичного контракта» НЕТ         — источник ТОЛЬКО слотов 5–7
  incident-web.md  frontend, «Публичного контракта» нет по типу — не источник ни для чего
  ui-kit.md        lib,      «Публичный API» вместо контракта   — не источник ни для чего
```

## Ожидаемый счёт

Применимых источников: **слоты 1–4 — два** (`auth`, `geo`); **слоты 5–7 — три** (плюс `dispatch`).

| Слот | Числа | Исход |
|---|---|---|
| 1 путь и версионирование | согласны 2 (auth, geo), противоречат 0 | правило `/v1/<множественное>` |
| 2 коды ошибок | согласны 2 — `409` на безопасный повтор | правило |
| 3 пагинация | **наблюдений 1** (только `geo`, `nextCursor`) | «не определено: наблюдений 1» |
| 4 идемпотентность | согласны 2 — `auth` по `sessionId`, `geo` по `zoneId` | правило |
| 5 семантика `null` | согласны 2 — `null` = «источник недоступен» | правило |
| 6 формат дат | согласны 3 — везде `iso8601`, суффикс `At` | правило |
| 7 именование | согласны 3 по полям (`camelCase`) и 3 по enum'ам (нижний регистр латиницей) | два правила |

Шесть слотов с правилами, один — со строкой «не определено: наблюдений 1». Плюс строка отчёта:
форма тела ошибки из карточек **не наблюдается вообще**.

Термины: `ГОСБ` и `ЧОП` спросить, `ГБР` — **не спрашивать**: расшифровка стоит в карточке
`incident-web` прямо в строке возможности, её берут оттуда дословно.

## Ловушки

**1. `dispatch` — самая дорогая.** Это `backend` без «Публичного контракта»: событийный сервис.
Соблазн — либо выкинуть его из источников целиком (тогда знаменатель слотов 5–7 занижен до двух),
либо считать источником слотов 1–4 (тогда он выглядит «промолчавшим» и завышает `M`). Верно —
источник ровно слотов 5–7.

**2. `incident-web` и `ui-kit` не должны попасть в знаменатель нигде.** У фронта «Публичного
контракта» нет по форме карточки, у библиотеки вместо него «Публичный API» — сигнатуры функций, а
не HTTP-стыки. `ui-kit` вдобавок противоречит всему сразу: `unixtime` вместо `iso8601`,
`NEW | IN_PROGRESS | CLOSED` заглавными. Взятый в источники, он превратит слоты 6 и 7 в
расхождения, и правил не останется.

**3. Идемпотентность живёт в прозаической строке назначения**, а не в строке `-`:
`Отзыв сессии. Идемпотентен по \`sessionId\`.` Ищущий только по строкам `-` запишет «наблюдений 0».

**4. Аббревиатуры лежат ровно в тех секциях, которые Шаг 1 запретил читать** — `ГБР` и `ГОСБ` в
«Экранах» и «Что умеет для пользователя», `ЧОП` в «Состоянии и данных» у `incident-web`. Запрет
относится только к сбору наблюдений по слотам; перенесённый на Шаг 3, он теряет все три термина.

**5. `nextCursor: string|null` — `null` здесь значит «страниц больше нет».** В слот 5 (семантика
`null` = «источник недоступен») это наблюдение **не идёт**: разные по назначению поля дают разные
смыслы `null`, и это не расхождение внутри карточки. Засчитавший его отправит слот 5 в вопрос
вместо правила.

**6. `ГБР` расшифрован прямо в карточке** — «Назначить ГБР (группа быстрого реагирования) на
инцидент». Спросивший про него просит человека продиктовать прочитанное.

## Красный исход

Файлы записаны без учёта того, что подтверждение стояло в задаче (то есть ход закончился вопросом
и пустой папкой); либо расшифровки аббревиатур предложены самим скиллом; либо изменены карточки
или `manifest.yaml`.
