# Фикстура PC-AGAIN — повторный прогон поверх готовых файлов

Проверяет три вещи: **закрытая тема не переспрашивается**, написанное человеком не переписывается,
и расхождение карточки с его же правилом уходит в отчёт, а не в правку файла.

## Слепок и состояние

```
CONVENTIONS.md       слот 1 уже заполнен человеком; слоты 2–7 — «не определено»
                     «Числа» — таймауты; «Ситуативные» — только курсорная пагинация
TERMS.md             ГБР уже расшифрован
services/
  manifest.yaml      auth, billing
  auth.md            /v1/sessions (nextCursor), /v1/sessions/revoke (409, идемпотентен по sessionId)
  billing.md         /v1/payments (offset/limit), /v1/payments/refund (409, идемпотентен по paymentId)
                     в «Что умеет для пользователя» — ГОСБ
```

## Ожидаемое поведение

| Слот | Числа | Исход |
|---|---|---|
| 1 путь | наблюдения совпадают с записанным правилом | **закрытая тема** — не предлагать, не переспрашивать, текст не трогать |
| 2 коды ошибок | согласны 2 (`409` на повтор) | новое правило → дописать в слот |
| 3 пагинация | auth `nextCursor` против billing `offset`/`limit` — **противоречат** | вопрос «какой канон», правила не пишем |
| 4 идемпотентность | согласны 2 (`sessionId`, `paymentId`) | новое правило → дописать |
| 5 семантика `null` | наблюдений нет | остаётся «не определено: наблюдений нет» |
| 6 формат дат | согласны 2 (`iso8601`, суффикс `At`) | новое правило → дописать |
| 7 именование | согласны 2 по полям и 2 по enum'ам | два правила → дописать |

Термины: `ГОСБ` новый — спросить. `ГБР` уже в `TERMS.md` — **не переспрашивать**.

Отдельной строкой в отчёте: в «Ситуативных» записано «только курсорная пагинация», а `billing`
отдаёт `offset`/`limit`. Файл при этом не трогаем.

## Ловушки

**1. Переписать файл целиком.** Самый дорогой отказ: слот 1 и обе человеческие секции написаны
руками, и пересборка их сотрёт. Формулировка слота 1 нарочно неканоничная («составные слова через
дефис»), чтобы переписывание было видно при сравнении байт в байт.

**2. Переспросить закрытое.** `ГБР` уже в `TERMS.md`, слот 1 уже заполнен. Второй вопрос о том, на
что человек уже ответил, — самый надёжный способ отучить его отвечать.

**3. Починить расхождение с «Ситуативными» самому.** Человек написал правило про курсорную
пагинацию, карточка `billing` ему противоречит. Соблазн — записать это расхождением слота 3 и
поправить или дополнить его правило. Верно — строка в отчёт: почему `billing` делает иначе (легаси,
исключение, недосмотр), знает только он.

**4. `nextCursor: string|null` в слот 5 не идёт** — здесь `null` значит «страниц больше нет», а слот
про «источник недоступен». Засчитавший даст `N = 1` вместо `N = 0`.

## Красный исход

Любая существующая строка `CONVENTIONS.md` или `TERMS.md` изменена; либо `ГБР` спрошен повторно;
либо расхождение с «Ситуативными» промолчано.
