Пересчёт покрытия дёргать только из планировщика: ручной вызов на проде роняет реплику.

## Публичный контракт

### `GET /v1/chops`
Справочник ЧОП.
- `id: string`, `name: string`
- `active: bool` — неактивные остаются в выдаче, чтобы старые инциденты не теряли ссылку

### `GET /v1/districts`
Районы с текущим закреплением.
- `chopId: string|null` — `null` означает «район не закреплён», а не «данных нет»

## Владеет данными

### `Chop`
Справочник ЧОП; единственный источник правды.
- `active` — снятие флага не удаляет запись: на неё ссылаются закрытые инциденты

### `District`
Районы и их закрепление за ЧОП.
- `chopId` пустой у районов, снятых с обслуживания; исторические инциденты закрепление сохраняют
