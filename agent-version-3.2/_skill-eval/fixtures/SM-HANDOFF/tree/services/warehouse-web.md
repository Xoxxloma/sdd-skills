# warehouse-web — frontend

> Генерируется. Правки руками затираются.
> Заметки человека — в `services/manifest.yaml`, поле `notes`.
> Форма — `reference/card.template.md` скилла `service-map`. Соседние карточки формой не являются.

## Назначение

Рабочее место оператора склада: очередь приёмки, печать ТТН, отметка о приёме груза.

## Что умеет для пользователя
| Возможность | Для кого |
|---|---|
| Посмотреть очередь отправлений на приёмку | Оператор склада |
| Распечатать ТТН по отправлению | Оператор склада |

## Стек
| Слой | Чем |
|---|---|
| Язык и фреймворк | TypeScript, React |
| Роутинг | React Router |

## Экраны
| Роут | Экран | Что делает пользователь |
|---|---|---|
| `/queue` | Очередь приёмки | фильтрует по складу и открывает отправление |
| `/queue/:id` | Отправление | сверяет груз, печатает ТТН, отмечает приём |

## Потребляемые API
| Сервис | Вызов | Зачем |
|---|---|---|
| `shipping` | `GET /api/shipments` | очередь отправлений на экране приёмки |
| `shipping` | `GET /api/shipments/{id}/waybill` | печать ТТН |
