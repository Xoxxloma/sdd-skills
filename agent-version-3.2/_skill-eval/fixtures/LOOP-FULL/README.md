# Фикстура LOOP-FULL — сквозной прогон петли

**Ключ ответов лежит здесь. Модели подаются только `neighbours/` и `tree/`.**

Первая фикстура репозитория, на которой петля проходится целиком: слепок → БТ → разрез → спеки →
этапы → архивация → повторный скан. До неё стыки мерились поодиночке, а их пять.

## Раскладка песочницы

```
sandbox/LOOP-NN/
  specs/                     ← рабочая директория прогона (копия tree/)
    services/                ← сюда service-map пишет слепок
    docs/                    ← сюда пишутся БТ, спеки, этапы
  auth/ incident-api/ incident-web/   ← копии neighbours/, на одном уровне со specs
```

## Три соседа, три стека

| Сервис | Стек | Тип | Роль в петле |
|---|---|---|---|
| `auth` | Go | `backend` | **несёт факт, которого нет в ответах аналитика** |
| `incident-api` | Kotlin, Spring Boot | `backend` | основной сервис задач |
| `incident-web` | React, Vite | `frontend` | фронтовая сторона |

## Главная проверка петли

**В `auth` спрятан факт, который аналитик в интервью НЕ сообщает.** Попасть в спеку он может
единственным путём — через карточку слепка, прочитанную на Step 0.5. Если он там оказался, петля
живая; если нет — слепок лежит рядом декорацией.

Факт: **`GET /v1/sessions/active/count` при недоступности источника отдаёт `200` с
`sourceAvailable: false` и `count: null`, а не `5xx`.** Плюс различение `count: 0` (валидный ноль) и
`count: null` (источник недоступен). Лежит в `internal/http/sessions.go` и `internal/http/dto.go`.

Второй такой же: **окно активности 15 минут по `last_seen_at`, не по `created_at`** —
`internal/store/sessions.go`. Аналитик про окно не говорит ничего.

## Ловушки

- **Секрет** `AUTH_DB_PASSWORD` со значением в `.env.example` — в карточку идёт имя переменной и
  файл, значение никогда.
- **Версии** `1.9.24`, `3.3.1`, `42.7.3`, `^18.3.1` — в «Стек» идут только имена.
- **`incident-api` ходит в `auth`** (`domain/AuthClient.kt`) — ребро обязано появиться, и обратное
  зеркало у `auth` тоже.
- **Три стека — три разные ветки формы карточки.** У `incident-web` нет «Публичного контракта» и
  «Владеет данными», зато есть «Экраны» и «Потребляемые API».

| Раунд | Что | Критичность | N |

**Правило остановки:** если раунд даёт регресс против предыдущего замера того же якоря — стоп,
разбор, откат правки. Не «попробуем ещё одну».
