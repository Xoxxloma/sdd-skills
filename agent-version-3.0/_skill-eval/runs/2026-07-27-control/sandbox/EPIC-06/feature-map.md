# Карта возможностей

> Генерируется `service-map` из карточек и обновляется `archive-spec` при архивации спек.
> Правки руками затираются.

| Возможность | Сервис | Для кого |
|---|---|---|
| Отфильтровать инциденты по статусу, типу, периоду и ЧОП | `incident-web` | Аналитик безопасности |
| Назначить ГБР на инцидент | `incident-web` | Оперативный дежурный |
| Посмотреть зоны покрытия и изохроны прибытия | `incident-web` | Аналитик безопасности |
| Посмотреть историю выезда ГБР на инцидент | `incident-web` | Аналитик безопасности, оперативный дежурный |
| Построить изохрону по времени прибытия | `geo` | Аналитик безопасности |
