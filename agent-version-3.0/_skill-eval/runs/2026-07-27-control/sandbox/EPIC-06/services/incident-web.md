# incident-web — frontend

> Генерируется. Правки руками затираются.
> Заметки человека — в `services/manifest.yaml`, поле `notes`.

**Назначение.** Рабочее место аналитика безопасности: список инцидентов, карточка инцидента,
назначение ГБР, карта зон покрытия.

## Что умеет для пользователя
| Возможность | Для кого |
|---|---|
| Отфильтровать инциденты по статусу, типу, периоду и ЧОП | Аналитик безопасности |
| Назначить ГБР на инцидент | Оперативный дежурный |
| Посмотреть зоны покрытия и изохроны прибытия | Аналитик безопасности |
| Посмотреть историю выезда ГБР на инцидент | Аналитик безопасности, оперативный дежурный |

## Стек
| Слой | Чем |
|---|---|
| Язык и фреймворк | TypeScript, React, Vite |
| Роутинг | react-router |
| Серверное состояние | react-query |
| Клиентское состояние | zustand |

## Экраны
| Роут | Экран | Что делает пользователь |
|---|---|---|
| `/incidents` | Список инцидентов | фильтрует и открывает карточку |
| `/incidents/:id` | Карточка инцидента | смотрит детали, идёт к назначению ГБР |
| `/incidents/:id/assign` | Назначение ГБР | выбирает ГБР с расчётным временем прибытия |
| `/incidents/:id/history` | История назначений | видит прошлые выезды с названиями ЧОП |
| `/coverage` | Карта покрытия | строит изохроны по времени прибытия |
| `/settings/notifications` | Настройки уведомлений | выбирает каналы |

## Потребляемые API
| Сервис | Вызов | Зачем |
|---|---|---|
| `incident-api` | `GET /v1/incidents` | список с серверной пагинацией |
| `incident-api` | `GET /v1/incidents/:id` | детали инцидента |
| `incident-api` | `POST /v1/incidents/:id/assign` | назначение ГБР |
| `billing` | `GET /v1/squads/available` | список доступных ГБР |
| `geo` | `GET /v1/isochrone` | изохроны на карте покрытия |
| `geo` | `GET /v1/chops` | справочник ЧОП на карточке и в истории |
| `auth` | `GET /v1/sessions/count` | плашка активных сессий в шапке |

## Состояние и данные
| Что хранится | Где | Зачем |
|---|---|---|
| выбранные фильтры инцидентов | zustand + localStorage | переживают перезагрузку страницы |
| справочники ЧОП и типов инцидентов | react-query, staleTime 5 мин | не дёргать справочник на каждом экране |

## Зависит от
| Сервис или система | Зачем |
|---|---|
| хост-приложение | роль пользователя приходит из shell-контекста |

## Роли и доступ
| Роль | Что может |
|---|---|
| `analyst` | всё, кроме назначения ГБР |
| `dispatcher` | назначать ГБР; просматривать историю назначений |
| `viewer` | список и карточка; карта покрытия и история назначений скрыты |
