## Публичный контракт

### `GET /v1/isochrone`
Изохрона по точке и времени в пути.
- `minutes: int` — верхняя граница времени в пути
- ответ — GeoJSON-полигон; пустой полигон означает «точка вне обслуживаемой зоны»

### `GET /v1/chops`
Справочник ЧОП по региону.
- `regionId: string` обязателен
- ответ — массив `{ id, name, status, coverageRadiusM }`
- `status` — `active` | `suspended` | `terminated`
- `coverageRadiusM = null` означает «радиус не задан»
- ошибка `404` — регион неизвестен
- авторизация: любой авторизованный

## Владеет данными

### `CoverageZone`
Зоны покрытия; единственный источник правды.
- `geometry` хранится в проекции EPSG:4326

### `Chop`
Справочник ЧОП. Поля: `id`, `name`, `status`, `coverage_radius_m`, `region_id`.
