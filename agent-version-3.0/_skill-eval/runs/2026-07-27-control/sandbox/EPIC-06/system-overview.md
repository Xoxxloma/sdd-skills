# Обзор системы

> Генерируется `service-map` из карточек и обновляется `archive-spec` при архивации спек.
> Правки руками затираются.

## Сервисы

| Сервис | Тип | Назначение | Зависит от |
|---|---|---|---|
| `auth` | backend | владеет сессиями: выдача, продление, отзыв | API-шлюз |
| `incident-web` | frontend | рабочее место аналитика безопасности: список инцидентов, карточка инцидента, назначение ГБР, история выезда и карта зон покрытия | `incident-api`, `billing`, `geo`, `auth` |
| `geo` | backend | геоаналитика: зоны покрытия, изохроны времени прибытия, справочник ЧОП | API-шлюз |

## Сквозные сценарии

### История выезда ГБР на инцидент
Аналитик открывает карточку инцидента → переходит в историю назначений → `geo` отдаёт справочник ЧОП → `incident-web` показывает прошлые выезды с названиями ЧОП.
