# incident-web — frontend

> Генерируется. Правки руками затираются.
> Заметки человека — в `services/manifest.yaml`, поле `notes`.

**Назначение.** Веб-интерфейс для работы с инцидентами: просмотр списка, управление назначением групп быстрого реагирования (ГБР), отслеживание ситуации через карту покрытия, управление уведомлениями.

## Что умеет для пользователя
| Возможность | Для кого |
|---|---|
| Просмотреть список инцидентов с фильтрацией по статусу, типу, периоду, ЧОП | Аналитик, диспетчер |
| Открыть детали инцидента: адрес, время, тип, назначенная ГБР, история статусов | Аналитик, диспетчер |
| Назначить ГБР инциденту | Диспетчер |
| Просмотреть карту зон покрытия ЧОП и расчёты времени прибытия | Аналитик, диспетчер |
| Управлять каналами уведомлений | Аналитик, диспетчер, зритель |

## Стек
| Слой | Чем |
|---|---|
| Язык и фреймворк | React, React Router |
| Состояние | Zustand, @tanstack/react-query |
| Сеть | Axios |
| UI | MUI |

## Экраны
| Роут | Экран | Что делает пользователь |
|---|---|---|
| `/incidents` | Список инцидентов | фильтрует по статусу, типу, периоду, ЧОП; открывает карточку |
| `/incidents/:id` | Карточка инцидента | смотрит адрес, время, тип, назначенную ГБР, историю статусов; переходит на назначение ГБР |
| `/incidents/:id/assign` | Назначение ГБР | выбирает ГБР из доступных; смотрит расчётное время прибытия; подтверждает назначение |
| `/coverage` | Карта покрытия | просмотр зон покрытия ЧОП; построение изохрон по времени прибытия |
| `/settings/notifications` | Настройки уведомлений | управление каналами уведомлений |

## Потребляемые API
| Сервис | Вызов | Зачем |
|---|---|---|
| `incident-api` | `GET /v1/incidents` | получение списка инцидентов (вне манифеста) |
| `incident-api` | `GET /v1/incidents/:id` | получение деталей инцидента (вне манифеста) |
| `incident-api` | `POST /v1/incidents/:id/assign` | назначение ГБР инциденту (вне манифеста) |
| `billing` | `GET /v1/squads/available` | получение списка доступных ГБР |
| `geo` | `GET /v1/isochrone` | расчёт времени прибытия ГБР |

## Состояние и данные
| Что хранится | Где | Зачем |
|---|---|---|
| Фильтры инцидентов (статус, тип, период, ЧОП) | localStorage через Zustand | сохранение выбора при переходах между экранами |
| Справочники ЧОП и типов инцидентов | кэш @tanstack/react-query, TTL 5 мин | переиспользование на всех экранах |

## Зависит от
| Сервис или система | Зачем |
|---|---|
| `billing` | список доступных ГБР |
| `geo` | расчёт изохрон по времени прибытия |
| `incident-api` | список, детали и управление инцидентами (вне манифеста) |
