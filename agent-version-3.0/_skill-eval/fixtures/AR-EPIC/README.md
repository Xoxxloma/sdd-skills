# Фикстура AR-EPIC — архивация эпика

Проверяет три вещи: рекурсивный сбор спек внутри папки, пропуск уже влитого, подтверждение состава
до вливания.

## Дерево

```
docs/ARS-100/
  decomposition.md
  _foundation/
    technical_specification.md          <- влить
  ARS-101/
    technical_specification.md
    .archived                           <- УЖЕ влито неделю назад, пропустить
  ARS-102/
    technical_specification.md          <- влить
  ARS-103/
    business_requirements.md            <- спеки ещё нет, взять нечего
services/
  manifest.yaml
  auth.md
  geo.md
  incident-web.md
```

> **Детских БТ и эпик-БТ здесь намеренно нет** (раньше README рисовал их — дерево не совпадало с
> диском). Вход `archive-spec` — `technical_specification.md`, бизнес-требования он не читает
> вообще. Класть их сюда значило бы нарушить правило №2 корневого харнесса: не добавляй в фикстуру
> ничего, чего проба не читает. `ARS-103/business_requirements.md` — исключение и несёт нагрузку:
> именно он делает узел «существующим, но без спеки», ради чего и живёт пункт 4 ниже.

## Ожидаемое поведение

1. `Glob docs/**/ARS-100/` находит папку эпика.
2. Внутри собираются три `technical_specification.md`: `_foundation/`, `ARS-101/`, `ARS-102/`.
3. `ARS-101` отбрасывается: рядом лежит `.archived`.
4. У `ARS-103` спеки нет — в список не попадает и в отчёте упоминается как «спеки нет».
5. **До вливания** аналитику перечисляется состав: `_foundation` и `ARS-102`, с пометкой, что
   `ARS-101` уже влит. Ход останавливается до подтверждения.
6. После подтверждения — вливание, затем `.archived` кладётся в `docs/ARS-100/`.

## Ловушка

Метка на эпике накрывает поддерево. Значит после этого прогона у `ARS-103` спека появится уже
«под меткой» родителя, и при следующей архивации её пропустят как влитую, хотя она не вливалась.

Это осознанный размен, а не дефект: метка на эпике — заявление аналитика «уехало всё». Проба
проверяет, что скилл **сказал об этом вслух** на шаге подтверждения, назвав `ARS-103` как узел без
спеки. Молчаливое проглатывание — красный исход.

## Содержимое спек

`_foundation/technical_specification.md` — контракт общего справочника ЧОП, отдаёт `geo`.
`ARS-102/technical_specification.md` — экран истории назначений в `incident-web`, наследует
контракт фундамента без изменения состава.

Обе — со статусом «Готово к разработке» и происхождением 🟢 / 🟡 подтверждено аналитиком, чтобы
проба мерила механику архивации, а не гейт происхождения (его меряет AR-BASIC).
