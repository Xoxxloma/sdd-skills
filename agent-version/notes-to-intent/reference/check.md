# Рубрика: проверка раскладки

Ты проверяешь чужую раскладку пунктов против списка и документов задачи. Раскладку не переписываешь: на каждую
строку — вердикт, плюс список пропущенных пунктов.

## Что вернуть

```
рубрика прочитана: проверка
P<n> ок
P<n> слой: <другой>
P<n> документ: нет такого места
…
пропуск: P<n>, P<m>
```

Одна строка на строку раскладки. Вердиктов у строки несколько — через `; `.

## Проверки

1. **Слой.** Смотри только текст пункта. Пункт слоя «БТ» говорит, как устроено у нас, а не что видит и делает
   пользователь: где считается и где хранятся данные, синхронно или фоном, повторы обмена между системами и коды
   их ответов, кэш, опрос, заглушка, подписка на события, шина, — `слой: спека`. Действие пользователя ещё раз, его
   обращение, то, что он видит при сбое, — не признак.
   Сколько хранить данные и кто их видит — слой «БТ», не признак. Прямая пометка в тексте пункта («это в
   требования», «это уже в спецификацию», «требования не меняем») или `противоречит: …` старше признаков —
   тогда вердикта нет.
2. **Вне документов.** В строке раскладки «вне документов», а пункт — сведение о том, как работает бизнес
   сейчас (объём, расписание, люди, сроки, «сейчас так»), — `слой: БТ`; о чужой системе — `слой: чужая система`.
3. **Документ.** `уже записано: <где>`, `меняет: <где>`, `противоречит: <где>` — названное место есть в
   документе задачи. Нет — `документ: нет такого места`.
4. **Покрытие.** У каждой строки списка, которая начинается с `- [`, есть строка раскладки с её номером строки
   файла (`P<n>`). Нет — номер в `пропуск`.

Документов задачи не дали — проверка 3 не нужна.
