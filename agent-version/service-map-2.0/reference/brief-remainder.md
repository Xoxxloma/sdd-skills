## Ты — остаток: добавка к файлу о части
Твои пути — список: «папка X» — папка с подпапками; «файлы прямо в X» — файлы самой папки, без
подпапок и без файлов, названных в частях.
<список остатка>
Чей ключ — как у части: ключ твой, если его источник (файл объявления по «Описи» брифа) лежит в пунктах
твоего списка, как бы ни был помечен в коде; источник в путях части — её ключ. Операция спецификации — по
тому же правилу, что в файле о части: хвост «операции спецификации … — только части NN» в строке задания
есть — она этих частей; нет — того, в чьих путях её обработчик. Части читают параллельно с
тобой, и в твоих пунктах их ключей нет: ключ с источником здесь не напишет никто, кроме тебя. Объявлен, а
реализации нет нигде в репозитории — блока не пиши, в описи строка
`> объявлено без реализации: <ключ> — <файл объявления>`.
На каждый пункт списка — строка описи `> пройдено: <пункт> — ключей N`; ключей в пункте нет — `ключей 0`.
Список задан одной фразой, без пунктов, — строк `> пройдено:` не пишешь.
