# Markdown в браузере — одна команда

Скрипт `pack.sh` (на Windows — `pack.ps1`) лежит в папке `reference/` рядом с этим файлом. Он собирает файлы
в страницу `.to-html/<набор>/index.html` в текущей папке и открывает её в браузере. На странице — дерево файлов,
оглавление, поиск, схемы Mermaid, экспорт в html и копирование в Confluence или Word. Твоя работа — выбрать путь,
запустить скрипт и пересказать итог.

## Порядок

1. **Что открыть.**
   - В вызове есть путь или имя файла, папки (`docs`, `docs/x.md`) — сразу в скрипт, как есть, без поиска;
     нет такого пути — скрипт ответит `to-html: error not-found`, тогда ищи словами.
   - Сказано словами («заметки про поездку», «README сервиса») — `Glob` `**/*<основа слова>*` (файлы) и
     `**/*<основа слова>*/**` (папки: `Glob` отдаёт только файлы), основа — без окончания («поездк», «заметк»).
     Одно совпадение — оно. Несколько — спроси одной строкой, какое, перечислив пути. Ничего — скажи, что не
     нашёл, и спроси путь.
   - Ничего не названо или просят пустую страницу — без путей.

   Файлы сам не читай: скрипт сам возьмёт соседние файлы папки и то, на что открытый файл ссылается.

2. **Команда** — из корня репозитория, одна, для своей ОС; вторая — только после `error not-found`, с найденным
   путём. Пути — в кавычках, слэши прямые:

   macOS, Linux:

   ```
   bash .gigacode/skills/to-html/reference/pack.sh "<путь>" ["<путь>" …]
   ```

   Windows:

   ```
   powershell -NoProfile -ExecutionPolicy Bypass -File .gigacode/skills/to-html/reference/pack.ps1 "<путь>" ["<путь>" …]
   ```

   Если скиллы установлены в другую папку, путь до `reference/` начинается с неё. Именно через `bash …`, не
   `./…`; на Windows — только `powershell … -File`, не `bash`: там `bash` часто оказывается WSL.

   Тот же путь в этом разговоре уже открывал — добавь `--no-open` (на Windows `-NoOpen`): вкладка уже открыта,
   новую не плоди.

3. **Ответ** — по последней строке вывода, она начинается с `to-html:`. Русские строки над ней бывают
   кракозябрами — на них не опирайся.
   - `to-html: ok …` — «Открыл в браузере: <что открыл>. После правок — снова /to-html, потом F5 во вкладке.
     Если вкладка не появилась — открой: <адрес из `page=` как есть>»
   - `to-html: updated …` — «Обновил — нажми F5 во вкладке.»
   - `to-html: error <код>` или скрипт не запустился — подсказка из таблицы, больше ничего.

| В выводе | Подсказка пользователю |
|---|---|
| `to-html: error not-found` | Такого пути нет — уточни путь. |
| `to-html: error too-many` | В папке больше 2000 файлов — назови папку поуже. |
| `to-html: error no-text` | В папке нет `.md` и других текстовых файлов. |
| `to-html: error no-write` | В текущую папку нельзя писать — запусти из папки, где можно. |
| `bash: command not found`, `'bash' is not recognized` | На macOS и Linux bash есть из коробки — значит, агент запускает команды другой оболочкой; на Windows нужна команда для Windows из шага 2. |
| `running scripts is disabled`, `is not digitally signed`, `выполнение сценариев отключено`, `не имеет цифровой подписи`, любая другая ошибка запуска | Обойтись без скрипта: открыть файл `.gigacode/skills/to-html/reference/viewer/index.html` двойным щелчком и перетащить в окно папку или файлы. |

## Чего не делать

- Не читать файлы набора и не собирать html сам — всё делает скрипт.
- Не править `.to-html/` и файлы в `reference/`.
- Не запускать скрипт повторно «на всякий случай»: один вызов — одна команда.
