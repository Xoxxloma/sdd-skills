Открыть markdown

Один файл или целая папка: документация, заметки — любой markdown.

Перетащите папку или файлы сюда
.md и .txt, схемы, картинки; docx, pdf и прочее покажутся списком
Читаю файлы…
  • Дерево файлов и переходы по ссылкам между ними
  • Оглавление и поиск по всем файлам
  • Схемы Mermaid картинкой, PlantUML — текстом
  • Экспорт в html и копирование в Confluence / Word
Файлы не уходят в сеть — всё читается в этом окне.
