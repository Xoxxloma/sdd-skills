# Рубрика: проверка выкладки

Ты проверяешь выкладку, собранную из ноута аналитика. Форма любая: список, таблица, схема, письмо.
Элементы не переписываешь и своих не добавляешь: на каждый элемент со ссылкой — вердикт.

## Что вернуть

```
рубрика прочитана: выкладка
1 ок
2 нет пункта: 2
3 вид: 3 мысль
…
```

Номер — порядковый номер элемента со ссылкой на пункт `<дата> №<запись>.<позиция>`, считая сверху: строки, клетки
таблицы, подписи связей в схеме. Ссылка элемента — его собственная: в строке — после ` · ` в конце, в таблице — её
клетка, в схеме — подпись связи; у элемента из двух пунктов — обе. Ссылка внутри текста пункта (у спора — на
оспоренный пункт) — часть текста. Заголовки, имена участников, «в ноуте нет» не нумеруешь. Элемент без ссылки, который
что-то утверждает — решение, число, срок, связь между участниками, — строкой `без ссылки: «<элемент>»`; ссылка только на
запись (`<дата> №<n>`, без позиции) — тоже `без ссылки`.
Вердиктов у элемента несколько — через `; `.

## Проверки

1. **Пункт есть.** Строка пункта — `Grep -n "· <ссылка>( ‖|$)"` по ноуту: номер в конце строки, за ним конец строки или
   пометка. Не нашлась — строка без номера (дописана руками): `Read` записи `### <запись>` раздела `## <дата>`, пункт —
   строка `- [` на месте `<позиция>`. Нет и её — `нет пункта: K`. В строке есть `‖` — только проверка 4. В пункте — то,
   что говорит элемент: у связи в схеме — обе стороны и что между ними; у узла, где названо несколько участников, —
   каждый из них. Сведено из двух пунктов, а ссылка одна — `не так: K`. Не о том — `нет пункта: K`.
2. **Вид.** Вид у элемента («решено», «открыто», «сведение», «мысль») — тот же, что у пункта.
   Иной — `вид: K <вид в ноуте>`. Мысль, поданная как решённое, — всегда этот вердикт.
3. **Слова.** Каждое число, имя, срок, код, путь, метод и поле элемента есть в пункте, в тексте под `>`
   той же записи или в её исходнике (строка `> исходник: <путь>` или `> разбор: <путь>` — путь от папки ноута; не нашёлся — от корня репо). Нет — `не так: K`.
4. **Состояние.** В строке пункта есть `‖` — пункт выбыл: иди по номеру последней пометки (строку ищешь как в
   проверке 1), пока не дойдёшь до строки без `‖`. Вердикт — по последней пометке строки элемента, номер — той строки
   без `‖`: `‖ заменён` — `заменён: K → <номер>`; `‖ закрыт` — `закрыт: K → <номер>`;
   `‖ оспорен` — `оспорен: K → <номер>`; на пути `‖ снят` — `снят: K`.

Всё сошлось — `K ок`.
