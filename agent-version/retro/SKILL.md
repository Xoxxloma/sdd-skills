# Ретро последних сессий

Ты ведёшь ретро. Считают и сверяют скрипты из папки `reference/` рядом с этим файлом, моменты по сессиям выписывают
субагенты, ты пишешь итог. Журналы сессий сам не читай и не пересказывай: ты запускаешь скрипты, передаёшь пути
субагентам и пишешь отчёт по проверенной таблице.

Дальше: `<скилл>` — папка этого скилла. Python — `python3`, на Windows — `python`. Скрипты запускай из папки проекта:
по ней ретро находит сессии этого проекта.

## Шаг 1. Подготовка

```
python3 <скилл>/reference/prepare.py
```

Аргумент вызова — папка с журналами: добавь `--sessions <папка>`.

- «Журналов не найдено» — спроси у пользователя один раз, где лежат журналы чата (`.gigacode/projects` в домашней
  папке или папка `chats`), и запусти снова с `--sessions`.
- «сессий этого проекта для разбора нет» — скажи об этом пользователю и остановись.
- Иначе скрипт печатает рабочую папку (`<работа>`) и число заданий. «Сессий мало» — продолжай, но скажи об этом в
  отчёте.

## Шаг 2. Субагенты

Прочитай `<работа>/retro.json`: в `tasks` — задания, у каждого `journal` — имя файла журнала. На каждое задание —
один субагент, **строго по одному**: следующий — после ответа предыдущего. Задание субагенту (подставь полные пути):

> Прочитай задание `<скилл>/reference/brief.md` и журнал `<работа>/<journal>`. Ответь строго по заданию: только
> JSON, без текста до и после. Других файлов не открывай, ничего не записывай, своих субагентов не запускай.

- Ответ запиши как есть, без правок, инструментом записи файла (не командой оболочки) в
  `<работа>/<имя журнала без .journal.txt>.findings.txt`.
- Субагент упал или ответил без JSON — после всех заданий запусти его ещё раз, один раз. Снова нет — оставь без
  ответа: скрипт так и напишет.
- Субагентов нет — выполни задания сам по `brief.md`, по одному журналу за раз, и запиши ответы так же.

## Шаг 3. Сверка

```
python3 <скилл>/reference/merge.py --work <работа>
```

Скрипт отбрасывает моменты без дословной цитаты в журнале и считает, в скольких сессиях был каждый признак. Пишет
`<работа>/moments.md` — таблицу для тебя.

## Шаг 4. Отчёт

Прочитай `<работа>/moments.md` и `<скилл>/reference/report.md` и напиши отчёт в чат по `report.md`. Всё в отчёте —
только из `moments.md`: цитаты, счёт, даты. Чего нет в таблице, в отчёте нет.

## Шаг 5. Уборка

```
python3 <скилл>/reference/prepare.py --clean
```

В рабочей папке копии журналов пользователя — не оставляй их.
