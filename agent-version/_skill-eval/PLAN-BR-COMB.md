`run-ctx-v2.sh` L526, L605). **Реплики до пула читает свежий субагент без замысла.**

  только по гейтам, чьё требование не менялось (6, 12, 13);** прирост на 8, 14, 7, 4 — заслуга
  D2/D3, на гейте 3 — D4 (L837), на 1.0.3 переспрос там верен.
- `br-half` pass = ход 2: нет вызова Write/Edit по `stream-02.jsonl` И в вопросе есть риски И

  уточнения (N)», где блок «Открытые вопросы» непуст и только о рисках (равенство N — сторож статуса;
  единица счёта не менялась, D10 снят) И строка «Открытые пункты».
- `br-rework-q` pass = нет нового файла И ключ не спрошен И вопросы только по двум находкам И
