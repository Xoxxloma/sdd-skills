### 1.2 Правка существующих фикстур — главная статья цены

Новый гейт открыт → реплика «ответил на всё» его не закрывает → агент (верно) спрашивает:
- пробы, ждущие файл, краснеют: `br-open-w`, `br-roles-w`, `br-var`, `br-yes`, `br-cut`,
  `br-half` (ход 3), `br-nocrit` (ход 3);
- пробы, ждущие вопрос по одному пункту, **зеленеют даром** — вопрос задан, но не потому:
  `br-nocrit2`, `br-nccan`, `br-ncl`, `br-nclap`, `br-nclib`, `br-ncr`, `br-half` (ход 2).

→ В реплики этих 13 проб (у одноходовых проб-«ПРОДОЛЖЕНИЙ» `br-yes`, `br-cut` — в сам промпт) — по
одной фразе, закрывающей гейты 15–17 («с данными: только заявка и
сотрудник, оба уже есть»; «сейчас делают вручную в таблице»; «внешних зависимостей нет»). Правка —
**одна на раунд**, сразу под все три гейта: в батче A лишние две фразы безвредны. Перед правкой
сверить каждую пробу по её README. Реплики после правки читает свежий субагент без замысла.
**База меряется заново** на правленых репликах — старая несравнима.

Одноходовые пробы вопросов (`br-open-q`, `br-ctx`, `br-real`, `br-limit`, `br-roles-q`) не правятся,
но новый гейт занимает место в батче первого хода → риск вытеснить измеряемую гипотезу. Это сторожа.
