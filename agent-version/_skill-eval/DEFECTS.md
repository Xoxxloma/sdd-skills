## Как этим пользоваться

Берёшь одну строку — заводишь под неё круг по правилам из `PLAN-CONTEXT-2.md`: одна правка, один
критерий, десять прогонов. Не берёшь две сразу и не чинишь по дороге то, что попалось на глаза:
