**Гейт (Шаг 4, второе, маркерный):** маркер сущностей по коду = 0 → это нижняя граница, «маркер дал ноль — сверки нет». Гейт по этому классу не применяется.

**Сверка сверху («Сущности»):** маркер = 0, блоков `###` в «Владеет данными» — 4 (>0), формально это случай «добор на все блоки». Проверяю исключение двумя грепами по строкам сущностей:

- греп 1 `\([^)]*\)\s*$` — все 4 строки заканчиваются на `(...)`, совпадение есть: `(@Schema)` у всех четырёх.
- греп 2 (маркер таблицы) `\(@Entity|\(@Table|\(model\b` — среди этих четырёх строк совпадений 0 (`@Schema` не входит в набор).

Строки сущностей есть, а с маркером таблицы — ни одной → это ровно исключение из правила: «маркер вне таблицы (Mongo и подобные), сверки нет». Добор по верхней сверке не нужен.

**Сущности у ручек:** в обоих показанных блоках строка `сущности:` присутствует и ссылается на имена из «Владеет данными» этой же карточки (`Order`, `Customer` — оба в списке). По выдержке расхождений нет, добора не требует.

Итог: ни один из двух пунктов добора не требует.
