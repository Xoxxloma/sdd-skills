**Гейт (нижняя граница):** маркер сущностей по коду — 0 → по правилу «маркер дал ноль — сверки нет» здесь не сверяю. Это не выявляет проблему, а лишь снимает нижнюю проверку.

**Верхняя сверка (сущности):** маркер = 0, блоков «Владеет данными» — 18 (> 0). Проверяю исключение: грепом `\([^)]*\)\s*$` по строкам сущностей в описи (`NavigatorRequestFilter — dto/NavigatorRequestFilter.java` и т.д.) — ни одна строка не заканчивается скобочной группой, совпадений 0.
