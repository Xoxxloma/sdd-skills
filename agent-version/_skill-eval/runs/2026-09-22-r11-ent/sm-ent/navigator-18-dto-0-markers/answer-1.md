**Гейт по маркеру (нижняя граница):** маркер сущностей по коду = 0 → это нижняя граница, сама по себе гейт не запускает («маркер дал ноль — сверки нет»). Проверяем верхнюю сверку.

**Сверка сверху:** маркер сущностей по коду = 0, блоков `###` в «Владеет данными» = 18 (не ноль) → правило требует добор на все блоки, если не сработало исключение.

Проверяю исключение двумя грепами по данным строкам описи. Строки сущностей в описи имеют вид `Имя — dto/Имя.java` — ни одна не оканчивается `\([^)]*\)\s*$` (нет замыкающей скобки с маркером). Первый греп даёт 0 совпадений, значит формального «строки сущностей есть» (в смысле грепа) не выполняется — исключение «маркер вне таблицы, Mongo и подобные» не применяется. Falls через на дефолт: добор нужен по всем 18 блокам.

«Сущности у ручек» отдельно проходит формально — во всех показанных блоках контракта строка `сущности:` есть и ссылается на имена, присутствующие в «Владеет данными» (выдумок нет), но это не отменяет добор выше: сами эти имена — DTO без маркера хранения.
