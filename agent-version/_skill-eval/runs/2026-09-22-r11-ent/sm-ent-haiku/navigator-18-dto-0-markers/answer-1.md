## Сверка сверху (сущности в описи)

**Маркеров сущностей по коду:** 0
**Блоков `###` в «Владеет данными»:** 18

Правило: блоков не должно быть *больше* маркеров. 18 > 0 — **нарушено**.

**Проверка исключения:** маркер вне таблицы (Mongo и подобные) — проверяется двумя грепами по описи:
- Строки с формой `\([^)]*\)\s*$` (скобки в конце): 0 совпадений
- Из них с маркером `@Entity|@Table|model`: 0

Исключение требует наличия информации о маркерах в описи (в виде скобок). Её нет, поэтому исключение не применяется. Плюс все классы в `dto/` — это явные признаки DTO ответов, не сущностей хранения.
