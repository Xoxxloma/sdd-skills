**Проверка по пяти пунктам гейта (ответ на добор):**

1. **Ключи.** Заголовки блоков: `` `Shipment` `` (сущность в бэктиках), `сообщение «события отправления»`, `ограничение «приём отправлений партнёра отключён»` — все три формы верные, «письма»/«события»/голой подписи нет. Блок объекта один. Сошлось.

2. **Состав.** Блоков-сущностей по строкам `состояние:` — 1 (`Shipment`), в карточке 1 блок — сошлось. Ограничений по строке `ограничение:` — 1, в карточке 1 блок — сошлось. Сообщений: в описи две строки (`«груз доставлен»`, `«груз задержан»`), в «Событиях» два блока `публикует` (`shipment.delivered`, `shipment.delayed`) — итого нужно ≥2 блока сообщений. В карточке сообщение-блок один — «события отправления», объединивший оба топика и обоих получателей в одну запись. 1 < 2 по обеим меркам. **Не сошлось** — добор не выполнен по существу: вместо добавления второго блока субагент слил два разных вида сообщения (разные получатели, разные токены) в один.

3. **Значения.** Форма списком, не таблица. У `Shipment.status` три значения в строке `состояние:`, в блоке три строки (`NEW`/`ASSIGNED`/`DELIVERED`), без задвоенных правил на одно значение, токен — сам по себе. Сошлось (эта часть добором не менялась).

4. **Код.** Вне бэктиков в новом блоке нет пути, HTTP-глагола, camelCase или точечной цепочки. В бэктиках — только имена топиков (`shipment.delivered`, `shipment.delayed`), заголовок сообщения без бэктиков. Сошлось.

5. **Хозяин.** Блок ограничения не менялся — хозяин `partner-registry`, имя из манифеста. Сошлось.

**Важно про бюджет:** это уже второй прогон субагента для `shipping` (первый ответ + этот добор) — бюджет на сервис исчерпан. Расхождение сейчас — по пункту 2 (Состав), а не по пункту 4 (код), то есть под единственное исключение бюджета («второй добор по строкам с кодом») не подпадает.
