**1. Ключи.** Четыре `###`: `Shipment` в бэктиках, два `сообщение «...»`, один `ограничение «...»` — все заголовки соответствуют форме, лишних меток и `Сущность.поле` нет. Блок объекта один — только `Shipment`. Сошлось.

**2. Состав.** Блок-объект один — сущностей в `состояние:` тоже одна (`Shipment`). Сообщений в карточке теперь 2 (доставлен + задержан) — строк `сообщение:` в описи 2, блоков `публикует` в «Событиях» тоже 2: не меньше в обе стороны. Ограничение одно — строка `ограничение:` одна. Чужая сущность (`Attachment`) и справочники (`packageType`, `kind`) блоков не получили — верно. Сошлось.

**3. Значения.** «Владеет данными» — построчно `- поле: тип`, не таблица. В блоке `Shipment` три строки на три значения `status` (`NEW`/`ASSIGNED`/`DELIVERED`), дублей правила на разных значениях нет, «не определено» не потребовалось — все три перехода описаны. Токен в каждой строке — одно из значений, дат-исключений нет, посторонних имён полей нет. Сошлось.

В бэктиках — только значения перечисления (`NEW`, `ASSIGNED`, `DELIVERED`), имена топиков (`shipment.delivered`, `shipment.delayed`) и имя сервиса из манифеста (`partner-registry`). Заголовки сообщений без бэктиков. Сошлось, добор не нужен.
