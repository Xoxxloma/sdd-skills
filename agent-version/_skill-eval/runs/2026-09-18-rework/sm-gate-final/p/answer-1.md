**2. Состав.** Строка состояние: одна (`Shipment.status`) → блоков-сущностей должно быть 1, в карточке 1 (`Shipment`). Сообщений: строка `сообщение:` одна и блок «публикует» в Событиях один → в бизнес-правилах один блок сообщения. Ограничений: строка одна → блок один. Числа сошлись.

**3. Значения.** «Владеет данными» — таблиц `| Поле | Тип |` нет вовсе (списком через `-`), но это отдельный вопрос не гейта здесь; смотрю по существу правила 3.
