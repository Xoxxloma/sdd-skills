Ограничений — 1, строк `ограничение:` — 1. `Attachment` (только `справочник:`) блока не имеет — верно. Сошлось.

**3. Значения.** «Владеет данными» даёт значения через `|` в строках `- поле:` для `status` и `packageType` — форма верная. В блоке `Shipment` 4 строки на 3 значения строки `состояние:`; лишняя — «переназначено (`ASSIGNED`, `assignedAt` сдвинут)», это ровно разрешённое исключение (дата рядом с токеном, как в примере «продлена»), не заполнитель — текст правила отличается от «назначено». Токены строк — все из множества `NEW`/`ASSIGNED`/`DELIVERED`. Сошлось.

В бэктиках — только значения перечисления (`NEW`, `ASSIGNED`, `DELIVERED`), топик (`shipment.delivered`), имя сервиса из манифеста (`partner-registry`) и разрешённая дата-исключение (`assignedAt` сдвинут — это и есть тот самый один случай из трёх, дозволенный правилом 3).
