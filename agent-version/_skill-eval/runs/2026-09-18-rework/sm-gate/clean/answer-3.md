**2. Состав.** Блоков объектов 1 = строк `состояние:` в описи (1, `Shipment`). Сообщений 1 = строк `сообщение:` (1) и = блоков «публикует» в «Событиях» (1, `shipment.delivered`). Ограничений 1 = строк `ограничение:` (1). Перечисление `Attachment.kind` в опись попало как справочник, `weightKg`/`url` — не перечисления, пропусков нет. Сошлось.

**3. Значения.** В блоке `Shipment` три строки (`NEW`/`ASSIGNED`/`DELIVERED`) = трём значениям из строки `состояние:` («значений 3»); каждый токен — значение в бэктиках рядом со словом, два токена через `/`,`|`,`,` в одной строке нет. Сошлось.
