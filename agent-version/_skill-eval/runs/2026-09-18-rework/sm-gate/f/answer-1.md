**1. Ключи.** Все три `###` секции: `` `Shipment` ``, `сообщение «груз доставлен»`, `ограничение «приём отправлений партнёра отключён»` — все начинаются ровно с разрешённых форм. Сошлось.

**2. Состав.** Блоков объектов — 1, строк `состояние:` в описи — 1 (`Shipment`). Сообщений в блоке — 1, строк `сообщение:` — 1, блоков `публикует` в «Событиях» — 1. Ограничений — 1, строк `ограничение:` — 1. Сошлось.

**3. Значения.** У `Shipment.status` в «Владеет данными» — 3 значения через `|`, в блоке `Shipment` — 3 строки состояния (`NEW`/`ASSIGNED`/`DELIVERED`), это ≥3 — ок. Но четвёртая строка блока — «тип упаковки (`BOX` / `PALLET`) — задаётся при создании»: два токена в одной строке через `/`, а `packageType` в описи заявлен как `справочник:`, не `состояние:`. Это ровно случай «справочник, записанный состоянием» — расхождение.

**4. Код.** Ни одна строка секции не даёт совпадений по пяти регекспам (camelCase, `GET/POST/...`, ` /[a-z]`, трёхчастный dotted-lowercase, бэктики в заголовке сообщения). Сошлось.

**5. Хозяин.** В блоке ограничения — `partner-registry`, это имя сервиса из манифеста. Флагов `true`/`false` как состояния нет. Сошлось.
