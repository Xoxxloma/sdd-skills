# Профили форматов расшифровки

Исходник не переписываешь и не нормализуешь. Профиль говорит, где в строке время, говорящий и канал.
**Якорь** любой ссылки — номер строки файла (`L57`), плюс время и говорящий, если формат их несёт.

| Формат | Признак | Ссылка | Особенности |
|---|---|---|---|
| чат встречи | `ГГГГ-ММ-ДД чч:мм:сс - Фамилия Имя[ Отчество][ [B]][ (распознано)]: текст` | `L57 11:07:01 Фамилия [B]` | `(распознано)` — речь через распознавание; без пометки — **набрано в чате руками**: опора для кодов и ссылок. `[B]` — внешний участник, это не роль |
| VTT | `WEBVTT`, `00:01:02.000 --> 00:01:05.000`, `<v Имя>` или `Имя:` | `L210 00:12:31 Имя` | якорь — первая строка текста реплики |
| SRT | номер блока, `00:01:02,000 --> …` | `L88 00:01:02` | говорящего обычно нет |
| «Имя  0:01» | строка «имя время», текст ниже | `L88 0:14 Имя` | |
| конспект | списки и абзацы без времени | `L12` | говорящих может не быть: решающий неизвестен |
| текст из сообщения | — | цитата без строки | только короткий |
| ноут аналитика | шапка `тема:`, строка `# Ноут:`, разделы `## ГГГГ-ММ-ДД`, записи `### <№> · …` | `L57 2026-10-14 №3` | разбираешь только пункты `- [вид] …`; строки `> ` под ними — опора цитат. Говорящий — `решил:`, `ждёт:`, `со слов` пункта. `[решено]` — решение, принял — `решил:`; `[мысль]` и `[набросок]` — слова аналитика: вид «открытый вопрос» с пометкой «(со слов аналитика)». Позднее слово — только `вместо: <дата> №<n> «<начало пункта>»`: заменённый — пункт записи <дата> №<n> с таким началом, вид «отменено»; два расходящихся пункта без `вместо:` — открытый вопрос. `отвечает на: <дата> №<n> «<начало вопроса>»` закрывает тот `[открыто]`: записи «открытый вопрос» по нему нет, есть запись ответа. Строка `> исходник: <путь>` — исходник записи (путь от папки ноута), опора цитат и там. Текст ноута — опора для кодов и латиницы, как набранное в чате |

- Подряд идущие строки одного говорящего — одна реплика: цитата может занимать `L57–L60`.
- Метка `[B]`, `(распознано)` и подобные в цитату не входят.
- BOM в начале файла пропускай. Видишь кракозябры вместо букв — стоп: «пересохраните в UTF-8».
- Ни один профиль не подошёл — читай как конспект.
- Протокол по памяти (`> Источник: память аналитика`): вопрос «<тема>: это звучало на встрече или ваша
  мысль сейчас?», на который аналитик ответил «Моя мысль», говорит, что <тема> — не встреча. Записи по ней
  нет: в `отброшено` строкой «L<n> — мысль аналитика: <тема>», где L<n> — строка ответа.
