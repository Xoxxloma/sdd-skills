# Рубрика: проверка разбора

Ты проверяешь чужой разбор встречи против расшифровки. Записи не переписываешь и своих не
добавляешь: на каждую — вердикт, плюс список пропущенных строк.

## Что вернуть

```
рубрика прочитана: проверка
#1 ок
#2 цитаты нет: L<n>
#3 переиграно L<n>
#4 без опоры: <токен>
…
пропуск: L<n>, L<m>
```

Одна строка на запись. Вердиктов у записи несколько — через `; `.

## Проверки

1. **Цитата.** Прочитай `Read` строки L−2…L+2 вокруг названной и сравни цитату с текстом (метки
   формата не в счёт, `…` — пропуск) дословно: порядок слов и словоформы — как в строке. Не сошлась —
`цитаты нет: L<n>`, по каждой такой цитате.
2. **Вид.** У решения в цитатах есть принятие другим участником или строка итога. Нет — `не решение`.
   У условного есть оговорка, у открытого — слова, что ответа нет. Нет — `вид: <какой по цитатам>`.
3. **Позднее слово.** Возьми 2–4 слова предмета, включая формы на слух, и найди их `Grep` с `-i`
   после последней цитаты записи. Реплика ниже даёт по тому же вопросу **другой ответ** —
   `переиграно L<n>`. Временное решение по открытому вопросу («на время так, потом поменяем») — не
   другой ответ: вопрос остаётся открытым, решение стоит в его поле `до ответа`, вердикта нет.
4. **Опора.** Каждое число, код, номер требования или раздела, латинское слово, имя поля, метода или
   инструмента в `суть` есть в документе задачи или в строке, набранной в чате. Цитата распознавания —
   опора только для чисел. Нет — `без опоры: <токен>`.
5. **Слой.** Смотри только `суть`. В записи слоя «БТ» нет признаков реализации: сервер, фронт, бэк,
   запрос, код ответа, повтор, синхронно, фоном, хранится, кэш, опрос, заглушка. Есть — `слой: спека`.
   Прямая пометка в цитатах («это в требования», «это уже в спецификацию», «требования не меняем»)
   старше признаков — тогда вердикта нет.
6. **Документ.** `уже записано: <где>`, `меняет: <где>`, `противоречит: <где>` — названное место есть
   в документе задачи. Нет — `документ: нет такого места`.
7. **Покрытие.** Найди `Grep` с `-i` в строках темы и итога маркеры: «итого», «записываю»,
   «записала», «пометили», «решили», «договорились», «открытый вопрос», «вопрос открытый», «в спеку»,
   «в бэклог», «вне проекта», «не берём». Каждая найденная строка должна быть цитатой или строкой
   `итог` какой-то записи, или стоять в разделе «Отброшено». Иначе — в `пропуск`.

Документ задачи не дали — проверки 4 и 6 только по чату.
