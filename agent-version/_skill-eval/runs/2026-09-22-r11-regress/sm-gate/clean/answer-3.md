## Гейт «Бизнес-правила» — `shipping`

**1. Ключи.** Три `###`: `` `Shipment` `` (сущность в бэктиках), `сообщение «груз доставлен»`, `ограничение «приём отправлений партнёра отключён»` — все три формы разрешены, один блок на сущность. Сошлось.

**2. Состав.** Опись: 1 строка `состояние:` (Shipment) → карточка даёт ровно 1 блок сущности. Опись: 1 `сообщение:`, «События» дают 1 `публикует` → карточка даёт 1 блок сообщения (1≥1, 1≥1). Опись: 1 `ограничение:` → карточка даёт 1 блок. Attachment и оба справочника (`packageType`, `Attachment.kind`) блоков не получили — верно, справочник блока не имеет. Сошлось.

**3. Значения.** Строка `состояние:` даёт 3 значения (NEW|ASSIGNED|DELIVERED) → в блоке Shipment ровно 3 строки, каждая с одним токеном-значением в бэктиках, повторов правил на разных значениях нет. Сошлось.

**4. Код.** Вне бэктиков в секции — только русский текст, ни один из четырёх грепов не совпадает. В бэктиках — только значения перечисления (`NEW`/`ASSIGNED`/`DELIVERED`), имя топика (`shipment.delivered`) и имя сервиса из манифеста (`partner-registry`); заголовок сообщения без бэктиков. Сошлось.

**5. Переключатель.** Блок ограничения называет `partner-registry` — это имя есть в списке манифеста (`shipping`, `partner-registry`, `dispatch-web`). Сошлось.
