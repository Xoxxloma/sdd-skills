**1. Ключи** — заголовки: `` `Shipment` `` — отправление, `сообщение «груз доставлен»`, `ограничение «приём отправлений партнёра отключён»`. Все три в допустимой форме (сущность в бэктиках / `сообщение «` / `ограничение «`). Сошлось.

**2. Состав** — опись: 1 строка `состояние:` (Shipment), 2 строки `справочник:` (блока не получают), 1 `сообщение:`, 1 `ограничение:`. Карточка: 1 объектный блок (`Shipment`), 1 блок сообщения, 1 блок ограничения, `публикует shipment.delivered` в «Событиях» — 1 (не меньше строк `сообщение:`). Числа сошлись.

**3. Значения** — блок `Shipment`: строка `состояние:` даёт 3 значения (NEW/ASSIGNED/DELIVERED), в блоке 4 строки — по одной на каждое значение состояния плюс четвёртая: «коробка (`BOX`), паллета (`PALLET`) — тип упаковки, задаётся при создании». Это справочник `packageType`, вписанный в блок состояния строкой с двумя токенами через запятую — ровно случай «справочник, записанный состоянием». Справочник своего блока не имеет и в блок состояния втискиваться не должен. Не сошлось.

**4. Код** — вне бэктиков во всей секции нет ` /[a-z]`, `GET/POST/...`, camelCase, точечных путей. В бэктиках только значения перечислений (`NEW`, `ASSIGNED`, `DELIVERED`, `BOX`, `PALLET`), топик (`shipment.delivered`) и имя сервиса из манифеста (`partner-registry`). Заголовок сообщения без бэктиков. Сошлось.

**5. Переключатель** — в блоке ограничения назван `partner-registry`; это имя входит в список манифеста (`shipping`, `partner-registry`, `dispatch-web`). Сошлось.

ГЕЙТ: ДОБОР — в блоке `Shipment` секции «Бизнес-правила» убрать строку про `packageType` (`BOX`, `PALLET`) из состава значений состояния: это справочник, записанный как строка состояния с двумя токенами через запятую, а справочник своего блока/строк в «Бизнес-правилах» не получает.
