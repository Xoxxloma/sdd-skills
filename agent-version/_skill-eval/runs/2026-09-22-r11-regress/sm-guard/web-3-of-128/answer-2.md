## Расчёт гарда

**Класс: потребляемые API**
- было = 128
- исчезло = 3 (`billing`·GET /projects/0/estimate, `billing`·GET /projects/1/estimate, `billing`·GET /projects/2/estimate)
- появилось = 0
- порог: исчезло ≥ 3 (да, 3≥3) **и** 3·исчезло > было → 3·3=9 > 128 → **нет**
- условие не выполнено → порог по этому классу не сработал

Остальные классы (контракт, сущности, задачи, топики, экраны, роли, зависит от) в исходных данных не представлены — считаю, что по ним ключи не менялись (было=исчезло=появилось=0), порог не срабатывает.

Ни по одному классу условие маршрута не выполнено → продвижение поверх, исчезнувшие ключи — именами в отчёт Шага 6:
