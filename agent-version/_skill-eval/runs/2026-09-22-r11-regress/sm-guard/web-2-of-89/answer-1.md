## Гард — расчёт по классам

**потребляемые API**
- было = 89
- исчезло = 2 (`billing` · GET /projects/0/estimate, `billing` · GET /projects/1/estimate — присутствуют в прежней карточке, отсутствуют в черновике)
- появилось = 0 (все ключи черновика — подмножество прежних)
- порог: исчезло_c ≥ 3? 2 ≥ 3 — нет. Условие не сработало.
- опустело: класс табличный (первая+вторая колонки), не блочный — «опустело» к нему не считается.

Остальные классы (контракт, сущности, задачи, топики, экраны, роли, зависит от) в вводных не даны — по ним ключи не менялись, порог не проверяется.

Ни по одному классу условие маршрутизации не выполнено (2 исчезнувших ключа не достигают порога в 3, да и 3·2=6 не превышает было=89).
