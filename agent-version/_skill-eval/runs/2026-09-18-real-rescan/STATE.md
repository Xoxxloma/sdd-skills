# Раунд 2026-09-18-real-rescan — рескан repairy поверх карточек в старой форме (таблицы, перевёрнутые ключи)

SM-REAL, плечо `rescan`, sonnet, по 4 прогона × 4 параллельно, три круга: `real-rescan` (текст 1.5.0
из коммита `7e8a98c`), `real-rescan-2` (+ две правки), `real-rescan-3` (+ третья). Прежние карточки —
новая фикстура `SM-RESCAN-TABLE`: карточки BR-REAL, у `repairy-api` «Владеет данными» таблицей
`| Поле | Тип | Описание |` без значений перечислений (10 перечислений стали `…Enum`) и два
заголовка «Бизнес-правил» перевёрнуты. Так выглядел весь слепок прода с июля. Грейдеры:
`grade-sm-rescan-form.mjs` (форма: таблиц, перечислений со значениями, заголовков не с ключа, доля
дословных строк против `_prev/`) и `grade-sm-real.mjs` (бизнес-счётчики; научен видеть `rescan-*`).

**Вопрос раунда.** Правило 2 прежней карточки «формулировка прежняя, форма по шаблону» — работает ли
оно на живой репе: выйдет ли «Владеет данными» строками со значениями, останутся ли формулировки, и
что при этом делает ведущий.

## Круг 1 — текст 1.5.0

| Песочница | Таблиц | Перечислений со значениями | Ключ не первым | Дословно | Что сделал ведущий |
|---|---|---|---|---|---|
| rescan-1 | 0 | **10** | 0 | 229/229 | гейт поймал 3 нарушения, добор субагенту — вернул форму шаблона; гард api 0 исчезло; web по гарду не записан (8 ключей «исчезли») |
| rescan-2 | 0 | 0 | 0 | 226/229 | добор субагенту — список вместо таблицы, но `status: StatusEnum` без значений; гейт пропустил |
| rescan-3 | 0 | 0 | 0 | 228/229 | **переписал таблицу сам** «тем же содержанием», значений нет; **гард пропущен** — записал раньше, чем снял ключи |
| rescan-4 | 0 | 0 | 0 | 229/229 | как rescan-2 |

Субагент **во всех четырёх** вернул таблицу первым ответом: правило 2 в брифе форму не переломило.
Гейт 3 ведущего таблицу поймал **4/4** — гейт работает. Дальше три исхода из четырёх — кривые.
Бизнес-счётчики по всем четырём — годные (объектов 7–8/8, сообщений 14/14, кода 0, анкеров в слое
7/8); «токенов не из «Владеет данными» 14» у трёх — следствие отсутствующих значений.

**Правки после круга 1:** (а) правило 2: тип-перечисление без значений (`status: StatusEnum`) — тоже
не форма шаблона; (б) шапка гейта: добор — это повторный запуск субагента, ведущий не переписывает
ни строки, даже «тем же содержанием».

| rescan-4 | ✅ то же | 219/229 | то же |
| rescan-2 | прежняя карточка нетронута | 229/229 | добор вернул форму, но **потерял `GET /api/metrics` и префикс `/api` у всех 96** — пересчёт поймал, бюджет из двух прогонов кончился, **карточка честно не записана** |
| rescan-3 | прежняя карточка нетронута | 229/229 | то же: добор вернул форму и потерял ключи, web слил три строки кэша — не записана ни одна |

Ведущий больше не чинит сам — **0/4** (было 1/4), гард считается **4/4** (было 3/4), пересчёт после
добора ловит потери добора. Цена: форма выправляется ценой добора, а добор на карточке в 1000 строк
теряет ключи в половине случаев → **2/4 не записаны**. На проде это выглядит как «рескан ничего не
сделал».

**Правка после круга 2 (в):** ведущий проверяет форму прежней карточки двумя грепами ДО запуска
субагента и называет ему в брифе, что именно не по форме, — чтобы форма выправлялась первым
прогоном, а не добором.

Записаны **4/4** (было 2/4), доборов по api **2** вместо 4, форма со значениями **3/4** (было 1/4 и 2/4),
ведущий сам не чинит 0/4, гард считается 4/4. Единственный промах — значения перечислений остались
именем типа в одной песочнице из четырёх: субагент даже заменил фиктивный `StatusEnum` фикстуры на
настоящее имя типа из кода, но значения не выписал, и гейт 3 это пропустил.

## Итог

Три круга по четыре прогона на одной фикстуре, три правки по одной фразе:

| Круг | Форма со значениями | Записано | Ведущий чинит сам | Гард посчитан |
|---|---|---|---|---|
| 1 (1.5.0) | 1/4 | 4/4 | 1/4 | 3/4 |
| 2 (+ тип без значений — не форма; добор — субагент) | 2/4 | 2/4 | 0/4 | 4/4 |
| 3 (+ форма прежней карточки проверяется до запуска) | **3/4** | **4/4** | 0/4 | 4/4 |

Правило 2 в брифе субагента форму само не ломает ни в одном круге: субагент воспроизводит прежнюю
форму, пока ведущий не назовёт её нарушением явно. Держит форму связка «проверка до запуска + гейт 3
+ добор субагенту». Остаток — «тип без значений» в гейте 3 — одна песочница из четырёх.

**Чего раунд не говорит.** repairy-api — 1000 строк карточки, consolidate прода — больше; потеря ключей
добором на нём вероятнее. Формулировки (правило 2) держатся во всех кругах: 96–100 % строк вне
«Владеет данными» дословно.
