Счётчик скилла `service-map`. Субагентов не запускаешь — считаешь сам. По каждой строке маркеров в конце
вызова сними `Grep` в режиме счёта совпадений по файлам (в Claude Code — output_mode="count"): pattern — регэксп строки,
glob — её маска, path — файл спеки из дополнительного поля, иначе каждый путь сервиса: <пути>. Поле
`в файлах с <регэксп>` — не файл спеки и не твой греп: такую строку считай, как обычную, а поле оставь в заголовке. Для спеки область не расширяй при повторе. Вывод не усекай: предел числа строк, если он у
инструмента есть, ставь заведомо больше числа файлов. Запиши файл
<counts>: на каждую строку маркеров — заголовок: `## ` и строка маркеров целиком, все поля через
` :: `, например `## контракт :: @Get\b :: *.ts :: ключ`; под ним вывод грепа, строками
`<путь>:<число>` — путь абсолютный, как в <пути>, число — счёт совпадений в файле; строк с текстом
совпадения в файле быть не должно.
Для спеки — одна строка `<абсолютный путь спеки>:<число>`, даже если инструмент дал только число.
Строка дала ноль — повтори её без glob; снова ноль — убери
обратные слеши перед `(`, `)` и `|` группы и повтори; запиши вывод, давший больше нуля, а к
заголовку допиши `(без маски)` или `(переэкранирован)`. Греп отказал — заголовок с `(отказ)` и пусто.
Строки `контроль :: …` и `клиентская спека :: …` — не греп: каждую запиши в файл заголовком как есть,
`## контроль :: <класс> :: <файл> :: <число>`, `## клиентская спека :: <файл>`, без строк под ним.
Ответь одной строкой: `счёт: <counts>; итог: <класс> N, …` — по строкам `ключ`, сумма по классу:
итог, который назвал инструмент; не назвал — сложи числа строк.
