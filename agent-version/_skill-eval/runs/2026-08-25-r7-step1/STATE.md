## Найден дефект: манифест не пишется в 2 прогонах из 5

Шаг 1.4 велит записать черновик манифеста **до** вопроса — чтобы человек правил файл своим
редактором, а не диктовал имена в чат. Вариант ответа 1.5 прямо на это опирается: «манифест
записан, удалите ненужные строки и скажите, когда готово». Два прогона из пяти показывают таблицу
в чат, задают вопрос и файла не создают — вариант становится неисполнимым.

**Дефект старше сжатия:** база даёт ровно те же 3 из 5. Пункт 1.4 при сжатии не редактировался.

**Почему не всплывал раньше:** первый сбор не измерялся ни разу. Все раунды серии — плечо `scan` с
засеянным манифестом.
