## Проверка по пяти числам

**(1) Блоков `###`.** Ожидаю: сущности из «Владеет данными» со строкой-перечислением — `Shipment` (`status`, `packageType`) и `Attachment` (`kind`) = 2, плюс строк `сообщение:` в описи = 1, плюс строк `ограничение:` в описи = 1 → **4**. Фактически в «Бизнес-правилах» блока 3: `Shipment`, сообщение «груз доставлен», ограничение «приём отправлений партнёра отключён». Блока `Attachment` нет. **Не сошлось.**

**(2) Строк `-` в блоке объекта vs значений в опись-строке `состояние:`.** Для `Shipment` в описи `состояние:` даёт 3 значения (`NEW`|`ASSIGNED`|`DELIVERED`), в блоке 3 строки-`-`. 3 ≥ 3 — сошлось для того блока, что есть. Сравнить блок `Attachment` не с чем: он отсутствует и в описи для него нет строки `состояние:` (есть только `справочник:`, а этот тип грепом не берётся).

**(3) Токены в блоках объектов — значения из «Владеет данными».** В блоке `Shipment`: `NEW`, `ASSIGNED`, `DELIVERED` — все стоят справа от `:` в `- status: NEW | ASSIGNED | DELIVERED`. Выдуманных токенов и строк-на-поле нет. **Сошлось.**

**(4) Блоков сообщений vs блоков `публикует` и строк `сообщение:`.** Блоков сообщений — 1, блоков `публикует` в «Событиях» — 1, строк `сообщение:` в описи — 1. 1≥1 и 1≥1. **Сошлось.**

**(5) Блоков ограничений vs строк `ограничение:`.** Блоков ограничений — 1, строк `ограничение:` в описи — 1, совпадает; в блоке нет `true`/`false`, условие названо словами («пока оно действует»). **Сошлось.**

## Причина расхождения

Опись нарушает формат: вместо строки `состояние:` для перечислимых полей `Shipment.packageType` и `Attachment.kind` субагент завёл несуществующий в брифе тип строки `справочник:`, а итог свёл в «состояний 1 (значений 3), **справочников 2**, сообщений 1, ограничений 1» — не тот четырёхчисленный формат `⟹ состояний N (значений K), сообщений M, ограничений L`. Из-за этого под `Attachment.kind` (PHOTO|PDF) и `Shipment.packageType` (BOX|PALLET) не появилось блоков «Бизнес-правила» — ровно тот случай, для которого рассчитан грепный тест (1): проверка идёт по «Владеет данными», а не по самодельной категории субагента.

ГЕЙТ: ДОБОР — переименовать в описи строки `справочник:` (для `Shipment.packageType` и `Attachment.kind`) в `состояние:`, пересчитать итог в форму «состояний N (значений K), сообщений M, ограничений L» без категории «справочников»; добавить блок `### Attachment` в «Бизнес-правила» по значениям `PHOTO`/`PDF` и покрыть значения `packageType` (`BOX`/`PALLET`) строками правил.
