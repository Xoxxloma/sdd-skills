# Манифест при первом сборе: пишется до вопроса (2026-08-25, r8)

Плечо `first`, 5 прогонов. Правка одна, число одно.

## Дефект

Шаг 1.4 велит записать черновик манифеста, 1.5 — задать один вопрос и остановиться. Два прогона из
пяти показывали таблицу в чат, задавали вопрос и файла не создавали. Вариант ответа «сначала уберу
лишние» просит человека открыть манифест своим редактором — без файла он неисполним.

**Механизм виден дословно в отказавших прогонах, и он не про забывчивость.** Один переписал вариант
ответа в будущее время:

> **Уберу лишние** — **напишу** манифест со всеми, удалите ненужные строки

В скилле стоит «манифест **записан**». То есть 1.4 прочитано не как «сделай сейчас», а как «что
произойдёт, если человек выберет второй вариант». Второй прогон сделал наоборот: процитировал
«manifest recorded» дословно, файла не создав, — утверждение о состоянии, которое неверно.

## Правка

**1.4:** «файл пишется СЕЙЧАС, до вопроса, а не после ответа на него», с причиной (без файла второй
вариант неисполним) и с явным закрытием хода мысли отказа: отложить запись «на случай, если
выберут» нельзя — выбор без файла делать не из чего.

**1.5:** слово «теперь» объявлено обязательным, вопрос задаётся после `Write`, второй вариант —
утверждение о сделанном, а не обещание. Промах назван буквально: «напишу манифест, если выберете» —
та же строка в будущем времени, и она означает, что файла нет.

**964 → 971 строка.**

## Результат

| | SKILL.md | манифест записан |
|---|---|---|
| база | 982 | 3 из 5 |
| база после сжатия Шага 1 | 964 | 3 из 5 |
| **после правки** | **971** | **5 из 5** |

База измерена дважды на разных редакциях и дала одно и то же — порог твёрдый, а не случайное «до».

Остальное в Шаге 1 не сдвинулось: четыре сервиса в каждом манифесте, worktree-сосед 4 из 5,
остановка вопросом 5 из 5.

**Статистика:** 3/5 против 5/5 при n=5 даёт p≈0.17 — само по себе не доказательство. Довод к числу
прилагается механический: отказ был именно тем, что правка адресует (будущее время в варианте
ответа), и ни один из пяти прогонов этого больше не сделал.
