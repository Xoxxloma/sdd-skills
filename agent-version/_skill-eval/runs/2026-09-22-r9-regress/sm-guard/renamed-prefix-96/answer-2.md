## Гард — расчёт по классам

**контракт**: было 96, исчезло 96, появилось 96.
Причина: каждый путь сменил префикс `/api/v1/items/...` → `/v1/items/...`, поэтому ни один старый ключ не совпадает ни с одним новым — строкового совпадения нет ни у одной пары.

Порог: исчезло_c = 96 ≥ 3, и 3·96 = 288 > было_c = 96 → условие сработало.

Остальные классы (сущности, задачи, топики, экраны, потребляемые API, роли, зависит от) в исходных данных не даны — грепы по ним не приведены, посчитать нечего.

Появилось (96) ≈ исчезло (96) по одному классу — похоже на переименование (смена префикса `/api/v1/` → `/v1/`), а не на утрату функциональности. Но по формуле это не освобождает от порога: правило всё равно маршрутизирует в `_pending`, а отчёт обязан назвать это переименованием, а не потерей.
