## Гард — расчёт по классам

Данные есть только по одному классу — **потребляемые API**. Остальные классы (контракт, сущности, задачи, топики, экраны, роли, зависит от) в перечнях не приведены — по ним нет утоньшения для расчёта.

**потребляемые API:**
- было = 128
- исчезло = 3 (`billing` · GET /projects/0/estimate, `billing` · GET /projects/1/estimate, `billing` · GET /projects/2/estimate)
- появилось = 0
- опустело = 0 (блока без строк нет — класс без тела блока, только строки таблицы)

Проверка порога: исчезло_c ≥ 3 → 3 ≥ 3 — истина. Но 3·исчезло_c > было_c → 3·3 = 9 > 128 — ложь. Условие требует оба одновременно, значит порог **не сработал**.

Второе условие (опустело) неприменимо — блока с телом здесь нет.

Ни по одному классу порог не превышен → маршрут ПОВЕРХ. Исчезнувшие ключи — именами в отчёт Шага 6: `billing` · GET /projects/0/estimate, `billing` · GET /projects/1/estimate, `billing` · GET /projects/2/estimate.
