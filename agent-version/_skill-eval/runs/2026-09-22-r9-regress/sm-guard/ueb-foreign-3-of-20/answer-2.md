## Расчёт гарда

**Класс: сущности**
- было_сущности = 20
- исчезло_сущности = 3 (Order, Customer, Invoice)
- появилось_сущности = 0
- опустело_сущности = не считается для этого класса (не блок с телом, а список ключей — здесь это фактически список, но по правилу таблицы для класса «сущности» ключ — `###` в «Владеет данными», для «опустело» аналогично нужен подсчёт строк внутри блока; таких данных не дано, поэтому опустело не оцениваю — беру только исчезло/появилось)

Проверка порога:
- исчезло_сущности ≥ 3 → 3 ≥ 3 — верно
- 3·исчезло_сущности > было_сущности → 3·3 = 9 > 20 — **неверно**

Оба условия конъюнкции должны выполняться одновременно («и»), а второе не выполняется → порог по классу «сущности» **не сработал**.

Других классов в данных нет, других ключей на проверку не дано.

Появилось ≈ исчезло? Нет (0 ≠ 3), переименованием не выглядит — просто три сущности пропали без замены.

Итог: ни один класс не превысил порог.
