## Гард по классам

**сущности:** было 19, исчезло 19, появилось 0
- порог: исчезло_c ≥ 3 (19≥3 ✓) и 3·исчезло_c > было_c (57 > 19 ✓) → **сработал**
- появилось (0) не ≈ исчезло (19) → это не похоже на переименование, это чистая потеря класса

**контракт:** было 13, исчезло 0, появилось 0 — порог не сработал

**остальные классы** (задачи, топики, экраны, потребляемые API, роли, зависит от) — ключей по ним не дано, класса «было» нет, порог не считается.

Хотя бы один класс превысил порог (сущности) → маршрут в `_pending`.
