## Гард — расчёт по классам

**Сущности:** было 19, исчезло 19, появилось 0.
Порог: исчезло_c ≥ 3 (19≥3 ✓) и 3·исчезло_c > было_c (57 > 19 ✓) → **порог сработал**.
Не переименование: появилось (0) ≠ исчезло (19), новых ключей нет — компенсации нет, класс просто обнулился.

**Контракт:** было 13, исчезло 0, появилось 0 → порог не сработал.

Прочие классы (задачи, топики, экраны, потребляемые API, роли, зависит от) в перечнях не даны — трактую как было 0 у обоих, порог не применим.

Класс «сущности» пересекает порог → маршрут — `_pending`. Прежняя карточка на диске не трогается; в отчёт идёт строка `ГАРД` с числами (было 19 / исчезло 19 / появилось 0 по сущности) и вопрос человеку: урезали сервис или скан не дочитал сущности.
