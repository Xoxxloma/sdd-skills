**1. Ключи.** Заголовки секции: `### \`Shipment\`` (сущность в бэктиках), `### сообщение «груз доставлен»`, `### ограничение «приём отправлений партнёра отключён»` — все три формы верны. Сошлось.

**2. Состав.** Опись: `состояние:` — 1 строка (Shipment) → 1 блок объекта в карточке — есть. `сообщение:` — 1 строка, `публикует` в «Событиях» — 1 (`shipment.delivered`) → 1 блок сообщения — есть. `ограничение:` — 1 строка → 1 блок ограничения — есть. Перечисления `Shipment.status`, `Shipment.packageType`, `Attachment.kind` из «Владеет данными» все поименованы в описи (состояние/справочник/справочник), непропущенных нет; у справочников (packageType, Attachment.kind) блоков в «Бизнес-правилах» нет — верно. Сошлось.

**3. Значения.** «Владеет данными» — форма `- поле: тип`, по одному полю на строку, без таблиц и слипшихся строк; у перечислений значения через `|` в самой строке `- поле:`. Блок `Shipment` в «Бизнес-правилах» — 3 строки на 3 значения из `состояние: ... NEW | ASSIGNED | DELIVERED`, токен каждой строки — одно из значений (`NEW`, `ASSIGNED`, `DELIVERED`), других имён полей нет, задвоенных правил нет. Сошлось.

**4. Код.** Вне бэктиков в секции «Бизнес-правила» токенов-нарушителей (пути, HTTP-глаголы, camelCase, точечные ключи) не найдено. В бэктиках — только значения перечисления (`NEW`, `ASSIGNED`, `DELIVERED`) и имя топика (`shipment.delivered`) — оба класса разрешены; в заголовке сообщения бэктиков нет. Сошлось.

**5. Переключатель.** Блок `ограничение «приём отправлений партнёра отключён»` не называет переключатель вообще — нет ни имени из манифеста (`shipping`/`partner-registry`/`dispatch-web`), ни роли из «Роли и доступ» (`DISPATCHER`/`COURIER`). Требование гейта — явно назвать, кто условие включает и выключает. Не сошлось.

ГЕЙТ: ДОБОР — в блоке `### ограничение «приём отправлений партнёра отключён»` не назван переключатель; довнести строку вида «переключатель: `<имя из манифеста | роль>`» (кто включает/выключает приём отправлений партнёра) и, при необходимости, синхронно поправить эту же строку в `<опись>`, если она была там для этого ограничения.
