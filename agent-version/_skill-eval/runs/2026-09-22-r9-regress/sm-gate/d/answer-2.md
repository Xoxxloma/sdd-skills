Прогоняю пять чисел гейта «Бизнес-правила» по карточке `shipping`.

1. **Ключи.** Три `###`: `` `Shipment` `` — отправление, `сообщение «груз доставлен»`, `ограничение «приём отправлений партнёра отключён»`. Все три формы верные (сущность в бэктиках / «сообщение «» / «ограничение «»), лишних заголовков нет. Сошлось.

2. **Состав.** Опись: `состояние:` — 1 (Shipment), `сообщение:` — 1, `ограничение:` — 1. Карточка: блоков-сущностей 1 (Shipment; Attachment не входит — у него только справочник `kind`, состояния нет), сообщений 1 (совпадает и с 1 `публикует` в «Событиях»), ограничений 1. Сошлось.

3. **Значения.** «Владеет данными»: `- поле: тип`, по одному полю на строку, оба перечисления (`status`, `kind`, `packageType`) через `|` — форма верная. В блоке `Shipment` (Бизнес-правила) — 3 строки на 3 значения из `состояние: ... (значений 3)`, токены `NEW`/`ASSIGNED`/`DELIVERED` разные, заполнителя нет. Сошлось.

4. **Код.** По всей секции «Бизнес-правила» вне бэктиков — ни путей, ни HTTP-глаголов, ни camelCase, ни точечных ключей. В бэктиках только значения перечисления (`NEW`, `ASSIGNED`, `DELIVERED`) и топик `shipment.delivered` — оба разрешённых класса. Заголовок сообщения без бэктиков. Сошлось.

5. **Переключатель.** В блоке `ограничение «приём отправлений партнёра отключён»` вообще не назван переключатель — только «диспетчер видит причину отказа» (это про то, кто ВИДИТ отказ, а не кто ВКЛЮЧАЕТ условие). Ни имени из манифеста (`shipping` / `partner-registry` / `dispatch-web`), ни роли из «Роли и доступ» (`DISPATCHER` / `COURIER`) как переключателя в блоке нет. При этом и в самой описи строка `ограничение:` тоже без `переключатель: ...` — расхождение с формой описи из брифа. Не сошлось.

ГЕЙТ: ДОБОР — потребую у субагента вписать в блок `ограничение «приём отправлений партнёра отключён»` (и синхронно в строку `ограничение:` описи) явного переключателя по коду `integration/PartnerGate.kt` — кто включает/выключает приём отправлений: если это внешний сервис из манифеста, то `переключатель: partner-registry`, если условие переключает сам `shipping` (например, ролью или своей настройкой) — соответствующая роль из «Роли и доступ»; без факта в коде — `переключатель: не определено`.
