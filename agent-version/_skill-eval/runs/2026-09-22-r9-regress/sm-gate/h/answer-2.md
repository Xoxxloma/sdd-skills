**1. Ключи.** Заголовки: `` `Shipment` `` — отправление, `сообщение «груз доставлен»`, `ограничение «приём отправлений партнёра отключён»` — все три формы разрешены (сущность в бэктиках / «сообщение «» / «ограничение «»). Блок объекта один — для `Shipment`. Сошлось.

**2. Состав.** Строк `состояние:` в описи — 1 (Shipment) → блоков объектов в карточке — 1 (`Shipment`). Сообщений в описи — 1, блоков `публикует` в «Событиях» — 1, блоков сообщения в «Бизнес-правилах» — 1 (1≥1, 1≥1). Ограничений в описи — 1, блоков — 1. Справочники (`packageType`, `kind`) блока не имеют по правилу — и в карточке их нет. Сошлось.

**3. Значения.** «Владеет данными»: `- поле: тип`, одно поле на строку, значения через `|` (`status`, `packageType`, `kind`) — форма верна, не таблица. В блоке `Shipment` строк 4 ≥ значений 3 (NEW/ASSIGNED/DELIVERED); четвёртая строка — законное исключение (дата `assignedAt` сдвинут при том же токене `ASSIGNED`), не заполнитель. Двух токенов через `/`,`|`,`,` в одной строке нет. Сошлось.

**4. Код.** Прогнал четыре грепа по тексту секции «Бизнес-правила» вне бэктиков — ни ` /[a-z]`, ни HTTP-глаголов, ни camelCase, ни `a.b.c`-путей не найдено. В бэктиках — только значения перечисления (`NEW`/`ASSIGNED`/`DELIVERED`), топик (`shipment.delivered`, 2 точки максимум — не триггерит `{2,}`), имя сервиса (`partner-registry`) и одно допустимое исключение-дата (`assignedAt` сдвинут). Сошлось.

**5. Переключатель.** Блок ограничения называет `partner-registry` — это имя есть в списке манифеста (`shipping`, `partner-registry`, `dispatch-web`). Сошлось.
