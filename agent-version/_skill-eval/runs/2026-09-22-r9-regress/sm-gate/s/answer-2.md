**1. Ключи** — сравнил заголовки `###` в «Бизнес-правилах» со строками описи: `` `Shipment` — отправление``, `сообщение «груз доставлен»`, `ограничение «приём отправлений партнёра отключён»` — все три формы верные (сущность в бэктиках / «сообщение «» / «ограничение «»), блок объекта один. Сошлось.

**2. Состав** — состояний в описи 1 (Shipment) → блоков объектов в карточке 1. Сообщений в описи 1 → сообщений в карточке 1, и «публикует shipment.delivered» в «Событиях» тоже 1 — не меньше. Ограничений в описи 1 → в карточке 1. Справочники (Shipment.packageType, Attachment.kind) блока не получили — верно, справочник блока не имеет. Сошлось.

**3. Значения** — форма «Владеет данными»: строки `- поле: тип`, не таблица, слипшихся полей нет. Но у поля `status` — `` `status`: `ShipmentStatus` — перечисление`` — тип назван «перечисление», а значения через `|` не выписаны (сравни с `packageType`: `` `BOX` | `PALLET` ``, где значения на месте). Опись даёт состояние `Shipment.status NEW | ASSIGNED | DELIVERED` — три значения должны стоять в строке `- status:` через `|`, а не заменяться словом «перечисление». Это «тип без значений» — не сошлось.
Отдельно: в блоке «Бизнес-правила» строк 3, значений в `состояние:` тоже 3, токены (`NEW`/`ASSIGNED`/`DELIVERED`) соответствуют, заполнителя нет — это само по себе сошлось.

**4. Код** — прогнал четыре грепа по секции «Бизнес-правила»: ` /[a-z]` — нет совпадений; `\b(GET|POST|PUT|PATCH|DELETE)\b` — нет (DELIVERED не равен DELETE); `\b[a-z]+[A-Z][A-Za-z]*\b` вне бэктиков — нет; `\b[a-z]+(\.[a-z-]+){2,}\b` — нет. В бэктиках только значения перечисления, имя топика и имя сервиса из манифеста. Сошлось.

**5. Переключатель** — блок ограничения называет `partner-registry`; имя есть в списке манифеста (`shipping`, `partner-registry`, `dispatch-web`). Сошлось.

ГЕЙТ: ДОБОР — в «Владеет данными» строка `status` не даёт значения перечисления через `|` (написано `ShipmentStatus` — перечисление вместо `NEW | ASSIGNED | DELIVERED`); перечень для добора: переписать строку `- status: ...` в блоке `Shipment` секции «Владеет данными» по форме `- поле: \`знач1\` | \`знач2\` | \`знач3\`` с теми же тремя значениями, что в описи (`NEW | ASSIGNED | DELIVERED`).
