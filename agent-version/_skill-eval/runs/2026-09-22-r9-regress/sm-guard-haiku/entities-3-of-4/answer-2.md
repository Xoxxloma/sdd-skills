## Расчёт гарда

**контракт**
- было: 12
- исчезло: 0
- появилось: 0
- Порог: 0 ≱ 3 → не срабатывает

**сущности**
- было: 4
- исчезло: 3 (Customer, Invoice, Payment)
- появилось: 0
- Проверка: исчезло_сущности = 3 ≥ 3 ✓, и 3 × 3 = 9 > 4 ✓
- Порог: **срабатывает**

Так как у класса сущности оба условия выполнены, маршрут срабатывает.

```
ГАРД: В _pending
```
