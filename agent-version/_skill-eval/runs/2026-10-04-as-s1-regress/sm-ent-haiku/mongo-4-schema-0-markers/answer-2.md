Проверю по двум правилам.

### Маркерный гейт (ГЕЙТ)
Маркеры по коду: 0. Правило говорит: "Маркер дал ноль — сверки нет (это нижняя граница)". Гейт пройден автоматически.

### Сущности — сверка сверху
Блоков `###` в «Владеет данными»: 4. Маркеров по коду: 0.  
Условие: 4 > 0 — нарушение. Но есть исключение: "Маркер по коду дал ноль, а блоки есть... строки сущностей есть, а с маркером таблицы ни одной — маркер вне таблицы (Mongo и подобные), сверки нет."

Проверю по грепам:
- Строки сущностей (паттерн `\([^)]*\)\s*$`): все 4 — Order, Customer, Invoice, Payment с (@Schema) — ✓
- С маркером таблицы (`@Entity`, `@Table`, `model`): ни одной — все только @Schema, не @Entity/@Table — ✓

**Исключение подходит:** маркер вне таблицы, сверки нет.

### Сущности у ручек
Видимые блоки:
- `GET /api/orders` — есть `сущности: → Order` (в списке сущностей ✓)
- `GET /api/customers` — есть `сущности: → Customer` (в списке сущностей ✓)

Все видимые ручки имеют строку `сущности:` с именами из «Владеет данными». Добор не требуется.
