Другие классы грепы не дали, у них было = исчезло = появилось = 0, порог не срабатывает. Опустело считается только по классам с блоками `###`, а у «Потребляемых API» это таблица, так что там опустело_c = 0.

| Класс | было | исчезло | появилось | опустело | Порог |
|---|---|---|---|---|---|
| потребляемые API | 89 | 2 | 0 | н/п (таблица) | нет |
| контракт, сущности, задачи, топики, экраны, роли, зависит от | 0 | 0 | 0 | 0 | нет |

Порог по классу «потребляемые API»:
- Исчезновение: `исчезло_c ≥ 3` не выполнено, потому что 2 < 3. Второе условие `3·2 = 6 > 89` тоже ложно.
- Опустевшие блоки: `опустело_c ≥ 3` не выполнено, потому что 0 < 3.

Исчезли два ключа, оба в классе «потребляемые API»:
