1. **Ключи:** сошлось. Три заголовка секции: `` `Shipment` — отправление ``, `сообщение «груз доставлен»`, `ограничение «приём отправлений партнёра отключён»`. Блок сущности один, в заголовке сообщения бэктиков нет.
2. **Состав:** не сошлось.
   - Блоков объектов 1, строк `состояние:` с одной сущностью 1. Сообщений 1 при одной строке `сообщение:` и одном `публикует`. Ограничений 1 при одной строке `ограничение:`. Эти три сравнения сошлись.

3. **Значения:** сошлось.
   - «Владеет данными» оформлено строками `- поле: тип`, таблицы нет, у перечислений значения стоят через `|`.
   - В блоке `Shipment` три строки на три значения состояния. Токен в каждой строке один, заполнителей и повторов нет.
   - Лишних имён полей нет, строк с несколькими полями тоже нет.
4. **Код:** сошлось. Вне бэктиков нет совпадений ни с одним из четырёх грепов. В бэктиках только значения перечисления (`NEW`, `ASSIGNED`, `DELIVERED`), топик `shipment.delivered` и имя из манифеста `partner-registry`.
5. **Переключатель:** сошлось. `partner-registry` есть в списке манифеста, `true`/`false` и «внешней конфигурации» в блоке нет.
