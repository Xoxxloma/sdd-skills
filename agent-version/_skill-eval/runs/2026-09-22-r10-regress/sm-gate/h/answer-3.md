Прогоняю пять чисел гейта «Бизнес-правила» по карточке `shipping`.

1. **Ключи.** Три `###`: `` `Shipment` — отправление `` (сущность в бэктиках), `сообщение «груз доставлен»`, `ограничение «приём отправлений партнёра отключён»` — все три формы верные, посторонних заголовков нет, блок один на сущность. Сошлось.

2. **Состав.** Опись: состояние — 1 (Shipment) → блоков объектов 1, есть; сообщение — 1 строка и 1 `публикует` в «Событиях» → блоков сообщений max(1,1)=1, есть; ограничение — 1 строка → блоков 1, есть. Справочники (`packageType`, `kind`) блоков не получили — верно, у них своих блоков быть не должно. Сошлось.

3. **Значения.** «Владеет данными» в форме `- поле: тип`, не таблица. У `status` перечисление через `|` (3 значения). Повтор `ASSIGNED` — не заполнитель, а ровно санкционированное исключение «дата рядом с токеном» (`` `ASSIGNED`, `assignedAt` сдвинут ``), по форме идентичное примеру из правил. Двух токенов через `/`, `|`, запятую в одной строке нет. Сошлось.
