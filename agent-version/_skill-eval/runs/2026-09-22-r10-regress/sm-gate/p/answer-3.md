## Гейт «Бизнес-правила» — `shipping`

**1. Ключи.** Заголовки в разделе: `` `Shipment` `` (сущность в бэктиках), `сообщение «груз доставлен»`, `ограничение «приём отправлений партнёра отключён»` — все три формы соответствуют правилу, бэктиков в заголовке сообщения/ограничения нет. Один блок на сущность (`Shipment` — единственный). Сошлось.

**2. Состав.** `состояние:` в описи — 1 (Shipment) → блоков объектов в карточке — 1. `сообщение:` в описи — 1 → блоков сообщения — 1, `публикует` в «Событиях» — 1 (1 ≥ 1, 1 ≥ 1). `ограничение:` в описи — 1 → блоков ограничения — 1. Прочие перечисления своей сущности (`weightKg`, `url`) не enum — сиротских перечислений нет. Сошлось.

**3. Значения.** Форма «Владеет данными» — строки `- поле: тип`, не таблица; значения через `|`. Но в блоке `Shipment` строка `- коробка (\`BOX\`), паллета (\`PALLET\`) — тип упаковки, задаётся при создании` несёт ДВА токена (`BOX` и `PALLET`) в одной строке через запятую — это ровно случай «справочник, записанный состоянием» из правила. `packageType` — справочник (по описи), а не состояние, и оформлен как ложная пара state-строк вместо описания в форме справочника. **Не сошлось.**

**4. Код.** Вне бэктиков в разделе четыре регэкспа не совпадают (путей, глаголов, camelCase, dotted-key нет). В бэктиках — только значения перечислений (`NEW`, `BOX`…), имя топика (`shipment.delivered`) и имя сервиса (`partner-registry`) — всё разрешённое. Сошлось.

**5. Переключатель.** Блок ограничения называет `partner-registry` — есть в списке манифеста (`shipping`, `partner-registry`, `dispatch-web`). Сошлось.

ГЕЙТ: ДОБОР — в блоке `` `Shipment` `` раздела «Бизнес-правила» строка «коробка (`BOX`), паллета (`PALLET`) — тип упаковки, задаётся при создании» смешивает два токена справочника `packageType` в одной строке через запятую (записывает справочник как состояние); переписать эту строку по форме: один токен — одна строка, как у остальных строк блока (или убрать из блока «Бизнес-правила», если для `packageType` в коде нет правила, зависящего от значения — справочник не обязан иметь блок/строку в этом разделе).
