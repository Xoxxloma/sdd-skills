**1. Ключи.** Три `###`: `` `Shipment` — отправление``, `сообщение «груз доставлен»`, `ограничение «приём отправлений партнёра отключён»` — все три формы верны, один блок на сущность. Сошлось.

**2. Состав.** Опись: `состояние:` 1 (Shipment), `сообщение:` 1, `ограничение:` 1, `публикует` в «Событиях» 1. Карточка: блоков объектов 1 (Shipment), сообщений 1, ограничений 1. Attachment (только справочник) блока не получил — верно. Сошлось.

**3. Значения.** «Владеет данными» — форма `- поле: тип`, не таблица; у `status`, `packageType`, `kind` значения через `|`. Но в блоке `Shipment`: 3 значения в `состояние:`, а строка «перевешено (`ASSIGNED`, `weightKg` изменён)» повторно использует `ASSIGNED` с полем в скобках — а разрешено исключение только для **даты**, не для произвольного поля («Любое другое имя поля — строка на поле, добор»). Не сошлось.

**4. Код.** В бэктиках блока `Shipment` встречается `weightKg` — имя поля, а в бэктиках этой секции допустимы только значение перечисления, имя вида/топика, имя сервиса из манифеста и дата-исключение. Имя поля запрещено нигде в секции, включая бэктики. Не сошлось.

**5. Переключатель.** В блоке ограничения назван `partner-registry` — есть в списке манифеста (`shipping`, `partner-registry`, `dispatch-web`). Сошлось.
