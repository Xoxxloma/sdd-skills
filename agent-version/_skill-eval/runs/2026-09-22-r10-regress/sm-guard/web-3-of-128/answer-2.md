## Гард — подсчёт по классам

Дано только по классу «потребляемые API» (остальные классы в грепах не приведены — по ним данных нет, порог не считаем).

**потребляемые API:**
- было = 128
- исчезло = 3 (`billing` · GET /projects/0/estimate, /projects/1/estimate, /projects/2/estimate)
- появилось = 0
- опустело — неприменимо (не блочный класс, считается по строкам таблицы)

Проверка порога: исчезло ≥ 3 → 3 ≥ 3, истина. Но 3·исчезло > было → 3·3=9 > 128 — ложь. Условие требует **обеих** частей одновременно, а сработала только первая. Порог не сработал.

Других классов с данными нет, поэтому по остальным считаем «было=0, исчезло=0» — порог не сработал и там.

Итог: ни один класс не пересёк порог → продвижение поверх, с исчезнувшими ключами (`billing` GET /projects/0,1,2/estimate) — именами в отчёт Шага 6.
