**Потребляемые API**
- было = 128
- исчезло = 3 (`billing` · GET /projects/0/estimate, /projects/1/estimate, /projects/2/estimate)
- появилось = 0
- опустело — неприменимо (это таблица, не блок с телом)

Проверка порога: исчезло_c ≥ 3 → 3 ≥ 3 ✓, но 3·исчезло_c > было_c → 3·3=9 > 128 — **ложно**. Условие «И» не выполнено → порог не сработал.

Появилось ≈ исчезло — нет (0 ≠ 3), переименованием не является.
