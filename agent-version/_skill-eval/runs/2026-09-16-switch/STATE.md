## Что это значит

1. **Третий вид блока работает и выводится из кода.** В `after3` пример в шаблоне из другой
   предметной области, а блок «ограничение» стоит в 6/6, владелец назван, формулировки свои
   («пока флаг взведён на их админке, любая операция отказывает с сообщением …»). В `after2` три
   блока из шести совпадали с примером дословно — это было заражение, а не результат; исправлено.
2. **Четыре полевые ловушки sonnet на тире A не ловится ни в одном плече:** чужой флаг как
   состояние 0/6, ошибка как сообщение 0/6, строк на поле 0, писем по видам 6/6 — уже в `before`.
   Полевые провалы навигатора и consolidate шли с ведущего на живых репах (747 и 1236 файлов,
   модель стенда пользователя — flash), не с субагента на 300-строчной фикстуре. Их держат
   новые гейты Шага 4: (2) значения против строки `состояние:` описи, (3) токен — значение, не
   поле, (4) сообщений не меньше строк `сообщение:`, (5) ограничения. Тир A их не подтверждает
   и не опровергает; подтверждение — ярус Б.
3. **Код в строках правилом не держится — ни старым, ни новым.** Медиана упала с 4 до 1 после
   перечня конкретных утечек, но ноль не достигается: `byEmail=true`, `409`/`403`, тело события,
   перечень полей в скобке состояния (`closedBy = "system"`, `closeReason = null`). Ровно поэтому
   регистр в «Бизнес-правилах» переведён из проверки в гейт со вторым добором у ведущего:
   секция уезжает в БТ дословно.
4. **Грейдер поправлен один раз по данным**, не по желаемому: скобка с токеном состояния —
   форма примера самого шаблона, и считать её кодом значило красить зелёное в красное.

```

     /work/navigator-api "navigator, consolidate, dispatch-web" > prompt.md

node grade-sm-switch.mjs runs/2026-09-16-switch/<плечо> …
```
