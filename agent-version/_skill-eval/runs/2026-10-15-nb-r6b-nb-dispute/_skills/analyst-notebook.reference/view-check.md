# Рубрика: проверка выкладки

Ты проверяешь выкладку, собранную из ноута аналитика. Форма любая: список, таблица, схема, письмо.
Элементы не переписываешь и своих не добавляешь: на каждый элемент со ссылкой — вердикт.

## Что вернуть

```
рубрика прочитана: выкладка
1 ок
2 нет пункта: 2
3 вид: 3 набросок
…
```

Номер — порядковый номер элемента со ссылкой `<дата> №<n>`, считая сверху: строки, клетки таблицы,
подписи связей в схеме. Заголовки, имена участников, «в ноуте нет» не нумеруешь. Элемент без ссылки, который
что-то утверждает — решение, число, срок, связь между участниками, — строкой `без ссылки: «<элемент>»`.
Вердиктов у элемента несколько — через `; `.

## Проверки

1. **Пункт есть.** Найди запись `### <n>` в разделе `## <дата>` ноута (`Grep -n "^## |^### "`, затем
   `Read` записи). В ней есть пункт `- [вид] …` о том, что говорит элемент: у связи в схеме — обе стороны и
   что между ними; у узла, где названо несколько участников, — каждый из них. Сведено из двух пунктов, а ссылка
   одна — `не так: K`. Нет — `нет пункта: K`.
2. **Вид.** Вид у элемента («решено», «открыто», «сведение», «мысль», «набросок») — тот же, что у пункта.
   Иной — `вид: K <вид в ноуте>`. Набросок или мысль, поданные как решённое, — всегда этот вердикт.
3. **Слова.** Каждое число, имя, срок, код, путь, метод и поле элемента есть в пункте, в тексте под `>`
   той же записи или в её исходнике (строка `> исходник: <путь>` — путь от папки ноута). Нет — `не так: K`.
4. **Замена.** `Grep -n "вместо: <дата> №<n>"` по ноуту. Нашёлся пункт, у которого текст в кавычках после
   ссылки — начало пункта элемента, — `заменён: K → <дата> №<m>` (ссылка заменившего).
5. **Закрыт.** Элемент — открытый вопрос, а `Grep -n "отвечает на: <дата> №<n>"` нашёл пункт, у которого
   текст в кавычках — начало этого вопроса, — `закрыт: K → <дата> №<m>` (ссылка ответа).

Всё сошлось — `K ок`.
