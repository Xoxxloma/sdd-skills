### Правила описи (Шаг 3)

**Три строки описи, из которых собираются «Бизнес-правила» (только `backend` и `fullstack`).**
`состояние:` — по строке на каждое поле-перечисление у сущности **из «Владеет данными» этого
сервиса** и на каждую дату вида «принято / удалено», с перечнем значений и файлом. **Булево поле —
не перечисление.** Флаг, который сервис читает у соседа и по которому отказывает целиком, — не
состояние, а строка `ограничение:`. `сообщение:` — по строке на каждый вид исходящего
сообщения человеку или соседу (уведомление, письмо, push, событие в шину, запись в чужое
хранилище), с получателем и файлом, где оно отправляется. **Ответ на запрос сообщением не
является** — ни тело, ни ошибка, ни её текст: код ошибки живёт в «Публичном контракте». **Виды считай по коду отправки, а не
по одному модулю:** каждый тип уведомления — вид; **каждый шаблон письма в модуле почты — тоже
вид** (метод `sendXxx` = один вид); каждый публикуемый топик — вид. **Одна строка на каждое имя
типа в коде** — константу, значение перечисления, метод отправки: семь имён — семь строк, и
сворачивать их в «уведомление участнику» нельзя, свёрнутый вид — потерянный вид. `ограничение:` —
по строке на внешнее условие, при котором сервис отказывает или меняет поведение целиком: флаг у
соседа, режим обслуживания, лицензия, лимит — словами, с файлом проверки; своё поле-перечисление
ограничением не бывает, это состояние. Итог — строкой
`⟹ состояний N (значений K), сообщений M, ограничений L`. Значения перечислений в описи уже есть у сущностей — строка
`состояние:` их собирает в одно место, чтобы блоки секции считались против неё. Сообщение — класс,
которого в описи раньше не было: получатели считаются в модуле отправки, у которого нет ни
эндпоинта, ни задачи, и без этой строки они не доезжают никогда.

**В блоке объекта — строка на каждое значение и ни одной строки на поле.** Перечень полей уже
стоит в «Владеет данными»; строка «`поле` — что это» в «Бизнес-правилах» — пустышка, а блок из
таких строк — схема, а не правила. Строка начинается с подписи значения, токен значения — после
неё в бэктиках, дальше правило.

**Что из кода в строку не идёт — ни в одном из трёх видов блоков:** путь и HTTP-глагол, код
ошибки и HTTP-статус (их место — «Публичный контракт»), поле со значением (`byEmail=true` — это
«подписчики с включённым e-mail», `closedBy = "system"` — «закрыто системой»), тело события,
кэш и срок его жизни, имя шаблона письма. Токен в строке один: у объекта — значение после
подписи (дата, которой состояние отличается, — рядом с ним в скобках, как `expiresAt` в примере
шаблона), у сообщения — имя вида или топик в конце строки. Заголовок сообщения — словами, у
топика тоже: «назначение закрыто» — соседям, а `navigator.assignment.closed` в строке.


### Гейт (Шаг 4)

- **Бизнес-правила (ГЕЙТ, `backend` и `fullstack`):** пять чисел; из описи для них берёшь
  только строки `состояние:`, `сообщение:` и `ограничение:` — три грепа, не чтение. (1) Блоков
  `###` в секции столько, сколько в «Владеет данными» сущностей со строкой вида `- поле: A | B`
  или с датой «принято / удалено», плюс строк `сообщение:`, плюс строк `ограничение:` в описи.
  (2) В каждом блоке объекта строк `-` не меньше, чем значений в строке `состояние:` описи по
  этой сущности. Не по «Владеет данными»: там значения мог не перечислить тот же субагент, и обе
  стороны сойдутся на нуле; в описи значения списаны с кода. (3) Каждый токен в бэктиках внутри
  **блоков объектов** — значение, то есть стоит справа от `:` в строке `- поле: A | B` в «Владеет
  данными». Токена там нет — выдуман; токен есть, но слева от `:` — это имя поля, и строка с ним
  — строка на поле, а не на значение. Блоки сообщений этим не проверяются: у сообщения токен —
  имя вида из кода, и в «Владеет данными» его нет законно, а имя метода отправки токеном не
  бывает. (4) Блоков сообщений не меньше, чем блоков `публикует` в «Событиях», **и** не меньше,
  чем строк `сообщение:` в описи: первое не зависит от описи вовсе, второе ловит свёрнутые
  письма — четыре шаблона в одном блоке проходят по топикам. (5) Блоков ограничений столько,
  сколько строк `ограничение:`; в блоке ограничения нет `true`/`false` — условие названо словами.
  Расхождение — добор с перечнем сущностей, значений, видов и условий. Зачем пять, а не одно:
  первое ловит пропущенный объект, второе — пропущенное состояние, третье — сочинённое и строку
  на поле, четвёртое — сообщения, которых субагент не счёл сообщениями или свернул, пятое — чужой
  флаг, записанный как своё состояние.
