## К7 — гейт «Бизнес-правил» против шаблона: ВОСПРОИЗВОДИТСЯ, 3 из 3

Проба `k7-gate-only/`: ведущему дан дословный текст скилла про секцию (бриф, правила описи, гейт,
бюджет доборов — вырезаны из живого `SKILL.md` по якорям) и ответ субагента по сервису `shipping`.
Карточка **верна по шаблону**: у `Shipment` настоящий статус и справочник `packageType`, у
`Attachment` только справочник `kind`; блок один — `Shipment`, три строки на значения статуса,
блок сообщения один. Опись написана как велит бриф — строка `состояние:` на каждое поле-перечисление.

Все три ответа: `ГЕЙТ: ДОБОР` — потребовать блок `Attachment` со строками на `PHOTO` и `PDF` и
строки на `BOX`, `PALLET` в блоке `Shipment`. То есть ведущий отправляет верную карточку на добор
и просит ровно те блоки-пустышки, которые шаблон запрещает («справочник блока не получает»).
Причина в тексте: слова «справочник» у ведущего в скилле нет вовсе, правило живёт только в
шаблоне, который читает субагент; гейт (1) считает сущности «Владеет данными» с любой строкой
`поле: A | B`, гейт (2) — значения всех строк `состояние:` описи. Цена пробы — $0,27.
