**Класс "потребляемые API"**

| Метрика | Значение |
|---------|----------|
| **было** | 128 |
| **исчезло** | 3 |
| **появилось** | 0 |
| **опустело** | 0 |

**Проверка порога:**

Условие 1: `исчезло ≥ 3` → `3 ≥ 3` ✓  
AND `3 · исчезло > было` → `9 > 128` ✗

Условие 2: `опустело ≥ 3` → `0 ≥ 3` ✗

Оба условия не срабатывают.

**Исчезнувшие ключи:**
- `billing` · GET /projects/0/estimate
- `billing` · GET /projects/1/estimate
- `billing` · GET /projects/2/estimate
