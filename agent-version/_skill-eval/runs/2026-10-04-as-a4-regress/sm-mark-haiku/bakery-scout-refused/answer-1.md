Анализирую маркерный гейт. Разведчик запускался дважды, оба раза не назвал ни одной строки формата `<класс> :: <регэксп> :: <glob> :: ключ|ориентир`. По инструкции: "Не помогло — у сервиса нет маркеров: счёт пропущен, строка в отчёт «разведчик не назвал маркеров — внешней сверки нет»".

Так как маркеров нет вообще, нижняя граница для каждого класса = 0. По правилам гейта: "Класс, у которого строк `ключ` нет или они дали ноль, сверки не получает и ничего не блокирует".
