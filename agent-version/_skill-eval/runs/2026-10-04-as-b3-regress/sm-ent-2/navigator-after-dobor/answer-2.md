Добор по сущностям не нужен.

- **Сверка сверху:** блоков `###` в «Владеет данными» 0, маркеров `@Entity\b` 0. 0 не больше 0, поэтому сверка проходит. Случай «греп ноль, а блоки есть» не наступает, потому что блоков нет.
- **Сущности у ручек:** блоков без строки `сущности:` 0, так что добора по ключам не требуется.
- **Нижняя граница:** маркер дал ноль, значит сверки нет. Опись тоже пуста (0 сущностей), так что детектор узкого маркера не срабатывает.

В отчёт строкой: «Маркер сущностей `@Entity\b` дал 0, сущностей в описи 0, блоков «Владеет данными» 0 — внешней сверки по классу «сущности» нет».
