# Разбор

Вес сервиса = сумма маркеров `ключ` + 0.5 × сумма маркеров `ориентир`
= (96 + 41 + 6) + 0.5 × 9
= **147.5**

Вес 147.5 > K (80) → нужна нарезка на части (Шаг 3.5, а не единый читающий на 3.2–3.4).

Техническое условие: Bash есть, `reference/plan.sh` входит в скилл, числа счёта готовы. Препятствий для нарезки нет.

# Действия

ДЕЙСТВИЕ: Запустить `bash reference/plan.sh services/.work/ferry-booking/counts.txt 80 0.5 "../ferry-booking"` для построения плана нарезки.

ДЕЙСТВИЕ: По выводу плана запустить читающих субагентов для каждой части параллельно (не более 6 одновременно) в Шаге 3.5.

ДЕЙСТВИЕ: После завершения всех частей запустить голову, затем склейку (`assemble.sh`).

ДЕЙСТВИЕ: На Шаге 4 проверить чтение по маркерам поточно для каждой части (не для остатка).
