**1. Ключи.** Сошлось. Заголовки секции: `` `Shipment` ``, `сообщение «груз доставлен»`, `ограничение «приём отправлений партнёра отключён»`. Блок сущности один.

**2. Состав.** Сошлось.
- Блоков объектов 1, строк `состояние:` с одной сущностью тоже 1.
- Сообщений 1, строк `сообщение:` 1, блоков `публикует` 1.
- Ограничений 1, строк `ограничение:` 1.
- Перечисления `packageType` и `kind` названы в описи справочниками, пропущенных нет.

**3. Значения.** **Не сошлось.**
- Форма «Владеет данными» верная: строки `- поле: тип`, значения через `|`.
- В блоке `Shipment` четыре строки при трёх значениях состояния, но четвёртая лишняя: «тип упаковки (`BOX` / `PALLET`) — задаётся при создании».
- Это справочник (`packageType`, в описи он `справочник:`), записанный состоянием, с двумя токенами через `/`. У справочника блока нет, значит, строку надо убрать.
- Три строки состояний (`NEW`, `ASSIGNED`, `DELIVERED`) в порядке: по одному токену, правила разные.

**4. Код.** Сошлось. Вне бэктиков все четыре грепа пустые: слеш в `` `BOX` / `PALLET` `` стоит перед пробелом, а не перед буквой. В бэктиках только значения перечислений, топик `shipment.delivered` и имя из манифеста `partner-registry`. В заголовке сообщения бэктиков нет. Эти грепы проверены по описанию без запуска.

**5. Переключатель.** Сошлось. `partner-registry` есть в списке манифеста. Значений `true` и `false` в блоке нет.
