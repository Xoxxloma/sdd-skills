Гейт «Бизнес-правила» по ответу по `shipping`:

1. **Ключи** — сошлось. В секции три `###`: `` `Shipment` ``, `сообщение «груз доставлен»` и `ограничение «приём отправлений партнёра отключён»`. Бэктиков в заголовке сообщения нет, блок сущности один.
2. **Состав** — сошлось. Блоков объектов 1, строк `состояние:` 1. Сообщений 1, строк `сообщение:` 1 и блоков `публикует` 1. Ограничений 1, строк `ограничение:` 1. Оба справочника (`packageType`, `Attachment.kind`) названы в описи, блоков не имеют.
3. **Значения** — сошлось. «Владеет данными» оформлена строками `- поле: тип`, а не таблицей. Значения всех перечислений стоят через `|`. В блоке `Shipment` три строки на три значения, токены одиночные, заполнителей и повторов нет.
4. **Код** — **не сошлось**. В блоке ограничения в бэктиках стоит ключ конфига `shipping.partner-gate.enabled`. В бэктиках допустимы только значение перечисления, имя вида или топика, имя сервиса из манифеста и дата. Топик `shipment.delivered` в блоке сообщения допустим. Вне бэктиков совпадений с четырьмя грепами нет.
5. **Переключатель** — **не сошлось**. Блок называет «внешнюю конфигурацию (вне манифеста)», это не имя из манифеста (`shipping`, `partner-registry`, `dispatch-web`) и не роль из «Роли и доступ» (`DISPATCHER`, `COURIER`). «Внешняя конфигурация» и флаг — не переключатель. Строка `ограничение:` в описи тоже без `переключатель:`, а в ней названо условие «флаг … в конфиге».

ГЕЙТ: ДОБОР — по ограничению «приём отправлений партнёра отключён» правь через `Edit` оба файла, опись и черновик, и ничего больше не трогай. (а) Убери из блока в «Бизнес-правилах» ключ конфига `shipping.partner-gate.enabled` и слова «внешняя конфигурация (вне манифеста)»: по правилу 4 имя флага недопустимо нигде в секции. (б) Назови переключатель, то есть того, кто условие включает и выключает: имя сервиса из манифеста (`shipping`, `partner-registry`, `dispatch-web`) либо роль из «Роли и доступ» этой карточки (`DISPATCHER`, `COURIER`), и впиши `переключатель: <имя>` в строку `ограничение:` описи.
