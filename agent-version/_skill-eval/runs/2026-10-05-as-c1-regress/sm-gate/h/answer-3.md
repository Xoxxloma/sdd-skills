1. **Ключи.** Три заголовка `###` секции: `` `Shipment` — отправление``, `сообщение «груз доставлен»`, `ограничение «приём отправлений партнёра отключён»`. Каждый начинается с допустимой формы. Блок сущности один. Сошлось.
2. **Состав.**
   - Блоков объектов 1, строк `состояние:` с одной сущностью (`Shipment`) тоже 1.
   - Сообщений 1: это не меньше одной строки `сообщение:` и одного блока `публикует` в «Событиях».
   - Ограничений 1, строка `ограничение:` тоже одна.
   - Перечисления `packageType` и `kind` названы в описи справочниками, блока не имеют. Пропущенных нет. Сошлось.
3. **Значения.**
   - «Владеет данными» оформлена строками `- поле: тип`, не таблицей. У обоих перечислений значения стоят через `|`.
   - В блоке `Shipment` 4 строки на 3 значения. Токены строк: `NEW`, `ASSIGNED`, `ASSIGNED` с датой, `DELIVERED`.
   - Вторая строка с `ASSIGNED` законна: состояние отличает дата `assignedAt` в скобках рядом с токеном.
   - Правила в строках разные, заполнителей нет, строк с двумя токенами нет. Сошлось.
4. **Код.**
   - Вне бэктиков четыре грепа ничего не находят: нет ` /[a-z]`, глаголов HTTP, camelCase и цепочек из трёх сегментов через точку.
