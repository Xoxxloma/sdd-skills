# Вход: бизнес-требования

Источник — `business_requirements.md`, пункт — требование `FR-N` из §4.1. Здесь — как читать БТ, как
требование становится шагами пути (файл типа `kinds/user-flow.md`) и когда рисовать нечего.

Типы: путь пользователя.

## Чтение и отказ

Читай только §4.1 «Описание функционала / бизнес-процесса»: другие разделы на схему не идут, даже если в
них есть подробности процесса. Требование — каждый номер `FR-N` в начале абзаца или пункта списка §4.1, в
любой разметке (жирный, пункт списка, отдельная строка); выпиши их для себя — это список требований. §4.1
нет, он пуст, в нём только `TBD` или нет ни одного `FR-N` → ответ «В БТ нет описания процесса с номерами
требований (§4.1) — рисовать нечего.» Файл не пишешь.

## Требование → шаги

| Что на схеме | Как найти в тексте требования |
|---|---|
| шаг | действие: кто и глагол с тем, на что он направлен, — словами текста, без пересказа и добавлений; несколько действий через «и» или запятую — отдельные шаги по порядку, у второго действия того же субъекта субъект повторяешь; действие системы — тоже шаг. Фраза о возврате или о конце ветки — не шаг: она даёт только стрелку (строки «возврат» и «конец ветки») |
| развилка | условие: «если …», «в случае …»; текст развилки — условие словами текста, вопросом; ветка «да» — что сказано при условии, «нет» — что сказано после «иначе», «если нет», «в противном случае» |
| основная ветка | ветка, после которой текст не говорит ни о конце, ни о возврате; таких две или ни одной — ветка «да». Другая — ответвление |
| возврат | текст говорит, что шаг делают ещё раз («снова …», «начинает заново», «возвращается к …») — стрелка к этому шагу |
| конец ветки | текст говорит, что дальше ничего («на этом всё», «работа прекращается», «… не создаётся») — стрелка в «Конец» |
| не на схеме | требование без действия в процессе: права, роли, видимость данных, ограничения доступа |

## Чего ты не делаешь никогда

- **У БТ один автор** — `business-requirements-doc`.
- **Не рисуешь, кто кого вызывает.** Сервисов и контрактов в БТ нет; схема взаимодействий — по спеке.
