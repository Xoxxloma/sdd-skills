1. **Ключи.** Три `###`: `` `Shipment` `` , «сообщение «груз доставлен»», «ограничение «приём отправлений партнёра отключён»» — все начинаются верно, по одному блоку на сущность. Сошлось.

2. **Состав.** Опись: состояний 1 → блоков объектов 1 (`Shipment`) — есть. Сообщений 1 (опись) и публикует-блоков 1 (Событиях) → блоков-сообщений 1 — есть. Ограничений 1 → блоков-ограничений 1 — есть. Сошлось.

3. **Значения.** «Владеет данными» — форма `- поле: тип`, не таблица — ок. У `status`, `packageType`, `kind` значения через `|` — ок. Но в блоке `Shipment` строка «перевешено (`ASSIGNED`, `weightKg` изменён)» — токен в скобках не дата-исключение, а имя поля `weightKg`: запрещено правилом «любое другое имя поля — строка на поле, добор». Не сошлось.

4. **Код.** Та же строка: `weightKg` в бэктиках — не значение перечисления, не имя вида/топика, не имя сервиса, не дата — недопустимо нигде в секции. Остальные строки секции (в т.ч. `shipment.delivered`, `partner-registry`) — легитимные исключения. Не сошлось.

5. **Переключатель.** Блок ограничения называет `partner-registry` — есть в списке манифеста (`shipping`, `partner-registry`, `dispatch-web`). Сошлось.
