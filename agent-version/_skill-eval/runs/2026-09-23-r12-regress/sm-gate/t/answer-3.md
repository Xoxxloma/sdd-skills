**1. Ключи.** Все три `###` в «Бизнес-правилах» начинаются по форме: `` `Shipment` ``, `сообщение «груз доставлен»`, `ограничение «файл не является выгрузкой АС Каскад»`. Совпадений нет — сошлось.

**2. Состав.** Строк `состояние:` в описи — 1 (Shipment) → блок-объект один, в карточке один (`Shipment`). Строк `сообщение:` — 1, блоков `публикует` в «Событиях» — 1 → в карточке 1 блок сообщения. Строк `ограничение:` — 1 → в карточке 1 блок ограничения. Attachment (справочник, не состояние) блока не имеет — верно. Сошлось.

**3. Значения.** «Владеет данными» — форма `- поле: тип`, не таблица. В блоке `Shipment` три строки на три значения строки `состояние:` (NEW/ASSIGNED/DELIVERED), без дублей правила на разных значениях, токены — значения перечисления. Сошлось.

**4. Код.** В секции «Бизнес-правила» вне бэктиков не встречено ни путей, ни HTTP-глаголов, ни camelCase, ни точечных ключей; в бэктиках — только значения перечисления и топик `shipment.delivered`. Сошлось.

**5. Переключатель.** Блок ограничения называет переключателем «АС Каскад». Список манифеста — `shipping`, `partner-registry`, `dispatch-web`; список «Роли и доступ» — `DISPATCHER`, `COURIER`. «АС Каскад» нет ни там, ни там, а внешняя система исключением не является (правило прямо это оговаривает) — расхождение.

ГЕЙТ: ДОБОР — переключатель ограничения «файл не является выгрузкой АС Каскад» назван внешней системой «АС Каскад», которой нет ни в списке манифеста (`shipping`, `partner-registry`, `dispatch-web`), ни в «Роли и доступ» (`DISPATCHER`, `COURIER`); правило прямо запрещает внешней системе быть переключателем — субагенту нужно перепроверить по коду, кто в этом сервисе реально включает/выключает приём файлов не в формате АС Каскад (сервис из манифеста либо роль), и переписать строку переключателя в обоих файлах (опись и черновик) этим именем — либо, если такого переключателя в коде нет, снять строку `ограничение:` из описи и блок «ограничение «...»» из черновика как обычную валидацию формата файла, перенеся факт строкой ошибки в «Публичный контракт».
