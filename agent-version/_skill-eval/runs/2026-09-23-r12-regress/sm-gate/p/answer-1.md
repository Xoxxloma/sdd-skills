**1. Ключи.** Заголовки секции: `` `Shipment` ``, «сообщение «груз доставлен»», «ограничение «приём отправлений партнёра отключён»» — все три формы верные. Сошлось.

**2. Состав.** `состояние:` в описи — 1 (Shipment) → блоков объектов 1, в карточке 1. `сообщение:` — 1, блоков `публикует` в «Событиях» — 1, в карточке 1 сообщение. `ограничение:` — 1, в карточке 1. Attachment (только справочник, без `состояние:`) блока не получил — верно. Сошлось.

**3. Значения.** Блок `Shipment` держит 3 строки на 3 значения `состояние:` (NEW/ASSIGNED/DELIVERED) — но добавлена 4-я строка: «коробка (`BOX`), паллета (`PALLET`) — тип упаковки, задаётся при создании». Это `Shipment.packageType` — справочник из описи, а не состояние; два токена (`BOX`, `PALLET`) в одной строке через запятую — ровно случай «справочник, записанный состоянием». Справочники строк в блоке состояния не получают вовсе. Не сошлось.

**4. Код.** Вне бэктиков — только слова, ни одного пути/HTTP-глагола/camelCase/dotted-пути. В бэктиках — только значения перечисления (`NEW`, `ASSIGNED`, `DELIVERED`, `BOX`, `PALLET`), имя топика (`shipment.delivered`), имя сервиса из манифеста (`partner-registry`). В заголовке сообщения бэктиков нет. Сошлось.

**5. Переключатель.** В блоке ограничения назван `partner-registry` — есть в списке манифеста (`shipping`, `partner-registry`, `dispatch-web`). Сошлось.
