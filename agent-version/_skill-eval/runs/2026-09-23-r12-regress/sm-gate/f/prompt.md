## Прежняя карточка `<прежняя>` — открой ТОЛЬКО после описи

### Гейт (Шаг 4)

- **Бизнес-правила (ГЕЙТ, `backend` и `fullstack`): пять грепов; из описи берёшь только четыре
  её строки.** Любое расхождение — добор с перечнем, и добор — это **повторный запуск субагента**:
  ни одну строку черновика ты не пишешь сам, даже «тем же содержанием» — кода ты не видел; добор правит файл сам.
  **Ответ добора проходит все пять заново**, а не только то, за что назначен.
  1. **Ключи.** Каждый `###` секции начинается с имени сущности в бэктиках, `сообщение «` или
     `ограничение «`. Иной заголовок — «письмо», «событие», подпись впереди ключа, `Сущность.поле`
     — добор. Блок объекта один на сущность.
  2. **Состав.** Блоков объектов столько, сколько сущностей в строках `состояние:`. Сообщений не
     меньше строк `сообщение:` и не меньше блоков `публикует` в «Событиях». Ограничений столько,
     сколько строк `ограничение:`. Перечисление своей сущности, не названное в описи ни
     состоянием, ни справочником, — пропущено. Чужая сущность и справочник блока не имеют.
  3. **Значения.** Форма «Владеет данными» — строки `- поле: тип`; если секция оформлена таблицей
     `| Поле | Тип |` — добор раньше всего остального. Несколько полей в одной строке `- ` — **не
     расхождение и не добор**: карточка пишется, строка в отчёт с их числом. У каждого перечисления
     значения стоят через `|` в строке `- поле:`, тип без значений — добор.
     В блоке строк не меньше, чем значений в его строках `состояние:`; строка `не определено`
     считается, а две строки с одним и тем же правилом на разных значениях — заполнитель, добор:
     форма для значения без перехода — `не определено`. Токен строки — одно из значений.
     Исключение одно — дата, которой состояние отличается, в скобках рядом с токеном
     («продлена (`active`, `expiresAt` сдвинут)»): это законно. Любое другое имя поля — строка
     на поле, добор. Два токена в одной строке через `/`, `|` или запятую — справочник,
     записанный состоянием: добор.
  4. **Код.** Вне бэктиков ни одной строки секции с ` /[a-z]`, `\b(GET|POST|PUT|PATCH|DELETE)\b`,
     `\b[a-z]+[A-Z][A-Za-z]*\b`, `\b[a-z]+(\.[a-z-]+){2,}\b`; в бэктиках — только значение
     перечисления, имя вида или топика, имя сервиса из манифеста и дата-исключение из числа 3; ни одного бэктика в заголовке
     сообщения. Не помог добор — **второй, только по этим строкам**: единственное исключение из
     бюджета, секция уезжает в бизнес-спеку дословно.
  5. **Переключатель.** В блоке ограничения назван тот, кто условие включает и выключает, и это
     имя стоит в одном из двух списков: имена из манифеста либо роли из «Роли и доступ» этой же
     карточки — два грепа. Нет ни там, ни там — добор; «внешняя система» исключением не является.
     «Внешняя конфигурация», «настройка», ключ конфига — не переключатель. `true`/`false` в блоке —
     чужой флаг записан состоянием.

### Бюджет доборов

**Бюджет: не больше двух прогонов субагента на сервис.** Первый и, если понадобился, ещё один.
Второй — единственный, и он один **на все причины**: пустой ответ, отказ, нет файлов, не сошлись
числа на Шаге 4, пустое тело больше чем у половины блоков. Исключение одно — второй добор по
строкам с кодом в «Бизнес-правилах», число 4 гейта Шага 4.

**Добор — это не перезапуск и не «верни всё заново».** Числа на Шаге 4 не сошлись — запусти
субагента того же типа с тем же брифом плюс блок в конце:

```
## Добор
Файлы `<опись>` и `<черновик>` уже написаны твоим предшественником и почти верны. Не переписывай
их и не создавай заново. Правь только через `Edit`, только перечисленное ниже, остальное не трогай.
Правка, которая меняет состав ключей — снята чужая сущность, разделено сообщение, добавлен или
убран ключ, — вносится в ОБА файла: и в черновик, и в опись, чтобы они сошлись; опись тоже твоя,
а ведущий сверяет одно с другим и сам не правит ничего.
<перечень: ключи, которые не развёрнуты; строки, которые надо переписать; класс, которого нет в описи>
```

Перечень — из Шага 4, дословно. Без перечня субагент ответит тем же: он уже один раз решил, что
суть передана. Целиком переписанный файл в доборе — не добор, а второй прогон, и цена ему —
потерянное в секциях, к которым добор отношения не имел.

## Бизнес-правила

### `Shipment` — отправление
- новое (`NEW`) — создаёт диспетчер; пока курьер не назначен, отправление можно отменить
- назначено (`ASSIGNED`) — диспетчер назначает курьера; после назначения отменить может только диспетчер

- тип упаковки (`BOX` / `PALLET`) — задаётся при создании

### сообщение «груз доставлен»
- при отметке о вручении; получает получатель груза; отправителю не уходит; топик `shipment.delivered`

### ограничение «приём отправлений партнёра отключён»
- условием управляет `partner-registry`; пока оно действует, новые отправления этого партнёра не принимаются, диспетчер видит причину отказа

| `DISPATCHER` | создаёт отправления, назначает курьера, отменяет |
| `COURIER` | отмечает вручение |
