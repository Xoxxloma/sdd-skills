## Расчёт по классам

**контракт** — было 30, исчезло 0, появилось 0.
Черновик содержит ровно те же 30 ключей построчно. Порог: 3·0 > 30 — нет. Не сработал.

**бизнес-правила** — не считается вовсе (правило прямо исключает этот класс: его заголовки меняются при приведении формы к шаблону, это гейтится отдельно против описи на Шаге 3). Изменение 22 → 14 и добавление суффикса «— (по шаблону)» в ключи гарда не идёт, сколько бы строк ни исчезло.

**остальные классы** (сущности, задачи, топики, экраны, потребляемые API, роли, зависит от) — данных по ним не дано, то есть по ним нет ни исчезновений, ни опустошений для учёта.

Ни у одного считаемого класса не выполнено ни `(исчезло_c ≥ 3 и 3·исчезло_c > было_c)`, ни `(опустело_c ≥ 3 и 3·опустело_c > было_c)`.
