## Разбор по классам

**контракт** — было 30, исчезло 0, появилось 0. Множества совпадают дословно (включая `-1/-2/-3` суффиксы). Порог: исчезло≥3 и 3·исчезло>было → 0≥3 — не сработал.

**бизнес-правила** — **не считается**: этот класс прямо исключён правилом гарда («Не считаются вовсе: «Бизнес-правила» (их заголовки меняются при приведении формы к шаблону — это переформатирование, и оно у тебя уже гейтится против описи)»). То, что состав сжался с 22 до 14 строк (и правки вида добавления `(по шаблону)`), гардом Шага 4 не учитывается вообще — ни в один из счётчиков (исчезло/появилось/опустело) он не попадает.

Остальные классы из таблицы (сущности, задачи, топики, экраны, потребляемые API, роли, зависит от) в данных не представлены — по ним нет ни прежних, ни черновых ключей, порог не может сработать (было=0).

## Итог

Единственный считаемый класс — контракт — не пересёк порог ни по «исчезло», ни по «опустело». Бизнес-правила формально просели, но правило гарда явно выводит этот класс из подсчёта, так что это не голосует за `_pending`.
