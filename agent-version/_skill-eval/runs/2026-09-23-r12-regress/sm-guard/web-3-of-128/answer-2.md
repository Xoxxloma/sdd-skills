## Гард — расчёт по классам

**потребляемые API**
- было = 128, появилось = 0, исчезло = 3 (`billing` · GET /projects/0/estimate, /1/estimate, /2/estimate)
- опустело — неприменимо (класс без блока/тела)
- порог: исчезло_c ≥ 3 → 3 ≥ 3 ✅, но 3·исчезло_c > было_c → 9 > 128 ❌ → порог **не сработал**

Остальные классы (контракт, сущности, задачи, топики, экраны, роли, зависит от) в перечнях не даны — принимаю было=исчезло=появилось=0, порог не сработал.

Ни по одному классу оба условия маршрута не выполнены → продвижение поверх. В отчёт (Шаг 6) — исчезнувшие ключи именами: `billing` · GET /projects/0/estimate, `billing` · GET /projects/1/estimate, `billing` · GET /projects/2/estimate.
