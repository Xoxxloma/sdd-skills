## Расчёт гарда

**Класс: потребляемые API**
- было = 128
- исчезло = 3 (`billing`·GET /projects/0/estimate, `billing`·GET /projects/1/estimate, `billing`·GET /projects/2/estimate)
- появилось = 0

Проверка порога: исчезло_c ≥ 3 → 3 ≥ 3, верно. Но 3·исчезло_c > было_c → 3·3=9 > 128 — неверно. Порог не сработал.

Опустело — неприменимо к этому классу (не блок с телом, а строки таблицы).

Остальные классы (контракт, сущности, задачи, топики, экраны, роли, зависит от) в перечнях не даны — данных об изменениях по ним нет, порог по ним не срабатывает.

Появилось (0) не ≈ исчезло (3) — это не похоже на переименование, а на точечную потерю трёх строк.

Ни по одному классу условие маршрута в `_pending` не выполнено.

В отчёт (Шаг 6) — именами:
- `billing` · GET /projects/0/estimate
- `billing` · GET /projects/1/estimate
- `billing` · GET /projects/2/estimate
