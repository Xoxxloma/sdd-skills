## Расчёт гарда

**Класс: потребляемые API**
- было = 128
- исчезло = 3 (`billing`·GET /projects/0/estimate, `billing`·GET /projects/1/estimate, `billing`·GET /projects/2/estimate)
- появилось = 0
- порог: исчезло_c ≥ 3 → 3 ≥ 3 (да); 3·исчезло_c > было_c → 9 > 128 (нет)
- условие не выполнено → не триггерит

Остальные классы (контракт, сущности, задачи, топики, экраны, роли, зависит от) в перечнях не даны — данных об изменениях по ним нет, порог не срабатывает.

Ни один класс не превысил порог → продвижение поверх, с потерянными ключами в отчёте Шага 6 (три записи `billing`·GET /projects/{0,1,2}/estimate).
