## Гард — подсчёт по классам

**Потребляемые API** (первая+вторая колонки — сервис плюс вызов):
- было: 89
- исчезло: 2 — `billing` · GET /projects/0/estimate, `billing` · GET /projects/1/estimate
- появилось: 0
- опустело: не применимо (табличный класс, не блок)

Проверка порога: исчезло_c = 2, что не ≥ 3 → условие `(исчезло_c ≥ 3 и 3·исчезло_c > было_c)` ложно. Второе условие (опустело) к табличным классам не относится.

Остальные классы (контракт, сущности, задачи, топики, экраны, роли, зависит от) в перечнях грепов не переданы — данных об изменениях по ним нет, порог не срабатывает.

Ни один класс не превысил порог 3 ключей с большинством от было_c.
