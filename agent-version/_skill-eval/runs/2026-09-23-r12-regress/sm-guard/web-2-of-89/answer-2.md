## Гард — расчёт по классам

Ключи даны только для одного класса — **потребляемые API**. По остальным классам (контракт, сущности, задачи, топики, экраны, роли, зависит от) перечней нет — принимаю было = исчезло = появилось = 0, порог не может сработать.

**Потребляемые API:**
- было = 89 (billing · GET /projects/0/estimate … /projects/88/estimate)
- черновик = 87 (billing · GET /projects/2/estimate … /projects/88/estimate) — подмножество прежней
- исчезло = 2: `billing` · GET /projects/0/estimate, `billing` · GET /projects/1/estimate
- появилось = 0
- опустело — не считается: класс табличный (первая+вторая колонки), не блочный, «опустело» определено только для классов с `###`-блоками

Порог: исчезло_c ≥ 3 и 3·исчезло_c > было_c → 2 ≥ 3 = **ложно**. Порог не сработал.

Остальные классы: данных нет → 0/0/0 по всем, порог не сработал ни у одного.

Ни один класс порог не превысил → маршрут ПОВЕРХ. Исчезнувшие ключи — именами в отчёт (Шаг 6): `billing` · GET /projects/0/estimate, `billing` · GET /projects/1/estimate.
