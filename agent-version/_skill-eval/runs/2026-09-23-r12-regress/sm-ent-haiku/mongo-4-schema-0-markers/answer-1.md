Анализирую по двум правилам.

**Маркерный гейт (сверка вверх)**
- Маркеров по коду: 0 (`@Entity\b|@Table\(` и т.д. не найдены)
- Блоков в описи: 4 (Order, Customer, Invoice, Payment)
- Правило: "Маркер дал ноль — сверки нет" (нижняя граница)
- Гейт не срабатывает

**Сверка сущностей сверху (верхняя граница)**
- Блоков `###` (4) > Маркеров (0) → обычно добор
- Проверяю исключение: "маркер вне таблицы (Mongo и подобные)"

Два grep по описи:
1. Строки сущностей `\([^)]*\)\s*$`:
   ```
   Order — schema/Order.java (@Schema) ✓
   Customer — schema/Customer.java (@Schema) ✓
   Invoice — schema/Invoice.java (@Schema) ✓
   Payment — schema/Payment.java (@Schema) ✓
   ```
   Есть 4 строки

2. Из них с маркером таблицы `\(@Entity|\(@Table|\(model\b`:
   - Ищу `(@Entity`, `(@Table`, `(model` — не найдено ни в одной
   - Только `(@Schema)` — это OpenAPI маркер, не хранения

**Итог:** Строки сущностей есть, маркеры таблицы отсутствуют → исключение срабатывает (маркер вне таблицы). Проверка по "Сущности у ручек": в выдержке обе строки есть, имена совпадают со списком.
