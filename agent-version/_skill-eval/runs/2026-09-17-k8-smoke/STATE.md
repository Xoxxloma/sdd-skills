# Раунд 2026-09-17-k8-smoke — дым-тест правки К8 (этапы необязательны)

**Что это.** Не замер, а дым-тест: 2 + 2 прогона на sonnet, без базы. Вопрос раунда — «новая ветка
маршрута работает?», а не «стало лучше?». Текст — ветка `fix/audit-k8-optional-stages`, рабочее
дерево грязное, источник истины — `_skills/` (оркестратор 1.1.0 с хвостом Шага 5: станция
`/spec-readiness` + вопрос «Разбить спеку на этапы?»). Под-скиллы заглушены (`RT-BUG/stubs`).

**Запуск.** `SM_MODEL=sonnet RUN_TIMEOUT=1200 SKILL_EVAL_SEED_ROOT=<свой на плечо> bash run-ctx.sh <проба> runs/2026-09-17-k8-smoke 2 2`,
оба плеча параллельно. Потолок ходов 8, effort — умолчание CLI.

  скилле. Рекомендацию модель не добавляет ни в одну сторону.

- **Развилка Шага 6** в этой фикстуре закрыта промптом заранее («на сегодня закончить, другую
