2. **Состав: сошлось.** Строк `состояние:` одна, блок объекта один (`Shipment`). Сообщений 1: строк `сообщение:` 1, блоков `публикует` 1. Ограничений 1 из 1. Перечисления `packageType` и `Attachment.kind` названы в описи справочниками и блоков не имеют, неназванных перечислений нет.
3. **Значения: не сошлось.**
   - Форма «Владеет данными» — строки `- поле: тип`, не таблица.
   - `packageType` и `kind` имеют значения через `|`.
   - `status` записан как `` `ShipmentStatus` — перечисление `` без значений. Это «тип без значений», по правилу добор.
   - Строк в блоке `Shipment` 3, значений 3, токены — значения, заполнителей нет.
4. **Код: сошлось.** Вне бэктиков нет ни ` /[a-z]`, ни HTTP-глаголов, ни camelCase, ни имён из трёх и более частей через точку. В бэктиках только `NEW`, `ASSIGNED`, `DELIVERED`, топик `shipment.delivered` и `partner-registry` из манифеста. В заголовке сообщения бэктиков нет.
