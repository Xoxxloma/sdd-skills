## Разбор

По Шагу 3.1, вес сервиса = сумма маркеров `ключ` + 0.5 × сумма `ориентир` = (34+12+3+4) + 0.5×2 = **54**. 
Это **меньше K = 80**, поэтому по правилу «Вес сервиса больше K — сервис читают части: 3.5 вместо 3.2–3.4» нарезка не требуется. Читать будет один субагент (Шаг 3.2–3.4).

По Шагу 3.1, перед запуском читающего нужно: (1) запустить счётчика для создания counts.txt; (2) запустить reference/plan.sh, чтобы подтвердить, что первая строка вывода говорит «нарезка не нужна»; (3) затем Шаг 3.2 — читающий субагент.
