## Разбор

Вес сервиса = 118 (контракт) + 37 (сущности) + 5 (задачи) = **160 ключей**.

По правилу 3.5: 160 > K=80 → обычно требуется нарезка (`plan.sh` → части → склейка через `assemble.sh`).

Но условие:
> Нарезка и склейка — скрипты этого скилла, и им нужна командная строка. Её нет — нарезки нет.

Командной строки (Bash/PowerShell) нет → нарезку выполнить невозможно → склеить части нечем → читаю целый сервис одним субагентом по 3.2–3.4, сообщаю человеку причину.
