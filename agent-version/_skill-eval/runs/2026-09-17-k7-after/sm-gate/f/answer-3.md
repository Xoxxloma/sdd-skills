## Проверка по пяти числам

**(1) Число и состав блоков.** В описи одна строка `состояние:` → сущность `Shipment`. Блоков объектов в карточке — один (`Shipment`), доп. блок на `Attachment` не заведён — верно, у него только `справочник:`, блока не полагается. Плюс блок сообщения (1 строка `сообщение:` → 1 блок) и блок ограничения (1 строка `ограничение:` → 1 блок). Итого 1+1+1 = 3 блока, в карточке ровно 3. Сошлось.

**(2) Строк в блоке объекта не меньше значений.** У `Shipment.status` в описи 3 значения (`NEW | ASSIGNED | DELIVERED`). В блоке `Shipment` — 4 строки (три состояния + строка про тип упаковки). 4 ≥ 3, минимум соблюдён. Сошлось (формально).

**(3) Токены в блоках объектов — только значения.** `NEW`, `ASSIGNED`, `DELIVERED` — законные значения `status` из «Владеет данными». А вот строка «тип упаковки (`BOX` / `PALLET`) — задаётся при создании» — это значения поля `packageType`, которое в описи названо `справочник:`, а не `состояние:`. У строки несколько токенов через `/`, и после них нет ни того, кто переводит, ни условия, ни следствия («задаётся при создании» ничего не решает и не запрещает) — по правилу проверки это справочник, записанный состоянием, внутри блока объекта. Не сошлось.

**(4) Блоков сообщений не меньше `публикует` и не меньше строк `сообщение:`.** Блоков сообщений — 1, блоков `публикует` в «Событиях» — 1, строк `сообщение:` в описи — 1. Заголовок блока — словами, токен-топик `shipment.delivered` — в строке, не в заголовке. Сошлось.

**(5) Блоков ограничений столько же, сколько строк `ограничение:`.** По одному с каждой стороны. В теле блока условие названо словами, управляющий — `partner-registry` (сервис из манифеста), `true`/`false` нет. Сошлось.

Расхождение по пункту (3): в блок объекта `Shipment` затесалась строка справочника (`packageType`), у которой нет ни переводчика, ни условия, ни следствия — по правилам гейта справочник блока вообще не получает и не должен появляться строкой состояния внутри чужого блока.

ГЕЙТ: ДОБОР — убрать из блока `Shipment` строку «тип упаковки (`BOX` / `PALLET`) — задаётся при создании»: `packageType` — справочник, а не состояние, блока (и строки в блоке состояния) ему не положено.
