Источники: только карточки, то есть `services/auth.md` и `services/geo.md`. Файлы из `services/_pending/` не источники: `_pending/geo.md` и `_pending/billing.md` рёбер не дают и зеркал не получают.

- **`geo`:** берётся `services/geo.md`, а не `_pending/geo.md`. Прежняя карточка остаётся как есть.
- **`billing`:** карточки на диске нет, есть только кандидат. Значит, `billing` не источник, если в этом прогоне карточку не запишут.
- **Шаг 5:** если в прогоне не записана ни одна карточка, шага нет. Пишу одну строку и иду на Шаг 6.
- **Как читаю:** строки достаю через `Grep` без чтения карточек целиком.
