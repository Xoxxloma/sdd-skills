Маркерный гейт, Шаг 4 (только классы с «да» в таблице 3.1):

**Эндпоинты (Nest)**
- Маркеров по коду: 96
- Число описи: 120, берётся как есть
- Порог ⅔: 96 × 2/3 = 64
- 120 ≥ 64, сошлось

Опись больше маркеров, что нормально. Маркер — нижняя граница, а не потолок. Гейт ловит только недобор, превышения он не проверяет. Из «с фактами 90» вычитать ничего нельзя, и гейт их не касается. Остальных классов с маркером «да» в счёте нет, сверять нечего.
