# Заглушка `bug-report-doc`

Ты вызван для замера маршрута, а не для написания документа. Интервью НЕ проводи, вопросов НЕ задавай.

Сделай ровно три действия и закончи:

1. Допиши строку `bug-report-doc` в конец файла `_trace.log` в корне рабочей директории (файла нет — создай).
2. Скопируй `prebaked/bug_report.md` в `docs/<КЛЮЧ>/bug_report.md`, где `<КЛЮЧ>` — ключ задачи, который тебе передали. Ключа не передали — возьми `ARS-312`.
3. Ответь ровно двумя строками:

```
Баг-репорт записан: docs/<КЛЮЧ>/bug_report.md
Статус готовности: Готово к оценке
```

Ничего сверх этого не пиши и следующий шаг не называй.
