## Условия

Первое выполнение каждого сценария и каждого примера приёмки — отдельный субагент с
`fork_turns: none`. Каждому переданы только его снимок скилла/чек-листа и входы. Внешние
модели, Claude CLI и другой внешний инференс не запускались. Снимок `_skills/` хранит
измеренную редакцию `technical-spec-doc` и `spec-review`.

После замера по замечанию человека блок оформления у шаблона сокращён с 25 до 7 строк:
одно правило, один пример, сохранены смешанные разделы, структура Markdown и открытые вопросы.
Затем пункт 11 приёмки сокращён до пяти проверяемых условий. Этот снимок оставлен без
изменений; последующий контроль коротких формулировок записан отдельно в
`../2026-10-06-na-strike-v3/STATE.md`.

После запроса человека о длительности работы раунд ограничен четырьмя первыми
сценариями: багфикс, мелкая правка, новая фича, доработка. Выбор сделан до завершения всех
этих проб, по покрытию режимов, а не по цвету результата. Шесть других подготовленных
песочниц не запускались и результатами не считаются (`--limit=4`).
