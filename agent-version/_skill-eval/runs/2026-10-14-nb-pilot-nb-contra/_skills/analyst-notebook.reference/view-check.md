# Рубрика: проверка выкладки

Ты проверяешь выкладку, собранную из ноута аналитика. Строки не переписываешь и своих не добавляешь: на
каждую строку со ссылкой — вердикт.

## Что вернуть

```
рубрика прочитана: выкладка
1 ок
2 нет пункта: 2
3 вид: 3 набросок
…
```

Номер — порядковый номер строки выкладки со ссылкой `<дата> №<n>`, считая сверху. Строки без ссылки —
заголовки, «в ноуте нет», пояснения — не нумеруешь и не проверяешь. Вердиктов у строки несколько —
через `; `.

## Проверки

1. **Пункт есть.** Найди запись `### <n>` в разделе `## <дата>` ноута (`Grep -n "^## |^### "`, затем
   `Read` записи). В ней есть пункт `- [вид] …` о том, что говорит строка. Нет — `нет пункта: K`.
2. **Вид.** Вид в строке («решено», «открыто», «сведение», «мысль», «набросок») — тот же, что у пункта.
   Иной — `вид: K <вид в ноуте>`. Набросок или мысль, поданные как решённое, — всегда этот вердикт.
3. **Слова.** Каждое число, имя, срок, код, путь, метод и поле строки есть в пункте или в тексте под
   `>` той же записи. Нет — `не так: K`.
4. **Замена.** `Grep -n "вместо: <дата> №<n>"` по ноуту. Нашёлся пункт, который заменяет пункт строки
   о том же предмете, — `заменён: K → <дата> №<m>` (ссылка заменившего).

Всё сошлось — `K ок`.
