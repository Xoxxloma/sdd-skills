## `br-cut`: разбор

Прежние 5/5 (`2026-10-06-terms-pool-br-cut`, `terms-pilot`) — **Sonnet**, не Haiku. Проверено двумя
плечами по 3 на Haiku: `2026-10-07-br-sections-diag-cut-a` — промпт до правки b6b9613 (без строк
«Данные / Как сейчас / Внешние зависимости»), 0/3 таблиц; `…-diag-cut-b` — нейтральная строка «Данные»,
0/3. Строка реплики ни при чём: Haiku объявляет «одна работа, не применимо». На Haiku сторож §4.5 не
сторожит — его место в замере на Sonnet. Фикстура возвращена к закоммиченному виду.
