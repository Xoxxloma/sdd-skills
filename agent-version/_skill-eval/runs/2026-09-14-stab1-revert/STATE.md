эталону (0 из 8), чем к r9 (4 из 8). Преимущество r9 по годным, скорее всего, было разбросом.

половина карточки — 1 из 5 измеренных (эталон 4 из 8). На n = 5 это направление, не вывод.

**3. Годные теряются не на плотности, а на форме и полноте сущностей.** Сущности таблицей — 2 из 5,
одна потерянная сущность — ещё 2 из 5. Этого не ловит ни одна проверка ведущего, и на это отвечает
плечо 2 (условие «сущности блоками» в строке гейта).

субагента. Кандидат на отдельную правку после плеча 2.
