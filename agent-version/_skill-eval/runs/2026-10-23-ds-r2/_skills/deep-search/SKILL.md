# Глубокий поиск — как система работает сейчас

Аналитик спрашивает, как что-то работает сейчас. Ответ ищет **разведчик** — субагент: по карточкам
`services/` находит сервис, по манифесту — его репу рядом, в коде — ответ. Ты запускаешь разведчика,
сверяешь его ссылки и отвечаешь в чат. Ты ничего не пишешь.

**Бриф разведчика — `reference/brief.md` рядом с этим файлом**, в папке скилла, а не в репозитории со
спеками. Путь считай от `SKILL.md`, разведчику передавай абсолютным. Бриф не пересказывай и не
вклеивай — разведчик читает его сам. Файла нет → остановись: «не нашёл `reference/brief.md`, скилл
установлен не полностью».

## Шаг 1 — вопрос

- О том, как система работает сейчас → Шаг 2.
- Как сделать, как лучше, что поменять → одна строка: «Это вопрос проектирования — его решают в
  `/technical-spec-doc`. Могу рассказать, как это работает сейчас». Стоп.
- Смешанный → разведчику отдай только часть «как сейчас»; в ответе одна строка, что остальное — для
  спеки.
- Вопроса нет → спроси одной строкой, что посмотреть.

## Шаг 2 — разведчик

Корень — текущая папка. `Glob pattern="*.md" path="services"` (папка — параметром `path`, не в
шаблоне) пуст → «не вижу `services/` — запусти из репозитория со спеками». Стоп.

Один разведчик на вопрос. Тип субагента — любой, у которого есть `Read`, `Grep`, `Glob`; писать ему не
нужно. Промпт — этот, с подстановкой, без своих добавлений:

```
Ты — разведчик скилла deep-search. Сначала прочитай бриф <абсолютный путь к reference/brief.md> и работай строго по нему.
Вопрос: <вопрос аналитика его словами>
Корень: <абсолютный путь к текущей папке>
```

При повторном запуске после выбора аналитика добавь строку `Сервис: <имя>` или `Репа: <абсолютный
путь>`.

В ответе нет ни одного из заголовков `## ОТВЕТ ПО КОДУ`, `## СЕРВИС НЕ ОПРЕДЕЛЁН`, `## КОДА НЕТ`,
`## СЛИШКОМ ШИРОКО` → разведчик работал не по брифу. Перезапусти один раз тем же промптом. Снова нет —
скажи аналитику, что поиск не удался. По памяти не отвечай.

Субагента запустить нельзя → выполни бриф сам, теми же шагами.

## Шаг 3 — разведчик не дошёл до кода

- `## СЕРВИС НЕ ОПРЕДЕЛЁН` или `## КОДА НЕТ` → вопрос аналитику: варианты — сервисы и папки из ответа
  разведчика, до четырёх, остальные — строкой в тексте вопроса. Выбрал сервис → перезапуск с
  `Сервис:`, выбрал папку → с `Репа:` (путь абсолютный).
- `## СЛИШКОМ ШИРОКО` → вопрос аналитику: какие один-два сервиса смотреть; перезапуск с `Сервис:`.
- Перезапуск один. Снова не дошёл до кода → ответ тем, что разведчик нашёл в карточках и документах,
  со строкой «кода рядом не нашёл».

## Шаг 4 — сверка ссылок

Каждую ссылку `[в коде]` открой. Ссылка `<репа>/<путь>:<строка>` → файл `<абсолютный путь этой
репы из ## ПРОЧИТАНО>/<путь>`, `Read` с `offset` = строка − 2, `limit` = 5; у диапазона `:<a>-<b>` —
`offset` = a − 2, `limit` = b − a + 5. Строка не показывает того, что сказано в пункте, или файл не
открылся → пункт убери и добавь в ответ строку «N ссылок не подтвердил — пункты убрал». Ссылки
`[из документа]` не сверяешь.

## Шаг 5 — ответ в чат

```
Как сейчас: <1–3 строки сути словами>
- [в коде] <что делает код> — <репа>/<путь>:<строка>
- [из документа] <что сказано> — services/<файл>.md | context/<файл>.md
- [вне кода] <что и где живёт>
- [не нашёл] <часть вопроса без ответа в коде>
Читал: <репа>, ветка <ветка> — локальная копия, могла отстать от удалённой.
```

- Две репы — обе в строке «Читал».
- Пункты — из ответа разведчика после сверки, своих не добавляешь. Имена ручек, событий, статусов —
  как в коде.
- Разведчик написал, что карточка расходится с кодом → строка «Карточка `services/<сервис>.md`
  расходится с кодом: <что>. Обновить: `/service-map <сервис>`».
- Разведчик назвал `Рядом вне манифеста: …` → после ответа вопрос аналитику: посмотреть там? Варианты —
  эти папки. Выбрал → перезапуск с `Репа:`.

## Не делаешь

- не читаешь карточки и код сам — кроме сверки на Шаге 4 и случая, когда субагента нет;
- не пишешь и не правишь файлы, не предлагаешь записать ответ;
- не запускаешь git;
- не проектируешь и не советуешь, как сделать.
