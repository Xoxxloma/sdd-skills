# Критерии зелёного регресса для третьего круга (записаны ДО результатов, 21:10)

База: `2026-09-21-before-rescan` (1.5.0, rescan ×2), `2026-09-21-sm-biz-pilot` (1.5.0, scan ×1).
Второй круг 2.0.0: `2026-09-21-r2-scan`, `2026-09-21-r2-rescan`.

## rescan ×3 (главное)
- карточек записано **2 из 2** во всех трёх (база 1 из 2);
- `grade-sm-guard.mjs`: нарушений маршрута 0, перезаписей при потере выше порога 0;
- строк-фактов медиана ≥ 176; анкеров ≥ 8/14; форма по шаблону 3/3; дословно ≥ 90 %;
- `grade-sm-trace.mjs`: Write карточки ведущим 0.

## scan ×3
- 96/96, 20/20, 1/1 во всех трёх; факты медиана ≥ 240 (0,9 × 266); анкеров ≥ 11/14 медиана;
- **экраны ≤ 26** (ключ 24) — до снятия маркера экранов текст круга 3 его уже не содержит: проверка, что перебор 30–53 из второго круга был побочным эффектом
  маркера `<Route`, и снятие маркера его убрало; бизнес-анкеров в слое ≥ 7/8; строк с кодом 0.

## «Три круга без изменений»
Круг считается «без изменений», если по всем пунктам выше вердикт тот же, что в предыдущем
круге, и текст скилла между кругами не менялся. Второй круг → третий: текст менялся (маркер
экранов, один добор, источник через добор), значит счёт кругов без изменений начинается с третьего.

## Что не является критерием (наблюдается, в отчёт)
Read шаблона и прежних карточек ведущим (текстовый запрет, инструмент в руках); строка гейта
«Бизнес-правил» в отчёте; цена прогона.
- Порог сервисов за прогон снижен до пяти (решение владельца 21.09); плечо на 10 клонов (SM-ADV R8) не гоняется.
