# Критерии зелёного — раунд `br-comb` (PLAN-BR-COMB v2.2), записаны ДО результатов

Модель: Haiku на всём раунде (`SM_MODEL` не передаётся, умолчание `run-ctx-v2.sh`). N=10 на пробу.
Считаем прогоны, не единицы счётчика. Прогон без артефакта по вине стенда (`_escaped.txt`,
`_api-failure.txt`, session limit, 403) — «не измерено», из знаменателя выпадает.

**Каждая проба — в СВОЕЙ папке раунда** (`runs/2026-10-02-brc-<плечо>-<проба>/`): `run-ctx-v2.sh` по
концу пробы сносит снимок `/tmp/skill-eval-seed/<раунд>-skills`, и соседняя проба той же папки теряла бы
скилл посреди прогонов (пилот 2026-10-02 так и шёл — обошлось, повторные чтения скилла не случились).

## Правило отката (PLAN §3)

1. Красный → разбор красных прогонов → откат правки по механизму; механизм не найден — батч целиком.
2. D2 и D3 — вне отката (решения человека): красный от них — правка формулировки.
3. A красный после отката по механизму → раунд стоп.
4. **Три красных подряд на одном батче → стоп** (условие выхода цели).

## Условие выхода

Полностью зелёный регресс после C, либо три красных подряд на любом батче.
