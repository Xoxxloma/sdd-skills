## Решение

Прополка **принята**. Итог дня по `sr-gap`: база 3,8 дыр при 17,5 пунктах → 4,5 дыр при 13,6.

## Грейдер: две починки анкеров по живым формулировкам

Оба — класс дефекта, описанный в шапке `grade-sr.mjs` (падеж, короткое окно), найдены по
строке «ПОДОЗРЕНИЕ НА АНКЕР» и разобраны глазами:

- `g6`: `гонк[аиу]` не ловил «при гонке отзыва с решением» — добавлен предложный падеж;
- `g4`: окно `422[^.\n]{0,60}пол` не дотягивалось до «код 422 (данные заявки не прошли проверку) —
  указывает ли ответ на конкретное поле формы», 62 знака; окно расширено до 80.

После починок рычаг 1 4,4 → 4,5, прополка 4,3 → 4,5; база, рычаги 2 и 3 не изменились.

Оставшиеся подозрения разобраны и не засчитаны: `run-4` про роль спрашивает только про потерю
роли посреди сеанса, не про серверную проверку; `run-2`/`run-5` про строку списка не спрашивают.
