## Расчёт гарда

Классы, которые считаются согласно правилу:
- **контракт** (60 и 30 в описи — считаем)
- **бизнес-правила** — **не считаются** (явное исключение в правиле)
- остальные классы в данных не представлены (пусты)

---

### Класс: контракт

| Метрика | Значение |
|---------|----------|
| было | 30 |
| исчезло | 0 |
| появилось | 0 |
| опустело | 0 |

Проверка условий для `_pending`:
- (исчезло ≥ 3 и 3·исчезло > было)? → (0 ≥ 3 и 0 > 30)? → **ложь**
- (опустело ≥ 3 и 3·опустело > было)? → (0 ≥ 3 и 0 > 30)? → **ложь**
