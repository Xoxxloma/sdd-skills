- Ключ задачи: MNT-410
- Задача: система мониторинга станков сама замечает неисправность, но мастера узнают о ней по телефону от начальника смены. Нужно, чтобы по каждой неисправности автоматически появлялась заявка на ремонт, а мастера работали по списку заявок.
- Проблема: о неисправности узнают с опозданием, станок простаивает лишние часы.
- Как будет идти процесс: система мониторинга сообщает о неисправности — появляется заявка на ремонт; начальник смены назначает ответственного мастера и плановую дату устранения; мастер видит заявку в списке, устраняет неисправность и закрывает заявку.
- Кто пользуется: начальники смен и мастера ремонтной службы.
- Роли: «начальник смены» — назначает мастера; «мастер» — работает по заявке. Обе роли в системе есть, новых не заводим.
- Цель: как начальник смены хочу получать заявку на ремонт сразу при неисправности, чтобы станок не простаивал.
- Ценность: простой станков сокращается — сейчас это в среднем 3 часа на неисправность.
- Риски: рисков нет.
- Приоритет: высокий.
- Срок: 01.06.2027.
- Что входит: (1) автоматическая заявка на ремонт по неисправности; (2) назначение мастера; (3) список заявок у мастеров и закрытие заявки. Не входит: учёт запчастей, плановые ремонты.
- Когда считаем готовым: (1) система мониторинга сообщила о неисправности — заявка появилась в списке; (2) начальник смены назначил мастера — мастер видит заявку у себя; (3) мастер закрыл заявку — она ушла из списка открытых.
