# Состав данных: заявка на ремонт от системы мониторинга станков

Заявка появляется, когда система мониторинга сообщает о неисправности станка: одна неисправность — одна заявка.

- **Станок**
  - Инвентарный номер станка (`machine.invNo`) — видно в карточке заявки
  - Цех (`machine.workshop`) — видно в карточке заявки и в списке заявок
  - Модель станка (`machine.model`) — видно в карточке заявки
  - Дата последнего планового ремонта (`machine.lastServiceDate`) — видно в карточке заявки
- **Неисправность**
  - Код неисправности (`fault.code`) — видно в карточке заявки
  - Описание неисправности от системы мониторинга (`fault.text`) — видно в карточке заявки
  - Время обнаружения неисправности (`fault.detectedAt`) — видно в карточке заявки
  - Признак остановки станка (`fault.stopped`) — видно в карточке заявки
- **Заявка на ремонт**
  - Номер заявки (`request.number`) — присваивается автоматически; видно в карточке и в списке заявок
  - Уровень срочности (`request.urgency`) — «срочная», если станок остановлен, иначе «обычная»; видно в списке заявок
  - Ответственный мастер (`request.master`) — назначает начальник смены; видно в списке заявок
  - Плановая дата устранения (`request.dueDate`) — ставит начальник смены при назначении мастера; видно в карточке заявки
