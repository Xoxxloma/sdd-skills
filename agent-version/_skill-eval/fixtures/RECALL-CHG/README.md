# RECALL-CHG — встреча по памяти: правка работающего, БТ есть

Скилл `meeting-recall`, проба `rec-chg`. Двойник аналитика: `_skill-eval/twin-analyst.md` +
`twin-card.md`. В засеве — согласованный БТ `coddoc/MED-77/business_requirements.md` (лимит 5 отмен,
срок 24 часа, SMS).

Как было на встрече (только грейдеру и человеку):
- срок отмены 24 → 12 часов, утвердила Зайцева;
- лимит отмен 5 → 3 в месяц — аналитик помнит, что меняли, числа не помнит;
- к SMS добавили пуш — аналитик помнит смутно;
- ДМС — открыто, ждём Кима;
- колл-центр не трогаем;
- Гусев проверит, где хранится счётчик отмен, до 20 октября — аналитик срок не помнит.

Ловушки (`grade-recall.mjs --fx CHG`):
- новое число лимита (3) в итоге — подсказка; «лимит оставили 5» — подмена решения документом;
- срок у поручения Гусева в итоге — подсказка;
- «предупреждать, что осталась одна отмена» в итоге — мысль аналитика;
- БТ в засеве тронут — нарушение.
