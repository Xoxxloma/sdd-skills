# Техническая спецификация: Парковочная сессия с оплатой при выезде

> **Задача:** PRK-9
> **Источник (БТ):** бриф аналитика
>
> **Статус готовности:** Готово к разработке
>
> **Открытые вопросы (решить до / во время разработки):**
> Открытых пунктов нет.

## 1. Обзор изменения

### 1.1. Что делаем и тип изменения

**Суть:** Водитель в приложении начинает парковочную сессию, шлагбаум открывается, при выезде сессия закрывается и списывается оплата по тарифу зоны.

**Тип:** новый функционал

**Стороны:** Fullstack

### 1.2. Затронутые сервисы и владельцы

| Сервис | Роль в задаче | Владелец/команда | Происхождение |
|--------|---------------|------------------|---------------|
| `parking-web` | Фронт водителя: начало и завершение сессии | Команда приложения | 🟢 |
| `parking-api` | Бэк сессий: открывает, закрывает, считает | Команда парковок | 🟢 |
| `notify` | Уведомления водителю | Команда уведомлений | 🔵 подтв. аналитиком |
| `tariff-service` | Тарифы зон | Команда тарифов | 🔵 подтв. аналитиком |
| `gate-controller` | Управление шлагбаумами, датчики проезда | Команда оборудования | 🔵 подтв. аналитиком |
| `billing` | Списание оплаты | Команда биллинга | 🔵 подтв. аналитиком |

## 2. Взаимодействия (ядро)

### INT-1. Начало парковочной сессии — 🟢
- **Граница/направление:** `parking-web` → `parking-api`
- **Триггер:** водитель нажал «Начать парковку» на экране зоны
- **Контракт (запрос):** `POST /v1/sessions`, тело `{ zoneId, plate }`
- **Контракт (ответ):** `{ sessionId, startedAt }`
- **Ошибки:** `404` — зона не найдена; `409` — у машины уже есть открытая сессия
- **Авторизация:** водитель с подтверждённым номером телефона
- **Происхождение:** 🟢 новое

### INT-2. Событие «сессия начата» — 🟢
- **Граница/направление:** событие: `parking-api` → `notify` (через брокер)
- **Триггер:** сессия успешно создана
- **Контракт (событие):** `session.started` — `sessionId`, `plate`, `startedAt`
- **Ошибки:** при недоставке брокер повторяет отправку, не более 3 попыток
- **Происхождение:** 🟢 новое

### INT-3. Тариф зоны — 🔵
- **Граница/направление:** `parking-api` → `tariff-service`
- **Триггер:** расчёт стоимости при создании и при закрытии сессии
- **Контракт (запрос):** `GET /internal/tariffs/{zoneId}`
- **Контракт (ответ):** `{ pricePerHour, freeMinutes }`
- **Ошибки:** см. «Каталог ошибок»
- **Происхождение:** 🔵 подтверждено аналитиком

### INT-4. Открыть шлагбаум — 🔵
- **Граница/направление:** `parking-api` → `gate-controller`
- **Триггер:** сессия создана, машина стоит у въезда
- **Контракт (запрос):** `POST /v1/gates/{gateId}/open`
- **Контракт (ответ):** не применимо — контроллер подтверждает приём команды без тела
- **Ошибки:** `204` приходит и при уже открытом шлагбауме; при молчании контроллера повтор через 10 с, не более 3 попыток
- **Происхождение:** 🔵 подтверждено аналитиком

### INT-5. Завершение сессии и оплата — 🟢
- **Граница/направление:** `parking-web` → `parking-api` → `billing`
- **Триггер:** водитель нажал «Завершить и оплатить»
- **Контракт (запрос):** `POST /v1/sessions/{id}/finish` от приложения в `parking-api`; дальше `parking-api` списывает оплату вызовом `POST /v2/charges` в `billing`
- **Контракт (ответ):** `parking-web` получает от `parking-api` `{ amount, status: "paid" }`; тело ответа `billing` для `parking-api` в спеке не описано
- **Ошибки:** `402` — оплата отклонена; `502` — биллинг недоступен
- **Происхождение:** 🟢 новое

### INT-6. Машина проехала шлагбаум (колбэк) — 🟢
- **Граница/направление:** `parking-api` ← `gate-controller` (колбэк)
- **Триггер:** машина проехала под шлагбаумом; датчик зафиксировал проезд, контроллер сообщает номер шлагбаума и время
- **Контракт (запрос):** `POST /v1/gates/{gateId}/passed`, тело `{ plate, passedAt }`
- **Контракт (ответ):** пустое тело
- **Ошибки:** `401` — подпись колбэка неверна
- **Происхождение:** 🟢 новое

### Каталог ошибок (сводно)
| Код | Тело/сообщение | Когда | Состояние UI |
|-----|----------------|-------|--------------|
| 404 | `zone not found` | зоны нет | ошибка на экране зоны |
| 409 | `session already open` | сессия уже открыта | переход к открытой сессии |
| 503 | `tariff unavailable` | сервис тарифов недоступен | «попробуйте позже» |
| 402 | `payment declined` | оплата отклонена | экран выбора карты |
