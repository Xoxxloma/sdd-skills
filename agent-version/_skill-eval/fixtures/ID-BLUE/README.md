# Фикстура ID-BLUE — подпись стрелки у карточки «изменение существующего» (`interaction-diagram`)

Заведена 2026-10-26 после ревью покрытия п.2б. Спека — `SHT-410` из `RV-BLUE` (выход `technical-spec-doc` 1.7.0).
У карточек изменения в «Контракт (запрос)» стоит «без изменений», путь — в строке «Существующий стык».

| Карточка | Строка стыка | Подпись на стрелке |
|---|---|---|
| INT-1 (изменение) | 🟡, словами | `INT-1` — пути нет |
| INT-2 (потребление) | — | `INT-2 · GET /api/v3/badges?holderLogin={login}` или без запроса — из «Контракт» |
| INT-3 (изменение) | `GET /v1/trips/{tripId}` → поля, 🔵 | `INT-3 · GET /v1/trips/{tripId}` — без полей |
| INT-4 (изменение) | `GET /v1/trips` отдаёт …, 🔵 | `INT-4 · GET /v1/trips` |

Проба `id-blue`: ход 1 — промпт, ход 2 — «Короткую», ход 3 — участники, звенья INT-1/3/4 и порядок
(`q-turn2.txt`); конец — по файлу `coddoc/SHT-410/interaction_diagram.md`. Грейдер `grade-id-blue.mjs`.

**Ответ хода 3 дополнен 2026-10-26 (после раунда `top-id`).** Граница у INT-1, INT-3 и INT-4 —
``FE → BE (`shuttle-web` → `shuttle-api`)``: два знака `→`, второй в скобках. По `inputs/spec.md` это
условие вопроса «цепочка», а без ответа на него карточка со знаком в скобках со схемы снимается. Прежний ответ
закрывал только участников и порядок. В 7 прогонах из 8 (`2026-10-26-cov-d` run-1/2, `2026-10-26-top-id`
run-1/2/4/5/6) скилл о цепочке не спросил, и на схеме были все 5 карточек; в `top-id` run-3 спросил — законно, — не
получил ответа и нарисовал 2 стрелки из 5, без INT-1, INT-3 и INT-4. Красный был от фикстуры, а не от скилла.
В ответ добавлена одна фраза, как ответил бы аналитик: у INT-1, INT-3 и INT-4 одно звено FE → BE, в
скобках те же стороны под именами сервисов. Подписи стрелок и пути в ответе не названы: их скилл обязан
взять из спеки сам, это и меряет проба. Фразы об участниках и порядке — прежние; вопроса «нет направления»
эта спека не вызывает, у всех карточек знак есть. Грейдер не менялся.
