## КАРТОЧКА (фрагменты)

```markdown
## Владеет данными

### `Shipment` — отправление
- `status`: `NEW` | `ASSIGNED` | `DELIVERED`
- `packageType`: `BOX` | `PALLET`
- `weightKg`: decimal
- `assignedAt`: timestamp

### `Attachment` — вложение к отправлению
- `kind`: `PHOTO` | `PDF`
- `url`: string

## События

### публикует `shipment.delivered`
- после отметки курьера о вручении; тело: идентификатор отправления и время вручения

## Бизнес-правила

### `Shipment` — отправление
- новое (`NEW`) — создаёт диспетчер; пока курьер не назначен, отправление можно отменить
- назначено (`ASSIGNED`) — диспетчер назначает курьера; после назначения отменить может только диспетчер
- переназначено (`ASSIGNED`, `assignedAt` сдвинут) — диспетчер меняет курьера до вручения; прежний курьер получает отмену
- доставлено (`DELIVERED`) — курьер отмечает вручение; вернуть в работу нельзя

### сообщение «груз доставлен»
- при отметке о вручении; получает получатель груза; отправителю не уходит; топик `shipment.delivered`

### ограничение «приём отправлений партнёра отключён»
- условием управляет `partner-registry`; пока оно действует, новые отправления этого партнёра не принимаются, диспетчер видит причину отказа

## Роли и доступ
| Роль | Что может |
|---|---|
| `DISPATCHER` | создаёт отправления, назначает курьера, отменяет |
| `COURIER` | отмечает вручение |
```
