# Фикстура SM-GATE — гейт «Бизнес-правила» у ведущего `service-map`, изолированно

Ведущему даётся дословный текст скилла про секцию (бриф, правила описи, гейт, бюджет доборов —
вырезается из указанного `SKILL.md` по якорям, поэтому меряется именно эта редакция) и готовый
ответ субагента по сервису `shipping`. Инструментов и диска нет. Вопрос один: гейт пройден или
нужен добор. Приём тот же, что у `SM-HANDOFF`: ответ субагента подменён — это цена детерминированности.

| Вариант | Что в ответе субагента | Ожидание |
|---|---|---|
| `clean` | верная по шаблону карточка: у `Shipment` состояние и справочник, у `Attachment` только справочник; блок объекта один | `ГЕЙТ: ПРОЙДЕН` |
| `a` | настоящее состояние `Courier.status` есть в описи и в «Владеет данными», блока нет | `ДОБОР`, назван `Courier` |
| `b` | перечисление `priority` есть в «Владеет данными», в описи не названо ни состоянием, ни справочником | `ДОБОР`, назван `priority` |
| `c` | чужая сущность `Department` «схема partner-registry, на чтение» заведена объектом | `ДОБОР`, назван `Department` |
| `d` | в блоке ограничения не назван тот, кто управляет условием | `ДОБОР` про ограничение |
| `e` | бэктик в заголовке `сообщение «…»` | `ДОБОР` про заголовок |
| `f` | справочник записан строкой состояния: `BOX / PALLET`, правила нет | `ДОБОР` про упаковку |
| `g` | строка на поле: «перевешено (`ASSIGNED`, `weightKg` изменён)» — второй токен — имя поля, не дата | `ДОБОР` про `weightKg` |
| `h` | дата, которой состояние отличается, рядом со значением в скобках: «переназначено (`ASSIGNED`, `assignedAt` сдвинут)» — форма, которую бриф разрешает («как `expiresAt` в примере шаблона»); у двойника два посаженных места — строка правила и поле `assignedAt` во «Владеет данными» | `ГЕЙТ: ПРОЙДЕН` |
| `i` | «Владеет данными» таблицей `Поле / Тип / Описание` без значений перечислений — форма июльских карточек | `ДОБОР` про значения или таблицу |
| `j` | заголовок `письмо «…»` вместо `сообщение «…»` | `ДОБОР` про заголовок |
| `k` | подпись впереди ключа: `### Отправление (`Shipment`)` | `ДОБОР` про заголовок или ключ |
| `l` | два недостижимых значения записаны одинаковым заполнителем «значение enum, кода перехода нет; проставляется напрямую» | `ДОБОР` про заполнитель / «не определено» |
| `n` | те же два значения строками `не определено: перехода в коде нет` | `ГЕЙТ: ПРОЙДЕН` |
| `o` | хозяин ограничения — свой конфиг, названный «внешняя конфигурация (вне манифеста)» | `ДОБОР` про хозяина |
| `p` | справочник строкой с двумя токенами через запятую | `ДОБОР` про упаковку / справочник |
| `q` | второй шаг: добор просил блок «груз задержан», ответ на добор слил оба сообщения в один блок «события отправления» с двумя топиками | `ДОБОР` про слитые сообщения / два блока |
| `r` | второй шаг, ответ на добор верный: два блока сообщений | `ГЕЙТ: ПРОЙДЕН` |

Запуск: `./run-sm-gate.sh <SKILL.md> <папка-раунда> [N]`; `SM_GATE_ONLY="g h"` — только названные варианты. Грейдер: `grade-sm-gate.mjs <папка-раунда>/sm-gate`.
Файлы `answer-*.md` собраны из одного чистого ответа точечными заменами, чтобы двойники
отличались от чистого ровно посаженным местом.
