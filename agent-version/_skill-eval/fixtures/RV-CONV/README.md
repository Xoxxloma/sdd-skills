# Фикстура RV-CONV — приёмка сверяет 🟢-контракт с правилами из `context/`

Заведена 2026-08-14 под шаг 3 `PLAN-CONTEXT.md`. Повод: на `TS-CTX` правило формы из
`context/conventions.md` применяют не все прогоны, а `technical-spec-doc` расти не должен —
нагрузка кладётся на приёмку, которая читает один документ и ничего не пишет.

## Вход

```
docs/RMS-4021/technical_specification.md   спека, чистая по всем 11 пунктам чек-листа,
                                           и с ТРЕМЯ промахами против context/conventions.md
docs/RMS-4021/business_requirements.md     источник (FR-1, FR-2) — из RV-CLEAN, не тронут
context/conventions.md                     те же правила, что в TS-CTX
```

Спека — копия `RV-CLEAN` (на ней приёмка два раунда подряд давала «нарушений: 0»), в которую
внесены ровно три отступления. Так отделяется новый пункт от старых: всё, что найдено сверх этих
трёх, — либо ложное срабатывание, либо находка старого пункта на неизменённом тексте.

## Подложенные промахи — каждый прослеживается до строки `context/conventions.md`

| # | Что в спеке | Строка правила | Секции |
|---|---|---|---|
| 1 | `GET /rooms/occupancy` — путь без `/v1/` | §1 «`/v1/<множественное-число>`, версия сегментом пути» | INT-1 |
| 2 | `as_of: timestamp` — `snake_case`, без суффикса `At`, без `iso8601` | §6 «`iso8601` в UTC; имя поля с суффиксом `At`» + §7 «Поля — `camelCase`» | INT-1, JSON-пример, §3.2, §4.3 |
| 3 | `401` при отказе по роли | §2 «`403` — роль не даёт права на операцию» | INT-1, каталог ошибок, §3.3, §4.4 |

Все три — про **свой 🟢-дизайн**, а не про чужую систему: правило применяется молча и метку не
меняет. Промах в чужой карточке (INT-2, `GET /api/v2/calendar/events`) нарушением НЕ является и
за него краснить нельзя — путь чужого сервиса конвенции не подчиняется.

## Что должно произойти

Приёмка называет **хотя бы один** из трёх промахов с цитатой из файла. Критерий шага —
**≥8 прогонов из 10**.

Чего быть не должно: пункта про INT-2 (чужой путь `/api/v2/`), требования переписать `busyUntil`
(он правилам соответствует) и оценок качества решения.

## Возврат

`./run-ctx.sh rv-conv <раунд> 10`, грейдер `grade-rv-conv.mjs`.
