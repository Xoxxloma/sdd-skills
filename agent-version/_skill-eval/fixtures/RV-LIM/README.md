# Фикстура RV-LIM — счётная строка «порог без примера на границе» в приёмке (`spec-review`)

Заведена 2026-10-26 под п.2 `PLAN-FROM-POCOCK.md`, шаг 4. Документы — замороженные выходы скиллов этого же
раунда: БТ `EXP-310` — `br-lim-w` run-1 (`runs/2026-10-26-p2-s1`), запрос на правку `ARS-326` — `cr-lim-w`
run-1 (`runs/2026-10-26-p2-s2`). Грязные двойники — те же файлы с другим ключом, у которых пример на границе
вырезан: `EXP-311` — у FR-2 (порог 7 500 ₽) и FR-3 (срок до 25-го) по одному значению; `ARS-327` — у `FR-1`
«до 25 фотографий» без 26-й, и из «Как проверят» 26-я тоже убрана.

Пример на границе — форма гипотезы, а не условие закрытия гейта (Р9), поэтому его отсутствие — **не
нарушение**, а счётная строка. FR-4 у БТ (лимит 3 заявки) — свой критерий аналитика без порога («видит,
сколько осталось»): по правилу пункта не считается.

| Проба | Промпт | Верно |
|---|---|---|
| `rv-lim-clean` | `bt-clean-prompt.txt` | `критериев с порогом без примера на границе: 0`; ни одно нарушение не про границу |
| `rv-lim-dirty` | `bt-dirty-prompt.txt` | `…: 2`; ни одно нарушение не про границу |
| `rv-crlim-clean` | `cr-clean-prompt.txt` | `«как должно стать» с порогом без примера на границе: 0` |
| `rv-crlim-dirty` | `cr-dirty-prompt.txt` | `…: 1` |

Грейдер — `grade-rv-lim.mjs --case=bt-clean|bt-dirty|cr-clean|cr-dirty`.
