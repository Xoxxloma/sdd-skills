# PSS-2215 — Техническое решение

## Цель

Реализовать выгрузку согласованных заявок на пропуск в журнал поста охраны на дату визита и
отметку «выгружено» у заявки. Добавить на пост охраны фильтр по подразделению.

Ссылка на требования: proposal.md (openspec/changes/archive/2026-09-20-pss-2215-guard-export/proposal.md)

## Что меняем

### Выгрузка заявок на пост охраны

**Проблема:** пост охраны получал список визитов письмом от бюро пропусков, письмо приходило после
начала смены.

**Решение:**

- PassExportServiceImpl — добавлена выгрузка согласованных заявок на дату визита, заявки берутся
  со статусом `approved`
- GuardJournalClient — добавлен клиент журнала поста охраны, отправка пачкой по 50 заявок
- PassExportScheduler — задача по расписанию в 06:00, повтор через 10 минут при ошибке журнала
- PassController — добавлен метод `POST /v1/passes/export` для ручного запуска выгрузки

### Отметка «выгружено»

**Решение:**

- В `VisitorPass` добавлено поле `exportedAt`, заполняется после ответа журнала
- Повторно выгруженная заявка в журнал не отправляется

### SQL-миграция

**Решение:**

- Файл: V2_14__add_exported_at.sql — добавляет колонку `exported_at` в таблицу `visitor_pass`
- Регистрация в changelog: db.changelog-2.14.xml

### Рефакторинг

**Решение:**

- DateFormatHelper.java — вынесена логика форматирования дат визита из трёх сервисов (40+ строк
  очищенного кода)
- PassMapper — упрощено преобразование заявки в запись журнала
- PassExportServiceImplTest.java — добавлены тесты на выгрузку и повтор

### Фильтр по подразделению на посту охраны

**Решение:**

- GuardJournalClient — в запись журнала добавлен код подразделения заявителя
- Фильтр на стороне журнала поста не менялся

Ключевые изменённые файлы:

1 src/main/java/ru/office/pass/export/PassExportServiceImpl.java (+164 строк) 2 src/main/java/ru/office/pass/export/GuardJournalClient.java 3 src/main/java/ru/office/pass/export/PassExportScheduler.java 4 src/main/java/ru/office/pass/common/DateFormatHelper.java 5 src/main/resources/db/changelog/2.14/V2_14__add_exported_at.sql

## Критерии приёмки (технические)

- Согласованные заявки на дату визита выгружаются в журнал поста охраны в 06:00
- У выгруженной заявки заполнено поле `exportedAt`
- Повторный запуск выгрузки не отправляет уже выгруженные заявки
- Миграция V2_14__add_exported_at.sql успешно применяется и колонка появляется в БД
- Тесты PassExportServiceImplTest проходят

## Границы

### В скоупе:

- Выгрузка согласованных заявок в журнал поста охраны
- Отметка «выгружено»
- Рефакторинг форматирования дат (выделение DateFormatHelper)
- Тесты на ключевые сценарии

### Вне скоупа:

- Выписка самого пропуска
- Отмена выгрузки отозванной заявки
