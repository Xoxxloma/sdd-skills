## 4. Функциональные требования

### 4.1. Описание функционала / бизнес-процесса
- **FR-1.** Пользователь может создавать заявку.
- **FR-2.** Пользователь может просматривать заявки.
- **FR-3.** Пользователь может редактировать заявку.
- **FR-4.** Система уведомляет пользователя.

### 4.2. Критерии приёмки
- **[FR-1]** Дано: пользователь в системе. Когда: он создаёт заявку. Тогда: заявка создана.
- **[FR-2]** Дано: пользователь в системе. Когда: он открывает заявки. Тогда: заявки отображаются.
- **[FR-3]** Дано: заявка существует. Когда: пользователь редактирует её. Тогда: заявка изменена.
- **[FR-4]** Дано: событие произошло. Когда: система его обработала. Тогда: пользователь уведомлён.
