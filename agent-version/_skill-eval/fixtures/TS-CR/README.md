# Фикстура TS-CR — спека в режиме мелкой правки

Регресс `reference/small-change-mode.md` (2026-10-24, причёсывание): у стенда не было пробы спеки в этом режиме.
Флаг мелкой правки изображён промптом, ответы аналитика — заранее («ПРОДОЛЖЕНИЕ»).

| Проба | Вход | Ждём |
|---|---|---|
| `ts-cr-timeout` | `coddoc/UA-410/change_request.md` — таймаут отправки 3 → 10 с во фронте (взят из замера применимости 5.36, `ua-timeout`) | контракт не тронут → §2 «новых/изменённых взаимодействий нет»; §5.1 по существу (10 с); §6.2 по существу; тип «мелкая правка» |
| `ts-cr-api` | `coddoc/UA-420/change_request.md` — в ответ списка заявок поле с именем согласующего | контракт тронут → §2 INT-карточка с примером JSON и `null` у черновика; §6.2 по существу |

Грейдер — `grade-cr-spec.mjs <плечо> --case=timeout|api`.
