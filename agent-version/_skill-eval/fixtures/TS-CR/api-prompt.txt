в каждую заявку добавляем поле с именем согласующего: строка, у черновика — null. Имя берём из той же заявки,
согласующий в ней уже хранится — новых таблиц, полей в базе и миграций нет. Других потребителей у списка нет.
Доступ, нагрузка, кэш и ошибки не меняются. Выкат: сначала portal-api, затем portal-web; старый фронт новое
поле просто не показывает. Остальные решения — явно подтверждённое содержание документа-источника.
