## Должно быть

- Ровно один `notes/<папка>/notebook.md`; шапка `---` с непустой темой и `ключ: —`.
- На ходу 1 ноут не записан.
- Один раздел `## <дата прогона>`, записи с `### 1`; заголовок записи — `встреча 2026-10-12` (или `12.10`), не «по памяти».
- Пункты записи — пять пунктов списка как есть (тот же вид, те же слова; склонение имени и «решила:» — не правка), ни
  одного сверх списка.
- Строка `> исходник:` с путём к списку (от корня, от папки ноута, ссылкой markdown — всё равно).

## Не должно быть

- ` · L<n>` в пунктах ноута; `вместо:` и `отвечает на:` (прошлых записей нет).
- Других новых или изменённых файлов, список — байт в байт; пунктов вне пяти видов; `[решено]` без `решил:`; чисел, сроков,
  имён, кодов не из промпта, реплики и списка (номера строк ` · L<n>` источником не считаются).

Предупреждения (в счёт не идут): папка ноута — не тема строчными через дефис; в заголовке нет «: <предмет>»; нет
заголовка «# Ноут: …».
