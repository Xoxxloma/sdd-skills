# Смены курьеров

- Дневная смена 08:00–20:00, ночная 20:00–08:00.
- За ночную смену доплата 640 ₽ за выход.
- Маршрутный лист передаётся сменщику в окне 20 минут вокруг границы смены; передача позже — через диспетчера.
