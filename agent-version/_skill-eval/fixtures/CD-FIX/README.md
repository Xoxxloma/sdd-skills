# Фикстура CD-FIX — режим починки: чужой файл становится видимым, но не переписывается

Скилл запускается **без аргумента**. Источника нет вовсе: чинится то, что уже лежит в `context/`.
Ловит два дефекта, которые в этом режиме стоят дороже всего: **правку чужого тела** и
**переписанное чужое описание**.

Промпт называет симптом («часть файлов петля не подхватывает»), а не причину. Слова `description`
в нём нет намеренно: иначе прогон узнает, чего не хватает, из промпта, а не из скилла, и проба
станет вакуумной.

## Вход — три файла, три разных состояния

| Файл | Состояние | Что обязано произойти |
|---|---|---|
| `context/greenhouse-frost.md` | шапки НЕТ вовсе | появилась шапка с `description`; **тело не тронуто ни одним символом**; `source`/`updated` НЕ выдуманы |
| `context/lab-turnaround.md` | шапка есть (`owner`, `updated`), `description` нет | добавлен `description`; `owner` и `updated` на месте; `source` не выдуман; тело не тронуто |
| `context/courier-shifts.md` | шапка полная, `description` есть | не тронут вовсе — ни описание, ни тело |

Третий файл — не украшение. Правило «уже существующие описания не переписываются» проверить
нечем, если все файлы в папке одинаково сломаны; а соблазн «привести всё к одному виду» на слабой
модели срабатывает регулярно.

**`source`/`updated` у починенных файлов выдумывать нельзя:** откуда файл приехал, неизвестно.
Строка `source: context/greenhouse-frost.md` (файл сам себе источник) или дата импорта «сегодня» —
это выдумка о происхождении, и грейдер считает её отдельно.

## Анкеры и почему их нельзя угадать

Тело сверяется **посимвольно с эталоном фикстуры** — грейдер читает
`fixtures/CD-FIX/context/*.md` и сравнивает то, что осталось после шапки. Это строже любого
списка анкеров: заметит и переписанную формулировку, и «причёсанный» список, и добавленную
строку.

Опорные значения на случай ручного разбора: `Т-4`, `Т-7`, `+2,5 °C`, `+0,8 °C`, `18 минут`,
`1,5–2 градуса`; `БХ-14`, `31 часа`, `9 рабочих дней`, `CITO`; `640 ₽`, `20 минут`. Все некруглые
или придуманные: «30 минут» и «сутки» модель напишет не читая.

Описание `courier-shifts.md` сверяется строкой целиком:
`смены курьеров: границы смен, доплата за ночь, окно передачи маршрутного листа`.

## Законный исход

Оба невидимых файла получили `description`, третий не тронут, тела всех трёх совпадают с
эталоном, новых файлов в `context/` не появилось. Гейт описания снят промптом («придумывай сам и
сразу пиши»), поэтому законный исход здесь — **запись**, а не вопрос.

## Красный исход

Тело хоть одного файла отличается от эталона. Описание `courier-shifts.md` переписано. Хотя бы
один невидимый файл остался без `description`. У починенного файла появился выдуманный `source`
или `updated`. В `context/` появился новый файл (отчёт, индекс, «README»).

## Прогон

```bash
./run-ctx.sh cdoc-fix <раунд> 10
node grade-cdoc.mjs <раунд>/cdoc-fix --probe=fix
```
