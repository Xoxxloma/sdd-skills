# objects-registry — backend

> Генерируется. Правки руками затираются.
> Заметки человека — в `services/manifest.yaml`, поле `notes`.
> Форма — `reference/card.template.md` скилла `service-map`. Соседние карточки формой не являются.

## Назначение

Единый справочник охраняемых объектов для пульта и договорного отдела: по объекту известны адрес, текущий режим охраны и ответственное лицо клиента с телефоном. Поддерживает постановку и снятие объекта с охраны, смену ответственного лица, поиск объекта по названию и адресу. Главные объекты — охраняемые объекты и договоры охраны.

## Что умеет для пользователя
| Возможность | Для кого |
|---|---|
| Найти объект по названию или адресу | Диспетчер, менеджер договоров |
| Поставить объект под охрану или снять | Менеджер договоров |
| Сменить ответственное лицо по объекту | Менеджер договоров |

## Публичный контракт

### `GET /v2/objects`
Поиск объектов по названию или адресу.
сущности: → `GuardedObject`
- `query` — подстрока названия или адреса, не короче трёх символов
- отдаёт не больше 20 записей, пагинации нет

### `GET /v2/objects/{id}`
Карточка охраняемого объекта.
сущности: → `GuardedObject`, вложенно `Responsible`
- `address: string` — адрес одной строкой, как в договоре
- `guardMode: armed` \| `disarmed` \| `maintenance`
- `responsible: { name: string, phone: string }` — одно лицо; если не назначено — `null`
- ошибки: `404` — объекта нет или договор расторгнут

### `PUT /v2/objects/{id}/guard-mode`
Смена режима охраны.
сущности: → `GuardedObject`
- ошибки: `409` — режим уже установлен, повтор безопасен

## События

### публикует `objects.guard-mode.changed`
Режим охраны объекта изменён.
- `objectId: string`, `guardMode: string`, `changedAt: iso8601`
- ключ партиции — `objectId`

## Фоновые задачи

### `expireContracts`
Снимает с охраны объекты с истёкшим договором.
- расписание `0 3 * * *`
- переводит `guardMode` в `disarmed`, событие `objects.guard-mode.changed` публикует

## Владеет данными

### `Contract`
Договор охраны с клиентом.
- `id`: `string`
- `objectId`: `string`
- `validUntil`: `iso8601`

### `GuardedObject`
Охраняемые объекты; единственный источник адресов и ответственных лиц.
- `id`: `string`
- `name`: `string`
- `address`: `string`
- `guardMode`: `armed` \| `disarmed` \| `maintenance`
- `responsibleName`: `string?`
- `responsiblePhone`: `string?`
— `maintenance` ставится менеджером на время работ на объекте; сработки в этом режиме на пульт не приходят
