# geo — backend

> Генерируется. Правки руками затираются.
> Заметки человека — в `services/manifest.yaml`, поле `notes`.
> Форма — `reference/card.template.md` скилла `service-map`. Соседние карточки формой не являются.

**Назначение.** Геоаналитика: зоны покрытия, изохроны времени прибытия.

## Что умеет для пользователя
| Возможность | Для кого |
|---|---|
| Построить изохрону по времени прибытия | Аналитик безопасности |

## Стек
| Слой | Чем |
|---|---|
| Язык и фреймворк | Go |
| Хранилище | PostgreSQL + PostGIS |

## Публичный контракт

### `GET /v1/isochrone`
Изохрона по точке и времени в пути.
- `minutes: int` — верхняя граница времени в пути
- ответ — GeoJSON-полигон; пустой полигон означает «точка вне обслуживаемой зоны»

## Владеет данными

### `CoverageZone`
Зоны покрытия; единственный источник правды.
- `geometry` хранится в проекции EPSG:4326
