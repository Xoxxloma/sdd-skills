# Сеть клиник партнёра

- Москва, Тверская — терапия, кардиология; по прикреплению без направления.
- Казань, Сибгата Хакима — терапия, травматология; хирургия только по направлению.
- Тюмень, Мельникайте — терапия; узкие профили через телемедицину.
