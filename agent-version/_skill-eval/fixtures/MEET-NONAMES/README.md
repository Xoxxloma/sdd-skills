Говорящих нет: ни меток, ни тире. Имена — только в обращениях и самоназваниях: Кира (аналитик), Стас (разработчик),
Айдар (старший администратор), Изольда Марковна (хозяйка); Зульфия (бухгалтер) — не на встрече. Дата — только в имени

единого имени → предоплату «не делаем» — без имени → неявки — без выбора → планшет → скидка — «это к Зульфие».
