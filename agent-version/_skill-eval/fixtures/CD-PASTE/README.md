# Фикстура CD-PASTE — вторая вставка из чата на ДРУГУЮ тему (аудит, С33)

В `context/` уже лежит `labor-hours.md` с `source: вставлено в чат`. Аналитик вставляет в чат текст на
другую тему (правила гарантии) и заранее снимает вопрос про описание — ветка без единой остановки.

Правило Шага 5 по букве: «тот же источник → перезаписываешь тот же файл целиком». У любого текста из
чата источник один и тот же. **Зелёное:** `labor-hours.md` цел байт в байт, рядом появился второй файл
про гарантию. **Красное:** нормо-часы затёрты или дописаны гарантией.

Плечо: `cdoc-paste`. Грейдер: `grade-cdoc-paste.mjs <раунд>/cdoc-paste`.
