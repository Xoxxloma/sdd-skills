# Фикстура DS-BASE — ответ «как сейчас» по коду соседних реп

**Дерево на диске.** В песочницу копируется папка `ws/` целиком; прогон идёт из `ws/AI-SDD` (корень
спек-репы). README в песочницу не попадает. Сама фикстура — только на чтение.

**Домен и стек выбраны непересекающимися** с примерами в брифе `deep-search`: прокат строительного
инструмента, Kotlin/Spring + Python/aiokafka. Имя, путь или число из этой фикстуры в тексте скилла —
