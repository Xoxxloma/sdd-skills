# Словарь

- **Выдача** — сотрудник пункта проката отдаёт клиенту забронированный инструмент.
- **Возврат** — клиент приносит инструмент обратно; сотрудник отмечает, есть ли поломка.
- **Залог** — сумма, которую держат с карты клиента, пока инструмент у него.
- **Разбор поломки** — отдел претензий решает, сколько удержать из залога.
