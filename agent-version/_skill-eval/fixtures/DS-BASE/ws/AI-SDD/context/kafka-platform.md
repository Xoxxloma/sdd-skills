# Kafka: регламент платформы

- Имена топиков в коде сервисов не пишутся. Сервис читает их из переменных окружения, значения
  задаёт платформа в репозитории деплоя `platform-deploy`, папка `values/<стенд>`.
- На каждом стенде свои имена топиков. Прод-имя на тестовом стенде не используется.
- Доступ сервиса к топику — заявкой в платформенную команду, отдельно на каждый топик и стенд.
- DLQ платформа по умолчанию не создаёт. Нужна — указывается в заявке на топик.
