# orders-api — backend

> Генерируется. Правки руками затираются.
> Заметки человека — в `services/manifest.yaml`, поле `notes`.
> Форма — `reference/card.template.md` скилла `service-map`. Соседние карточки формой не являются.

## Назначение

Принимает и ведёт заказы интернет-магазина: оформление корзины в заказ, оплата, смена статусов до
выдачи. Главные объекты — заказы и их позиции.

## Стек
| Слой | Чем |
|---|---|
| Язык и фреймворк | Go, chi |
| Хранилище | PostgreSQL |

## Публичный контракт

### `GET /orders`
- сущности: `Order`
- список заказов покупателя, новые сверху; `createdAt` — в UTC

### `POST /orders`
- сущности: `Order`, `OrderItem`
- оформить корзину в заказ; `422` — корзина пуста

## Владеет данными

### `Order`
- `status`: `NEW` → `PAID` → `SHIPPED` → `DONE`; `CANCELLED` из любого до `SHIPPED`
- `createdAt` — UTC
