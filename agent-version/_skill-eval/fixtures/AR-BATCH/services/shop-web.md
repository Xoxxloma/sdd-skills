# shop-web — frontend

> Генерируется. Правки руками затираются.
> Заметки человека — в `services/manifest.yaml`, поле `notes`.
> Форма — `reference/card.template.md` скилла `service-map`. Соседние карточки формой не являются.

## Назначение

Витрина магазина и личный кабинет покупателя: собрать корзину, оформить и оплатить заказ,
посмотреть свои заказы.

## Стек
| Слой | Чем |
|---|---|
| Язык и фреймворк | TypeScript, React |

## Экраны
| Роут | Экран | Что делает пользователь |
|---|---|---|
| `/cart` | Корзина | меняет состав, оформляет заказ |
| `/orders` | Мои заказы | смотрит список и статусы |
| `/orders/:id` | Заказ | смотрит позиции, оплачивает |

## Потребляемые API
| Сервис | Вызов | Где |
|---|---|---|
| `orders-api` | `GET /orders` | Мои заказы |
| `orders-api` | `POST /orders` | Корзина |

## Зависит от

|---|---|
