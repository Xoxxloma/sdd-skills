# NRS-MULTI — правда фикстуры

**Записана ДО прогонов и от них не зависит.** Без такого файла грейдер сверяет прогон сам с собой:
общее число он получает сложением того, что нашёл, и сумма сходится при любой потерянной папке.

Репа `medex` — монорепа медицинских осмотров: **четыре приложения** в `apps/` (у каждого свой
`package.json`) плюс два пакета в `packages/`. Порог Шага 2.5 (меньше 500 файлов **И** меньше 150
ключей) перевалило **ровно одно** приложение — `apps/api`. Разрез при этом обязателен для всей
репы: причина «в репе несколько сервисов» не зависит от размера ни одного из них.

Все числа воспроизводятся командами:

```bash
bash make.sh ./out && cd out/medex
EP='@Get\(|@Post\(|@Put\(|@Delete\('
find apps/api -name '*.ts' | wc -l                                  # 720
grep -rhoE "$EP" apps/api | wc -l                                   # 96
find apps/api -name '*.entity.ts' | wc -l                           # 41
grep -rhoE '@Cron\(' apps/api | wc -l                               # 5
grep -c "'medex\." apps/api/src/config/queues.ts                    # 9
find apps/web \( -name '*.ts' -o -name '*.tsx' \) | wc -l           # 180
find apps/web -name 'page.tsx' | wc -l                              # 24
grep -rhoE 'fetch\(' apps/web | wc -l                               # 31
grep -rhoE 'create\(' apps/web | wc -l                              # 6
find apps/bot -name '*.ts' | wc -l                                  # 11
grep -rhoE '@Command\(' apps/bot | wc -l                            # 7
find apps/importer -name '*.ts' | wc -l                             # 6
find packages/contracts -name '*.ts' | wc -l                        # 14
grep -rhoE '^export (type|interface) ' packages/contracts | wc -l   # 22
find packages/ui -name '*.tsx' | wc -l                              # 40
```

Пояснения к трём числам, которые иначе не сойдутся:

- **эндпоинты 103 = 96 (`api`) + 7 (команды бота).** Команда телеграм-бота — операция контракта,
  а не «не эндпоинт»: у неё своя строка в карточке. Маркер `@Command(`;
- **событий 9, а не 11.** Строк с именем топика по репе одиннадцать, но `sort -u` даёт **9**:
  два топика импортёра — те же самые, что объявил `api`. Ключ — имя топика, а не строка в конфиге:

  ```bash
  grep -rhoE "'medex\.[a-z.]+'" . | wc -l          # 11 строк
  grep -rhoE "'medex\.[a-z.]+'" . | sort -u | wc -l # 9 топиков  ← это ключи
  ```

- **задачи 8 = 5 (`api`) + 3 (`importer`).** `@Cron` — фоновая задача, не событие.

Ещё одна мелочь счёта: маркер состояния `create(` по всей репе даёт **7**, а не 6 — седьмое
срабатывание это `NestFactory.create(` в `apps/api/src/main.ts`. Маркер фронта применяется к
фронту, а не к репе целиком.

## Связность внутри `apps/api`: звезда

Матрица — 39 рёбер, **420 ссылок**; сквозные (`common`, `shared`, `config`, `errors`) из неё
выброшены, они у всех.

**`examination` — хаб: 274 конца из 420, то есть 65 %** (179 ссылок наружу, к двенадцати модулям,
и 95 обратно, от семнадцати). Следующий по степени — `invoice`, 77.

**Внутри ядра слабого шва не существует:** между самими модулями ядра ссылок **нет вовсе**, всё
ядро висит на хабе. Самая тонкая граница ядра — `audit` ↔ `examination`, 12 ссылок; типичная —
`patient` ↔ `examination`, 50.

**Периферия отделяется чисто.** Три кластера: внутри десятки связей, к ядру единицы.

Воспроизводится так:

```bash
cd out/medex/apps/api/src/modules
for d in */; do p=${d%/}
```

## Что эта фикстура ловит

1. **Приложение — единица сама по себе, даже если оно крошечное.** `apps/bot` (11 файлов) и
   `apps/importer` (6 файлов) обязаны получить **свою строку** — кусок либо «сквозное». Пропасть
   как мелочь они не могут. У `importer` при этом ноль эндпоинтов: ноль по одному классу — не
   пустой сервис, у него 3 задачи и 2 события.
2. **Внутрь приложения лезут ТОЛЬКО когда оно само над порогом.** Под-куски полагаются `api`, и
   больше никому. Под-куски у `web` («страницы / компоненты / клиент API») — красный исход: это
   разрез по слоям одного сервиса, а он и так читается одним сканом (180 файлов, 61 ключ).
3. **`packages/ui` — ноль ключей, куском не становится.** В каждом из 40 файлов `export function`,
   но роутов нет, вызовов чужого API нет, состояния нет, а `package.json` приватный и полей
   публикации (`main`, `exports`, `types`) в нём нет — значит это не `lib` и экспорты ключами не
   являются. Строка про него обязана быть: «сквозное, 0 ключей».
4. **`packages/contracts` — тот же `export`, но это `lib`.** `main`, `types`, `exports` на месте,
   22 экспорта типов — 22 ключа, тип куска `lib`. Различает эти две папки не имя и не вид, а поля
   публикации в `package.json`.
5. **Типы кусков в одной репе разные:** `backend` (`api`, `bot`, `importer`), `frontend` (`web`),
   `lib` (`contracts`). Один тип на все куски — красный исход: тип задаёт форму карточки.

## Зелёный исход

1. Перечислены **поимённо все шесть** единиц из `apps/*` и `packages/*`, и у каждой в отчёте свой
   адрес: кусок или «сквозное». Приложение без строки — худший исход шага.
2. **Кусков не меньше шести:** `medex-web`, `medex-bot`, `medex-importer`, `medex-contracts` и
   **два-четыре** под-куска `api`. Меньше — значит приложения склеены.
3. **Резалось только `api`**, и сказано почему: 720 файлов и 151 ключ против 180/61 у `web`.
4. **Хаб назван поимённо и числом:** `examination`, 274 из 420 ссылок, 65 %, это звезда. Молчание
   о звезде — красный исход, даже если куски предложены разумные.
5. **Ядро осталось одним куском**, периферия отделена — A, B, C узнаваемы в составе под-кусков.
   Дробление ядра на домены — разрез по живому в десятках мест.
6. **События названы: 9**, и сказано, что они объявлены в `src/config/queues.ts`, а не в модулях.
   «Событий 0, `@EventPattern` в коде нет» — результат первого приёма, а не класса.
7. **Задачи и события не перепутаны:** задач 8, событий 9 — две разные строки таблицы.
8. **Сквозные названы поимённо, с нулём по каждому классу:** `common`, `shared`, `config`,
   `errors` внутри `api` и `packages/ui` целиком.
9. **Арифметика сошлась по каждому из восьми классов**, и общее число посчитано отдельной
   командой, а не сложением кусков.

## Красные исходы, ради которых фикстура и собрана

- «все приложения под порогом → разрез не нужен» либо «над порогом только `api`, остальное одной
  строкой» — репа осталась одной карточкой, где смешаны бэкенд, фронт, бот и импортёр;
- `bot` и `importer` не упомянуты нигде, при этом «Не вошло: —»;
- `web` нарезан на под-куски заодно с `api` — «Кто меня потребляет» разъезжается между тремя
  карточками одного фронта;
- `packages/ui` объявлен куском `medex-ui` с сорока экспортами — ключей у него ноль;
- `packages/contracts` объявлен сквозным «это же общие типы» — у него 22 ключа и тип `lib`;
- события посчитаны по модулям и объявлены нулём; либо посчитаны строками конфигов и объявлены
  одиннадцатью;
- эндпоинты посчитаны по файлам-контроллерам (их 32) или по классам, а не по методам (96):
  отношение 96 / 32 = 3 — столько методов в файле и лежит;
- сущности посчитаны только по `apps/api` (41) и потеряны две в `apps/bot`: по репе их 43;
- под-куски `api` названы `api-core` / `api-shared` / `api-common` — это разрез по слоям.
