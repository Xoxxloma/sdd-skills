# Фикстура BR-NC-LEAVE — критерий дан не всем требованиям: по номерам (`business-requirements-doc`)

Заведена 2026-10-03, вторая проба темы `BR-NOCRIT` (прод «у FR-2 нет критерия приёмки»). Кадровый портал,
отпуска `HR-512`. Три требования: (1) подать заявку, (2) руководитель согласует или отклоняет, (3) бухгалтерия
получает уведомление. Критерии даны **по номерам** — у (1) и у (3); у (2) нет. Пропуск заметен сильнее, чем в
`BR-NOCRIT`: растянуть «по (1)» или «по (3)» на согласование нечем.

Ходы: `brief-prompt.txt` → вопросы; `leave-turn2.txt` → ответы на всё. Стоп после хода 2 (`TURNS_CAP=2`).
**Верно:** на ходе 2 спросить критерий согласования, файл не писать. **Красное:** записать БТ с критерием
согласования, которого аналитик не давал. Грейдер — `grade-br-nocrit.mjs --case=leave`, проба `br-ncl`.
