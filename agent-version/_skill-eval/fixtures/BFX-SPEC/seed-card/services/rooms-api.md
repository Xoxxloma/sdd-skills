# rooms-api — backend

> Генерируется. Правки руками затираются.

## Назначение

Переговорные комнаты офиса и бронирование их сотрудниками.

## Что умеет для пользователя
| Возможность | Для кого |
|---|---|
| Посмотреть список переговорок с этажом и вместимостью | Сотрудник |
| Забронировать переговорку на время | Сотрудник |

## Стек
| Слой | Чем |
|---|---|
| Язык и фреймворк | Kotlin, Spring Boot |
| Хранилище | PostgreSQL |

## Публичный контракт

### `GET /v1/rooms`
Список переговорок офиса.
сущности: → `Room`

### `POST /v1/rooms/{roomId}/bookings`
Бронь переговорки на время.
- ответ `201` — бронь создана
- `409` — на это время занято

## Владеет данными

### `Room`
Переговорная комната.
- `roomId`: `string`
- `name`: `string` — название на табличке у двери
- `floor`: `int`
- `capacity`: `string` — число мест

### `Booking`
- `roomId`: `string`
- `startsAt`: `iso8601`
- `endsAt`: `iso8601`
- `employeeLogin`: `string`
