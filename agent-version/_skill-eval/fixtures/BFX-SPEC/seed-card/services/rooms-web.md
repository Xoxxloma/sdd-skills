# rooms-web — frontend

> Генерируется. Правки руками затираются.

## Назначение

Экран, где сотрудник подбирает переговорку и бронирует её на время встречи.

## Экраны
| Экран | Путь | Что на нём |
|---|---|---|
| Переговорки | `/rooms` | список переговорок, фильтры «Этаж» и «Вместимость: от N человек», кнопка «Забронировать» |

## Потребляемые API
| Сервис | Вызов |
|---|---|
| `rooms-api` | `GET /v1/rooms`, `POST /v1/rooms/{roomId}/bookings` |
