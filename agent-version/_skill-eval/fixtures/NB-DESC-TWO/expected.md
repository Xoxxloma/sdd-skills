# NB-DESC-TWO — что считается верным (скилл `analyst-notebook` 1.2.0, ноут по словам, сходятся два)

> **Написано до первого прогона.** Толкование, дописанное после чисел, подгоняется под результат.
> Если ожидание неверно — правь этот файл отдельным ходом и с объяснением.

**Засев:** побайтно засев NB-DESC-ONE (таблица ноутов — в `NB-DESC-ONE/expected.md`).

**Промпт:**
```
/analyst-notebook запиши в ноут по АС Друг: чат с Киселёвым А. (АС Друг)
Киселёв А.: Решаю так: заявки шлёте по одной, сразу при создании, пакетом не копите.
Киселёв А.: Номер заявки в АС Друг возвращаем сразу, в ответе на отправку.
```
Реплика на каждый ход — «Да, согласен с рекомендацией.» (заглушка: выбор — за рекомендацией скилла). Конец диалога —
«Кисел» в `notes/`; потолок 5 ходов.

**Опора в скилле:** Шаг 1 — основы сошлись не у одного → вопрос: до трёх ноутов, у кого сошлось больше основ (иначе
ближайший к тексту) первым, у каждого «<тема> — <о чём>», плюс «новый ноут». Текст — про заявки, ближе «интеграция с АС
Друг», но запись во второй ноут красной не считается: выбор сделала реплика.

## Должно быть

- В ходах до первой записи ноута — вопрос (строка с `?`), где названы оба ноута с их «о чём»:
  - «интеграция с АС Друг» — тема (`интеграц…`) и слово её «о чём» (обмен / портал / обслуживание);
  - «отчётность АС Друг» — тема (`отчётн…`) и слово её «о чём» (выгрузка / ежемесячных / бухгалтерию / выполненных).
- Новая запись ровно в одном из двух ноутов: старая часть байт в байт, новый раздел `## <дата прогона>`, записи с
  `### 1`; на ходу 1 ноут не записан.
- `[решено]` «по одной» / «сразу» с `решил: Киселёв`; пункт про номер заявки.
- Третий ноут («дежурства на складе») и остальное — байт в байт, новых файлов нет.

## Не должно быть

- Записи в оба ноута; записи без вопроса о ноуте.
- Пунктов вне пяти видов; `[решено]` без `решил:`; чисел, сроков, имён, кодов не из промпта и реплики.

Предупреждения (в счёт не идут): запись в «отчётность АС Друг» (текст про заявки — ближе первый); пункт про номер —
не `[сведение]`.

Грейдер — `grade-nb.mjs --fx DESC-TWO`.
