# Фикстура SM-MONO-DGS — монолит, чей контракт объявлен Netflix DGS

Для пробы разведчика Шага 3.0 (`PLAN-AUTOSPLIT.md` §2, критерий А-1; в плане — «NRS-TAIL --dgs»).
По форме — как адъютант с прода (`repo-split-log.md`): ~1000 java-файлов, GraphQL-операции
большинством, REST меньшинством, Kafka через reactor-kafka без аннотаций, топики только в конфиге.
Стек, имена и домен — свои (`casedesk`, рабочее место инспектора), не адъютанта.

**Собирается скриптом:** `./make.sh <куда>` (по умолчанию `./out`, он в корневом `.gitignore` по
правилу `**/_skill-eval/fixtures/*/out/`). Детерминированно, без `random`, ~20 секунд. В конце
`make.sh` печатает числа, посчитанные `grep` по собранному дереву, — по классам и по папкам. Правка
генератора разошлась с `expected.md` — чинить генератор, а не правду.

## Что внутри

Одно приложение: `pom.xml` в корне, `src/main/java/ru/kontrol/casedesk/`, **1052 java-файла**,
17 схем `src/main/resources/schema/*.graphqls`, `application.yaml`, `.git/HEAD` (признак репы).

| Что | Сколько | Зачем в фикстуре |
|---|---|---|
| операции контракта | **120** | 104 DGS (`@DgsQuery` 42, `@DgsMutation` 36, `@DgsSubscription` 2, `@DgsData(parentType = "Query")` 14, `… "Mutation"` 10) + 16 REST. Старая таблица маркеров видит только REST — 16 из 120 |
| `@DgsData` полей | **72** | **ловушка «резолвер поля — не операция».** `@DgsData(parentType = "<Пакет>Item", field = …)` рядом с 24 корневыми. `@Dgs(Query\|Mutation\|Subscription\|Data)` + REST даёт **192** (1,6 ×) |
| `@DgsComponent` | **55 классов** | **ловушка «пометка класса».** Добавленная к контракту строкой `ключ` даёт 175 — 1,46 ×, в окно влезает; ловится только по месту совпадения |
| класс-уровневый `@RequestMapping` | **5 из 8** REST-контроллеров | та же ловушка тише: `@(…\|Request)Mapping\(` даёт 125 — 1,04 × |
| `@Query` JPA | **44** | **ловушка «JPQL — не контракт».** Строкой `ключ` в контракте даёт 164 — 1,37 ×, в окне |
| сущности | **60** | **ловушка двойной аннотации.** `@Entity` и `@Table` на одних и тех же классах → `@Entity\|@Table` даёт **120** |

| `*.graphqls` | **17** | поля корневых типов (104) совпадают с DGS-операциями кода; ключ — объявление в коде, схема — ориентир |

Почему сдвоенные ловушки «влезают в окно». Окно критерия — [0,8; 1,5] × правды. Завышения на
`@Query` (1,37), `@DgsComponent` (1,46), `@RequestMapping` (1,04) числом не видны — их ловят строки
ловушек грейдера по месту совпадения. Сделано намеренно: на настоящем адъютанте соотношения те же
порядка, и проба должна мерить правило, а не удачу с числом.

## Раскладка песочницы пробы

Дерево едет в песочницу `sm-scout` без правды: `<раунд>/sandbox-scout/SM-MONO-DGS/casedesk/`
(`fixtures/SM-SCOUT/sandbox.sh`). Разведчику передаётся абсолютный путь `casedesk/`.

## Правда

`expected.md` — по классам, по верхним папкам (ключей каждого класса в каждой папке — вход нарезки),
что даёт каждый наивный маркер. В песочницу не едет. Числа по классам продублированы в
`fixtures/SM-SCOUT/truth.json` вместе с эталонными маркерами.
