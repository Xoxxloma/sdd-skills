# Фикстура NRS-TAIL — контракт в коде, кусок-слон и хвост, который не склеивается

Вторая фикстура набора, где **одно** приложение перевалило порог Шага 2.5 и режется изнутри.
Первая — `RS-HUB` (1354 java-файла, контракт ВНЕ кода). NRS-TAIL кладёт скилл на тот же путь, но
меняет все три ловушки на противоположные, чтобы мерилось правило, а не память о прошлой фикстуре.

**Собирается скриптом, а не лежит файлами:** `./make.sh <куда>` (по умолчанию `./out`, он в
корневом `.gitignore` по правилу `**/_skill-eval/fixtures/*/out/`). 2100 заглушек в git стоят
дороже трёхсот строк генератора. Сборка детерминированная (никакого `random`), ~12 секунд.

## Что внутри

`cargonet` — грузоперевозки, Java + Spring Boot + JPA + Kafka. **Стек и домен выбраны не такими,
как у `RS-HUB`** (там `opscore`, операционное ядро на сгенерированном контракте): проверяется
правило, а не память о примере.

Одно приложение: один `pom.xml` в корне, один `src/main/java/ru/cargonet/`, один деплой.
**2100 java-файлов**, сорок пакетов в `ru/cargonet/v2/` плюс `ru/cargonet/legacy/`.

| Что | Сколько | Зачем в фикстуре |
|---|---|---|
| эндпоинты | **139** | **ловушка на ширину регулярки.** Аннотации в коде ЕСТЬ, счёт кажется тривиальным. Но рядом 47 `@Query`, и `@(Get\|Post\|Put\|Delete)Mapping\|@Query` даёт **186**. А класс-уровневый `@RequestMapping` стоит на 14 контроллерах из 48 — счёт по нему даёт **14** |
| события | **18 топиков** | **ловушка «событие — топик, а не класс».** Имён топиков в коде нет вообще, только в `application.yaml`; обработчиков 6 |
| сущности | **88** | **ловушка на двойную аннотацию.** `@Entity` и `@Table` на одних и тех же классах → `@Entity\|@Table` даёт **176** |
| задачи | **9** | 7 из них в `dispatcher` |
| `exchange` | **560 файлов, 0 ключей** | **ловушка на размер.** 27 % репы одним пакетом, резать по ключам нечем — ключей внутри нет |
| `common`, `exceptions`, `constants`, `configuration`, `security`, `baseclass` | **90 файлов, 0 ключей** | **ловушка на слой.** Соблазн собрать `cargonet-shared` |
| двенадцать пакетов по 6–7 файлов | **18 ключей** | **ловушка на хвост.** Пломбы, паллеты, весовая, геозоны, разрешения, заправки, страховки, штрих-коды, чек-листы, приёмки, повреждения, календарь — общего домена нет, кусок `misc` не пишется в карточку |
| связность | **549 ссылок, 70 % через `consignment`** | звезда: хвост между собой связан слабо (165 ссылок на все пары) |
| `README.md` + `CHANGELOG.md` | — | приманка на археологию: скилл не имеет права судить о жизненном цикле чужой репы |

Рядом лежит `weather-api` — 30 файлов, свой `.git`, Go. **В манифест он НЕ входит**: в
`specs/services/manifest.yaml` одна строка, `cargonet`. Нужен, чтобы Шаг 1 не выродился в
«кроме монолита в округе ничего нет», а приписывание соседа к монолиту стало наблюдаемой ошибкой.

## Раскладка песочницы

```
sandbox/NRS-NN/
  AI-SDD/services/manifest.yaml   ← рабочая директория прогона (копия out/specs/)
  cargonet/                       ← монолит, соседом к спек-репе
  weather-api/                    ← сосед со своим .git, в манифесте его нет
```

`./seed.sh <куда>` собирает её (и сам вызовет `make.sh`, если `out/` ещё нет).

## Правда

`expected.md` — точные числа по каждому классу ключей, что даёт каждый наивный маркер, шесть
нулевых пакетов поимённо, двенадцать крошечных с их ключами, числа связности и размер каждого
пакета в файлах. **В песочницу `expected.md` не едет**: прогон не должен видеть правду ни при
каком блуждании.

## Проверка генератора

`make.sh` в конце печатает числа, посчитанные `grep`ом по собранному дереву, а не по замыслу.
Если правка генератора разошлась с `expected.md` — чинить генератор, а не правду.
