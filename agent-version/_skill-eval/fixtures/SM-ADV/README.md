# SM-ADV — адверсарные пробы на механики `service-map` 2.0

Пробы на слом восьми новых механик. Ничего из существующего стенда не правится: изолированные
пробы гоняются своим раннером, пробы на реальном коде — обёрткой над `runs/2026-08-24-sm-real/run.sh`.

```
fixtures/SM-ADV/
  iso/<группа>/case-*.md      изолированные пробы (без инструментов); prompt.json — что вырезать из
                              SKILL.md / keyed-update.md по якорям и что спросить; expect.json — ожидания
  cards/<вариант>/            прежние карточки для плеча rescan (SM_RESCAN_CARDS) — из BR-REAL
  cards/pending-seed/         кандидат «прошлого прогона» для services/_pending/ (SM_ADV_PENDING)
  patches/*.diff              патчи кода поверх засева (SM_REAL_PATCH); удаление контроллеров — SM_ADV_DROP
  prompts/*.md                промпты стенда с другим аргументом запуска (SM_ADV_PROMPT)
  seed.sh                     обёртка над SM-REAL/seed.sh: SM_ADV_DROP / SM_ADV_PENDING / SM_ADV_CLONES / SM_ADV_MANIFEST
../make-sm-adv.mjs            собирает iso/ и cards/
../run-sm-adv-iso.sh          раннер изолированных; ../grade-sm-adv-iso.mjs — грейдер
../run-sm-adv.sh              обёртка над run.sh для реального кода; ../grade-sm-adv.mjs — счётчики по файлам
```

Пересобрать: `node make-sm-adv.mjs`. Самопроверки: `node grade-sm-adv-iso.mjs --selftest`,
`node grade-sm-adv.mjs --selftest`. Промпты без запуска: `SM_ADV_DRY=1 ./run-sm-adv-iso.sh <SKILL.md> <раунд>`.

## Пометки в ожиданиях

- **[замысел≠текст]** (`design: true`) — ожидание идёт от инварианта, а буква скилла даёт другое.
  Красный здесь означает «текст победил замысел», и чинить надо текст, а не модель.
- **[исполнение]** (`exec: true`) — проба проверяет исполнение формулы, не замысел: ожидание — пересказ
  формулы, и зелёный не говорит, что формула верна.
- **распределение** — `want` нет: текст скилла на этот случай ответа не даёт, снимается, что делает модель.

## Что придумано, но не оформлено

- **Обрыв субагента на реальном коде** — из `claude -p` нельзя оборвать вложенный Agent детерминированно;
  «прерван» ловится только изолированно (группа `abort`).
- **Добор, переписавший файлы целиком, на реальном коде** — нельзя заставить субагента добора нарушить
  `Edit`; в файлах это видно только постфактум (`grade-sm-adv.mjs` ПРОДВИЖЕНИЕ не различит «переписал добор»
  и «первый прогон»). Нужен снимок `.work/` между первым запуском и добором — хук в трассе, которого нет.
- **Монорепа с несколькими сервисами в одной папке для маркерного счёта** — у SM-REAL нет такой репы;
  `SM_ADV_MANIFEST` с `path: ../repairy-api/src/auth, ../repairy-api/src/projects` (кусок репы) даст счёт по
  двум путям (40 маркеров) — плечо возможно, но ожидание по «Бизнес-правилам» и сущностям для куска не выписано.
- **GraphQL `extend type Query`** — в SM-REAL нет GraphQL; изолированно только замечание в `graphql-2-vs-38`.
- **Гард по регистру ключа** (`norm-case`) на реальном коде — потребовалась бы прежняя карточка с `get /…`,
  которую субагент, вернув «прежнюю формулировку дословно», может и воспроизвести в нижнем регистре; исход
  не детерминирован, оставлено изолированно.
- **Одинаковые ключи в двух карточках-клонах (R8)** — 8 копий `resonance-api` дадут одинаковые «Зависит от»;
  Шаг 5 соберёт зеркала между клонами только если код ссылается на имена манифеста — не ссылается, значит
