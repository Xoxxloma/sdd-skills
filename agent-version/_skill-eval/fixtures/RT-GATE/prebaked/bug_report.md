# Баг-репорт: Мигание полигона зоны покрытия при отрисовке на карте

> **Статус готовности:** Готово к оценке
> **Задача:** ARS-312

## 1. Затронутый бизнес-процесс
Аналитик УОР смотрит зоны покрытия на карте, чтобы понять, откуда доедет группа. Экран `/coverage`.

## 2. Шаги воспроизведения
1. Открыть экран `/coverage`
2. Выбрать любой район
3. Дождаться построения зоны → полигон зоны отрисовывается, пропадает примерно на полсекунды и отрисовывается заново

*Отдельных шагов у самого мигания нет — оно происходит на этом же пути, само.*

## 3. Фактический результат
Полигон зоны отрисовывается, пропадает примерно на полсекунды и отрисовывается заново. Итоговая картинка верная, но мигание видно каждый раз. Заметили после перехода карты на новый источник тайлов. Данные баг не портит, в базе ничего неверного не сохраняется.

## 4. Ожидаемый результат
- **FR-1:** Полигон отрисовывается один раз, без пропадания — 🔵 со слов аналитика, документа нет

## 5. Критичность и срочность починки
Средняя. Работать можно, но на демонстрациях заказчику выглядит как сбой. Общий релиз, не хотфикс.
