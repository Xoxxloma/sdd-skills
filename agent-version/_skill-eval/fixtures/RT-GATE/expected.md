# RT-GATE — готовый документ идёт мимо приёмки и гейта 2Б

> **Переписано 2026-09-22 под `analyst-workspace` 1.3.0.** Первая редакция (1.2.0, тот же день) ждала
> обратного — остановки вопросом гейта на готовом БТ; по ней сняты `runs/2026-09-22-rt-gate-pilot4`
> (haiku 0/3) и `pilot-sonnet` (1/1). С 1.3.0 приёмка и гейт стоят только после ЗАПИСИ документа
> под-скиллом; принесённый готовым документ принят при записи и переспрашивать выбор аналитика
> нельзя. Гейт после записи меряет `rt-feature` с грейдом `--probe=feature-gate`.

**Вход.** На диске готовый БТ `docs/SMSEC-77/business_requirements.md` (копия `RT-CONT/ARS-102` с
другим ключом): §4.5 «не применимо», «Открытые вопросы — не осталось», статус «Готово к оценке».
Аналитик приносит его готовым — ветка «Аналитика: Создаем Спецификацию на основе готового
документа». Заглушки под-скиллов те же, что в `RT-BUG`.

**Двухходовой стенд.** Реплика «Да, годится.» повторяется каждый ход — она нужна хвосту маршрута
(вопрос про этапы), не входу.

## Верно

| Что | Ожидание |
|---|---|
| ход 1 | БТ прочитан ради маршрута (§4.5 «не применимо» → одна фича), `technical-spec-doc` запущен **в этом же ходе** |
| приёмка БТ | **не запускается** — документ принят при записи |
| вопрос гейта | **не задаётся** — «идём дальше — писать спеку?» переспрашивал бы выбор Шага 1 |
| источник в трассе | `docs/SMSEC-77/business_requirements.md`, `флаг=обычный` |
| `business-requirements-doc` | не вызван — документ уже есть |
| разрез | не вызван: §4.5 «не применимо» |
| дальше | как в `rt-feature`: приёмка спеки, станция `/spec-readiness`, вопрос про этапы, этапы, приёмка `stages/` |

## Красное — отдельными счётчиками

1. **Приёмка готового БТ запущена** — лишний вызов, документ уже принимался.
2. **Вопрос гейта задан** — переспрос выбора аналитика (правило 2).
3. Спека запущена не первым ходом — лишняя остановка на входе.
4. `business-requirements-doc` вызван — готовый документ переписан.
5. Разрез — на одной фиче резать нечего.

## Не нарушение

- Строка «БТ на одну фичу, запускаю `technical-spec-doc`» перед запуском.
- Точка очистки и вопрос про этапы на хвосте Шага 5 — они про спеку, не про вход.
