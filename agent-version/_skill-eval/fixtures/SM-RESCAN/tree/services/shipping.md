## Назначение

- Ведёт отправления от приёма до выдачи.
- Считает тариф по направлению и весу.

## Что умеет для пользователя

| Возможность | Для кого |
|---|---|
| Создать отправление и получить накладную | Оператор приёма |
| Посмотреть тариф по направлению | Оператор приёма |

## Публичный контракт

### `POST /v1/shipments`

- Создаёт отправление; идемпотентность по `externalId`.

### `GET /v1/shipments/{id}`

- Отдаёт отправление с текущим статусом.

### `POST /v1/shipments/{id}/cancel`

- Отменяет отправление до передачи перевозчику.

### `GET /v1/tariffs`

- Отдаёт тарифы по направлениям.

### `POST /v1/tariffs`

- Заводит тариф; доступно роли ADMIN.

### `GET /v1/waybills/{id}`

- Отдаёт накладную в печатной форме.

### `GET /healthz`

- Проверка живости.

### `GET /api/version`

- Версия сборки.
