# Фикстура BR-LIM — пример на границе в критерии приёмки (`business-requirements-doc`)

Заведена 2026-10-26 под п.2 `PLAN-FROM-POCOCK.md`: у критерия с числом гипотеза несёт пример на границе с
конкретными значениями — само значение и ближайшее за ним — и вопрос, включительно ли. Решение Р9: пример —
форма гипотезы, а не условие закрытия гейта 11.

Обе пробы одноходовые, в форме «ПРОДОЛЖЕНИЕ» (как `BR-YES`): прошлый ход агента пересказан, гейты кроме
критериев закрыты ответом аналитика. Окружение пустое. Задача `EXP-310` — компенсация расходов в портале
сотрудника. Три правила с числами разного вида: сумма (7 500 ₽), срок (до 25-го числа следующего месяца),
количество (не больше 3 заявок в месяц) и одно без числа (подача заявки). **Числа намеренно не те, что в
примере правила в тексте скилла** (там 5 000 и 18:00): иначе проба зеленеет копированием примера.

| Проба | Промпт | Верно | Красное |
|---|---|---|---|
| `br-lim-q` | `q-prompt.txt` — «критерии предложите сами» | вопросы по гейту 11; у каждого из трёх правил с числом гипотеза несёт значение и ближайшее за ним (7 500 / 7 500,01; 25-е / 26-е; 3-я / 4-я) — оба значения, как требует правило; файла нет | граница не названа хотя бы у одного правила; файл записан с выдуманными критериями |
| `br-lim-w` | `w-prompt.txt` — гипотезы с границей подтверждены, по сроку уточнение, по лимиту заявок аналитик дал свой критерий без границы | файл `coddoc/EXP-310/business_requirements.md` этим ходом, «Готово к оценке», без TBD/⚠️; §4.2: у порога — 7 500 и 7 500,01; у срока — 25-е и 23:59 / 26-е; у лимита — критерий аналитика («сколько заявок осталось»), отвергнутая граница («четвёртая — отказ») не вписана | файла нет (переспросил границу — пере-строгость, Р9); границы порога или срока нет в §4.2; отвергнутое вписано |

Грейдер — `grade-br-lim.mjs --case=q|w`.

**Строгий критерий (2026-10-26, по базе).** Прежний скилл на Sonnet и без правки спрашивает «7 500 включительно?» — с
одним словом «включительно» грейдер зеленел на базе 2/2. Правило требует двух значений, и критерий — по нему: база
0/2, после правки 3/3. Одно «включительно» печатается справкой, в критерий не идёт.
