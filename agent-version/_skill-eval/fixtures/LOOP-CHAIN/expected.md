## Стыки форм — выход N принят N+1 без правки руками

- **1→2.** Список стадии 1 — файл `*.points.md` с первой строкой `# Пункты:`; ноут берёт его по строке «список
  пунктов» (`analyst-notebook/SKILL.md:98`), а не по строке «текстовый файл» (`:99`). Ответ «файл разбирает
  `/meeting-intake`» — красный: стык разорван.
- **1→2.** Дата встречи в заголовке записи — из `> Встреча:` списка (`:98`): `встреча 2026-10-14`, не дата прогона.
- **2→3.** Строка спора, записанная на стадии 2, выгружается спором, а пункт по её ссылке — нет (`:254–255`).
- **3→4.** Выгрузка открывается `notes-to-intent` по первой строке `# Пункты:` (`notes-to-intent/SKILL.md:39`);
  `> Задача: —` ведёт к вопросу о ключе (`:55–56`), ответ «ключа ещё нет» — к `docs/_inbox/` и шапке
  «ключа ещё нет» (`:60–61`; `intent.md:15`).
