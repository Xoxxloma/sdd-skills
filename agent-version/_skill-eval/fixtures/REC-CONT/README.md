# REC-CONT — встреча по памяти: продолжение по готовому протоколу

Скилл `meeting-recall`, проба `rec-cont` (`PLAN-LOOP-HARDEN.md`, Н13 — часть «продолжение по `*.recall.md`»). Двойник
аналитика: `_skill-eval/twin-analyst.md` + `twin-card.md`. Засев — протокол, брошенный посреди Шага 3:
`seed/docs/ATL-58/meeting-2026-10-05.recall.md`. Шапка, заметки, пересказ, подтверждённые темы, раунд по одной теме из
двух; итога нет. Документа задачи нет (`документ: нет`).

Как было на встрече (только грейдеру и человеку; двойник этого не видит):
- 5 октября 2026, мастерская на Васильевском;
- мерки клиента сохраняются в профиль при первом снятии — приняла Шилова; хранить 3 года — аналитик срок не помнит;
- заказы по эскизу клиента принимать в любом ателье, шить только на Васильевском (там манекены) — предложил Вахрушев,
  приняла Шилова; аналитик не уверен, что договорились, и не помнит, кто принял;
- заказов по эскизу сейчас 15 в месяц — со слов Вахрушева;
- «через год мерки поплывут» — догадка аналитика, на встрече не звучала.

Что ловит:
- Шаг 0 «Продолжение»: пересказ, темы и раунд по меркам заново не спрашиваются, первый вопрос — раунд по заказам по
  эскизу;
- дальше Шаг 4 и Шаг 5; итог и список собраны из всего протокола, включая засеянные «Не помню» и «Моя мысль»;
- старые строки протокола целы, новые встают перед `## Итог по памяти`.

Ход диалога (≈ 4 хода агента):
1. Путь к протоколу → чтение → раунд «Заказы по эскизу клиента: кто это принял?», «…: какое число заказов назвали?».
   «Кто это принял?» при «не уверен» агент может и не задать — оба прочтения законны (`expected.md`, стык 6).
2. «Не помню», «15 в месяц» → вопрос Шага 4 (с Шиловой).
3. Конец не помнит, Шилова назвала бы решённым мерки → итог Шага 5, «Записать» / «Поправить».
4. «Записать» → итог в протоколе, список `meeting-2026-10-05.points.md`, отчёт.

Ожидания, ловушки на ложь и стыки — `expected.md`.
