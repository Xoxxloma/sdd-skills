# Фикстура SR-BLUE — готовность спеки после п.2б (`spec-readiness`)

Заведена 2026-10-26 под шаг 4 п.2б `PLAN-FROM-POCOCK.md`. Спеки — те же замороженные выходы `technical-spec-doc` 1.7.0,
что в `RV-BLUE` (происхождение — в её README): `SHT-410`, `SHT-411`, `UA-420`.

| Проба | Спека | Верно |
|---|---|---|
| `sr-blue-yes` | `SHT-410`: три изменения (стык INT-1 — 🟡, INT-3/INT-4 — 🔵), два потребления | расписки: изменения в 🟢, потребление в 🔵/🟡; вопросы по изменению есть; про прежнее поведение ручек — не больше одного пункта |
| `sr-blue-idk` | `SHT-411`: изменения на 🟡-стыке, новое, три потребления | то же |
| `sr-blue-cr` | `UA-420`: мелкая правка, одна карточка изменения | расписки и вопросы по изменению есть (сторож: правило не глушит своё) |

«Прежнее» — поведение существующей ручки, которого изменение не касается: одновременная запись на последнее место,
потолок и дубли записей, ушедший или исчезнувший рейс, «уже записан», объём списка рейсов, отзыв роли, пустой список,
прежние поля и путь стыка. Грейдер `grade-sr-blue.mjs` считает такие пункты отчёта по признакам содержания этих спек;
пункт, где рядом названо изменение (пропуск, велосипед, офис, сортировка, согласующий), прежним не считается.
