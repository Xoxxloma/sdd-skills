# SM-GAPS — ключ ответов (в песочницу не едет)

Две фикстуры под шесть классов потерь service-map-2.0 против v1 (разбор прода 2026-10-24: два бэкенда и
фронт). Каждый факт заложен в коде так, как он лежал на проде; грейдер — `grade-sm-gaps.mjs`.

## back/harvest-ledger (backend, Java Spring, ручки из спецификации) — размер прода

Ручки — `implements <Тег>Api`, интерфейсы генерирует openapi-generator из
`src/main/resources/openapi/harvest-ledger.yaml` в `target/`, в исходниках их нет. Префикс — `/api/v1/ledger`
(context-path). Операций спецификации 50: реализованы 48, без реализации 2. Сущностей 13 (одна — чужая
таблица `weathergrid.station_reading`), задач 6. Вес по ключам ≈ 69 при K = 30 — по умолчанию сервис режется
на части; `SM_MONO_K=100` — один читающий на весь сервис (как ueb на проде с весом 25–29).

Действия «Что умеет» (бэкенд):
- агроном: посмотреть свои замеры; сохранить замеры за дни недели; отправить неделю на подтверждение;
  посмотреть состояние своей недели; удалить свой черновик за день; запросить открытие закрытой недели;
  посмотреть свои запросы; отозвать свой запрос, пока нет решения; посмотреть свои участки; завести участок;
  изменить участок; убрать участок в архив (замеры на нём остаются);
- главный агроном: посмотреть замеры агронома; подтвердить неделю; вернуть неделю с комментарием;
  посмотреть запросы на открытие; решить по запросу; посмотреть свои шаблоны; создать шаблон и назначить
  агрономам; проверить, у кого уже есть шаблон; посмотреть шаблон; изменить свой шаблон; удалить шаблон;
  назначить шаблон ещё агрономам; снять шаблон с агронома; запросить передачу шаблонов другому главному
  агроному; посмотреть недельную сводку;
- методист: посмотреть все шаблоны; добавить культуру; переименовать культуру или сменить группу; удалить
  культуру (вместе с ней удаляются её значения в сохранённых замерах); посмотреть, где используется культура;
  создать, изменить, удалить группу культур (непустую — нельзя); решить по передаче шаблонов;
- главный агроном и методист: посмотреть сводку по регионам или хозяйствам; выгрузить сводку в Excel;
  посмотреть сводку по культурам; выгрузить сводку в PDF — недоступно; посмотреть список главных агрономов;
- любой с номером: справочник культур, группы культур, регионы и хозяйства, кто я, мои регионы; загрузить
  показания метеопостов — без проверки роли; посмотреть последнюю загрузку;
- автоматически: черновики прошлой недели в понедельник уходят на подтверждение сами; окна правки
  закрываются через 72 часа; запрос на передачу шаблонов без решения закрывается через 14 дней;
- недоступно: сохранить замеры за агронома; разослать недельную сводку.

Роли кода: `AGRONOMIST`, `HEAD_AGRONOMIST`, `METHODIST`.
