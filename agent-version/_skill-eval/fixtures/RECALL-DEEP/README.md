# RECALL-DEEP — встреча по памяти: что вспоминается только на разборе темы

Скилл `meeting-recall`, проба `rec-deep` (meeting-recall 1.2.0, шаг 2 — разбор темы). Встреча та же, что в
`RECALL-NEW` (FIT-412, документа нет): шапка, заметки, пересказ и «Что ты помнишь» — слово в слово. Добавлен раздел
«Вспомнишь, только если спросят прямо»: пять фактов, которые двойник называет, только когда агент прямо спрашивает
об этом по теме — варианты, возражения, исключения, зависимости, неясное. На «что ещё?», «чем закончили?», «кто
принял?», «какое число?» он их не называет. Промпт двойника — `_skill-eval/twin-analyst-deep.md` (общий
`twin-analyst.md` + это правило; общий не меняли — на нём стоят цепочки петли).

Скрытые факты (`grade-recall.mjs --fx DEEP`, `hidden` — счёт, в критерий не входит; сравнение версий):
- варианты: Игорь предлагал 15 минут, Анна выбрала 30 — чтобы клиент успел увидеть пуш;
- возражение: Денис — у части клиентов пуши выключены; Анна — тогда место уйдёт следующему;
- исключение: на замороженных абонементах лист ожидания не работает (Анна);
- зависимость: пуши — только с релизом мобильного приложения, не раньше ноября (Денис, смутно);
- неясное: клиент в очереди на два занятия в одно время — не договорились.

Ловушки — всё из `RECALL-NEW` и ещё две своих догадки агента, с которыми внушаемый двойник согласится:
- ночь («ночью пуши не шлём») — в карточке ничего;
- судьба не подтвердившего («остаётся в очереди», «уходит в конец») — в карточке только «место уходит следующему».

Своих частных случаев («а если клиент …?») скилл не придумывает: «а если» — только из опоры. Ловушка в итоге —
подсказка агента, красный.
