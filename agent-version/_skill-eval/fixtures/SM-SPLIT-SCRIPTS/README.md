# SM-SPLIT-SCRIPTS — независимые тесты скриптов нарезки (service-map-2.0, задача Б)

`plan.sh`, `assemble.sh`, `promote.sh` проверяются по контракту брифа стенда (`PLAN-AUTOSPLIT.md` §4),
тела скриптов и SKILL.md при написании не читались. Моделей не запускает.

```bash
bash test-split-scripts.sh <папка со скриптами>        # например ../../../service-map-2.0/reference
bash test-split-scripts.sh selftest                    # эталон стенда: всё ok, ОШИБКА 0
SM_REF_BUG=nodedup bash test-split-scripts.sh selftest # порча эталона: проверки обязаны покраснеть
SM_SPLIT_KEEP=1 …                                      # не удалять временную папку с выводами
```

## Фазы

| Фаза | Что | Чем проверяется |
|---|---|---|
| 0 | оракул `plan-oracle.mjs` против `cases/plan/*/expect.json` (числа руками) | расхождение — «СТЕНД», код 1 |
| 1 | `plan.sh` на 18 синтетических случаях: границы K, папка и файл тяжелее K, ориентир с w, Windows-пути, два корня, файлы вне корней (ловушка префикса `svc`/`svc-old`), w=0, байтовая сортировка, хвост вывода Grep, файл в двух классах, рекурсия, упаковка файлов, файл в корне, тяжёлая папка между лёгкими | `expect.json` + альтернативы (`alts`) + инварианты |
| 2 | `plan.sh` на настоящих деревьях (NRS-TAIL K=40 и K=100, SM-MONO-DGS, repairy-api), корень в Windows-форме и через «/» | оракул и его варианты + инварианты |
| 3 | `assemble.sh` на `cases/assemble/*`: дубли, сортировка, заглушки, CRLF, 7 отказов, опись без головы | `expect.json` |
| 4 | круговой: карточка `runs/2026-10-04-as-base/…/repairy-api.md` режется `prep.mjs roundtrip` на голову и 3 части с 22 намеренными дублями и склеивается | заголовки `###`, строки тел, строки таблиц, опись |
| 5 | `promote.sh`: верная копия (кириллица, пробел, CRLF, без перевода строки в конце), перезапись, недоступный путь, сбойный `cp` в PATH, нет черновика, `<куда>` — папка | байты файлов |

Инварианты плана (не зависят от ожидания): каждый файл с весом ровно в одной части; напечатанный вес
части = сумма её путей; часть ≤ K, кроме одиночного файла; сумма частей = общий вес; папка части не
тяжелее K; номера 01…S подряд; разбивка части по классам = счёт по её путям.

## Статусы

`ОШИБКА` — расхождение с контрактом; `неоднозначность` — совпало с вариантом прочтения, который
контракт не исключает (метка варианта в выводе); `устойчивость` — вне контракта (хвост Grep, CRLF);
`справочно` — то, о чём контракт молчит; печатается, не судится.

Где контракт молчит — решения оракула и разбора записаны в шапках `plan-oracle.mjs` (O1–O7) и
`asm-lib.mjs` (L1–L5). Эталон для самопроверки — `selftest/` (оракул, `asm-ref.mjs`, promote через
временный файл); с настоящими скриптами не связан.
