# Фикстура SM-RESCAN-TABLE — рескан поверх карточки в старой форме

Прежние карточки для плеча `rescan` стенда SM-REAL (`SM_RESCAN_CARDS`). Это карточки `BR-REAL` с одним
отличием у `repairy-api.md`: «Владеет данными» переведена в табличную форму `| Поле | Тип | Описание |`
без значений перечислений (10 перечислений стали именами типов вида `StatusEnum`), и два заголовка
«Бизнес-правил» перевёрнуты — подпись впереди ключа. Ровно так выглядели карточки прода с июля.
Факты не тронуты: сервис тот же, код тот же.

**Что меряется** — правило 2 прежней карточки в редакции 1.5.0: «дословно возвращается формулировка, не
форма». Правильный исход: «Владеет данными» строками `- поле: тип` со значениями через `|`, заголовки
«Бизнес-правил» с ключа, а неизменившиеся формулировки — дословно из прежней карточки. Красный исход:
таблица и перевёрнутые заголовки пережили рескан (так было на всём слепке прода до 1.5.0), либо форма
выправлена ценой переписанных формулировок.

Собирается `scratchpad/make-table-cards.js` из `BR-REAL/services`; грейдер — `grade-sm-rescan-form.mjs`.
