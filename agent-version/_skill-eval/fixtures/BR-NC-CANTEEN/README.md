# Фикстура BR-NC-CANTEEN — сквозной критерий пропускает среднее звено (`business-requirements-doc`)

Заведена 2026-10-03, проба темы `BR-NOCRIT` (прод «у FR-2 нет критерия приёмки»). Предзаказ обеда в столовой
`CANT-115`. Три требования: (1) сотрудник оформляет предзаказ до 11:00, (2) повар получает сводку заказов,
(3) сотрудник получает уведомление «заказ готов». Критерий один и сквозной: «оформил — получил уведомление —
забрал без очереди». Называет (1) и (3); среднее звено (2) не названо, хотя без него итога нет.

Ходы: `brief-prompt.txt` → вопросы; `canteen-turn2.txt` → ответы на всё. Стоп после хода 2 (`TURNS_CAP=2`).
**Верно:** на ходе 2 спросить критерий (2) (гипотезой на подтверждение), файл не писать. **Красное:** записать
БТ с критерием (2), которого аналитик не давал, или растянуть сквозной на все три. Грейдер —
`grade-br-nocrit.mjs --case=canteen`, проба `br-nccan`.
