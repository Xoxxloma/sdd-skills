## 1. Обзор изменения

### 1.1. Что делаем и тип изменения

**Суть:** Ученик отправляет эссе на автоматическую проверку и получает оценку от языковой модели; учитель проверяет эссе на заимствования; раз в сутки оценки выгружаются в электронный журнал.

**Тип:** новый функционал

**Стороны:** Fullstack

### 1.2. Затронутые сервисы и владельцы

| Сервис | Роль в задаче | Владелец/команда | Происхождение |
|--------|---------------|------------------|---------------|
| `school-web` | Кабинеты ученика и учителя | Команда кабинета | 🟢 |
| `school-api` | Бэк заданий и эссе | Команда заданий | 🟢 |
| `essay-checker` | Проверка эссе, обращение к языковой модели | Команда проверки | 🟢 |
| `plagiarism-check` | Поиск заимствований | Команда проверки | 🔵 подтв. аналитиком |
| `journal-service` | Электронный журнал | Команда журнала | 🔵 подтв. аналитиком |

*Внешняя языковая модель Lexa подключена по договору; её API в этой спеке не описывается.*

### 1.3. Связь с бизнес-требованиями

Ученик получает оценку эссе без ожидания учителя, учитель быстрее проверяет оригинальность, оценки попадают в журнал без ручного ввода.

## 2. Взаимодействия (ядро)

### INT-1. Проверка эссе языковой моделью — 🟢
- **Граница/направление:** `school-web` → `school-api` → `essay-checker` → Lexa (внешний LLM)
- **Триггер:** ученик нажал «Проверить эссе» на странице задания
- **Контракт (по звеньям):**
  - `school-web` → `school-api`: `POST /v1/essays/{essayId}/review`, тела нет — эссе указано в пути.
  - `school-api` → `essay-checker`: `POST /internal/reviews`, синхронно. Запрос — JSON `ReviewRequest { essayText, gradeLevel }`. Ответ — JSON `ReviewResult { score }`.
  - `essay-checker` → Lexa: контракт провайдера в спеке не описан.
- **Ошибки:** `404` — эссе не найдено; `504` — модель не ответила за 30 с
- **Авторизация:** ученик — автор эссе
- **Происхождение:** 🟢 новое

### INT-2. Проверка на заимствования — 🔵
- **Граница/направление:** `school-web` → `school-api` → `plagiarism-check`
- **Триггер:** учитель нажал «Проверить на заимствования» в карточке эссе
- **Контракт (запрос):** тело `{ language, threshold }`
- **Контракт (ответ):** `{ similarity, matches }`
- **Ошибки:** `403` — эссе не из класса учителя; `503` — сервис заимствований недоступен
- **Авторизация:** учитель класса, к которому относится эссе
- **Происхождение:** 🔵 подтверждено аналитиком

### INT-3. Выгрузка оценок в журнал — 🔵
- **Граница/направление:** `school-api` → `journal-service`
- **Триггер:** по расписанию, раз в сутки в 02:00
- **Контракт (запрос):** `POST /v1/journal/batch`, тело `{ classId, grades }`
- **Контракт (ответ):** `{ accepted, rejected }`
- **Ошибки:** `409` — оценки класса за этот день уже выгружены
- **Происхождение:** 🔵 подтверждено аналитиком

### Каталог ошибок (сводно)
| Код | Тело/сообщение | Когда | Состояние UI |
|-----|----------------|-------|--------------|
| 404 | `essay not found` | эссе удалено или не существует | ошибка на странице задания |
| 504 | `review timeout` | модель не ответила за 30 с | «проверка заняла слишком долго, попробуйте позже» |
| 403 | `forbidden` | эссе не из класса учителя | «нет доступа» |
| 503 | `originality unavailable` | сервис заимствований недоступен | «попробуйте позже» |
| 409 | `already exported` | оценки за день уже в журнале | не применимо — вызов без UI |
