# Фикстура SM-REAL — `service-map` на настоящем коде

**Ключ ответов — в `KEY.md`. В песочницу он не едет.** Дерева фикстура не держит: оно собирается
`seed.sh` из реальных реп пользователя на каждый прогон.

## Зачем она нужна

Весь прежний стенд `service-map` синтетический, в двух формах:

- `repo.md` — весь «код» вклеен в промпт одним файлом. Стоимость перехода между файлами при этом
  **нулевая**, а полевой дефект ровно в ней: `List<ShipmentDto>` виден сразу, поля `ShipmentDto`
  лежат в другом файле, и субагент туда не идёт;
- `neighbours/` — настоящее дерево, но **13–33 файла на всю фикстуру** и 5–20 на сервис, написанных
  автором фикстуры под проверяемое правило.

Максимум, на котором скилл мерен, — **48 ключей**. В CHANGELOG 5.0 это записано прямо: «с поля
известен успешный скан репы на 800 файлов со второй попытки; граница не проведена».

Здесь один только `repairy-api` даёт **96 эндпоинтов, 20 сущностей, 125 файлов** — вдвое сверх
всего измеренного, и структура задана фреймворком, а не замыслом автора фикстуры.

`resonance-api` добавляет форму, которой в стенде нет вовсе: **ни ORM, ни декораторов**, express с
хранением в JSON-файлах. Секция «Владеет данными» там про файлы, а не про таблицы.

## Что здесь можно измерить впервые

| Что | Почему только здесь |
|---|---|
| граница «сколько берёт один субагент» | 96 ключей против мереных 48 |
| плотность при настоящей цене перехода | факт лежит в другом файле по-настоящему, а не в другой секции одного `repo.md` |
| гейт на запись у `frontend` | у фронта все секции табличные, блоков `###` ноль — условие 1 гейта его не считает (`SKILL.md:573`) |
| второй глоб на Шаге 2.1 | `resonance-web` лежит в worktree-форме и в манифесте отсутствует |
| правило «только читаешь чужие репы» | синтетическим фикстурам писать было незачем; здесь есть `.env`, `prisma/`, миграции |
| секреты | `.env` едут в песочницу намеренно |

## Два плеча, числа не складываются

| Плечо | Засев | Законный исход |
|---|---|---|
| `scan` | `manifest.yaml` (три строки из четырёх сервисов), аргумент `repairy-api repairy-web` | две карточки, обратные рёбра, отчёт, и в отчёте назван новый сосед `resonance-web` |
| `first` | манифеста нет | черновик манифеста со всеми четырьмя + остановка прозой |

## Что НЕ покрыто

- **Тип `lib`.** `packages/shared` и `apps/telegram` в стенд не берутся — решение от 2026-08-24.
  Ветка формы под `lib` остаётся мереной только на синтетике.
- **Разрезанная репа.** Обе репы здесь разложены по сервисам заранее; путь «монолит целиком →
  `repo-split`» мерится своим раундом, и мешать его с плотностью нельзя.
