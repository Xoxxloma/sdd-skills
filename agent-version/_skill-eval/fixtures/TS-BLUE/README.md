# Фикстура TS-BLUE — путь и модель у 🔵; изменение существующего взаимодействия (`technical-spec-doc`)

Заведена 2026-10-26 под п.2б `PLAN-FROM-POCOCK.md` (решения Р6–Р8). Одно дерево, два варианта ответов аналитика.
Обе пробы одноходовые, «ПРОДОЛЖЕНИЕ»: прошлый ход агента — три вопроса о существующем — пересказан, остальные
тех-гейты закрыты ответами. Задача `SHT-410` — запись на корпоративный шаттл.

| Взаимодействие | Источник | Вид после 2б |
|---|---|---|
| бэк шаттла → служба пропусков (`badge-service`, чужая) | карточка `services/badge-service.md`: блок ручки `сущности: → Badge, только badgeId и state`, поля — в «Владеет данными» | потребление существующего |
| ответ карточки рейса (`shuttle-api`, наш) + поле `bikeRack` | карточка `services/shuttle-api.md`: блок ручки `сущности: → Trip, без officeCode`, поля — в «Владеет данными» | изменение существующего |
| бэк шаттла → справочник сотрудников (`org-directory`, чужой) | карточки нет — путь называет аналитик | потребление существующего |

Авторизация в чужих системах — 🟡 в обоих вариантах (роль `badge.reader` в карточке есть, аналитиком не
подтверждена — в спеку не идёт).

| Проба | Промпт | Верно после 2б | Прежний скилл |
|---|---|---|---|
| `ts-blue-yes` | `yes-prompt.txt` — «да» по пропускам и по ручке рейса, путь справочника назван аналитиком | (а) пропуска — 🔵 «по карточке», путь `/api/v3/badges` и поле `state`; (б) рейс — вид «изменение», заголовок 🟢, строка «Существующий стык» с `/v1/trips/{tripId}` и 🔵 «по карточке», таблица «было → стало» с `bikeRack`, JSON с `bikeRack`; (г) справочник — 🔵 «со слов», путь `/org/v1/employees` | путь пропусков словами, вида и таблицы нет |
| `ts-blue-idk` | `idk-prompt.txt` — «не знаю» по всем трём, но поле добавить нужно | (в) пропуска и справочник — 🟡, без пути и JSON; (ж) рейс — вид «изменение», 🟢, «Существующий стык» 🟡 без пути, в таблице только добавленное поле, JSON подписан фрагментом | вида и таблицы нет |

Грейдер — `grade-ts-blue.mjs --case=yes|idk`. Карточка взаимодействия находится по строке «Граница» (с кем
стык), а не по номеру INT.

**Карточки — по шаблону `service-map` (2026-10-26, ревью шага 1):** в блоке ручки — `сущности: → <Имя>` и отличие
ответа, поля — в «Владеет данными». Первая версия фикстуры выписывала поля прямо в блоке ручки, и проба зеленела
на случае, которого настоящие карточки не дают.
