# shuttle-api — backend

> Генерируется. Правки руками затираются.

## Назначение

Расписание корпоративного шаттла и запись сотрудников на рейсы.

## Что умеет для пользователя
| Возможность | Для кого |
|---|---|
| Посмотреть список рейсов и карточку рейса | Сотрудник |
| Записаться на рейс | Сотрудник |

## Стек
| Слой | Чем |
|---|---|
| Язык и фреймворк | Java, Spring Boot |
| Хранилище | PostgreSQL |

## Публичный контракт

### `GET /v1/trips`
Список рейсов на дату, по времени отправления.
сущности: → `Trip`, без `route`

### `GET /v1/trips/{tripId}`
Карточка рейса.
сущности: → `Trip`, без `officeCode`

### `POST /v1/trips/{tripId}/bookings`
Запись на рейс текущего сотрудника.
- ответ `201` — запись создана
- `409` — мест нет

## Владеет данными

### `Trip`
Рейс шаттла по маршруту в назначенное время.
- `departureAt`: `iso8601`
- `officeCode`: `string` — код офиса отправления
- `route`: `string` — название маршрута
- `seatsLeft`: `int` — свободных мест; `0` — мест нет
- `tripId`: `string`

### `Booking`
- `tripId`: `string`
- `employeeLogin`: `string`
