# shuttle-web — frontend

> Генерируется. Правки руками затираются.

## Назначение

Портал, где сотрудник смотрит рейсы шаттла и записывается на них.

## Экраны
| Экран | Путь | Что на нём |
|---|---|---|
| Список рейсов | `/trips` | рейсы на дату |
| Карточка рейса | `/trips/:tripId` | маршрут, время, свободные места, кнопка «Записаться» |

## Потребляемые API
| Сервис | Вызов |
|---|---|
| `shuttle-api` | `GET /v1/trips`, `GET /v1/trips/{tripId}`, `POST /v1/trips/{tripId}/bookings` |
