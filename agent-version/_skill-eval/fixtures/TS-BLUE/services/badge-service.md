# badge-service — backend

> Генерируется. Правки руками затираются.

## Назначение

Пропуска сотрудников в здания компании.

## Публичный контракт

### `GET /api/v3/badges/{badgeId}`
Пропуск по номеру.
сущности: → `Badge`
- `404` — пропуска с таким номером нет

### `GET /api/v3/badges?holderLogin={login}`
Пропуска сотрудника по логину.
сущности: → `Badge`, только `badgeId` и `state`

## Владеет данными

### `Badge`
Пропуск сотрудника в здания компании.
- `badgeId`: `string`
- `holderLogin`: `string` — доменный логин владельца
- `state`: `active` \| `blocked` \| `expired`

## Роли и доступ
| Роль | Что может |
|---|---|
| `badge.reader` | читать пропуска — сервисная роль для систем-потребителей |
