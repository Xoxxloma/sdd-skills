# HDR-CR: доработка запроса на правку с заполненной шапкой

Проба `cr-rework-w`. Засев — чистый `ARS-326` из `RV-LIM` с двумя строками шапки: `Редакция: 1 (2026-10-02)`
и версия прошлого выпуска скилла. Решение меняется одной репликой, поэтому файл обязан быть записан.

Ожидание: `Редакция: 2 (день прогона)`, в «Версии скилла» прежняя запись и версия из снимка.
Грейдер: `grade-header.mjs --probe=cr-rework-w`.
