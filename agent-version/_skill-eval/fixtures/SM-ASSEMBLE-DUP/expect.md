# telescope-api — backend

## Бизнес-правила

### `Reservation` — бронь ночи на телескопе
- запрошена (`REQUESTED`) — наблюдателем на свободную ночь
- подтверждена (`CONFIRMED`) — дежурным оператором, если купол исправен

### сообщение «бронь подтверждена»
- при подтверждении брони; получают подписчики топика `telescope.reservation.events`

## Публичный контракт

### `GET /api/domes/status`
Блок без дубля — должен выйти как есть.
сущности: → `Dome`
— строка семантики посреди
- факт после семантики

### `GET /api/nights/forecast`
прогноз облачности на ночь
сущности: → не сущность, ответ weather-feed
- `cloudCover: int` — процент облачности

### `GET /api/nights/free-count`
Счётчик свободных ночей.
сущности: → не сущность, агрегат по `Reservation`
- `telescopeId` (query, uuid, обязателен) — телескоп
- закрытые по погоде ночи не считаются

### `query night`
Ночь наблюдений по идентификатору.
сущности: → `ObservingNight`
- ночь, закрытая по погоде, — ошибка доступа

## События

### потребляет `sky.cloud-alert`
Облачность — ночь закрывается.
- из тела читается только `nightDate`
- повтор безопасен: отмена идемпотентна по `nightDate`

### публикует `telescope.reservation.events`
Событие по брони всем подписчикам.
- ключ — идентификатор брони
- шлётся из outbox отдельной задачей

### публикует на telescope.reservation.events
Изменение брони.
- ключ — идентификатор брони
- в тестовых средах топик другой

## Владеет данными

### `Dome`
Купол.
- `id`: `uuid`

### `Reservation`
Бронь или заявка.
- `id`: `uuid`
- `observerId?`, `telescopeId?`: `string`
- `night?` / `dome?` — к чему относится бронь
- `status?`: перечисление, при создании `REQUESTED`
- `statusChangedAt?`, `cancelReason?`
  — продолжение у частично нового поля
- `createdAt`, `version`
— при отмене по погоде причина ставится автоматически
— отменённая по погоде бронь в очередь не возвращается

### `ShiftLogEntry`
Запись журнала.
- `id`: `uuid`
- `operatorId`: `uuid`
- `summary`: `string?` — краткое содержание смены
- `createdAt`, `updatedAt` проставляются автоматически
- domeId, note
— запись с пометкой оператора не удаляется

### `Telescope`
Телескоп.
- `id`: `uuid`
- `aperture`: `int`
- `mount`: `string`
