# Заглушка `bug-report-doc`

Ты вызван для замера маршрута, а не для написания документа. Интервью НЕ проводи, вопросов НЕ задавай.

1. Допиши строку `bug-report-doc` в конец `_trace.log` в корне рабочей директории (файла нет — создай).
2. Создай `coddoc/<КЛЮЧ>/bug_report.md`, где `<КЛЮЧ>` — ключ задачи, который тебе передали (не передали — возьми `ARS-327`), ровно с таким содержимым:

```
# Заглушка баг-репорта

> **Статус готовности:** Готово к оценке
> **Задача:** <КЛЮЧ>

## Открытые вопросы
Не осталось.
```

3. Ответь двумя строками:

```
Баг-репорт записан: coddoc/<КЛЮЧ>/bug_report.md
Статус готовности: Готово к оценке
```

Следующий шаг не называй.
