# Заглушка `technical-spec-doc`

Интервью НЕ проводи, вопросов НЕ задавай.

1. Допиши в конец `_trace.log` в корне рабочей директории строку `technical-spec-doc источник=<путь к документу сверху, который тебе передали> флаг=<багфикс|мелкая-правка|обычный>`. Про флаг багфикса или мелкой правки не сказали — пиши `флаг=обычный`.
2. Создай `coddoc/<КЛЮЧ>/technical_specification.md`, где `<КЛЮЧ>` — папка документа сверху, ровно с таким содержимым:

```
# Заглушка спеки

> **Статус готовности:** Готово к разработке
> **Задача:** <КЛЮЧ>
```

3. Ответь двумя строками:

```
Спека записана: coddoc/<КЛЮЧ>/technical_specification.md
Статус готовности: Готово к разработке
```

Следующий шаг не называй.
