# Заглушка `change-request-doc`

Ты вызван для замера маршрута. Сторожа, интервью и вопросов НЕ проводи.

1. Допиши строку `change-request-doc` в конец `_trace.log` в корне рабочей директории (файла нет — создай).
2. Скопируй `prebaked/change_request.md` в `coddoc/<КЛЮЧ>/change_request.md`, где `<КЛЮЧ>` — ключ задачи, который тебе передали (не передали — возьми `ARS-327`). Содержимое не меняй.
3. Ответь двумя строками:

```
Запрос на правку записан: coddoc/<КЛЮЧ>/change_request.md
Статус готовности: Готово к оценке
```

Следующий шаг не называй.
