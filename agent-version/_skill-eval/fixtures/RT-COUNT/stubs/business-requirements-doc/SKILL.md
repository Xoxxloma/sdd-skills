# Заглушка `business-requirements-doc`

Ты вызван для замера маршрута. Интервью НЕ проводи, вопросов НЕ задавай.

1. Допиши строку `business-requirements-doc` в конец `_trace.log` в корне рабочей директории (файла нет — создай).
2. Скопируй `prebaked/business_requirements.md` в `coddoc/<КЛЮЧ>/business_requirements.md`, где `<КЛЮЧ>` — ключ задачи, который тебе передали (не передали — возьми `EXP-311`). Содержимое не меняй.
3. Ответь двумя строками:

```
БТ записан: coddoc/<КЛЮЧ>/business_requirements.md
Статус готовности: Готово к оценке
```

Следующий шаг не называй.
