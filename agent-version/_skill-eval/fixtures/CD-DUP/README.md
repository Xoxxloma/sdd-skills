# Фикстура CD-DUP — повторный импорт: обновление, а не второй файл рядом

Ловит **дубль**. Два файла об одном и том же — худший исход этого режима, и незаметный: греп по
`^description:` покажет оба, читающий скилл откроет оба и получит два разных числа на одну работу.
Ошибка не всплывает при импорте — всплывает через месяц в спеке.

## Вход

```
context/labor-hours.md    импортирован в январе: 5 работ, шапка из трёх полей,
                          source: inbox/normo-chasy.csv, updated: 2026-01-19
inbox/normo-chasy.csv     тот же источник, пересчитанный: 6 работ
```

Что изменилось в источнике против январского файла — ровно две вещи:

| Что | Было в `context/labor-hours.md` | Стало в CSV |
|---|---|---|
| `NH-3407` «Замена ремня ГРМ» | `4.6` | **`7.3`** |
| `NH-3312` «Регулировка развал-схождения» | строки нет | **новая строка, `2.9`, разряд 5** |

Того, что это повторный импорт, прогону сообщают **дважды и по-разному**: словами аналитика
(«тот же файл, что я приносил в январе») и полем `source` в существующем файле, которое указывает
ровно на этот путь. Достаточно любого из двух — проба не про догадливость.

## Анкеры и почему их нельзя угадать

| Анкер | Что доказывает | Почему не угадывается |
|---|---|---|
| **число `.md` в `context/`** | обновление, а не дубль | главный анкер; печатаются имена |
| `NH-3312` + `2.9` | новая строка доехала | придуманный код, некруглые часы |
| `7.3` | пересчитанное значение подхвачено | не 7 и не 8 |
| `4.6` **отсутствует** | старое значение не осталось рядом с новым | сохранившееся `4.6` — след «дописал, не обновив» |
| `updated` ≠ `2026-01-19` | дата импорта переставлена | январская дата в обновлённом файле — забытое поле |

Пять прежних работ (`NH-3106`, `NH-3208`, `NH-3251`, `NH-3512`) обязаны остаться: обновление —
не повод потерять строки, которых в изменениях нет.

## Законный исход

**Один** файл в `context/`, в нём шесть работ, `7.3` вместо `4.6`, `NH-3312` на месте, `updated`
переставлен. Гейт описания снят промптом («правь сам, я заранее согласен»), поэтому законный
исход — запись, а не вопрос.

Переименование файла (например, `labor-hours.md` → `normo-chasy.md`) с удалением старого дублем
не считается и красным не красится: греп увидит один документ. Грейдер печатает имена, чтобы
человек это видел.

## Красный исход

В `context/` два и более `.md` про нормо-часы. Единственный файл без `NH-3312` (импорт не
доехал). `4.6` и `7.3` в одном файле одновременно. Потерянные прежние работы.

## Прогон

```bash
./run-ctx.sh cdoc-dup <раунд> 10
node grade-cdoc.mjs <раунд>/cdoc-dup --probe=dup
```
