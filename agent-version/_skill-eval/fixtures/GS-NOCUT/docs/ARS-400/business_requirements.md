# Бизнес-требования: работа со справочником подрядчиков в кабинете

## 1. Введение и контекст
### 1.0. Тип изменения
Новая функциональность.
### 1.1. Описание проблемы
Справочник подрядчиков ведётся в excel-файле у менеджера. Данные расходятся, актуальную версию
никто не знает, а вся работа с подрядчиками упирается в этот файл.

### 1.2. Конечные потребители
Менеджер по подрядчикам, служба безопасности, бухгалтерия.

## 2. Бизнес-требования
### 2.1. Бизнес-цель
Перевести работу с подрядчиками в кабинет, чтобы данные были в одном месте.

## 4. Функциональные требования
- **FR-1.** Карточка подрядчика в кабинете: реквизиты, контакты, статус. Критерий: карточка
  открывается из списка и показывает актуальные данные справочника.
- **FR-2.** Поиск и фильтр по справочнику подрядчиков. Критерий: поиск по названию и ИНН
  возвращает подрядчика за один запрос.
- **FR-3.** Заявка на нового подрядчика с согласованием службой безопасности. Критерий: заявка
  проходит цикл «создана → на согласовании → решение» без почты.
- **FR-4.** Журнал изменений справочника: кто и когда правил карточку. Критерий: по каждой правке
  видно автора, дату и старое значение.
- **FR-5.** Выгрузка справочника подрядчиков в XLSX для бухгалтерии. Критерий: выгрузка содержит
  те же поля, что карточка, и открывается в Excel.

### 4.2. Критерии приёмки
Указаны в каждом FR выше.

### 5.3. Ролевая модель
Менеджер по подрядчикам, специалист СБ, бухгалтер.
