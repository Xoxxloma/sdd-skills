# Фикстура FND-RESUME — эпик с готовой спекой #0, «Продолжить начатое» после очистки контекста

Заведена 2026-10-31. Проверяет связь детей с фундаментом #0, когда решение Шага 4 из переписки уже стёрто: оркестратор
должен взять детей-наследников из заголовка `INT-0` спеки `_foundation/` («наследуют: …») и звать спеку ребёнка в режиме B
с путём к спеке #0. До 2026-10-31 оркестратор искал эту связь в `decomposition.md`, где её нет.

Засев — `FND-EPIC/seed-kid` в форме после правки: у `INT-0` спеки #0 — «наследуют: PRT-601, PRT-602», в
`decomposition.md` нет раздела «Следующий шаг». Спек детей нет. Заглушки — из `RT-EPIC`; заглушка `technical-spec-doc`
пишет в `_trace.log` режим вызова и путь к спеке #0.

| Проба | Скилл | Красный | Зелёный |
|---|---|---|---|
| `fnd-resume` | `analyst-workspace` + заглушки | спека ребёнка позвана без режима B или без пути к спеке #0; спека #0 переписана; спека на эпике | у каждого позванного ребёнка `режим=наследует #0` и `спека_0=…/_foundation/technical_specification.md` |

Грейдер — `grade-fnd-resume.mjs <каталог плеча>`, самопроверка `--selftest`.
