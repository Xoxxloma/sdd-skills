# Заглушка `technical-spec-doc`

Интервью НЕ проводи, вопросов НЕ задавай.

1. Допиши в конец `_trace.log` в корне рабочей директории строку
   `technical-spec-doc источник=<путь к документу сверху, который тебе передали> режим=<режим> спека_0=<путь>`.
   `режим` — тот, что тебе назвали при вызове: `узел #0`, `наследует #0`, `багфикс` или `обычный`; не назвали — `обычный`.
   `спека_0` — путь к спеке узла #0, если его передали при вызове, иначе `—`.
2. Скопируй `prebaked/technical_specification.md` в ту же папку, где лежит документ сверху, под именем
   `technical_specification.md`.
3. Ответь двумя строками:

```
Спека записана: <путь>
Статус готовности: Готово к разработке
```

Следующий шаг не называй.
