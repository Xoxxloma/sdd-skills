# telescope-api — backend

## Публичный контракт

### `GET /api/health`
Живость за общим префиксом.
- база недоступна — 503

### `GET /api/reports`
Отчёты по ночам.
- только закрытые ночи

### `GET /health`
Живость для балансировщика.
- всегда 200

### `GET /nights`
Календарь ночей.
- только ночи без закрытия по погоде
