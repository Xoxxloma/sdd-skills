# telescope-api — backend

## Роли и доступ
| Роль | Что может |
|---|---|
| `NIGHT_OPERATOR` (системная роль) | отменяет брони любого наблюдателя |
| `OBSERVER` (роль пользователя) | бронирует свободные ночи |
| `GUEST` | смотрит календарь ночей |
| `OWNER` (обсерватория) | ведёт список телескопов |
| `OWNER` (бронь) | переносит свою бронь |
