# telescope-api — backend

## Роли и доступ
| Роль | Что может |
|---|---|
| `GUEST` (без входа) | смотрит календарь ночей |
| `NIGHT_OPERATOR` | отменяет брони любого наблюдателя |
| `OBSERVER` | бронирует свободные ночи |
| `OWNER` (обсерватория, администратор) | ведёт список телескопов |
| `OWNER` (бронь, автор) | переносит свою бронь |
