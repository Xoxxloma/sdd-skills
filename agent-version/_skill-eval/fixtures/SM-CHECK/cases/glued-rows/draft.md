## Что умеет для пользователя
| Возможность | Для кого |
|---|---|
| Посмотреть список культур | все |
| Завести культуру или удалить её | методист |
| Удалить культуру — вместе с ней удаляются значения | методист |
| Нажать «Сохранить и закрыть» в форме культуры | методист |

## Публичный контракт

### `GET /api/crops`
Список культур.
- ответ: список культур с названием и цветом

### `POST /api/crops`
Новая культура.
- тело: название и цвет

### `DELETE /api/crops/{id}`
Удаление культуры.
- удаляются и значения культуры
