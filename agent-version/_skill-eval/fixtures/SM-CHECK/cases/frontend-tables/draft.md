| Возможность | Для кого |
|---|---|

## Стек
| Слой | Чем |
|---|---|
| Язык и фреймворк | TypeScript, React |

## Экраны
| Роут | Экран | Что делает пользователь |
|---|---|---|
| `/` | Главная | смотрит витрину |
| `/cart` | Корзина | правит корзину |
| `/orders/:id` | Заказ | смотрит заказ |

## Потребляемые API
| Сервис | Вызов | Зачем |
|:---|:---:|---:|
| `catalog` | `GET /v1/items` | список товаров |
| `orders` | `GET /v1/items` | позиции заказа |
| `orders` | `post /v1/orders` | оформление |
| `geo.example.org` | `GET /search` | подсказки адреса; вне манифеста |
