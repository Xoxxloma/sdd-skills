## Что умеет для пользователя
| Возможность | Для кого |
|---|---|
| Посмотреть ночи | наблюдатель |
| Отменить бронь | наблюдатель |
| Закрыть купол | дежурный оператор |

## Публичный контракт

### `GET /health`
Живость сервиса.

### `NightsController.getNight`
Ночь наблюдений.
- путь: не определено — спецификация вне репозитория

### `NightsController.listNights`
Ночи наблюдений.
- путь: не определено — спецификация вне репозитория

### `ReservationsController.cancel`
Отмена брони.
- путь: не определено — спецификация вне репозитория

### `rpc DomeService.Close`
Закрыть купол.
- ошибка: `FAILED_PRECONDITION` — купол уже закрыт

### `rpc DomeService.Open`
Открыть купол.
- ошибка: `FAILED_PRECONDITION` — купол уже открыт
