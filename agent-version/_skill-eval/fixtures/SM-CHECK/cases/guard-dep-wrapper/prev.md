# telescope-api — backend

## Зависит от
| Сервис или система | Зачем |
|---|---|
| `archive-store` | выгрузка снимков в архив; вне манифеста |
| `client.dome-control.host` | состояние купола перед подтверждением брони |
| `mail.host` (почтовый сервер) | письма наблюдателям; вне манифеста |
| `SKYCAM_LEGACY_URL` | снимок неба перед подтверждением брони; вне манифеста |
| `WeatherFeedClient` | прогноз облачности на ночь; вне манифеста |
