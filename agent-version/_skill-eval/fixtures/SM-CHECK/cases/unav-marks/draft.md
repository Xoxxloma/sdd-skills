## Публичный контракт

### `GET /api/orders`
Список заказов.
- только заказы покупателя

### `POST /api/orders/{id}/refund`
Возврат по заказу.
- недоступно: объявлено без реализации

### `GET /api/orders/{id}/invoice`
Счёт по заказу.
- отдаёт PDF счёта

| Сервис | Вызов | Зачем |
