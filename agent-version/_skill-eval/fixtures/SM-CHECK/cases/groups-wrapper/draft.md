## Что умеет для пользователя
| Возможность | Для кого |
|---|---|
| Посмотреть ночь и её сводку | наблюдатель |
| Забронировать ночь | наблюдатель |
| Отменить бронь | наблюдатель |

## Публичный контракт

### `GET /api/v1/nights/{id}`
Ночь наблюдений.
- ответ: дата, фаза Луны, прогноз облачности

### `GET /api/v1/nights/{id}/stats`
Сводка броней за ночь.
- ответ: число броней по телескопам

### `POST /api/v1/reservations`
Бронь ночи.
- тело: ночь и телескоп

### `POST /api/v1/reservations/{id}/cancel`
Отмена брони.
- ошибки: `409` — бронь уже отменена
