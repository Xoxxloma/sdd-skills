# projects — backend

## Роли и доступ
| Роль | Что может |
|---|---|
| `OWNER` (компания) | создаёт компанию |
| `EMPLOYEE` (компания) | ведёт проекты компании |
| `CUSTOMER` (компания) | смотрит свои проекты |
| `OWNER` (проект) | управляет командой проекта |
| `EMPLOYEE` (проект) | правит смету проекта |
| `CUSTOMER` (проект) | принимает работы |
