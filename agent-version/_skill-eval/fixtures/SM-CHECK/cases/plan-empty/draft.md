## Публичный контракт

### `GET /v1/orders`
- постранично

### `POST /v1/orders`
- без позиций — отказ

### `GET /v1/pay`
- список платежей

### `POST /v1/pay`
- создаёт платёж

### `GET /v1/pay/{id}`
- платёж по id

### `DELETE /v1/pay/{id}`
- отменяет платёж

### `GET /v1/pay/{id}/receipt`
- чек платежа

## Владеет данными

### `Order`
- id: UUID
