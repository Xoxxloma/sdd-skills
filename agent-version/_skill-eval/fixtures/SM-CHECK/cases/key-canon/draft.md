# sky — backend

## Публичный контракт

### `GET /api/nights`
сущности: → Night
- только открытые

### `GET /api/nights?phase=full`
сущности: → Night
- полные ночи

## События

### потребляет `sky.alert`
- предупреждение о погоде

### публикует в `night.closed` (шина)
- после закрытия ночи

### публикует состояние купола в Kafka
- при смене состояния

## Фоновые задачи

### `closeNights`
- 0 18 * * *

## Владеет данными

### `Night` — ночь наблюдения
- `id`: `uuid`

### Группы ночей (без полного состава)
- `name`
