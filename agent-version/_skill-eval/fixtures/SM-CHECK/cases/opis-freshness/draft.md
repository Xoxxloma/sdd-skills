# billing — backend

> Генерируется. Правки руками затираются.

## Назначение

Выставление и оплата счетов.

## Что умеет для пользователя
| Возможность | Для кого |
|---|---|
| Выставить счёт | Бухгалтер |
| Вернуть платёж | Бухгалтер |

## Бизнес-правила

### `Invoice` — счёт
- выставлен (`ISSUED`) — бухгалтером
- оплачен (`PAID`) — по событию банка

### `Payment` — платёж
- новый (`NEW`) — при создании

### сообщение «счёт оплачен»
- плательщику, сразу после оплаты

### ограничение «выставление счетов партнёру отключено»
- условием управляет `partner-registry`

## Стек
| Слой | Чем |
|---|---|
| Язык и фреймворк | Kotlin, Spring Boot |
| Шина | Kafka |

## Публичный контракт

### `GET /healthz`
Проверка живости.

### `GET /v1/invoices`
Список счетов.
сущности: → Invoice
- `total: int` — без отменённых

### `GET /v1/invoices/:id`
Один счёт.
сущности: → Invoice

### `POST /v1/invoices` — создание счёта
сущности: ← CreateInvoiceRequest · → Invoice
- ошибки: `409` — номер уже занят

### `POST /v1/payments/refund`
Возврат платежа.
сущности: ← RefundRequest · → Payment

## События

### потребляет `partner.disabled`
Партнёра отключили.
- группа `billing-partner`

### публикует `invoice.paid`
Счёт оплачен.
- ключ партиции — `invoiceId`

## Фоновые задачи

### `closeOverdue`
Закрывает просроченные счета.
- расписание `0 3 * * *`

## Владеет данными

### `Invoice`
Счета.
- `id`: `string`
- `status`: `DRAFT` \| `ISSUED` \| `PAID`
— номер уникален

### `Payment`
Платежи.
— проводится банком

## Зависит от

| `bank-gw` | проведение платежей; вне манифеста |
