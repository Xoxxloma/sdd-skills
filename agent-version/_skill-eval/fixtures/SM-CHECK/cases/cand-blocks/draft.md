# orders — backend

## Стек
| Слой | Чем |
|---|---|
| Шина | Брокер сообщений (свой) |

## Публичный контракт

### `GET /v1/orders`
сущности: → Order
- список

### `POST /v1/orders` — создание
  сущности: с отступом не считается
- тело

### `get /v1/orders/:id`
Один заказ.
- без строки сущностей

### `GET /v1/deliveries`
Доставки.
- без строки сущностей, но «live» в ключе — служебный по контракту

### `GET /healthz`
Живость.

### `GET /v1/Version`
Версия сборки.
