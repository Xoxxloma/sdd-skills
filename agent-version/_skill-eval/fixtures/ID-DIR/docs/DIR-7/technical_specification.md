# Техническая спецификация: Загрузка отчётов с проверкой антивирусом

> **Задача:** DIR-7
> **Источник (БТ):** бриф аналитика
>
> **Статус готовности:** Требуются уточнения (2)
>
> **Открытые вопросы (решить до / во время разработки):**
> 1. 🟡 **INT-6:** контракт вызова проверки у av-scanner не подтверждён.
> 2. ❓ **INT-7:** кто инициирует выгрузку в архив.

## 1. Обзор изменения

### 1.1. Что делаем и тип изменения

**Суть:** Пользователь загружает файл отчёта, файл проверяется антивирусом, после проверки отчёт становится доступен для скачивания, подписчики получают уведомление.

**Тип:** новый функционал

**Стороны:** Fullstack

### 1.2. Затронутые сервисы и владельцы

| Сервис | Роль в задаче | Владелец/команда | Происхождение |
|--------|---------------|------------------|---------------|
| `reports-web` | Фронт: список, загрузка, скачивание | Команда отчётов | 🟢 |
| `reports-api` | Бэк: хранит отчёты, запускает проверку | Команда отчётов | 🟢 |
| `av-scanner` | Проверка файлов | Команда безопасности | 🟡 к валидации |
| `notify` | Уведомления подписчикам | Команда уведомлений | 🔵 подтв. аналитиком |

## 2. Взаимодействия (ядро)

### INT-1. Список отчётов — 🟢
- **Граница/направление:** UI (страница «Отчёты») → `reports-api`
- **Триггер:** открытие страницы
- **Контракт (запрос):** `GET /v1/reports`
- **Контракт (ответ):** список отчётов `{ id, name, status }`
- **Происхождение:** 🟢 новое

### INT-2. Загрузка файла отчёта
- **Граница/направление:** UI → `reports-api`
- **Триггер:** пользователь выбрал файл
- **Контракт (запрос):** `POST /v1/reports/{id}/file`, multipart
- **Контракт (ответ):** `{ id, status: "scanning" }`
- **Происхождение:** 🟢 новое

### INT-3. Скачать файл отчёта — 🔵
- **Граница/направление:** UI (браузер) ↔ MinIO (S3)
- **Триггер:** клик по ссылке
- **Контракт (запрос):** GET по presigned-ссылке, ссылку выдаёт reports-api
- **Контракт (ответ):** файл
- **Происхождение:** 🔵 подтверждено аналитиком

### INT-4. Результат проверки (колбэк) — 🟢
- **Граница/направление:** `reports-api` ← `av-scanner` (колбэк)
- **Триггер:** проверка файла завершена
- **Контракт (запрос):** `POST /v1/reports/{id}/scan-result`
- **Контракт (ответ):** 204
- **Происхождение:** 🟢 новое

### INT-5. Событие «отчёт готов» — 🟢
- **Граница/направление:** событие: `reports-api` → `notify` (через Kafka)
- **Триггер:** проверка прошла успешно
- **Контракт (событие):** `report.ready` — `reportId`, `name`
- **Происхождение:** 🟢 новое

### INT-6. Запрос проверки файла — 🟡
- **Граница/направление:** `reports-api` → `av-scanner`
- **Триггер:** файл загружен (INT-2)
- **Контракт (запрос):** 🟡 к валидации — предположительно `POST /scan` со ссылкой на файл
- **Происхождение:** 🟡 к валидации

### INT-7. Выгрузка в архив — ❓
- **Граница/направление:** ❓ не решено — архив забирает отчёты сам или reports-api их отправляет
- **Контракт (запрос):** ❓ зависит от направления
- **Происхождение:** ❓
