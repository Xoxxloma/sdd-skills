# Техническая спецификация: пристройство животных из приюта

> **Задача:** ADP-41

## 1. Обзор изменения

Волонтёры приюта ведут карточки животных в реестре, а посетителям приходит СМС о назначенном знакомстве.

## 2. Взаимодействия

### INT-1 — Загрузка фото животного

- **Граница/направление:** Кабинет волонтёра → Реестр животных
- **Триггер:** волонтёр добавляет фото в карточку животного
- **Контракт (запрос):** `POST /v1/animals/{id}/photos`

### INT-2 — СМС о знакомстве

- **Граница/направление:** Календарь знакомств → СМС-шлюз
- **Триггер:** волонтёр назначил знакомство
- **Контракт (запрос):** `POST /v1/sms`
