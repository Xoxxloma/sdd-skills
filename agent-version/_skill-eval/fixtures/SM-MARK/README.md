# SM-MARK — изолированная проба маркерного гейта под разведчика (service-map-2.0)

Собирается `node make-sm-mark.mjs`. Контракт — `PLAN-AUTOSPLIT.md` §2–§3 (А2, А3, А5), критерий А-2;
ожидания выведены из плана, не из текста скилла. Каждый `case-*.md` — строки разведчика (Шаг 3.0),
счёт грепа ведущего по каждой строке (Шаг 3.1) и итоги описи по классам: то, что ведущий видит на
Шаге 4. Кода и черновика у него нет.

Раннер `run-sm-mark.sh <SKILL.md> <раунд> [N]` вырезает из SKILL.md `#### 3.0 Разведчик` … `#### 3.2 Запуск`
и маркерный гейт Шага 4 (`**Второе — маркерный гейт` … `**Три правила обхода`), даёт их прогону без
инструментов вместе с одним случаем. Формат ответа задан в конце промпта: разбор по классам, блок
`## Добор` (только если нужен), строки `ОТЧЁТ:` (только если правило велит), последняя строка
`МАРКЕРЫ: ДОБОР` либо `МАРКЕРЫ: ПРОЙДЕН`.

Грейдер `grade-sm-mark.mjs <раунд>/sm-mark` проверяет вердикт; у ДОБОР — число N в блоке добора
(и что в перечне нет класса, которому добор не положен); строку детектора — `ОТЧЁТ:` с обоими
числами класса; её отсутствие там, где детектора нет. `--selftest` гоняет `grader-selftest/`.

| Случай | Что ловит | Ожидание |
|---|---|---|
| (а) greenhouse-contract-18-of-45 | опись 40 % от суммы `ключ`-строк (38 + 7) | ДОБОР с «не меньше 45» |
| (б) ferry-contract-153-over-14 | узкий маркер: 14 при 153 в описи | ПРОЙДЕН + `ОТЧЁТ:` с 14 и 153 |
| (в) library-all-close | контроль: 29/27, 9/11, 4/4 | ПРОЙДЕН, ни добора, ни детектора |
| (г) vetclinic-topics-orientir-3-of-20 | `ориентир` не гейтит: топиков 3 при 20 | ПРОЙДЕН, по топикам добора нет |
| (д) bakery-scout-refused | разведчик не назвал маркеров дважды | ПРОЙДЕН + `ОТЧЁТ:` «сверки нет» |
| (е) skipass-entities-11-of-30-contract-64-over-9 | недобор сущностей и узкий контракт сразу | ДОБОР с «30», без контракта; `ОТЧЁТ:` с 9 и 64 |

Порог (А-2 и постоянный круг): 3/3 на каждый случай, Sonnet и Haiku.
В (г) строка отчёта о топиках («по ориентиру сверки нет») не штрафуется — план её не запрещает;
штраф — только за добор по топикам.
