# Баг-репорт: залог не освобождается после возврата целого инструмента по продлённой аренде

> **Статус готовности:** Готово к оценке
> **Задача:** RNT-52

## 1. Затронутый бизнес-процесс
Клиент вернул целый инструмент в пункт проката, залог должен освободиться. Затронуты аренды, которые
клиент продлевал.

## 2. Шаги воспроизведения
1. Клиент берёт инструмент напрокат на сутки, залог удержан
2. Клиент продлевает аренду ещё на сутки
3. Сотрудник пункта принимает инструмент целым, без отметки о поломке → залог остаётся удержанным

## 3. Фактический результат
После возврата целого инструмента по продлённой аренде залог остаётся удержанным. По аренде без продления
залог освобождается. Заметили по обращениям клиентов в колл-центр, около 30 в неделю; освобождают вручную.

## 4. Ожидаемый результат
- **FR-1:** Залог освобождается после возврата целого инструмента и по продлённой аренде, как по
  аренде без продления — 🔵 со слов аналитика, документа нет

## 5. Критичность и срочность починки
Высокая: деньги клиента удержаны без причины. Хотфикс.

Не осталось.
