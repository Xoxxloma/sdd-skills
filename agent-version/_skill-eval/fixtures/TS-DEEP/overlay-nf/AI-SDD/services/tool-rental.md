# tool-rental — backend

> Генерируется. Правки руками затираются.
> Заметки человека — в `services/manifest.yaml`, поле `notes`.
> Форма — `reference/card.template.md` скилла `service-map`. Соседние карточки формой не являются.

## Назначение

Даёт клиенту взять строительный инструмент напрокат на срок и вернуть его в пункт проката.
Поддерживает бронь инструмента, выдачу в пункте и возврат с отметкой о поломке. Главные объекты —
аренды инструмента и отметки о повреждении при возврате.

## Что умеет для пользователя
| Возможность | Для кого |
|---|---|
| Выдать забронированный инструмент | Сотрудник пункта проката |
| Принять инструмент назад, отметить поломку | Сотрудник пункта проката |

## Бизнес-правила

### `Rental` — аренда инструмента
- забронирована (`BOOKED`) — начальный статус аренды; где создаётся бронь — в коде не найдено
- выдана (`ISSUED`) — сотрудник пункта выдал инструмент; выдать можно только забронированный
- возвращена (`RETURNED`) — сотрудник принял инструмент; вернуть можно только выданный; поломка отмечается при возврате
- не определено: перехода в коде нет (`OVERDUE`)

### сообщение «инструмент возвращён»
- при каждом возврате; получает сервис залогов, чтобы решить судьбу залога

## Публичный контракт

### `POST /api/rentals/{id}/issue`
Выдача забронированного инструмента.
сущности: ← `id` · → `Rental`
- ошибки: аренда не найдена; инструмент уже выдан или возвращён

### `POST /api/rentals/{id}/return`
Возврат инструмента с отметкой о поломке.
сущности: ← `id`, `damaged`, `damageNote` · → `Rental`
- ошибки: аренда не найдена; вернуть можно только выданный инструмент

## События

### публикует событие возврата (топик из `RENTAL_EVENTS_TOPIC`)
Инструмент возвращён.
- `type: RENTAL_RETURNED`, `rentalId`, `toolId`, `customerId`, `returnedAt`, `damaged`, `depositAmount`
- ключ партиции — `rentalId`
- шлётся внутри транзакции возврата: не ушло — возврат откатывается, сотрудник пункта получает ошибку

### публикует событие продления аренды (топик из `RENTAL_EVENTS_TOPIC`)
Клиент продлил аренду.
- `type: RENTAL_EXTENDED`, `rentalId`, `customerId`, `plannedReturnAt`
- шлётся после сохранения продления
