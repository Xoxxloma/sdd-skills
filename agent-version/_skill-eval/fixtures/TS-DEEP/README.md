# Фикстура TS-DEEP — глубокий поиск из интервью тех-спеки (этап 2 `deep-search`)

**Дерево на диске.** Раннер `run-spec-deep.mjs` копирует `DS-BASE/ws/` и кладёт поверх `overlay/`; прогон
идёт из `ws/AI-SDD`. Код соседних реп — только из `DS-BASE`, здесь его копии нет. README и `replies.md` в
песочницу не попадают. Имя, путь или число отсюда и из `DS-BASE` в тексте скиллов — утечка стенда.

## Раскладка поверх DS-BASE

```
overlay/AI-SDD/services/manifest.yaml        tool-rental, deposit-service (код рядом) + customer-notify (папки нет)
overlay/AI-SDD/services/customer-notify.md   наш сервис уведомлений; push по идентификатору клиента — существующая возможность
overlay/AI-SDD/coddoc/RNT-41/business_requirements.md   БТ: push клиенту «инструмент принят» после возврата

replies.md                                   реплики аналитика по ходам пробы `deep`
```

Карточка `tool-rental` (из DS-BASE) **устарела**: «шлётся внутри транзакции возврата: не ушло — возврат
откатывается», «ключ партиции — `rentalId`». В коде — после коммита, ошибка отправки только в лог,
ключ `toolId`, повторов нет (DS-BASE, F1–F5, M1). Для FR-1 (не позже минуты) и FR-3 (один push на возврат)
это и есть допущение о существующем сервисе, которое спека несёт аналитику.
