# MEET-TWIN — аналитик возражает: правит предмет, условное в открытые, «без этих K»

Скилл `meeting-intake` 2.0.0, проба `meet-twin`. Карточка пробы — Н5 в `_skill-eval/PLAN-LOOP-HARDEN.md` (1.5).

**Что ловит.** Ветки исправления, которые нейтральная заглушка («согласен с рекомендацией») не проходит никогда:
- «Поправить» на вопросе «Встреча про: …?» → предмет списка — из поправки, а не из гипотезы;
- «В открытые вопросы» на вопросе о предоплате (условное решение) → `[открыто]`, а не `[решено]`;
- «Записать без этих K» на сводке со строкой «Похоже, не про …» → этих пунктов нет в списке, они в «Не вносим»
  разбора.

**Домен.** Шиномонтаж, сеть из трёх точек: онлайн-запись на сезонную переобувку. Соседние задачи на той же встрече —
склад хранения колёс (первые минуты, L8–L29) и скидочные карты (L76–L78). Ключа задачи нет — список в `docs/_inbox/`.

**Засев** (`seed/`): только `vstrecha-2026-10-20.txt` — чат встречи, 121 строка, 10:30–10:44, пять участников
(управляющий, старший мастер, администратор, разработчик сайта, аналитик). Бухгалтерии на встрече нет.

**Как устроен вход** (только грейдеру и человеку; двойник этого не видит):
- первую цель встречи называет управляющий — «разобраться со складом хранения колёс» (L8); аналитик сворачивает
  склад и возвращает к записи (L28), — гипотеза Шага 2 по «первой `задача:` карты» вероятно выйдет про склад;
- предоплата 500 рублей в пик принята всеми, но «если бухгалтерия согласует» (L81–L87);
- соседние задачи: решение по биркам на складе (L17–L18) и скидка 10% по карте (L76–L78), сведения о складе
  (L11–L16); весенний наплыв (L25–L26) читается двояко — склад или пик переобувки, не грейдится;
- два ранних слова, которые переиграли: «номер не надо» (L55 → L58), «на три недели» (L95, в той же реплике).

**Ход диалога.** За аналитика — двойник: общий промпт `twin-objector.md` + `twin-card.md`.
1. Вызов без ключа; `docs/` нет → вопрос о корне → «да, всё в текущей папке» (правило общего промпта).
2. «Встреча про: <гипотеза>?» → «Поправить: встреча про онлайн-запись на сезонную переобувку.»
3. Шаг 5: любой вопрос о предоплате — условное или `не решение`, с оговоркой или без — → «В открытые вопросы.»
   Прочие вопросы Шага 5 → по умолчанию.
4. Сводка со строкой «Похоже, не про …» → «Записать без этих K.»
5. Запись. Конец — когда записан список.

**Строка раннера** (`run-ctx-v2.sh`):

```
  meet-twin)  FIXTURE=MEET-TWIN;  PROMPT_FILE=w-prompt.txt; SKILL=meeting-intake; SEED_SUB=seed; TURN2_FILE=w-turn2.txt; TURNS_CAP=20; IDLE_MAX=20; DONE_RE='/docs/.*/meeting-[^/]*\.points\.md$'; TWIN_CARD=twin-card.md; TWIN_PROMPT=twin-objector.md; MEET_ENV=1 ;;
```

Ветки `--fx TWIN` в `grade-meet.mjs` пока нет — проверка по `expected.md`. Ответы двойника — `<песочница>/_twin/`.

**Ловушки** (подробно — `expected.md`): предмет по гипотезе после «Поправить»; предоплата решённой или `ждёт:` с
неназванной должностью; склад и скидка в списке после «без этих K»; «без номера» / «три недели» как действующее.
