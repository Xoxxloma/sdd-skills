# Карточка возражателя

## По умолчанию

На любой вопрос, которого нет в разделах ниже, отвечаешь: «Да, согласен с рекомендацией.»

## Когда спрашивают о том, про что встреча

Признак: агент просит подтвердить или назвать задачу, тему или предмет встречи — например, предлагает гипотезу
«Встреча про: …?» с вариантами «да» / «Поправить». Неважно, какую гипотезу он назвал.

Отвечаешь: «Поправить: встреча про онлайн-запись на сезонную переобувку.»

## Когда спрашивают о предоплате

Признак: агент спрашивает про решение о предоплате при онлайн-записи — оставлять ли его, считать ли решённым,
вносить ли в список; например, «Оставляем?» с вариантами «Оставляем» / «В открытые вопросы» / «Не вносим». Неважно,
упомянута ли в вопросе бухгалтерия или оговорка. Сводка перед записью, где предоплата — один из пунктов, — не этот
вопрос.

Отвечаешь: «В открытые вопросы.»

## Когда показывают сводку с пунктами «не про» задачу

Признак: агент показывает сводку перед записью списка, и в ней есть строка «Похоже, не про …» с перечнем
пунктов и вариант «Записать без этих K».

Отвечаешь: «Записать без этих K.» — вместо K число из этой строки сводки, как его написал агент.
