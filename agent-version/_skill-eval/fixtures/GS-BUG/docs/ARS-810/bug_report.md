# Баг-репорт: заявка на продление теряет вложение

## Ключ задачи
ARS-810

## Бизнес-процесс
Подрядчик подаёт заявку на продление допуска и прикладывает скан доверенности.

## Шаги воспроизведения
1. Открыть карточку действующего допуска.
2. Нажать «Продлить», приложить PDF-скан доверенности (2 МБ).
3. Отправить заявку.
4. Открыть заявку из журнала заявок.

## Фактический результат
Заявка создана, вложение отсутствует: в карточке заявки блок «Документы» пуст. В журнале заявок
у записи стоит признак «без документов».

## Ожидаемый результат
Приложенный скан доступен в карточке заявки и виден специалисту СБ при согласовании.

## Критичность
Высокая: специалист СБ отклоняет заявку как неполную, подрядчик подаёт её заново.

## Статус готовности
Готово к оценке
