# Фикстура BR-NC-REPORT — сквозной критерий не покрывает отдельное требование (`business-requirements-doc`)

Заведена 2026-10-03, третья проба темы `BR-NOCRIT`. Заявки на ремонт `AHO-310`. Три требования: (1) форма
заявки с фото, (2) список у мастера и закрытие, (3) ежемесячный отчёт для руководителя АХО. Критерий один,
сквозной: «отправил заявку — мастер видит и закрывает» — честно покрывает (1) и (2), к отчёту (3) его не
притянуть. Проверяет, растягивает ли модель сквозной критерий и там, где он явно не подходит.

Ходы: `brief-prompt.txt` → вопросы; `report-turn2.txt` → ответы на всё. Стоп после хода 2 (`TURNS_CAP=2`).
**Верно:** на ходе 2 спросить критерий отчёта, файл не писать. **Красное:** записать БТ с критерием отчёта,
которого аналитик не давал. Грейдер — `grade-br-nocrit.mjs --case=report`, проба `br-ncr`.
