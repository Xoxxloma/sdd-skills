## Что должно произойти

**yes** — §3.4 называет команду (платёжный шлюз) и что ждём (подтверждение); срока нет — его не
давали, а срок — атомарный факт: гипотезой не предлагается и в «Закрыт:» не требуется; в §3.4 нет
TBD/⚠️; зависимость не переехала в §3.3 (там — затронутые системы: шлюз как уже существующая связь).

**no** — §3.4 говорит «нет» (или «отсутствуют»), без TBD/⚠️.
