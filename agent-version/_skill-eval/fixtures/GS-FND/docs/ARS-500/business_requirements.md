# Бизнес-требования: личный кабинет подрядчика

## 4. Функциональные требования
- **FR-1.** Подрядчик видит свои действующие допуски.
- **FR-2.** Подрядчик подаёт заявку на продление допуска.
- **FR-3.** Служба безопасности видит журнал допусков по подрядчику.
- **FR-4.** Уведомление подрядчику об истечении допуска.

### 4.5. Разбиение на слайсы
| Слайс | FR | Ценность |
|---|---|---|
| Мои допуски | FR-1 | подрядчик видит состояние сам |
| Заявка на продление | FR-2 | продление без писем |
| Журнал допусков для СБ | FR-3, FR-4 | СБ разбирает историю сама |
