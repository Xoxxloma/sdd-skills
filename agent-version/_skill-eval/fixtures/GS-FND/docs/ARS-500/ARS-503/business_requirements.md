# Бизнес-требования: журнал допусков для службы безопасности

## 4. Функциональные требования
- **FR-3.** Специалист СБ смотрит журнал выданных допусков по подрядчику за период. Критерий:
  журнал строится по событиям аудита СБ и фильтруется по подрядчику и датам.
- **FR-4.** Подрядчику уходит уведомление за 14 дней до истечения допуска. Критерий: уведомление
  отправляется один раз на допуск.

### 4.3. Бизнес-данные

Унаследовано из эпика ARS-500.

| № | Объект | Что это | В системе |
|---|---|---|---|
| 1 | Допуск подрядчика | допуск на объект: объект, срок действия, статус | уже есть — справочник допусков подрядчиков |
| 2 | Заявка на продление допуска | заявка подрядчика по допуску, её статус виден подрядчику | новая |
| 3 | Событие аудита СБ | запись о выданном допуске для журнала службы безопасности | уже есть |
