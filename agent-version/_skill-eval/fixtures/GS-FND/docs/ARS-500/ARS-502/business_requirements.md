# Бизнес-требования: заявка на продление допуска

## 4. Функциональные требования
- **FR-2.** Подрядчик подаёт заявку на продление допуска из карточки допуска. Критерий: заявка
  создаётся по допуску, взятому из **справочника допусков подрядчиков**, и её статус виден
  подрядчику.

## Статус готовности
Готово к оценке
