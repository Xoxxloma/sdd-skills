# Фикстура SM-APOLLO — service-map на настоящем коде Spring

Синтетика SM-GAPS выходит почти на 100 % у обеих версий скилла и у всех моделей, прод — нет. Здесь настоящий
боевой код: Apollo (`apolloconfig/apollo`, Apache 2.0). Дерева фикстура не держит: раннер копирует его из
`projects/apollo` (клон без истории, коммит `fd33f8d` от 2026-10-24) в каждую песочницу, без `.git`.

Цель скана — `apollo-portal`: 137 внутренних ручек и 153 внешних (OpenAPI v1 по спецификации из другой репы —
в исходниках её нет, как у прод-сервисов со спекой в отдельном контракте), 14 сущностей, 3 фоновые задачи
на потоках вместо `@Scheduled`. Размер — как у большого прод-сервиса.

Файлы: `KEY.md` — ключ и опорные факты; `portal-rest.tsv` — внутренние ручки; `openapi-ops.tsv` — операции
внешней спецификации. Прогон: `run-sm-mono.sh <папка скилла> <раунд> SM-APOLLO`; грейдер —
`node grade-sm-apollo.mjs <раунд>`. Папка скилла — `service-map` (v1) или `service-map-2.0`.
