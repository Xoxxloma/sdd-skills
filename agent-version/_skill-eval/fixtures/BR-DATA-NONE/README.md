# Фикстура BR-DATA-NONE — гейты 15 и 16 без окружения

Заведена 2026-10-07 под `business-requirements-doc` 1.2.0 (PLAN-BR-SECTIONS, батчи A и B).
Окружения нет: ни `services/`, ни `context/` — засев пуст (README, промпты и реплики раннер
не кладёт). Меряет, что гипотеза без источника не ссылается на источник.

| Проба | Ключ | Промпт → реплика хода 2 | Грейдер |

Два хода (`TURNS_CAP=2`).

## Что должно произойти

**none** — тот же бриф, что `br-data-obj` (фото к работе по смете), но карточек нет. Ход 1 —
вопросы, файла нет; ни одной ссылки на карточку, `services/`, код или `repairy`, которых нет;
кодовых имён объектов нет; вопроса/гипотезы о сведениях фото нет. Ход 2 — §4.3 с фото, работой
по смете и актом приёмки, без сведений, которых не давали.

**asis-new** (новый функционал: бюро находок). Ход 1 — ни одной ссылки на несуществующий
источник («в карточке», «по коду»). Ход 2 («сейчас никак — вещи оставляют на ресепшене, учёта
нет») — §1.4 есть, говорит, что учёта нет, и не повторяет §4.1.

## Критерии (названы до прогонов)

PLAN-BR-SECTIONS §1.0: N = 3; провал новой пробы → разбор.
