## Что проверяется

Анкеры `fixtures/MEET-ACC/expected.md` (импорт `gradeInput`): фоновое заведение с повтором; оповещение дежурному;
повторное заведение → идентификатор, доступ выдан; логин хранится; состояние при открытии; синхронный отзыв; повторная
блокировка → запрос состояния; код системы вместо признака. Не должно быть: синхронного заведения, внутреннего
статуса, блокировки фоном, подписки решением, токенов карточки `idm`, форм на слух, шума. Цель — **новая спека**, вход
`coddoc/ACS-208/meeting-2026-10-09-spec.md`; БТ и список не тронуты; `services/` и `context/` не читались.

**Ожидания после круга 2 (решение пользователя: «спека делается на основании БТ»; layout.md: что видит пользователь

**P9 — в обе стороны (решение пользователя 2026-10-15).** «Между согласованием и выдачей нужен статус, которого в БТ
нет — ждёт ИБ» с пометкой встречи «(на встрече: в спецификацию — как отклонение от БТ, открытым вопросом)»: пометка

по-прежнему только «для БТ».

## Место каждого пункта (после круга 2)

Карта `PTS['ACC']` в `grade-ni.mjs` — выведена из текста скилла (layout.md, check.md, intent.md, Шаги 4–7) и
документов засева до прогонов круга 3. Первое место — основное; несколько мест — где правило по тексту пункта
двузначно, причина в последнем столбце. Пункт во входе — только в допустимом разделе; не во входе — место берётся из
ответов прогона (сводка Шага 6, вопрос Шага 5, отчёт, номера `P<n>`), последнее упоминание старше; место не
названо — пропуск `[сведение]` и `[решено]`/`[открыто]` с местом во входе — красный.

Дословность (Шаг 7) у пункта во входе — красный: потеряно «со слов <кто>» у сведения в «Сведениях»; пометка «не помню»
или «не уверен» изменена или снята; число пункта потеряно цифрой или словом (в том числе «вместо 24»); «вместо <как
сейчас>» потеряно; ФИО в «решил:» / «ждёт:» / «со слов» не из этого пункта; `[открыто]` с вариантами — без «?» и без
обоих вариантов; «решали:» — не парой «роль — ФИО» из шапки списка; «решает:» — фамилии нет в списке. Опора (с
2026-10-16): каждая строка входа — числа, ФИО, латиница — из текста списка и реплик аналитика. Предупреждение: нет
«решил: <кто>», «ждёт: <кто>», «(на встрече: …)».
