# NB-HUGE — выгрузка из ноута на 2000+ строк

Проба `nb-huge-export` (`run-ctx-v2.sh`). Засев — ноут «горнолыжная база» на 2036 строк, 351 пункт, 345 действуют; его
собирает `make-nb-huge.mjs` (детерминированно, текст синтетический: цель пробы — масштаб, а не смысл). Замены, ответ на
вопрос и спор разнесены на 700–1800 строк. Состояние стоит в самой строке, поэтому проба мерит полноту: выгрузить все
345 действующих строк и ни одной выбывшей, когда строк пунктов сотни. Промпт — `собери пункты`. Критерии — `expected.md`, спека — `state.json`, оценщик —
`grade-nbs.mjs --fx NB-HUGE`.
