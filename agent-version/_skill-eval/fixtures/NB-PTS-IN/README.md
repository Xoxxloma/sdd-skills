# NB-PTS-IN — список пунктов встречи в существующий ноут

Проба `nb-pts-in` (`run-ctx-v2.sh`), скилл `analyst-notebook` 1.2.0, Шаг 2 «список пунктов». Засев — ноут
«возврат товара без чека» (побайтно тот же, что в NB-CONTRA и NB-ANSWER) и список встречи
`docs/_inbox/meeting-2026-10-13.points.md` в форме `meeting-intake/reference/output.md` («Список пунктов»), написанный
руками. Расшифровки, на которую ссылается список, в засеве нет: ноут её не читает.

Четыре пункта списка — четыре случая сверки Шага 4: Соколова М. меняет своё решение (`вместо:` без вопроса о споре),
Гарипова Л. отвечает на открытый вопрос (`отвечает на:`), сведение Дёмина К. о чеке возврата — рядом с его открытым
вопросом, но не ответ на него (связи нет), новое решение о запуске (связи нет).

Переносит ожидания старых `mi-nb-same` (тот же человек передумал), `mi-nb-ans` (ответ на открытый вопрос) и ловушку
`mi-nb-out` (похожее, но не ответ): теперь в ноут ложится готовый список.

Промпт — `w-prompt.txt`, реплика — `w-turn2.txt`. Критерии — `expected.md`, грейдер — `grade-nb.mjs --fx PTS-IN`.
