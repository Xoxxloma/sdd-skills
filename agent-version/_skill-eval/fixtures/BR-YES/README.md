# Фикстура BR-YES — «да» на гипотезу закрывает гейт (`business-requirements-doc`)

Заведена 2026-10-02 для доказательства правки 1.1.1 (`Закрыт:` у ценности, цели, рисков, потребителей,
интеграций — «назвал **или подтвердил**»). До правки по букве «да» на гипотезу эти гейты не закрывал.

Одноходовая, в форме «ПРОДОЛЖЕНИЕ» (как `BR-OPEN/w-prompt.txt`): в `yes-prompt.txt` пересказан прошлый
ход агента — пять гипотез «понял так: … Верно?» — и ответ аналитика «по пунктам 1–5: да, всё так» плюс
остальные гейты прямым текстом. Так гипотезы фиксированы и не зависят от того, что модель спросила бы
сама (на `BR-REAL` Haiku гипотез почти не строит — «да» не на что было бы отвечать).

**Верно:** файл `docs/LIB-208/business_requirements.md` этим ходом, «Готово к оценке», без `TBD`/`⚠️`.
**Красное:** нет файла (переспросил подтверждённое) или открытые пункты.

Окружение пустое. Предметная область — корпоративная библиотека (не та, что у прода и у других проб).
Грейдер — `grade-br-yes.mjs`, проба `br-yes`.
