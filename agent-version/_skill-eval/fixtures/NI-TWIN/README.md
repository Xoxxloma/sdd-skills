## Цель: почему рекомендованной скорее всего будет не «правки БТ»

На диске БТ, спеки нет; все решения слоя «БТ» — «сейчас … → …» у работающей функции. `SKILL.md:117–118`: «Пункты
меняют то, что уже работает («сейчас так → станет так»), — правка работающего, даже если документов нет» — ждём
рекомендацию «правка работающего». Двойник выбирает «правки БТ» — законна по строке таблицы `SKILL.md:112` (БТ, спеки
нет, правила). Если рекомендацией окажется «правки БТ», карточка выбирает «правку работающего» (законна по
`SKILL.md:117–118`): ветка «не та цель» мерится в обоих случаях. Обе цели — вход `-bt.md`.
