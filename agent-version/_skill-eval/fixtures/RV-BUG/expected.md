# RV-BUG — что считается верным

> **Написано до первого прогона.**

Два плеча, один тип документа. Приёмка на диск не пишет — грейдится её ответ в чат.

## `rv-bug-clean` — ГЛАВНОЕ ПЛЕЧО

Документ `docs/ARS-312/bug_report.md` — замороженный выход прогона `bg-flick-w` круга 2, чистый по
всем семи пунктам.

| Что | Верно |
|---|---|
| эхо-строка | `чек-лист прочитан, тип: баг-репорт` |
| вердикт | **`нарушений: 0`** |
| счётная строка | `требований, стоящих только на памяти аналитика: 1` |

**Красное — любая находка.** Это ложное срабатывание, и оно дороже пропуска: список, краснящий на
корректном документе, перестают читать целиком.

Отдельно ловим три предсказуемых ложных повода, каждый своим счётчиком:

1. **«нет причины дефекта»** — причины в этой форме нет по устройству, и чек-лист это оговаривает.
2. **`🟡` названа нарушением** — «со слов аналитика» законно и является нормой, а не находкой.
3. **«документа нет — со слов аналитика» принято за битый путь** — это фраза, а не путь.

**Планка шага: `нарушений: 0` не меньше чем в 9 прогонах из 10.**

## `rv-bug-dirty`

Документ `docs/ARS-411/bug_report.md`. **Шесть посаженных нарушений, седьмой пункт намеренно
чистый** — он ловит проверку, которая срабатывает всегда.

| # | Пункт чек-листа | Что посажено |
|---|---|---|
| 1 | `source:` ведёт в несуществующий файл | `docs/ARS-777/technical_specification.md` — такой папки нет |
| 2 | ожидаемый результат без пометки происхождения | ни `🟢`, ни `🟡` |
| 3 | ожидаемый результат не нумерован | «Должно работать так: …» без `FR-*` |
| 4 | шаги воспроизведения не шаги | раздел написан прозой, нумерованных строк ноль |
| 5 | раздел пуст | «Фактический результат» пуст |
| 7 | число в статусе не сходится | статус `Требуются уточнения (3)`, в блоке 1 пункт |

**Пункт 6 (словарь статуса) — намеренно ЧИСТЫЙ.** `Требуются уточнения (3)` — законное значение;
неверно только число, и это пункт 7. Находка по пункту 6 означает, что проверка срабатывает на
корректном значении.

**Планка шага: в среднем не меньше 5 из 6.** Считается по числу найденных, а не по формулировке:
находка засчитывается, если названа секция или процитирована строка, к которой она относится.

## Чего эта фикстура НЕ меряет

Маршрутизацию проводника — он про баг-репорт ещё не знает. Приёмка здесь запускается напрямую.
