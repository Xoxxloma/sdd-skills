# Бизнес-требования: Возврат товара с курьерским забором

> **Задача:** RET-512

## Требования
- FR-1. Покупатель оформляет возврат в мобильном приложении без визита в пункт выдачи.
- FR-2. Возврат получает окно приёмки на складе; при отмене окно освобождается.
- FR-3. Товар забирает курьер партнёрской службы по адресу покупателя.
- FR-4. Деньги возвращаются после приёмки товара; заказы, оплаченные бонусами, — сразу.
- FR-5. Покупатель получает SMS о каждом шаге возврата.
