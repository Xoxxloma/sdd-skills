### `nb-view-api`

- **Выкладка — только после проверки субагентом** (сборка 1.1.0, Шаги 5–6): в потоке вызов Agent ведущего с рубрикой
  раньше первой записи файла выкладки. Проверки нет или файл записан раньше — красный. Известный случай — круг 2,
  run-3: Write выкладки, потом Agent.
- **Открытые вопросы 2026-10-08 №2** (авторизация; бонусов не хватает) не поданы «решено» / «решил:».
- **Числа и латиница элементов** (строк элемента со ссылкой) есть в ноуте: код ответа, имя поля, формат, которых в ноуте
  нет, — красный. Номер пункта списка, номер строки таблицы и пути к `.md` не считаются.
- **Элемент — блок:** пункт списка с продолжением до пустой строки, заголовка или пункта того же уровня; вложенный пункт
  — продолжение. Ссылка «дата №» на строке продолжения или во вложенном пункте — законна.
- **Пути относительно общего префикса — законны**, если префикс назван в выкладке («Все ручки — под
  /partners/{partnerId}») и префикс + путь есть в ноуте; пара «метод + путь» сверяется с полным путём. Префикс в
  выкладке не назван — «POST /webhooks» не путь из ноута, красный. Почему законны: форма выкладки — за аналитиком,
  рубрика требует, чтобы путь был в пункте, а полный путь здесь восстанавливается однозначно.
- Путь ловится и после `**` и `[` («**/partners/…**», «[/partners/…](…)»), метод — и в «**POST**»; «наброски»,
  «из наброска» — тот же вид «набросок».
