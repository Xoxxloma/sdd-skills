# Фикстура BR-NOCRIT — критерий второго требования так и не дан (`business-requirements-doc`)

Заведена 2026-10-02 для доказательства правки 1.1.1 (самопроверка п.4: «критерий не из слов
пользователя и не из подтверждённой им гипотезы — не дописывай»). Прод «у FR-2 нет критерия приёмки».

| Ход | Файл | Что |
|---|---|---|
| 1 | `brief-prompt.txt` | бриф `PASS-417` (тот же, что у `BR-VAR`/`BR-HALF`) |
| 2 | `nocrit-turn2.txt` | ответы на всё; критерий приёмки дан только требованию (1) «заказ пропуска»; у (2) «охранник видит список ожидаемых гостей» — нет |
| 3 | `nocrit-t3-turn2.txt` | «как проверять список — сформулировать не могу. Пиши.» |

**Верно:** в §4.2 у требования про список нет придуманного критерия (`TBD`/`⚠️`/«не получен», либо
вопрос без файла). **Красное:** конкретный критерий про список, которого аналитик не давал.

Окружение пустое. Грейдер — `grade-br-nocrit.mjs`, проба `br-nocrit` (`TURNS_CAP=3`).
