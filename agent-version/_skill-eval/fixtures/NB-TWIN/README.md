# NB-TWIN — запись письма, аналитик-двойник поправляет, спор «Старое», «не знаю»

Проба `nb-twin`, скилл `analyst-notebook` 1.2.0, режим записи, Шаги 4–6 (карточка Н12 в `PLAN-LOOP-HARDEN.md`).

**Домен** — цветочный магазин: покупатель на сайте выбирает не интервал, а точное время доставки букета. Люди:
Дробышева Н. (владелица), Оганесян К. (старшая флористка), Мельничук А. (логистика доставки), Сазонов Ф. (сайт).

**Засев** — `seed/notes/доставка-букетов-к-точному-времени/notebook.md`: 45 строк, 12 пунктов, 2026-10-07…2026-10-12;
решение Дробышевой Н. о допуске плюс-минус 15 минут, сведения, два открытых вопроса, мысль, набросок.

**Что ловит** — ветки исправления в записи:
- «Поправить» — поправка аналитика попадает в пункт, а цитата письма под `>` остаётся дословной;
- спор с решением другого человека, ответ «Старое» — пункт спора не пишется, письмо под `>` остаётся;
- решение без решившего, ответ «не знаю» — `[открыто]`, без выдуманного `решил:`;
- прошлые записи байт в байт; ложные `вместо:` / `отвечает на:` по общим основам («час пик», «30 минут»).

**Ход:** 1 — промпт (письмо Мельничука А.) → вопрос Шага 5: пункты, спор, кто решил, «Записать так или поправить?»;
2 — двойник: «Поправить: …», «Старое», «Не знаю» → пункты ещё раз; 3 — «Записать» → запись.

**Двойник** — `twin-card.md` с промптом `twin-objector.md`; умолчание — «Да, так.» (не «записывай»: на неожиданный
вопрос оно велело бы писать сразу). `w-turn2.txt` — заглушка: пул крутит ходы только при `TURN2_FILE`, реплику подменяет
двойник. Критерии — `expected.md` (до первого прогона). Оценщика нет; ключ — на усмотрение
владельца (`grade-nb.mjs --fx TWIN`).

**Строка для `run-ctx-v2.sh`:**

```
  nb-twin)    FIXTURE=NB-TWIN;    PROMPT_FILE=w-prompt.txt; SKILL=analyst-notebook; SEED_SUB=seed; TURN2_FILE=w-turn2.txt; TURNS_CAP=6; IDLE_MAX=6; DONE_GREP='получател'; TWIN_CARD=twin-card.md; TWIN_PROMPT=twin-objector.md; MEET_ENV=1 ;;
```

`DONE_GREP='получател'` — основы нет в засеве, она появляется в `notes/` только с записью письма.

**Не покрыто:** ответ «Новое» на спор (`вместо:` на старое решение, SKILL.md:145) — карточка отвечает только «Старое»,
второй карточки нет.
