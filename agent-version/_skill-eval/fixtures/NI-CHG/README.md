## Место каждого пункта (после круга 2)

Карта `PTS['CHG']` в `grade-ni.mjs` — выведена из текста скилла (layout.md, check.md, intent.md, Шаги 4–7) и
документов засева до прогонов круга 3. Первое место — основное; несколько мест — где правило по тексту пункта

ответов прогона (сводка Шага 6, вопрос Шага 5, отчёт, номера `P<n>`), последнее упоминание старше; место не
названо — пропуск `[сведение]` и `[решено]`/`[открыто]` с местом во входе — красный.

или «не уверен» изменена или снята; число пункта потеряно цифрой или словом (в том числе «вместо 24»); «вместо <как
сейчас>» потеряно; ФИО в «решил:» / «ждёт:» / «со слов» не из этого пункта; `[открыто]` с вариантами — без «?» и без
обоих вариантов; «решали:» — не парой «роль — ФИО» из шапки списка; «решает:» — фамилии нет в списке. Опора (с
2026-10-16): каждая строка входа — числа, ФИО, латиница — из текста списка и реплик аналитика. Предупреждение: нет
«решил: <кто>», «ждёт: <кто>», «(на встрече: …)».
