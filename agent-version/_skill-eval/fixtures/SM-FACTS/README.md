# SM-FACTS

Исходная синтетическая выборка для проверки чтения поведения: 24 операции
(18 REST, 4 GraphQL, 2 служебные), 2 модели хранения, 2 задачи, 3 события;
53 факта, из них критические находятся за пределами файлов объявлений обработчиков.
Источник истины — дерево, ожидаемые факты написаны отдельно и не передаются читающему.

`tree/` — сокращённый исходник для анализа, не запускаемый сервис: адаптеры
`fixture-database`, `fixture-broker`, `fixture-graphql` обозначают инфраструктуру.
Нельзя приписывать этим адаптерам поведение, которого нет в исходнике.
Отсутствие исполняемого сервиса не мешает проверить явно написанные условия, проекции и вызовы.

У служебного health только 204; ready содержит проверку БД и две ветви ответа.
GraphQL nullable-объявление не доказывает возврат null реализацией: resolver вызывает
общую логику, которая выбрасывает NOT_FOUND. Эти сведения должны сохраняться раздельно.
HOLD_REASON и NOT_HELD — подтверждённые доменные ошибки GraphQL-resolvers. HTTP-коды
400/409 из Express-обработчика не доказывают способ их доставки неизвестным GraphQL-адаптером;
эталон не требует этих транспортных кодов. Прежнее ошибочное ожидание сохранено в истории
исправлений измерения, оно не расходует лимит красных кругов скилла.
Внешний REST-префикс задаётся при подключении роутеров, не в файлах маршрутов.

Проверка текста допускает переформулировки и перестановки, но остаётся предварительной:
она не доказывает отсутствие всех возможных выдумок. Полный зелёный результат требует
ручного аудита карточки против дерева с хешем проверенного файла. Цена, пик и переходы
между файлами без доступной трассы отмечаются «не измерено».

Грейдер возвращает `status: not_measured` и код 3 без полного аудита; предварительные
регулярные совпадения не расходуют лимит красных кругов скилла. Аудит `card.md.audit.json`
содержит хеши карточки и эталона, автора, число выдумок, итог `pass`/`fail`, проверку
возможных противоречий и 53 решения `facts`: `index`, точный `source` эталона,
`status: present|missing`, обоснование `reason`, а для найденного факта — буквальную
цитату `evidence` из его собственного блока. Один общий штамп «проверено» недостаточен.
После такого аудита смысловое покрытие определяет результат независимо от лексических
ложных пропусков. Сам грейдер не доказывает верность решений человека.
