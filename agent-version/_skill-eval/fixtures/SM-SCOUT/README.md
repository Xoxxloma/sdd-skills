# Проба SM-SCOUT — разведчик Шага 3.0 называет маркеры, греп считает

Критерий А-1 (`PLAN-AUTOSPLIT.md` §5, `runs/2026-10-04-autosplit-criteria.md`): итог грепа по маркерам
разведчика в [0,8; 1,5] × правды по каждому классу на четырёх фикстурах, Haiku 4/5 на фикстуру;
`@Query` не в контракте, `@Table` не в сущностях, пометка класса и `@DgsData` не-корневого типа не
маркер; пик контекста разведчика ≤ 60k; полного обзора дерева (`Glob **/*`) нет.

Проба исходит из контракта плана (§2), а не из текста скилла: раннер берёт из SKILL.md только бриф.

## Песочница

Одна на раунд: `<раунд>/sandbox-scout/<фикстура>/<дерево>/` (в `.gitignore` по `runs/*/sandbox*/`).
У разведчика только Read/Grep/Glob — писать ему нечем, поэтому копия на прогон ничего не защищает, а
общая даёт главное: грейдер грепает ровно то дерево, что видел прогон, и настоящие репы не уезжают
между прогонами. Раннер снимает отпечаток песочницы до и после пула и до пула сверяет эталон с правдой.
NRS-TAIL и SM-MONO-DGS собираются генераторами заново (не из их `out/`), repairy/resonance — `SM-REAL/seed.sh`.

## Запуск

```bash

bash run-sm-scout.sh ../service-map-2.0/SKILL.md runs/<дата>-<раунд> 5
SM_SCOUT_ONLY="SM-MONO-DGS" bash run-sm-scout.sh <SKILL.md> runs/<раунд> 5   # одна фикстура
```

Прогон: `<раунд>/sm-scout/<фикстура>/run-NN/{answer.md,_stream.jsonl,cost.txt,…}`; промпт фикстуры —
`<раунд>/sm-scout/<фикстура>/prompt.md`, шаблон брифа — `_brief-template.md`.

## Грейдер — что и чем

- **Движок — тот же, что у инструмента Grep:** ripgrep, встроенный в Claude Code (бинарь `claude`,
  вызванный под argv0 `rg`), с флагами инструмента: `--hidden`, `--glob !.git` и родня, `--max-columns 500`,
  `-c -H --null`; поле glob разбирается как у инструмента (по пробелам, `{…}` целиком, иначе по запятым).
  `.gitignore` внутри деревьев учитывается так же, как у инструмента. Не нашёлся ripgrep — запасной JS
  RegExp с пометкой в отчёте (синтаксис расходится: lookaround/обратные ссылки у rg не компилируются,
  `\b`/`\w` у rg по Unicode).
- **Вердикт класса:** сумма строк `ключ` в [0,8; 1,5] × правды; правда 0 — зелёный, если сумма 0 или класс
  не назван. «Мягко» — класс с `без_ключа_законно` зелёный и без строки `ключ` (топики только в yaml,
  хранение без ORM): план разрешает «ориентир» (§2, §8). Отчёт печатает оба итога.
- **Ловушки — по месту совпадения**, не по тексту регэкспа: что ведущий насчитал бы, то и красит.
  `@Query` в контракте; `@Table` в сущностях; пометка класса (`@DgsComponent`/`@RestController`/`@Controller`
  в совпадении или совпадение на аннотации над объявлением типа, кроме сущностей); `@DgsData` не-корневого
  типа среди ключей.
- **Ещё красят:** регэксп не компилируется; строка маркера вне формы; пик контекста > 60k (max по ходам
  `input + cache_creation + cache_read`); Glob `**`, `**/*` по корню дерева или выше.
- **Не измерено:** `_api-failure.txt`, нет ответа/стрима/usage, прогон вызвал инструмент кроме Read/Grep/Glob.
- Фикстура: зелёных ≥ ⌈0,8 × измеренных⌉ (4 из 5).

## Самопроверка — до любого прогона

```bash
node grade-sm-scout.mjs selftest
```

Собирает `out/` (если нет), сверяет эталонные маркеры с правдой и грейдит 23 ответа из
`grader-selftest/sm-scout/<фикстура>/<случай>/` против `grader-selftest/expected.json`: верный на каждой
фикстуре; `@Table`; `@Query` JPA и `@Query()` Nest; `@DgsData` без parentType; `@RequestMapping`,
`@DgsComponent`, `@Controller` как ключ; пустой; невалидный регэксп (lookahead); наивный Express;
строка вне формы; бэктики; ложный топик; топики/сущности без ключа (строго красный, мягко зелёный);
пик 73,5k; Glob `**/*` по корню; отказ API. Печатает таблицу «случай — ожидалось — получено», код
выхода 1 при любом расхождении. Подробный отчёт — `out/selftest-GRADE.txt`.
