# MEET-LONG — что считается верным (скилл `meeting-intake`)

> **Написано до первого прогона.** Толкование, дописанное после чисел, подгоняется под результат.
> Если ожидание неверно — правь этот файл отдельным ходом и с объяснением.

**Зачем.** Длинная встреча: 660 строк, 52 минуты (реальные экспорты — ~400 строк на 30 минут). Меряет
путь, которого короткие фикстуры не задевают: карта в три окна, склейка темы между окнами, разбор темы
кусками (тема длиннее 400 строк), последнее слово между кусками, чужие темы с собственными решениями.

**Засев** (`seed/`): расшифровка `meeting-2026-10-12.txt` + `docs/PSS-2210/business_requirements.md`
(копия из `RT-E2E`). Ключ только в речи — «пэ эс эс двадцать два десять» (L174), набранного ключа нет.
Проба `meet-long` (`run-ctx-v2.sh`), промпт `/meeting-intake meeting-2026-10-12.txt`, реплика заглушки —
«Да, согласен с рекомендацией.» на каждый ход, конец — записан вход, потолок 20 ходов.

**Строение встречи.**
- L1–L165 — стендап по чужим задачам: отчёт по командировкам (решение «CSV, точка с запятой»), поиск,
  форма обратной связи (решения: телефон необязательный, кнопка справа, без капчи), процесс релиза.
- L166–L640 — PSS-2210 с заказчиком (служба безопасности) и бюро пропусков; внутри — перерыв (L475–L488,
  болтовня и баг поиска) и вставка про форму обратной связи (L541–L546, «тему оставь текстом»).
- L604–L625 — итоги; L629–L640 — уточнение после итогов; L641–L660 — следующая встреча.
- Групповые заявки: «делаем до пяти» (L244, L250, первое окно) → «вне проекта, тут я поторопился»
  (L392–L404, второе окно).

**Ожидаемый маршрут:** тем с решениями несколько → вопрос темы, рекомендована PSS-2210 (ключ сошёлся с
диском, решений больше всех) → цель **правки БТ** → условные (передача заместителю, предупреждение при
подаче) — «оставляем» → запись.

**Файлы:** `docs/PSS-2210/meeting-2026-10-12-bt.md` (вход) и `docs/PSS-2210/meeting-2026-10-12.razbor.md`
(разбор); БТ не тронут. Эталон — `etalon/`. Грейдер — `grade-meet.mjs --fx LONG`.

## Вход: должно быть

| Анкер | Где |
|---|---|
| срок подачи — до 18:00 последнего рабочего дня перед визитом | Решено |
| передача заместителю, если руководитель не ответил до 16:00 | Решено или Открыто (условное) |
| уведомление заявителю при решении | Решено |
| в уведомлении — дата и время визита, ссылка | Решено |
| номер документа видит только бюро | Решено |
| паспорт РФ или иностранный, для иностранного — гражданство | Решено |
| цель визита из списка | Решено |
| время визита — часы с 8 до 18 | Решено |
| комментарий при отклонении обязателен и виден заявителю | Решено |
| сколько хранить номер документа — к юристам | Открыто |
| срочный пропуск — вне проекта | Не входит (или Сведения/Решено со словами «вне проекта / как сейчас») |
| отчёт по визитам — в бэклог | Не входит или Открыто |

## Вход: не должно быть

- групповые заявки решением в «Решено» (переиграно L392–L404; групповые уже вне проекта в БТ §3.2);
- номер пропуска в уведомлении (не принято L466–L470);
- слой спеки: кеш, таблица, транзакция, почта/мессенджер/бот, маска, «десять цифр», настройки,
  производственный календарь, справочник праздников;
- чужие темы: CSV, бухгалтерия, командировки, форма обратной связи, капча, телефон в форме, сертификат,
  релиз;
- шум: ИФТ, столовая, Ёлкин, планёрка;
- формы на слух: «пэ эс эс», «двадцать два десять»; якоря и время.

## Разбор: должно быть

- цитаты сходятся со строками ±2;
- не потеряно: групповые «до пяти» как отменённое; кеш руководителя и транзакция — для спеки; номер
  пропуска — не принято.
