# Этап 01 — сводка занятости комнат по этажу

## Что делает
Собирает занятость комнат этажа на текущий момент из броней корпоративного календаря и отдаёт её
одним ответом плану этажа.

## Вход (стык)
Брони из корпоративного календаря — существующий API сервиса `calendar`, сервисный токен уже
выдан. Своего входа-стыка у этапа нет, он первый.

## Выход (стык) — контракт из спеки, дословно
- **Граница/направление:** FE → BE
- **Триггер:** открытие плана этажа, далее опрос раз в минуту
- **Контракт (запрос):** `GET /v1/rooms/occupancy`, параметр `floor: int` обязателен
- **Контракт (ответ):** `asOf: iso8601` — момент, на который снята сводка;
  `rooms: массив`, элемент — `roomId: string`, `state: free|busy`,
  `busyUntil: iso8601|null` — `null` всегда при `state = free`, у занятой комнаты заполнено
- **Пример ответа (успех):**
  ```json
  {
    "asOf": "2026-08-05T12:03:00Z",
    "rooms": [
      { "roomId": "7-01", "state": "busy", "busyUntil": "2026-08-05T15:30:00Z" },
      { "roomId": "7-02", "state": "free", "busyUntil": null }
    ]
  }
  ```
- **Ошибки:** `400` — этаж не передан или не число; `503` — календарь недоступен
- **Авторизация:** любой аутентифицированный сотрудник, отдельной роли не требуется

Сущность `RoomOccupancySnapshot`: `floor: int`, `asOf: timestamp`, `rooms: jsonb`, хранится не
дольше пяти минут.

## Проверка в одиночку
- Этаж, где нет ни одной брони → `rooms` заполнен, у всех `state = free`, `busyUntil = null`.
- Этаж с одной бронью до 15:30 → у этой комнаты `state = busy`, `busyUntil = 15:30`.
- Календарь отвечает ошибкой → ответ `503`, пустой сводки с `state = free` не отдаётся.
- Параметр `floor` не передан → ответ `400`.

## Из спеки — только относящееся к этому этапу
- **Трассировка:** FR-1 — комната с бронью приходит как `busy`; FR-2 — у `busy` заполнен `busyUntil`.
- **Авторизация:** эндпоинт доступен любому аутентифицированному сотруднику; к календарю ходим
  сервисным токеном, пользовательский контекст не передаётся.
- **НФТ:** сводка кэшируется пять минут; отсутствие данных и «все свободны» — разные состояния.

## Чего этот этап НЕ делает
Не рисует план этажа и не заводит фиче-флаг — это этап фронта. Не меняет существующие эндпоинты
плана этажа.
