# NB-BIG — большой ноут: выгрузка и выкладка со спорами и цепочками замен

Пробы `nb-big-export` и `nb-big-view`, скилл `analyst-notebook` 1.2.0 (карточка Н11 в `PLAN-LOOP-HARDEN.md`).

**Домен** — хостел: постоялец заселяется сам по коду, администратора на входе нет. Вместо «ресепшена» — «администратор на
входе»: основа «ресепш» есть в BR-DATA-NONE, BR-HALF, BR-NOCRIT, BR-VAR. Люди: Калинкина В. (управляющая), Туманов А.
(владелец), Подгорный С. (финансы), Шамрай З. (старшая горничная), Валиев Р. (сайт и PMS), Гусейнов Э. (поставщик замков).

**Засев** общий — `seed/notes/заселение-без-администратора/notebook.md`: 209 строк, 64 пункта, 16 дней
2026-09-21…2026-10-13, 24 записи — чаты, письма, созвоны со слов аналитика, мысли и наброски. Общие основы: «код» —
24 пункта, «брон» — 15, «зам(ок|к)» — 10, «заселен» — 6, «оплат» — 6. В ноуте: смена решения без слова «меняю»
(`вместо:`), принятый набросок (`вместо:`), открытый спор, отвеченный спор (`отвечает на:` + `вместо:`), три закрытых
вопроса (`отвечает на:`), три мысли, четыре наброска.

**Что ловит:**
- `nb-big-export` — «действующее» выгрузки (SKILL.md:251–255) на ноуте реального размера: вычеркнуть не тот пункт из
  записи, где два пункта начинаются одинаково; спор подать решённым; закрытый спор — открытым.
- `nb-big-view` — баг 2 (`PLAN-LOOP-HARDEN.md`, таблица 2.1): срез сборки не знает правила спора, оспоренное решение
  уходит в таблицу решённым. На текущей версии ждём красную, на исправленной — зелёную.
- Ожидания по багу 2 — по правке E9 (`runs/2026-10-16-harden-edits.md`): правило спора в обоих режимах и только без
  ответа, оспорен пункт о `<старое>`, соседи записи идут, ссылка элемента — концевая. Соседей спора на текущей версии
  выгрузка может выкинуть — там это предупреждение, на исправленной — красный.

**Ход:**
- `nb-big-export`: ход 1 — `/analyst-notebook заселение-без-администратора собери пункты`, вопросов не ждём, файл
  `notebook-<дата>.points.md`. Реплика «Да, давай.» — на случай вопроса.
- `nb-big-view`: ход 1 — `… собери таблицу решений по заселению` → план и «куда»; ход 2 — «Да, из всего ноута — всё,
  что решено. Файлом.» → проверка субагентом, файл `<…>-<дата>.md`.

Одна папка, два промпта — как NB-VIEW: `w-prompt-export.txt` + `w-turn2-export.txt`, `w-prompt-view.txt` +
`w-turn2-view.txt`. Критерии — `expected.md` (до первого прогона). Оценщика нет; ключи — на усмотрение владельца
(`grade-nb.mjs --fx BIG-EXPORT | BIG-VIEW`).
