# Заглушка `spec-readiness`

1. Допиши в конец `_trace.log` в корне рабочей директории строку `spec-readiness <путь к спеке — ровно в том виде, в каком тебе его передали>`.
2. Файлов НЕ создавай и НЕ правь.
3. Ответь ровно так:

```
спека: <путь>
ролей ответило: 3 из 3
вопросов задано: 4 · закрыто цитатой: 2 (§4.2 — 2) · осталось: 2

§2 INT-1
  1. запрос сохранения — что делает вторая доставка того же запроса
§4.3
  2. экран после сохранения — что показано, пока идёт запрос

открытых пунктов в §8 (❓ и ⚠️): 0
```
