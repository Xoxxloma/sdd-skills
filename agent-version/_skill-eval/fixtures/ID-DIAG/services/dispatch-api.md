# dispatch-api — backend

> Генерируется. Правки руками затираются.
> Заметки человека — в `services/manifest.yaml`, поле `notes`.
> Форма — `reference/card.template.md` скилла `service-map`. Соседние карточки формой не являются.

## Назначение

Бэкенд пульта централизованной охраны: диспетчер заводит инцидент по охраняемому объекту, назначает на него группу быстрого реагирования и закрывает по итогам выезда. Поддерживает регистрацию инцидента по сработке или звонку, назначение и снятие группы, закрытие с причиной. Главные объекты — инциденты и назначения групп.

## Что умеет для пользователя
| Возможность | Для кого |
|---|---|
| Завести инцидент по объекту | Диспетчер |
| Назначить группу на инцидент | Диспетчер |
| Закрыть инцидент с причиной | Диспетчер, старший смены |
| Посмотреть инциденты смены | Старший смены |

## Публичный контракт

### `GET /v1/crews`
Группы быстрого реагирования текущей смены.
сущности: → `Crew`
- только группы со статусом `on_shift`

### `GET /v1/incidents`
Список инцидентов смены.
сущности: → `Incident`
- фильтр `status`; без фильтра — только открытые
- диспетчер видит свои, старший смены — все

### `POST /v1/incidents`
Регистрация инцидента по объекту.
сущности: ← `objectId`, `reason` · → `Incident`
- `reason: alarm` \| `call` \| `scheduled`
- ошибки: `422` — объект не найден в справочнике

### `POST /v1/incidents/{id}/assign`
Назначение группы на инцидент.
сущности: ← `crewId` · → `Assignment`
- ошибки: `409` — инцидент уже закрыт

### `POST /v1/incidents/{id}/close`
Закрытие инцидента с причиной.
сущности: → `Incident`
- ошибки: `409` — инцидент уже закрыт, повтор безопасен

## События

### публикует `incident.created`
Инцидент зарегистрирован.
- `incidentId: string`, `objectId: string`, `reason: string`, `createdAt: iso8601`
- ключ партиции — `objectId`
- шлётся после коммита транзакции: при ретрае возможен дубль

## Фоновые задачи

### `autoCloseStale`
Закрывает инциденты без движения дольше суток.
- расписание `0 6 * * *`
- закрытым ставит причину `stale`; событий не публикует

## Владеет данными

### `Assignment`
Назначение группы на инцидент.
- `id`: `string`
- `incidentId`: `string`
- `crewId`: `string`
- `assignedAt`: `iso8601`

### `Crew`
Группы быстрого реагирования и их выход на смену.
- `id`: `string`
- `callsign`: `string`
- `status`: `on_shift` \| `off_shift`
- `tabletId`: `string?` — планшет группы; `null` у групп без планшета
— `on_shift` ставит старший смены при выходе группы, автоматически не меняется

### `Incident`
Инциденты по охраняемым объектам.
- `id`: `string`
- `objectId`: `string`
- `reason`: `alarm` \| `call` \| `scheduled`
- `status`: `open` \| `assigned` \| `closed`
- `createdBy`: `string`
- `createdAt`: `iso8601`
— `assigned` ставится при первом назначении группы, при снятии группы обратно в `open` не возвращается
