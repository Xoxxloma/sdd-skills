# dispatch-web — frontend

> Генерируется. Правки руками затираются.
> Заметки человека — в `services/manifest.yaml`, поле `notes`.
> Форма — `reference/card.template.md` скилла `service-map`. Соседние карточки формой не являются.

## Назначение

Пульт диспетчера централизованной охраны. Диспетчер регистрирует инцидент по сработке или звонку, назначает группу и закрывает инцидент; старший смены смотрит сводку по смене. Главные объекты — инциденты и назначения групп.

## Что умеет для пользователя
| Возможность | Для кого |
|---|---|
| Завести инцидент по объекту | Диспетчер |
| Назначить группу на инцидент | Диспетчер |
| Закрыть инцидент | Диспетчер, старший смены |
| Посмотреть сводку по смене | Старший смены |

## Стек
| Слой | Чем |

## Экраны
| Роут | Экран | Что делает пользователь |
|---|---|---|
| `/incidents` | Инциденты смены | фильтрует по статусу, открывает карточку |
| `/incidents/:id` | Карточка инцидента | назначает группу, закрывает инцидент |
| `/shift` | Сводка смены | смотрит открытые инциденты по диспетчерам |

## Потребляемые API
| Сервис | Вызов | Зачем |
|---|---|---|
| `dispatch-api` | `GET /v1/crews` | список групп смены при назначении |
| `dispatch-api` | `GET /v1/incidents` | список инцидентов смены |
| `dispatch-api` | `POST /v1/incidents` | регистрация инцидента |
| `dispatch-api` | `POST /v1/incidents/{id}/assign` | назначение группы |
| `dispatch-api` | `POST /v1/incidents/{id}/close` | закрытие инцидента |

## Состояние и данные
| Что хранится | Где | Зачем |
|---|---|---|
| выбранный фильтр статуса | store в памяти | переживает переход между экранами |
| текущая смена и роль | store в памяти, из токена | ветвление экранов по роли |
