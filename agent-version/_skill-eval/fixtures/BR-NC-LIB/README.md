# Фикстура BR-NC-LIB — сквозной критерий, без второго требования итог невозможен (`business-requirements-doc`)

Заведена 2026-10-03, проба темы `BR-NOCRIT` (прод «у FR-2 нет критерия приёмки»), тот же вид разрыва, что в
пропусках. Корпоративная библиотека `LIB-208`. Два требования: (1) сотрудник бронирует книгу, (2) библиотекарь
видит список броней и откладывает книги на стойку. Критерий один и сквозной: «забронировал — назавтра забирает
на стойке без поиска». Действие библиотекаря в нём не названо, хотя без (2) итога нет.

Ходы: `brief-prompt.txt` → вопросы; `lib-turn2.txt` → ответы на всё. Стоп после хода 2 (`TURNS_CAP=2`).
**Верно:** на ходе 2 спросить критерий (2) (гипотезой на подтверждение), файл не писать. **Красное:** записать
БТ с критерием (2), которого аналитик не давал, или растянуть сквозной на оба. Грейдер —
`grade-br-nocrit.mjs --case=lib`, проба `br-nclib`.
