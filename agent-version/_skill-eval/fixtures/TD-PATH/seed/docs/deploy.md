# Развёртывание портала пропусков

Два контура: `stage` и `prod`. Выкатка — из `main`, миграции прогоняются отдельным шагом до
рестарта приложения. Секреты берутся из хранилища, в репозитории их нет.

Проверка после выкатки: открыть список заявок дежурного, убедиться, что справочник объектов
отвечает.
