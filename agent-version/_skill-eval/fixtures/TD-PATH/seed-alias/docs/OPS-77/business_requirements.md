# Бизнес-требования: печать адреса отделения на квитанции

> **Статус готовности:** Готово к оценке
> **Задача:** OPS-77

## 1.1. Описание проблемы (Problem Statement)
На квитанции печатается только номер отделения. Клиент, которому нужно вернуться с документами,
ищет адрес по номеру сам.

## 1.2. Конечные потребители (End Users)
Клиент отделения. Сотрудник, который объясняет клиенту, куда прийти.

## 2.1. Бизнес-цель
Я как клиент хочу видеть адрес отделения прямо на квитанции, чтобы не искать его отдельно.

## 4.1. Описание функционала / бизнес-процесса
- **FR-1.** На квитанции печатается адрес отделения под его номером.

## 4.2. Критерии приёмки (Acceptance Criteria)
- **[FR-1]** Дано: квитанция формируется в отделении. Когда: она печатается. Тогда: под номером
  отделения стоит его адрес одной строкой.

## 4.5. Разбиение на слайсы
Не применимо: один деливербл.

## Открытые вопросы
Не осталось.
