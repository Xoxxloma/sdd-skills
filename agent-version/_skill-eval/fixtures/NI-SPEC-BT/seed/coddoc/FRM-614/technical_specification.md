# Спецификация: заказ лекарств на самовывоз из аптеки

> Задача: FRM-614 · БТ: coddoc/FRM-614/business_requirements.md
> Статус: черновик

## 1. Состав
- Приложение сети аптек — оформление заказа и «Мои заказы».
- Сервис заказов — новый: заказы и их статусы.
- Рабочее место провизора — сборка и выдача заказов.
- Система остатков аптек — уже работает: наличие препаратов по аптекам.

## 2. Оформление
2.1. Приложение передаёт заказ в сервис заказов: аптека, препараты, количество.
2.2. Сервис заказов сохраняет заказ со статусом «Собирается» и показывает его в рабочем месте
провизора этой аптеки.

## 3. Сборка и выдача
3.1. Провизор отмечает заказ собранным в рабочем месте провизора; сервис заказов ставит статус
«Готов к выдаче», клиент получает пуш «заказ собран».
3.2. При выдаче провизор вводит номер заказа и отмечает заказ выданным.

## 4. Снятие по сроку
4.1. Фоновая задача раз в час находит заказы, у которых истёк срок ожидания, ставит им статус
«Снят», возвращает препараты в наличие, клиент получает пуш «заказ снят: истёк срок».

## 5. Открытые вопросы
1. Откуда сервис заказов берёт наличие препарата при оформлении.
2. Что делает сервис заказов, если система остатков не ответила.
