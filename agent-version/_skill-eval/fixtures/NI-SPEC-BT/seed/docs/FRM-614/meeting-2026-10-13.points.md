# Пункты: заказ лекарств на самовывоз из аптеки
> Источник: docs/FRM-614/meeting-2026-10-13.recall.md
> Задача: FRM-614
> Встреча: 2026-10-13 11:00–11:45 · участники: директор по аптечной рознице (заказчик) — Гладких Таисия; архитектор — Шумейко Роман; бэкенд-разработчик — Бобылёв Кирилл; старший провизор — Веретенникова Лидия; аналитик — Ярцева Ольга · по памяти аналитика

- [мысль] А может, снимать заказ ровно тогда, когда истёк срок, своим таймером на каждый заказ, а не задачей раз в 10 минут? · L29
- [решено] Три дня, которые заказ ждёт клиента в аптеке, считаем с момента, когда клиенту пришло сообщение «заказ собран» — решил: Гладких Таисия · L41
- [решено] Препарат, которого нет в выбранной аптеке, тоже можно заказать: аптека получает его из распределительного центра за 1–2 дня, клиент видит дату, когда заказ будет готов — решил: Гладких Таисия · L42
- [решено] Повторный запрос клиента на тот же препарат в той же аптеке в тот же день отклоняем, клиент видит причину: «у вас уже есть заказ на этот препарат» — решил: Гладких Таисия · L43
- [решено] Больше пяти заказов в день одному клиенту не принимаем: на шестой запрос клиент видит «на сегодня лимит заказов исчерпан» — решил: Гладких Таисия · L44
- [решено] Наличие препарата в аптеке сервис заказов берёт из системы остатков аптек запросом в момент оформления, без кэша — решил: Шумейко Роман · L46
- [решено] Система остатков не ответила — сервис заказов повторяет запрос до трёх раз с паузой 2 секунды — решил: Бобылёв Кирилл · L47
- [решено] Пуш «заказ собран» отправляет сервис уведомлений сети по событию сервиса заказов через шину — решил: Шумейко Роман · L48
- [решено] Просроченные заказы снимает фоновая задача раз в 10 минут — решил: Бобылёв Кирилл · L49
- [открыто] Списывать препарат под заказ в системе остатков синхронно, при оформлении, или фоном, после ответа клиенту — ждёт: Шумейко Роман · L52
- [сведение] Система остатков аптек в вечерний пик, с 18 до 20, отвечает до 5 секунд — со слов Бобылёва Кирилла · L55
