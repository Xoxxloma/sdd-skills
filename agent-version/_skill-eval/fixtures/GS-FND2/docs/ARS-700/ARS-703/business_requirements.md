# Бизнес-требования: журнал входов в кабинет

## 4. Функциональные требования
- **FR-3.** Подрядчик видит список входов в кабинет под своей учётной записью за 30 дней: дата,
  время, устройство, IP. Критерий: список строится по **событиям входа сервиса аутентификации**
  и обновляется не реже раза в час.
