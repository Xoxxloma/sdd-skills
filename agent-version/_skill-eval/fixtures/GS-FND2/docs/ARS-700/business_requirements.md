# Бизнес-требования: личный кабинет подрядчика

## 4. Функциональные требования
- **FR-1.** Подрядчик видит свои действующие допуски на объекты.
- **FR-2.** Подрядчик подаёт заявку на продление допуска.
- **FR-3.** Подрядчик видит журнал входов в кабинет со своей учётной записи.

### 4.3. Бизнес-данные

| № | Объект | Что это | В системе |
|---|---|---|---|
| 1 | Допуск подрядчика | допуск на объект: объект, срок действия, статус | уже есть — справочник допусков подрядчиков |
| 2 | Заявка на продление допуска | заявка подрядчика по допуску, её статус виден подрядчику | новая |
| 3 | Событие входа в кабинет | вход под учётной записью подрядчика: дата, время, устройство, IP | уже есть — сервис аутентификации |

### 4.5. Разбиение на слайсы
| Слайс | FR | Ценность |
|---|---|---|
| Мои допуски | FR-1 | подрядчик видит состояние сам |
| Заявка на продление | FR-2 | продление без писем |
| Журнал входов в кабинет | FR-3 | подрядчик видит, кто заходил под его учёткой |

## Статус готовности
Готово к оценке
