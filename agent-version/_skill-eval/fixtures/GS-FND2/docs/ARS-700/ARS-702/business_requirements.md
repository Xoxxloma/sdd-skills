# Бизнес-требования: заявка на продление допуска

## 4. Функциональные требования
- **FR-2.** Подрядчик подаёт заявку на продление из карточки допуска. Критерий: заявка создаётся
  по допуску, взятому из **справочника допусков подрядчиков**, её статус виден подрядчику.
