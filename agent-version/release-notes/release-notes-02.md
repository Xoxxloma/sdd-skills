# Release notes: набор 5.36 → 5.81 (06.10 — 26.10.2026)

## Сквозное: папка `coddoc/`, «Автор» в шапке (5.40, 5.71, 5.80)

- Папка задач — `coddoc/` вместо `docs/`, во всех 17 скиллах. Старую `docs/` скиллы не читают и не переносят.
- В шапке БТ, баг-репорта, запроса на правку и спеки — строка «Автор»: логин из `whoami`. При доработке логин
  дописывается в список; у детского БТ — автор эпика.
- README и TUTORIAL описывают метки спеки по-новому: 🔵 с источником, три вида карточки взаимодействия.

## `deep-search` — новый скилл, 1.0.0 → 1.2.1 (5.72, 5.73, 5.76, 5.81)

- Отвечает, как система работает сейчас, по коду соседних реп: карточка → манифест → код. Каждая ссылка на код
  сверяется; файлов скилл не пишет.
- Из интервью спеки (1.1.0): у вопроса-допущения о сервисе с кодом рядом — вариант «Глубокий поиск». По вердикту
  «подтверждается / в коде иначе / не нашёл» — вопрос «Беру?».
- После «беру» (1.2.0) в спеку идут метод, путь и поля под 🔵 «по коду»; файлы и имена классов — нет.

## `to-html` — новый скилл, 1.0.0 → 1.0.3 (5.68–5.71)

- Markdown в браузере: один файл, папка или пустая страница под перетаскивание. Дерево, оглавление, поиск Ctrl+K,
  схемы Mermaid, ссылки на пункты ноута.
- Экспорт папки или документа одним html, копирование для Confluence и Word.
- Без сети и npm; на Windows работает в ограниченном PowerShell.
- На Linux браузер открывается стабильно, хранятся 10 последних наборов, «развернуть» у схемы и таблицы — на весь
  экран.

## Петля дискавери — четыре новых скилла (5.44–5.67)

Цепочка: встреча → список пунктов `*.points.md` → ноут → вход для БТ или спеки.

### `meeting-intake` 1.0.0 → 2.1.0 (5.44–5.50, 5.71)
- Расшифровка встречи → вход для БТ или спеки. С 2.0.0 — список пунктов и разбор с цитатами.
- Задача встречи спрашивается гипотезой («Встреча про: …?»); сказанное не про задачу помечается «другое», решает
  аналитик.
- Цитаты сверяются дословно; замена — только строкой из пяти строк своей цитаты.
- Решивший не выдумывается: говорящих нет — `[открыто] кто принял: …`.
- То, что во вход не пойдёт («вне документов», «уже записано»), в сводке показано списком.
- «В ноут» — созвон одной записью в ноут, разбор рядом.

### `meeting-recall` 1.0.0 → 1.3.0 (5.49, 5.50, 5.63–5.67, 5.71)
- Протокол встречи по памяти аналитика, когда расшифровки нет; на выходе — тот же список пунктов.
- О встрече утверждает только аналитик: догадок нет ни в вариантах ответа, ни в тексте вопроса.
- По теме — до трёх вопросов от сказанного, самый важный первым, вместо анкеты из семи.
- Окно с вариантами — после текста, отдельным ходом. У «предложил» — варианты, возражения, оговорки.
- Ссылка на созвон в шапку протокола не попадает.

### `analyst-notebook` 1.1.0 → 2.6.0 (5.49, 5.50, 5.53, 5.55–5.62, 5.71)
- Ноут на дискавери: `notes/<тема>/notebook.md`, записи по дням. Виды пунктов: решено (только с «решил:»), открыто,
  сведение, мысль.
- Сверка с прошлым: уточнение, передумал, ответ на открытый; спор разных людей — вопросом.
- `собери <что>` — выкладка любой формы со ссылкой у каждого элемента; `спроси <вопрос>` — ответ по ноуту без записи.
- 2.0.0: у каждого пункта номер, у старой строки пометка `‖ заменён / закрыт / оспорен` — статус со временем не врёт.
- Исправление записи — новой записью; прошлое не правится.
- Роли участников в шапке; что новее — по дате события, а не записи.
- Список встречи без находок пишется без второго «Записать так?».

### `notes-to-intent` 1.0.0 → 1.2.0 (5.50, 5.55, 5.57, 5.59, 5.60, 5.71)
- Список пунктов → вход для БТ или спеки: раскладка по слоям, сверка с документом.
- Во входе спеки решение, которое меняет БТ или противоречит ему, — в «Расходится с БТ» после вопроса аналитику.
- Роли — из шапки списка; мысли аналитика во вход не идут.

- Приёмке тех-спеки передаётся путь к документу-источнику — БТ, баг-репорту или запросу на правку.

## `technical-spec-doc` 1.3.2 → 1.7.0

### 1.3.2 → 1.4.1 — «Не применимо» по одному правилу (5.36, 5.40, 5.41)
- Шаблон, багфикс и мелкая правка решают одинаково: нет работы и проверки → «Не применимо: причина»; нужна проверка
  → ответ; сведений нет → вопрос, после отложения TBD.
- «Флагов нет» больше не означает «релизим атомарно».
- §8 багфикса и правки берёт пробелы из баг-репорта или запроса.
- В шапке «Автор».

### 1.4.1 → 1.6.0 — глубокий поиск из интервью (5.71, 5.73)
- У вопроса о существующем сервисе с кодом рядом — вариант «Глубокий поиск». Подтверждённое идёт под 🔵 «по коду
  <сервис>, ветка».

### 1.6.0 → 1.7.0 — источник у 🔵 и «изменение существующего» (5.76)
- Источник 🔵 — в метке: по карточке, по коду, по документу сверху, со слов.
- Путь, метод и поля под 🔵 — только из источника; неполный источник — JSON с подписью «фрагмент». Под 🟡 — словами,
  без пути.
- Новый вид карточки «изменение существующего»: строка «Существующий стык», таблица «поле | где | было | стало».
- Багфикс: изменение контракта — этим видом. Мелкая правка: своё — изменение, чужое — потребление.
