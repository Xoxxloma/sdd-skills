# Release notes: набор 5.82 (30.10.2026)

## Сквозное: редакция, дата и версия скилла в шапке (5.82)

- В шапке БТ, баг-репорта, запроса на правку и спеки — две служебные строки: `Редакция: N (ГГГГ-ММ-ДД)` и
  `Версия скилла: <скилл> <версия>`. У спеки «Редакция» была и раньше, теперь дата в ней обязательна.
- Первая запись — редакция 1, каждая доработка +1. В старом документе строки появятся при первой доработке,
  сразу с номером 2. Специально переносить старые документы не нужно.
- В строке версии только скилл, который пишет документ. Доработка на новой версии дописывает её через запятую,
  поэтому видно, на чём документ создан и на чём доработан.
- Детский БТ: редакция 1 с датой нарезки и версия `task-decomposition-doc`.
- Ручная правка файла эти строки не меняет: они показывают последнюю правку скиллом.

`business-requirements-doc` 1.6.0, `bug-report-doc` 1.3.0, `change-request-doc` 1.4.0, `technical-spec-doc` 1.8.0,
`task-decomposition-doc` 1.2.1.
