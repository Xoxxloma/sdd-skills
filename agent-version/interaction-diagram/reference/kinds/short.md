# Короткая схема: кто кого вызывает, по времени

Короткая — все пункты одной диаграммой: участники и по стрелке на звено, по времени. Как пункт
становится звеньями и подписями — файл входа; строки и скелет — файл формата. Здесь — что на схеме,
порядок, вопрос о нём, шапка, самопроверка и отчёт.

## Что на схеме

Участники и звенья всех пунктов, подпись — по файлу входа. Ответов, пометок и отдельного участника
«Пользователь» нет; человек, названный стороной пункта, — обычный участник. Пункты
идут в порядке из ответа аналитика, без ответа — по номерам; звенья одной цепочки — подряд.

## Вопросы

| Вопрос | Условие | Что спрашиваешь |
|---|---|---|
| порядок | пунктов больше одного | «По времени <пункты> идут в том же порядке, что в списке? Если нет — назовите номера по времени; кого не назовёте, поставлю в конец» |

Порядок назван не для всех пунктов → неназванные идут после названных, по номерам.

## Без ответа

| Вопрос без ответа | Что делаешь |
|---|---|
| порядок | пункты идут по номерам |

## Шапка

`<порядок>` — «по времени, со слов аналитика», если аналитик ответил на вопрос о порядке; иначе «по
номерам <пунктов>, не по времени».

## Самопроверка — перечитай записанный файл

1. id на стрелках = id пунктов источника, минус пункты без стрелок. Стрелок с одним id — столько,
   сколько звеньев у пункта; ни одной лишней.
2. Вид и направление каждой стрелки = строка таблицы «Строки» файла формата для её звена.
3. Имя каждого участника — сторона пункта, как её читает файл входа.
4. После `<id> ·` — ровно токен подписи звена по файлу входа; звену без токена — подпись только `<id>`.
5. Пункты идут в порядке из ответа аналитика, без ответа — по номерам; `<порядок>` в шапке говорит то же.
6. Где аналитик ответил, проверки 1–5 сверяй с его ответом, а не с источником; где не ответил — с
   таблицами «Без ответа».

## Отчёт

Строки `SKILL.md` Step 5 как есть. «Порядок» — «по времени, со слов аналитика» или «по номерам
<пунктов>, не по времени»; пункты, которые аналитик в порядке не назвал, перечисли здесь же: «в конце по
номерам: <id>».
