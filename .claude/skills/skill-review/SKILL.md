# Ревью скилла

Два субагента читают скилл независимо, с одним и тем же промптом. Ты (ведущий) собираешь их находки, сверяешь
каждую с текстом и отдаёшь отчёт. Скилл не правишь, своих находок не добавляешь.

## Шаг 1. Что ревьюим

- **Скилл.** По имени найди `**/<имя>/SKILL.md`. Нашлось несколько (рабочая версия и замороженная копия) —
  спроси гипотезой: «беру `<путь>` — в нём незакоммиченные правки?». Ревьюится вся папка: `SKILL.md`,
  `reference/`, шаблоны, скрипты.
- **Режим.** «Ревью правки», «проверь правку», «что я поменял» — только изменения в папке скилла. Изменений
  нет — скажи и спроси, ревьюить ли всю папку. Иначе — вся папка.
- **Папка проб.** В папке скилла и в каждой родительской до корня репо ищи подпапку `_skill-eval/fixtures/`,
  `evals/` или `fixtures/`; передай все найденные. Нет ни одной — завязку на пробы субагенты ищут только по
  признакам в самом тексте.

## Шаг 2. Два субагента

Одним сообщением запусти два субагента `general-purpose` с одинаковым промптом — подставь путь, режим и папку
проб. Промпт одинаковый, чтобы расхождение между ними говорило о тексте скилла, а не о разнице заданий.

```
Ты ревьюишь скилл для LLM-агента. Исполнитель скилла — модель уровня Sonnet, читает текст буквально.
Только чтение: ничего не правь, файлов не создавай.

Скилл: <путь к папке>. Прочитай целиком все файлы папки.
Режим: <вся папка | правка>. При правке возьми `git diff -- <папка>` и новые файлы из
`git status --porcelain -- <папка>`; находки — только по изменённым строкам, но противоречие
новой строки со старым текстом — находка.
Папки проб: <пути | нет>.

Ищи три вида дефектов, только их.

1. Критический баг — исполнитель сделает не то:
   - двусмысленность: фразу можно прочитать двумя способами, и прочтения ведут к разным действиям
     или разному результату. Неуклюжая, но однозначная фраза — не находка;
   - противоречие: два места велят разное в одной ситуации, и не сказано, что главнее. Ищи и между
     файлами (SKILL.md, reference/, шаблоны, скрипты);
   - битая ссылка: упомянут файл, раздел, шаг, поле или метка, которых нет, или номер шага указывает
     не туда. Проверяй Glob/Grep, не по памяти.
2. Заплаточность:
   - правило под один случай: закрытый перечень конкретных слов, фраз, значений вместо признака;
     исключение, понятное только тому, кто видел этот случай. Примеры после названного признака —
     не заплатка;
   - история и оправдание: «раньше…», «так уже терялось», «после правки», «в прошлой версии».
     Причина в настоящем времени («иначе X теряется») — норма;
   - дубль: правило, уже сказанное в другом месте другими словами.
3. Завязка на пробы:
   - имена, ключи задач, названия систем, цитаты, даты, доменные детали из папки проб — каждый
     характерный токен из примеров скилла проверь Grep по папкам проб;
   - счёт и следы проверки скилла: «2 из 5», номера прогонов и раундов, слова «проба», «замер»,
     «прогон», «стенд» в этом смысле;
   - примеры одного домена или одного стека, поданные как образец.

Не репортить: стиль, длину, порядок разделов, «можно лучше», недостающие возможности.

Ответ — список находок, по каждой:
- вид (1 баг / 2 заплатка / 3 пробы) и подвид;
- файл:строка;
- цитата дословно;
- почему: какие два прочтения / что с чем противоречит / какой случай латает / где в пробах (файл:строка);
- правка в 1–2 строки или «удалить».
Нет находок — «Находок нет». Без вступлений и итогов.
```

## Шаг 3. Сведение и сверка

1. Объедини: одно место — одна находка, в разделе самого тяжёлого вида (баг → заплатка → пробы), другие
   виды — в «Почему»; пометь «оба» или «один».
2. Сверь каждую сам, независимо от пометки:
   - цитата — `Grep -n` по куску цитаты; номер строки не тот — исправь; цитаты нет — отбрось;
   - суть — у двусмысленности правда два прочтения с разными действиями; противоречащие правила правда
     про одну ситуацию; битой ссылки правда нет; токен правда есть в папках проб.
3. Не подтвердилось — в «Отброшено», одной строкой.

## Шаг 4. Отчёт

```
## Ревью <скилл> — <вся папка | правка>

### Критические баги
1. `файл:строка` — «цитата»
   Почему: … Правка: … (оба)

### Заплаточность
…

### Завязка на пробы
…

Отброшено при сверке: N — <почему, коротко>.
```

Пустой раздел — «нет». Сверх шаблона ничего: ни вступления, ни итога. Правки в скилл — только по просьбе
пользователя. Новую волну ревью не предлагай.
