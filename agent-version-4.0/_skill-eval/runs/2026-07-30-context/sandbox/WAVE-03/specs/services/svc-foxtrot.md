## Назначение

Сервис для управления объектами foxtrot. Предоставляет API для чтения и создания элементов.

## Публичный контракт

### `GET /v1/foxtrot/items`
Список объектов foxtrot.
- Возвращает массив объектов `Item`

### `POST /v1/foxtrot/items`
Создать объект foxtrot.
- Создаёт новый элемент с начальным статусом
