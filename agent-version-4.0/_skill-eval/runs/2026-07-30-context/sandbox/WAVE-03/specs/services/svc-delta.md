## Публичный контракт

### `GET /v1/delta/items`
Список всех объектов delta.
- `items: Item[]` — массив объектов
- `Item.ID: string` — уникальный идентификатор
- `Item.Status: "active" | "archived"` — статус объекта; `active` означает текущее состояние, `archived` — заархивированное

### `POST /v1/delta/items`
Создание нового объекта delta.
- возвращает созданный Item с ID и статусом `active`

### `GET /healthz`
Проверка живости сервиса.
