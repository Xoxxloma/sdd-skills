# svc-alpha — backend

> Генерируется. Правки руками затираются.

## Назначение

Сервис alpha управляет объектами с возможностью отслеживания статуса жизненного цикла (активные и архивированные).

## Что умеет для пользователя
| Возможность | Для кого |
|---|---|
| Получить список всех объектов alpha | конечный пользователь |
| Создать новый объект alpha | конечный пользователь |

## Публичный контракт

### `GET /v1/alpha/items`
Список объектов alpha.
- `ID: string` — идентификатор объекта
- `Status: string` — `active` \| `archived`

### `POST /v1/alpha/items`
Создать новый объект alpha.
- ошибки: не определено

### `GET /healthz`
Проверка живости сервиса.
