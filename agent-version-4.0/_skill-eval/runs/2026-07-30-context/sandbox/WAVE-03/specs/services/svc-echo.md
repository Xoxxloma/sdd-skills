## Назначение

Сервис для обработки объектов echo. Предоставляет возможность получения списка объектов и создания новых объектов.

## Публичный контракт

### `GET /v1/echo/items`
Получение списка объектов echo.
- `items: []Item` — список активных и архивированных объектов

### `POST /v1/echo/items`
Создание нового объекта echo.
- `id: string` — идентификатор объекта
- `status: active | archived` — статус объекта при создании

### `GET /healthz`
Проверка живости сервиса.
