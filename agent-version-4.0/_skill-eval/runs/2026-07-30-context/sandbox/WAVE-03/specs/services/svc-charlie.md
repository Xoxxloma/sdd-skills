## Назначение

Сервис управления объектами charlie. Предоставляет API для отображения и создания объектов с отслеживанием состояния.

## Публичный контракт

### `GET /v1/charlie/items`
Список всех объектов charlie.
- возвращает массив объектов Item с полями ID и Status

### `POST /v1/charlie/items`
Создание нового объекта charlie.
- входных параметров не определено из кода

### `GET /healthz`
Проверка живости сервиса.
