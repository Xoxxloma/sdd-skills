Управление объектами alpha в системе. Предоставляет API для просмотра и создания объектов.

## Публичный контракт

### `GET /v1/alpha/items`

Список объектов alpha.
- `items: Item[]` — массив объектов
- `Item.ID: string` — уникальный идентификатор
- `Item.Status: active | archived` — статус объекта

### `POST /v1/alpha/items`

Создание объекта alpha.
- `Item.ID: string` — уникальный идентификатор
- `Item.Status: active | archived` — статус объекта

### `GET /healthz`

Проверка живости сервиса.
