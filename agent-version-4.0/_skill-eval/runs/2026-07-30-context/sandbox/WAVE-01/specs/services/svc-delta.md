# svc-delta — backend

> Генерируется. Правки руками затираются.

## Назначение

Управление объектами delta. Предоставляет API для создания и перечисления delta-элементов с отслеживанием их статуса.

## Что умеет для пользователя

| Возможность | Для кого |
|---|---|
| Получить список всех delta-объектов | Потребитель API |
| Создать новый delta-объект | Потребитель API |

## Стек

| Слой | Чем |
|---|---|
| Язык и фреймворк | Go, chi |

## Публичный контракт

### `GET /v1/delta/items`

Список объектов delta.
- Возвращает все доступные Item в системе

### `POST /v1/delta/items`

Создать объект delta.
- Создаёт новый Item с уникальным идентификатором

## Владеет данными

### `Item`

Delta-объект с отслеживанием жизненного цикла.
- `ID: string` — уникальный идентификатор объекта
- `Status: string` — `active` \| `archived` — состояние жизненного цикла объекта
