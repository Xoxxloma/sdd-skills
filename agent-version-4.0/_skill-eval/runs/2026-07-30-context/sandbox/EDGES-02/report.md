# Отчёт о сборке обратных рёбер

## Итог

Шаг 5 завершён. Обратные рёбра собраны для всех сервисов в манифесте.

## Рёбра и зеркала

Из исходящих рёбер (секции «Зависит от» и «Потребляемые API»):

**От `incident-api`:**
- auth: проверка сессии диспетчера → зеркало `incident-api | — | проверка сессии диспетчера` в auth ✓
- geo: район по адресу инцидента → зеркало `incident-api | — | район по адресу инцидента` в geo ✓

**От `geo`:**
- auth: проверка блокировки пользователя → зеркало `geo | — | проверка блокировки пользователя` в auth ✓
- auth: получение роли для фильтрации районов → зеркало `geo | — | получение роли для фильтрации районов` в auth ✓

**От `incident-web`:**
- auth: GET /v1/sessions/count → зеркало `incident-web | GET /v1/sessions/count | плашка активных сессий в шапке` в auth ✓
- geo: GET /v1/districts → зеркало `incident-web | GET /v1/districts | выпадающий список районов` в geo ✓
- incident-api: GET /v1/incidents → зеркало `incident-web | GET /v1/incidents | список инцидентов` в incident-api ✓
- API-шлюз: POST /gw/audit → **пропущено** (внешняя система, карточки нет)

**От `auth` и `incident-web`:** нет исходящих рёбер в «Зависит от»

## Карточки вне манифеста

Найдена карточка `services/legacy-reports.md` без соответствующей строки в `services/manifest.yaml`. Согласно инструкции (Шаг 5, п. 1), эта карточка не участвует в сборке рёбер. Её рёбра не зеркалились:
- legacy-reports → auth: проверка сессии — **не зеркалилось** (legacy-reports вне манифеста)

## Проверка симметрии

Все входящие рёбра в секциях «Кто меня потребляет» имеют парные исходящие рёбра в других карточках:

| Сервис | Входящие рёбра | Парные исходящие |
|---|---|---|
| `auth` | incident-api, geo (×2), incident-web | ✓ все есть |
| `geo` | incident-api, incident-web | ✓ все есть |
| `incident-api` | incident-web | ✓ есть |
| `incident-web` | — | (никто из манифеста не вызывает) |
