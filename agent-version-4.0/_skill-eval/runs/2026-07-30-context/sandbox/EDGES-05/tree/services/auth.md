## Заметки команды

Канонический владелец сессий.
Легаси-эндпоинт /v1/session не использовать: оставлен для старого мобильного клиента.

## Назначение

Аутентификация пользователей и учёт активных сессий.

## Что умеет для пользователя
| Возможность | Для кого |
|---|---|
| Посмотреть число активных сессий | Аналитик безопасности |
| Отозвать сессию вручную | Администратор |

## Стек
| Слой | Чем |
|---|---|
| Язык и фреймворк | Go, chi |
| Хранилище | PostgreSQL |

## Публичный контракт

### `GET /v1/sessions/count`
Счётчик активных сессий пользователя.
- `count: int` — только неистёкшие

### `POST /v1/sessions/revoke`
Отзыв сессии. Идемпотентен по `sessionId`.

## События
| Направление | Топик | Когда |
|---|---|---|
| публикует | `auth.session.revoked` | сессия отозвана |

## Владеет данными

### `Session`
Активные сессии; единственный источник правды.
