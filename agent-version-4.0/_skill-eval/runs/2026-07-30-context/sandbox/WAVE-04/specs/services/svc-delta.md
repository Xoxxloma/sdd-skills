# svc-delta — backend

> Генерируется. Правки руками затираются.
> Заметки человека — в `services/manifest.yaml`, поле `notes`.
> Форма — `reference/card.template.md` скилла `service-map`. Соседние карточки формой не являются.

## Назначение

Сервис управления объектами delta. Предоставляет операции для просмотра и создания элементов, обеспечивает отслеживание активности через поле статуса.

## Что умеет для пользователя

| Возможность | Для кого |
|---|---|
| Получить список объектов delta | потребитель API |
| Создать новый объект delta | потребитель API |

### `GET /v1/delta/items`

### `POST /v1/delta/items`
Создать объект delta.
