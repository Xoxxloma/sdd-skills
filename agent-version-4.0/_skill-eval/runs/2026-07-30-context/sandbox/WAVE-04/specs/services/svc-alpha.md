# svc-alpha — backend

> Генерируется. Правки руками затираются.

## Назначение

Управление объектами alpha в системе. Предоставляет API для создания и чтения объектов, а также проверку живости сервиса.

## Что умеет для пользователя

| Возможность | Для кого |
|---|---|
| Получить список объектов alpha | любой потребитель API |
| Создать новый объект alpha | любой потребитель API |
| Проверить живость сервиса | система мониторинга |

## Публичный контракт

### `GET /v1/alpha/items`
Список объектов alpha.

### `POST /v1/alpha/items`
Создать объект alpha.

### `GET /healthz`
Проверка живости сервиса.
