## Назначение

Управление объектами bravo; владеет сущностью Item и предоставляет API для их создания и получения списка.

## Публичный контракт

### `GET /v1/bravo/items`
Получение списка объектов bravo.
- возвращает список Item с их ID и статусом

### `POST /v1/bravo/items`
Создание нового объекта bravo.
- создаёт новый Item в системе

### `GET /healthz`
Проверка живости сервиса.
