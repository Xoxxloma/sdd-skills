## Назначение

Сервис управления объектами alpha. Отвечает за создание и получение списка объектов с возможностью отслеживания их состояния.

|---|---|
| Получить список всех объектов alpha | Любой потребитель |
| Создать новый объект alpha | Любой потребитель |
