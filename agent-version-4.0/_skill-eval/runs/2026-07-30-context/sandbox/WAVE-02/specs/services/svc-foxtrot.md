## Назначение

Управляет объектами foxtrot (items). Предоставляет API для создания и чтения списка объектов, каждый из которых имеет статус активности.

|---|---|
| Получить список объектов foxtrot | любой потребитель API |
| Создать объект foxtrot | любой потребитель API |
