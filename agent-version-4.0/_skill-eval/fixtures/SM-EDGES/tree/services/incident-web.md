# incident-web — frontend

> Генерируется. Правки руками затираются.
> Заметки человека — в `services/manifest.yaml`, поле `notes`.
> Форма — `reference/card.template.md` скилла `service-map`. Соседние карточки формой не являются.

## Назначение

Рабочее место диспетчера: список инцидентов и карточка инцидента.

## Что умеет для пользователя
| Возможность | Для кого |
|---|---|
| Отфильтровать инциденты по статусу | Диспетчер |

## Стек
| Слой | Чем |
|---|---|
| Язык и фреймворк | TypeScript, React |

## Экраны
| Роут | Экран | Что делает пользователь |
|---|---|---|
| `/incidents` | Список инцидентов | фильтрует и открывает карточку |

## Потребляемые API
| Сервис | Вызов | Зачем |
|---|---|---|
| `auth` | `GET /v1/sessions/count` | плашка активных сессий в шапке |
| `geo` | `GET /v1/districts` | выпадающий список районов |
| `incident-api` | `GET /v1/incidents` | список инцидентов |
| `API-шлюз` | `POST /gw/audit` | вне манифеста, карточки нет |
